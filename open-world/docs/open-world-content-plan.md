## A. 主线（现为新手引导 + 岛屿故事，拆分见任务系统改造 §4）

## 0. 规则

1. **唯一来源**：任务、步骤、路线、NPC、对白都写在 `config/excel/任务.xlsx`、`NPC.xlsx`、`对话.xlsx`；分区与地标坐标写在新的 `config/excel/世界.xlsx`。代码里不写文案、坐标、奖励。
2. **只用已有步骤类型**：`talk` 交谈、`interact` 调查/操作、`battle` 战斗、`defend` 守护、`choose` 选路线、`route_battle` 路线战斗、`boss` 首领。本方案不需要新机制（“护送”用“同伴跟随 + 到达后交谈”表现，跟随只是表现，不进判定）。
3. **旧任务 ID 全部保留**（`ss-c01-t01`…`ss-c06-t06`），只改步骤的 `map/zone/landmark` 和 `order`；新任务用 `ss-cXX-n01` 起编号，以免和旧 ID 混淆。
4. **地标 ID 保留**：旧地标（landing、objective、clue、route-a…）在新地图里仍存在，只是挪到对应分区；进行中的旧存档继续有效。
5. **经验总量不变**：每章主线经验总额保持现值。新任务从本章总额中分 15%，旧任务奖励等比 ×0.85。改完用 `pnpm balance` 复核 30 小时节奏。已领奖记录保持历史快照，不追改。
6. **老角色**：已经越过某个新任务位置的角色，该新任务视为已完成、不发奖；人物站位、剧情门、世界相位按当前进度直接解析。
7. **怪物等级 = 分区等级带**，不按玩家等级缩放；主线战斗点的普通营地在该步骤进行中对该角色暂停刷新。
8. **引导**：方向箭头 + 一行任务文字；目标不在本分区时指向最近已解锁传送点或分区出口。

## 4. 需要的新地标与物件

每章新增：1 个 `outpost`（前哨，含传送点）、1 个 `gate`（剧情门，开/关两态）、1 个首领门；多点调查/操作的任务把原来的单一地标拆成 a/b/c 或 1/2/3。合计约：前哨 6、剧情门 6、首领门 6、新增调查/装置地标约 15。美术见改造方案 §4.2、§4.3。

## 5. 验收

1. 新角色 1 级从落风坡开始，只做主线 + 顺路营地，6 章能在约 18 小时（`balance-30h-design.md` 主线时长）内走完，每章到首领门时等级不低于首领等级 −1。
2. 每章主线至少经过 5 个分区；剧情门在对应任务前打不开、完成后永久打开。
3. 人物在任何进度只出现在一个位置，与第 3 节一致；外出时港口服务照常可用。
4. 老角色：处于任意旧任务步骤的存档登录后，任务、步骤进度、人物站位正确；越过的新任务显示为已完成且无奖励。
5. 经验总额与改前一致（逐章核对），`pnpm balance`、`pnpm config:check`、真实数据库主线测试通过。

### 6.2 接取与开放条件

> 支线条件以 [任务系统改造](open-world-quest-system.md) §4–§6 为准：分区已发现 + 等级 ≥ 分区等级带下限 − 2，不再以主线任务为前置。

- 区域支线：玩家**进入该分区** + 主线进度达到本章（`pre` 填本章第一个主线任务）+ 等级 ≥ 分区等级带下限 − 2。区域人物头顶显示可接标记，全图上显示。

- 主线人物也可以发支线，但只在其“站位”所在地发（§3 站位表）。

### 6.3 悬赏（可重复）规则 —— 新机制

这是保证“打不过就去刷”的固定刷级路线（用户规则：总要有刷级路线）。

- 每分区 3 条悬赏同时挂出；完成一条后该位置冷却 10 分钟，再从本分区悬赏池随机刷出新的。
- 目标只计**服务端确认的击杀**（营地 cycle / `ow_kills`），按模板和分区过滤；不接受客户端自报。
- 奖励：经验 = 完成所需击杀的经验 × 0.5（额外加成，不超过打怪本身的一半），外加金币、材料；**不给装备**（装备仍走怪物掉落，保持每小时 20–25 件）。
- 防重：每条悬赏实例有唯一 ID，领奖走同一事务与幂等键。
- 实现：任务表新增字段 `repeat_cooldown_seconds`、`pool`（悬赏池 ID）；服务端新增“可重复任务实例”存储。补针对性测试：接取、计数、断线恢复、重复领奖。

## D. 怪物难度

## 8. 怪物难度方案

### 8.1 原则（用户已确认）

1. 怪物 = 模板 + 指定等级 + 档位（普通/精英/首领）+ 副本难度修正；唯一源 `packages/content/monsters.json`；**不按玩家等级缩放**。
2. 数值靠**推导**，不手调：
   - 怪物生命 = 参考玩家 DPS × 实战效率 × 目标体感击杀时间（TTK）；
   - 怪物攻击 = 由参考玩家生命/护甲与目标“怪物打死玩家时间”（TTD）反推。
3. 参考玩家 = 标准人 × 达标率（按游戏时长），见 `G:\webgame\数值设计S2\QT05_星潮海标准人属性规划_v2.xlsx`。
4. 每个关卡（首领门、地城）都必须有可重复的刷级路线：营地刷新 + 悬赏 + 野外地城。

### 8.2 目标（体感秒）

> **注意（2026-10-06 已确认）**：普通怪 TTK 随等级递减、怪物角色与群体生命预算、精英词缀、世界层级见 [割草爽感方案](open-world-grind-feel.md) §2–§3，下表“普通 2.5 秒”只适用于第 1 章。野外地城首领（墙）的生命/秒伤、钥匙与开荒时长以 [数值心流](open-world-numeric-flow.md) §3–§5 为准；首领达标率测试改为 0.8 / 0.85 / 1.0 / 1.2 四档。

| 档位 | 体感 TTK | TTD | 说明 |
|---|---|---|---|
| 普通 | 2.5 秒 | 40 秒 | 单只；一个营地（3–5 只，有群攻）目标 8–12 秒清完 |
| 精英 | 10 秒 | 20 秒 | |
| 稀有精英（新档位 `rare`） | 20 秒 | 20 秒 | `monsters.json` `ranks` 增加 `rare` |
| 章节首领 | 60–75 秒 | 30 秒 | 第一章 60，其余 75 |
| 野外地城首领 | 60 秒 | 30 秒 | |
| 试炼 / 高难 / 噩梦 1 层 / 团队 | 60 / 90 / 60 / 180 秒 | — | 见工作簿「副本推算」 |

跑图：营地间步行 4–6 秒，野外交战时间占比 ≥ 50%（现在实测 21–39%）。

### 8.3 现在的问题（来自工作簿实测）

- **前期普通怪偏硬**：第 1–2 章普通怪生命应 ×0.69–0.86。
- **后期严重偏软**：建议生命系数 L28 ×2.4、L36 ×3.9、L41 ×11、L51 ×44。
- **高难副本**：L50 高难首领需 ×81–130。
- **档位倍率不符合目标**：按 TTK 推导，精英生命应为普通的 4 倍（10 ÷ 2.5），现在 `ranks.elite.hp = 2`；精英攻击按 TTD 应为普通的 2 倍（40 ÷ 20），现在 1.5。
- 实战效率（体感 ÷ 站桩）：普通 0.68–0.80，首领 0.58–0.99（第 4、6 章首领偏低，首领机制让玩家无法持续输出）。

### 8.4 做法（按顺序）

1. **参数**：按工作簿当前值执行（「达标参数」各养成滞后时长、8.2 的目标）；用户以后改工作簿黄色格，重新跑第 2 步即可。
2. **重拟 `starsea` 等级曲线**：新增脚本 `tools/apply-monster-curve.ts`，复用 `tools/standard-player-model.ts` 的同一套计算，得到 1–60 级普通怪生命/攻击/护甲，写回 `monsters.json` `curves.starsea`。工作簿只作复核展示，不手抄数字。
3. **改档位倍率**：`ranks` 改为精英 hp ×4 / attack ×2，新增 `rare` hp ×8 / attack ×2；章节首领生命按各自目标 TTK 单独定（`campaign.json` bosses），不用统一倍率。
4. **分区内的难度分布**（按 `世界.xlsx` 营地表配置）：
   - 主路营地 = 分区等级带下限～中值；偏远营地 = 上限；精英营地（1 精英 + 2 普通）= 上限，每分区 3–5 个；稀有精英 = 上限 +1。
   - 营地间距 ≥ 10 格（仇恨半径 8），避免一次拉两个营地；精英营地远离主路。
   - 主线战斗点怪物等级 = 该分区中值；首领 = 章节首领等级（8/15/21/27/32/37，裂星潮后 42–52）。
   - 怪物名牌按等级差着色（灰：低 5 级以上 / 白 / 黄：高 1–2 / 橙：高 3–4 / 红：高 5+），只是显示，不改数值。
5. **野外地城**：模板 `normal`，`monsterLevel` = 入口所在分区上限 +1；三个地城分别对应本岛前、中、后段分区；可无限重复，作为刷级与刷装路线。
6. **旧副本重标**：试炼/高难/噩梦/团队按工作簿「副本推算」的建议 `enemyScale` 写回 `dungeons.json`（只改声明值，不加按副本 ID 的兜底）。
7. **裂星潮**：同一曲线延伸到 38–52，营地/地城按升阶后的等级重新解析；不另造曲线。
8. **星潮夜**（现有：同岛累计 40 击杀触发 5 只入侵）：大地图击杀更快，改为**同分区**累计 80 击杀触发；入侵怪从玩家 36 格外出现后走向玩家（不在原地凭空出现）。

### 8.5 验收（数值）

同一构筑、种子、样本，报告写明版本、策略与限制：

1. `tools/field-efficiency-probe.ts` 升级为按分区测：每章每个分区自动刷 3 分钟，普通怪体感 TTK 在 2.5 秒 ±20%，营地 8–12 秒清完，交战占比 ≥ 50%。
2. 首领：参考玩家达标率 0.8 / 1.0 / 1.2 三档各测 20 次；1.0 档胜率 ≥ 90%、体感 TTK 在目标 ±20%；0.8 档允许失败，但该等级附近有可重复刷级路线（营地 + 悬赏 + 地城）。
3. `pnpm balance`：30 小时 1→50 级偏差 ≤ 10%；每章到首领门时期望等级 ≥ 首领等级 − 1。
4. 反作弊阈值（抽检）用新数值的真实构筑重新测定，宁可漏判。

2. 新角色从 1 级到第六章尾声，只走主线 + 顺路内容能完成；每个功能在 §7 规定的时点开启，接口真实校验。
3. 老角色：任意旧进度登录后，功能、任务、人物站位、所在位置正确；无奖励重复、无功能回收。
4. `pnpm config:check`、内容校验、类型检查、生产构建、真实数据库测试、真实浏览器登录进入营地全部通过。
