## 组合执行能力与采用规则

契约位于 `packages/contracts/skill-mechanics.ts`、`packages/contracts/index.ts`，内容位于 `packages/content/skills-expanded.ts`、`packages/content/chapter-combat.ts`。规则由服务端解析，战斗核心消费已解析参数。没有在客户端重新实现等级、装备、技能成长或费用公式。

- 伤害分为 direct、periodic、derived。只有 direct 可以暴击、吸血、传导、施加装备燃烧、触发装备护盾、消费通用斩杀和打断；反击只处理 direct。持续伤害保存施加者、强度、类型、穿甲、结束及下一次 tick，不读取当前聚焦角色的属性。
- 状态以来源、目标、技能和效果建立实例。同源刷新保持下一次周期结算；不同来源的 DOT 独立，攻击、速度、减速和护甲修饰取最高。基础属性不被永久改写。死亡、到期、净化、来源丢失和消费均有事件。
- 首领普通控制时长为普通目标的 35%；恐惧和时间停滞免疫，牵引抵抗。正在执行未声明可打断技能时，眩晕和石化不能取消该动作，反馈为免疫。沉默仅阻止开始新主动技能，保留普攻和已经开始的读条。
- 时间停滞只影响选定敌人的行动；实例时钟、倒计时、冷却、已经释放的飞行物和区域继续。束缚禁止移动和突进，允许其他攻击和施法。
- 新多段和本体扇形使用单次总伤预算，余数落在末段。原有天赋／威能的 60% 每箭预算由服务端换算成单次总量后拆分，保留已投入构筑的伤害预算。原有永久攻击、必杀、光环和治疗／护盾修正继续沿用，本轮没有批量调整武器盘或经济。
- 临时攻击使用服务端提供的 `resolution.attackShare` 修改输出。冷却两池合成后整体最多降低 75%，只取整一次；最终冷却和贡献由服务端返回。前摇、通道、资源、控制和连接就绪分别反馈。
- 状态、多段进度、来源、投射物、区域、随机状态和免死消费均进入检查点。阶段转换保留角色资源、冷却、自身持续状态和免死消费；旧阶段的地面区域及针对旧怪物的排程在阶段结束时取消。
- 闪现需要合法地面位置；最大距离 10 格，等级成长最多 12 格，检查完整路径、墙体和活体接触。没有合法目标／路径时不扣费。相位只免疫声明为 physical 的伤害；新命中路径不能按特效颜色推断类型。
