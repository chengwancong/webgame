### 1.4 客观验收（build.py 已实现）

- 分级响度（上表）。
- 核心反馈（`CORE`）：小喇叭损失 ≤3dB，且 200Hz 以下占比 ≤0.5。
- impact / cast / warning / stinger 分级：小喇叭损失 ≤4dB。环境：≤6dB。
- 高频重复音（`FREQUENT`）：2–5kHz 占比 ≤0.45。
- 非循环音效时长 ≤3 秒。
- 变体之间：频谱相关 ≥0.8（像同一个声音），波形互相关 <0.9（不是同一条）。
- 不同 key 之间：同阶段、同前缀，频谱相关 ≤0.95（禁止孪生音）。
- 轻重层级（冲击响度 = K 计权 50ms 窗最大值）：暴击 ≥ 命中 +3dB，预警 ≥ 暴击，`player/cut` 命中 ≥ 命中 +2dB。

小喇叭损失 = 全频有效值与 200Hz 高通后有效值之比。这一条专门防止"整段能量都在 200Hz 以下，笔记本和手机上听不见"。现有合成音大面积如此（需求§1.1）。

### 1.5 配方约定（从标杆总结，全部遵守）

1. **四层结构**：
   - 瞬态：0–10ms，1.5–4kHz 带通噪声或咔嗒；
   - 身体：150–700Hz 扫频正弦/三角，或模态共振；
   - 质感：按元素选滤波噪声、噼啪、FM；
   - 尾巴：`room()`、噼啪尾、铃音余振。
2. **低频预算**：除首领重击、大招和环境外，200Hz 以下占比 ≤0.3。需要"重量感"时，用 80–170Hz 短促下扫，增益比主层低 12–15dB，并对主层做 150–260Hz 高通。**重量感靠中频冲击和瞬态，不靠低频。**
3. **变体**：
   - 核心参数（时长、起始音高、主共振频率）用**按变体序号错开的表**，见 `hit()` 的 `((.07,300),(.10,360),…)[v % 4]`；
   - 次要参数用 `rng(seed)` 抖动；
   - 骨架复用时选同一组骨架，见 `crit()` 用 `hit(seed, v % 3 + 1)`。
4. **确定性**：随机只用 `rng(seed)`、`jitter`、`gj`。种子由 `seed_of(key, stage, v)` 给出。禁止 `np.random` 全局状态和时间种子。
5. **电平**：配方内只调层间相对增益，最终电平全部交给分级归一。禁止在配方末尾手动乘总增益来"过验收"。
6. **时长**：命中 0.08–0.9 秒；施放 0.15–0.5 秒；大招命中 ≤2.5 秒；界面 ≤0.35 秒（提示框、结算类 ≤1 秒）。
7. **注释**：每个配方一行中文 `note`，写"声音意图 + 关键层"，会进试听标签。

## 2. 已确定的决策（不可推翻）

1. 本期全部音效用 `tools/audio` 离线程序合成，产物为 WAV（16bit；音效单声道 48kHz；环境立体声 32kHz）。
2. **技能按"每技能离线合成成品"出文件**，不在运行时叠加元素层和形态层文件。
   - 理由：运行时可以保持"一个 key 一个阶段一条采样"，孪生音验收才有意义，混音器也不用改。
   - 元素层、形态层只作为 Python 函数库存在。
   - 需求§6.1 的"由程序组合"按此理解。
3. 技能轻重按**冷却**分档：
   - ≤1 秒为填充，命中用 impact-light；
   - ≤6 秒为核心，命中用 impact-heavy；
   - ≤20 秒为冷却技，命中用 impact-heavy，且冲击比核心再高约 2dB；
   - >20 秒为大招，命中用 stinger。
   - 冷却从技能配置读取，**不按列表序号**。现有 `deriveSoundProfile` 的 `ordinal` 音高/时长偏移不得带入新配方。
4. 合成兜底保留：没有文件或文件加载失败的 key 继续走 `sound-profiles.ts` 合成，不删除。
5. 音乐（需求§3.1 的 27 首 BGM）和真实生物叫声不在本期合成范围。
   - 写入 `docs/audio-external-sourcing.md`（曲目、时长、风格要点、循环要求、优先级）。
   - 程序侧的音乐总线、状态机、淡入淡出照做，用静音占位。
   - 提示音乐（需求§3.3 共 12 个）可以合成，照 `stinger_levelup` 做。
6. 生物叫声（警觉、受击、死亡、待机）先按 `dusk_death` 做合成占位，清单标 `source: synth-placeholder`，同样列入外采清单。非人声部分全部正式做：挥舞、身体受击材质、机械、火灵、植物、裂隙等。
7. 设置提供五个滑块：主音量、音乐、环境、音效、界面；另加"后台静音"开关。保存在 `aw-settings`，旧存档只有 `volume` 时，把它当作主音量。
8. 音频清单的唯一来源是 `build.py` 生成的 `sample-manifest.json`。
   - 每条补字段：`source`（`synth` / `synth-placeholder` / `external`）、`license`、`note`。
   - 本期不建 Excel"音频清单"工作表。需求§9.3 第 1 条按此替代，记入裁决。
9. 预加载只限 `cue/`、`foley/`、`ui/` 和当前技能栏已装配技能的文件。其余在首次播放时加载（首次走合成），区域环境在进入区域时加载。把现在的"解锁时加载全部 wired"改掉。

## 4. 程序接入（各批需要的代码改动）

1. **混音器总线**：现有总线为 combat / ui，新增 music / ambience / foley，各接一个增益节点并受设置滑块控制。`SoundRecipe.bus` 扩展取值，限幅器只挂在总输出上。
2. **触发点**：
   - 战斗类沿用 `combat-sound-events.ts` 与 `main.ts` 的 `sound(kind)`；
   - 新的 cue 走 `cueRecipes`，并补 `soundPriority` 分档；
   - 脚步：新模块，按英雄每 tick 位移累计步距触发（走约 0.42 秒一步，按移速缩放），地面材质查 `world-dressing.ts` 或区域默认；
   - 界面：在 `ui-components.ts` 公共按钮/面板上统一挂，不在各页面分别写；
   - 掉落：在现有掉落落地/拾取动画事件上挂，品质取自物品；
   - 背包满：在满包停自动的同一处挂；
   - 环境：进入区域时切换，2 秒交叉淡化，长文件用 `HTMLAudioElement` + `MediaElementAudioSourceNode` 流式播放。
3. **防疲劳**（需求§9.3 第 5 条）：
   - 击杀 1 秒内超过 3 次，改用更轻的变体；
   - 同帧 ≥3 次击杀，改播一次 multi-kill；
   - 拾取同帧只播一次。
4. **压低**：首领预警与提示音乐播放时，音乐与 combat 总线压低 6dB，持续 0.6 秒后恢复。
5. **怪物音量**：`voice/` 与 `monster/` 在混音器里乘 `soundPriorities` 现有的怪物权重；不可见怪物不出声（现有规则）。
6. **试听 QA 页** `audio-qa.html`（只在 qa 模式构建，见 `vite.config.ts` 的 qa 入口）：
   - 按清单列出全部 key/阶段/变体，可逐条播放；
   - 每条标出"采样 / 合成兜底 / 缺失"，并显示 tier 和 source。
7. **覆盖测试** `tests/audio-coverage.test.ts`，以下每一项都必须有采样文件或明确的合成兜底：
   - 全部 vfx key 的各阶段；
   - 状态、cue；
   - 首领预警；
   - 已接入 key 的清单文件必须真实存在。
8. **混音器 `synthGain`（现为 .4）**：本期结束时若仍有合成兜底在用，量一次兜底与同类采样的冲击响度差。差距超过 6dB 时调整 `synthGain` 一次，不反复调。

不得改动：战斗模拟、服务端、伤害与判定、`apps/web/src/scene.ts`、`qa/combat-feel.ts`、`combat-vfx.ts`、`shield-feedback.ts` 和物理特效相关文件。`main.ts` 有其他会话的未提交改动，只能加自己的最小钩子，提交时只暂存自己的块（参考 `docs/reviews/pacing-identity-20261013/C7/stage-own.py` 的做法）。

## 6. 默认裁决表

| 歧义 | 裁决 |
|---|---|
| 某条验收改了三版配方仍过不了 | 保留最接近的一版，记残差（指标、差多少、原因），继续下一条；**禁止放宽阈值** |
| 技能冷却缺失或为 0 | 按形态：斩击/投射物/连锁为填充，爆发/区域/光束为核心，召唤/护盾为冷却技 |
| 技能元素与形态组合在标杆里没有 | 按第 1.6 节元素表 + 形态函数组合，不新造风格 |
| 两个技能元素和形态都相同，被判孪生 | 用冷却档、命中次数、飞行时长、★料拉开；仍不行，按技能 id 的哈希给确定性音高偏移（±1.5 半音以内） |
| 某怪物模板归不进 9 个躯体组 | 按美术外观选最近的组并记录；确实全不像时新开一组 |
| 某首领技能没有元素 | 按其特效 vfx 元素；再没有就用暗影 |
| 地面材质查不到 | 用区域默认材质（港口木、风原草、赤炉石、霜镜冰雪、雾铃苔土） |
| 界面某处不是公共组件 | 不单独挂音，记入"未覆盖界面"清单 |
| 文件总量膨胀（>80MB） | 先把环境改 24kHz、音效变体数降到验收下限（高频音 3、其余 2），仍超就记入报告，等转码 |
| 没有 ffmpeg 无法转 Opus | 本期保持 WAV；写 `tools/audio/transcode.mjs`（检测到 ffmpeg 才运行，转 Opus 96k/128k + AAC，清单改指向新格式），不运行也不算阻塞 |
| 其他会话中途改了 `main.ts` / `mixer.ts` | 重新读后在其基础上加钩子，不回退他们的改动 |
| 现有测试因音频改动失败 | 若是 mock 缺少真实 Web Audio 接口，补 mock；若是行为变化来自本期决策，更新期望并写依据；否则修代码 |
| 文案拿不准 | 遵守 `docs/copy-voice-handoff-20261009.md` |

## 8. 禁止事项

- 禁止放宽 build.py 的任何阈值或分级值；禁止为了过验收在配方末尾乘总增益；禁止手改 `sample-manifest.json`。
