# 野外状态与回城整理

2026-10-03 用户选定方案1：玩家需要注意背包、倒地与连接状态，主动回城整理，再重新开启全自动。

玩法原型采用《暗黑破坏神 III》的铁匠分解循环（https://us.diablo3.blizzard.com/en-us/artisan/blacksmith/）。死亡恢复参考《激战 2》的明确传送点复活操作（https://wiki.guildwars2.com/wiki/Waypoints），本作固定结果返回到归途营地。批量确认和保守保护清单为本作调整。

## 玩家路径

- 野外装备达到容量（当前24件）后停止全自动；即使没有待领取掉落，也不能重新开启。仍能手动移动、战斗和回城，低生命不自动回城／回血。
- 常驻状态提示提供「回城整理」。点击后保存已确认战斗收益，回到归途营地并打开行囊。行囊内显示实际占用／容量；菜单红点仅为待领取件数。
- 营地「批量分解」从服务端读取当前清单和强化石收益。普通、魔法、稀有的未保护装备可分解；已装备、锁定、强化、传奇、威能和武器盘装备排除。确认窗口列出名称、品质、件数和材料，不做属性优劣的自动判断。
- 提交时服务端重新检查库存版本和所有选中装备，保护检查失败时整批不提交。重复命令返回原回执；此前待领取掉落与金币保持。
- 整理后可「返回原区域」，沿用当前已击杀记录，不自动生成新一轮敌人。该快捷返回记录属于本次客户端会话；重载后仍可用远行界面选择区域。整理完成不会自动重新开启全自动。
- 野外死亡结果的「返回归途营地」固定返回主城，并由服务端保存营地为返回点，清除旧野外据点位置；刷新与重进仍回到营地。返回失败保留结果和重试入口，断线恢复成功后同一次显式操作可继续返回。

## 边界

批量分解入口在营地显示；现有逐件分解仍有单独确认，保留玩家明确处理强化装备的操作。持续运行的服务端副本沿用整场规则，满包不会暂停副本或清除已获得的超额装备。

本轮不扩大背包、不增加自动分解、不增加无限掉落暂存能力。沿用已有地面掉落与待领取记录，保证已经结算的收益不丢失。
