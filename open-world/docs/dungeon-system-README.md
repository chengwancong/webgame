## 🛠️ 开发流程

### Phase 1: 地图创建（优先）
```
1. 创建6个地图JSON文件
   - tundra.json (80x80)
   - tundra-boss.json (48x48)
   - abyss.json (96x96)
   - abyss-boss.json (48x48)
   - dragonbone.json (128x128)
   - dragonbone-boss.json (64x64)

2. 配置怪物刷新点
   - 普通怪：30-50只
   - 精英怪：3-5只
   - 安全点、传送门、BOSS入口

3. 注册到 packages/content/index.ts
```

### Phase 2: UI实现（并行）
```
1. BOSS血条组件
   - 显示BOSS名称、血量、阶段
   - 血量低于70%/40%高亮提示

2. 危险区域预警
   - 红圈标记AOE范围
   - 倒计时显示

3. 副本完成界面
   - 显示用时、击杀数、奖励
   - 返回城镇按钮
```

### Phase 3: 战斗系统（后续）
```
1. BOSS技能逻辑
2. 阶段转换机制
3. 特殊机制（黑暗侵蚀、光明祭坛等）
```

## 📊 数值参考

### 玩家成长曲线
```
Lv1:  HP=100,   攻击=15,  法力=100
Lv10: HP=300,   攻击=40,  法力=200
Lv20: HP=650,   攻击=85,  法力=380
Lv30: HP=1200,  攻击=150, 法力=650
```

### 怪物倍率
```
普通怪：HP×1.0,  攻击×1.0
精英怪：HP×4.0,  攻击×1.5
BOSS：  HP×10.0, 攻击×1.5
```

### 装备掉落率
```
普通怪：白60% 蓝30% 紫9% 金1%
精英怪：白30% 蓝50% 紫18% 金2%
BOSS：  蓝40% 紫50% 金10%
```
