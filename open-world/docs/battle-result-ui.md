## 实际流程

- 角色倒下或本次首领死亡时暂停战斗，先保存未提交的战斗报告，再读取服务端本次记录。
- 成功需本次授权内的首领击杀已经提交。保存中显示“战斗结束”；返回失败或返回断线时保留成功标题与战利品。
- 首次通关、技能书和新地区提示只读取实际首通结算。重复进入首领试炼创建独立授权；同一次进入请求的重试复用授权。
- 副本装备在击杀事务中直接存入背包。暂时允许副本掉落超过24格，返回后整理；野外装备仍走地面拾取。此容量处理为本次落地采用的默认方式，可独立调整。
- 战利品装备逐实例展示；材料、技能书按稳定ID累计。大量道具只在网格内部滚动，返回位置保持固定。
- 保存响应丢失后恢复连接，先查询原操作回执，再继续读取结果；不重新发奖。刷新后可恢复结果窗口，再返回已记录的安全区域／安全点；不会在失败副本直接复活。
- 结果窗口没有关闭按钮，Esc仅收起详情，不跳过返回流程。

## 服务端记录与兼容

`GET /api/combat/results/:permitId`仅允许角色所有者读取。累计记录版本1存于既有`ow_permits.private_data.battleResult`，与击杀、钱包、装备、回执和流水共用事务。掉落去向在出发时冻结；旧授权保持旧去向。接口只公开已经发放的物品及数量，不公开私有随机规则与未掉落候选。

数值是本次实际奖励累计，既不取背包余额差，也不把开销加到收益中。老授权缺少累计记录时金额显示“—”，首通标记未知，并提示早期收获未完整记录；不会用当前配置重建历史。

版本：客户端0.7.7、协议8、规则ow-11、资源world-art-20261002-v10-mini-navy、数据库10。新增字段存于原JSON列，不删除或重写角色成长、历史奖励或回执。
