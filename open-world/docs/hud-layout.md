# 主界面HUD落地

2026-10-03 用户批准采用最新主界面方案。正式入口接入ui/hud-layout.css与hud-context.ts，不导入旧HUD预览皮肤。

## 场景与功能

- 无敌人生成且不允许自动战斗的安全地图显示人物入口、完整A1六项非战斗菜单、侧边任务追踪。隐藏技能释放快捷栏与战斗模式。现行配置中该安全地图为归途营地；野外记录据点不被当作免战区域。
- 野外技能栏独立居中。2026-10-25 起（27 号 R1，推翻 10-11 野外固定半自动）：野外、世界活动、副本进入时即全自动；主城、城镇、休整点为半自动（技能自动、走位手动）。方向键／点地／摇杆为临时接管（`World.takeoverAt`），松手 1.5 秒（45 tick）回到自动并以当前位置为新锚点。满包时进入为半自动，且服务端拒绝开启自动（`BAG_FULL`）。
- 技能格状态（2026-10-11，用户反馈图标一闪一闪很难受）：超射程、无目标、施法中、冷却都不改图标；冷却是格子边框上一圈顺时针填满的细金环，角上显示整数秒（短于1秒的普攻不显示）；只有缺能量（进出都需持续600ms）和受控／倒下染色。原因文字仍在悬停提示里。
- 左下不再有模式切换，只显示自动状态（`autoStatusHtml`）：「自动中」绿点、「接管中」高亮点、「已停止」橙点＋「恢复自动」按钮（满包、处理中、阵亡时禁用）。安全地图与结算不显示。
- 副本按真实实例运行状态切换，任务／倒计时在上方，右侧中部常驻简洁退出图标，先确认再执行原有leave流程。取消后仍在本场计时。多人、倒地、断线或阶段准备时展开必要操作，保留治疗、救援、准备与恢复连接。
- 没有新增左下远行／副本快捷键。小地图打开现有远行页面，页面内保留副本目录入口。
- 满包提示与模式栏分开；容量读取真实快照。安全地图整理，野外回城整理，副本仅行囊入口且继续运行。金币、地图、头像、A1样式沿用共享控件；异常连接与收益提示保留。

## 任务与交互

任务条使用已确认的浅金／奶白渐隐样式，没有独立大窗口标题或重复“全部任务”按钮。主线来自StoryController，点击进入原有NPC交谈；其他最多两项当前任务来自TaskController，点击打开并定位真实详情。显示服务端目标和进度，未知数值不补零。任务数据按角色与revision刷新，没有自动领奖或新建持久追踪机制。右下任务入口保留完整列表与档案。

## 范围与验收

公共Token、原HUD皮肤、背包和公共表单控件与落地前审计哈希一致。未改变伤害、费用、冷却、掉落或存档格式。技能排序按钮未恢复。

HUD上下文、满包分支、单模式入口、真实任务进度测试通过；内容校验通过。实机验证任务详情定位、NPC交谈、地图／副本目录、野外模式选择、真实零消耗普通副本的退出确认／取消后持续计时／返回营地。1024×720及320×720无横向溢出，完成后恢复默认1280×720视口。完整满包分支由配置与组件测试覆盖，没有为了验收向玩家账号补造装备。

发布状态与截图保存在工程 .design/hud-release-20261003；交付前依次停止服务、构建、恢复服务，核对health/content并恢复真实营地会话。
