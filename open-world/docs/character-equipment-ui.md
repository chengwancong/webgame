# 人物装备界面

用户已确认魔兽世界／暗黑4参考稿并要求落地。正式人物页采用中央角色、两侧六部位、右侧常驻属性栏，沿用游戏蓝金界面。点击HUD头像或背包顶部“人物”进入概览，默认不展开候选。

点击部位后，仅展开该部位的候选和装备详情；候选、长详情分别内部滚动。穿戴、卸下、强化、锁定与分解沿用真实游戏命令；装备比较与费用由服务端返回，确认回执前不提前修改数值。Esc先关闭悬浮说明／确认，再收起候选，最后关闭人物窗口。收起候选后焦点回到对应槽位。

| 部位 | 运行数据 |
| --- | --- |
| 武器 | equipment.weapon |
| 衣服 | equipment.armor |
| 项链 | equipment.accessory |
| 头盔、鞋子、戒指 | 暂无运行装备，显示空槽及无候选状态 |

旧核心使用独立固定高度入口，保留equipment.core和原有效果。324条已登记装备定义不因此成为可穿戴或可掉落物品。界面没有修改数值槽位、存档结构、战斗公式或外观数据。

角色生命、攻击、护甲和详细属性消费Snapshot.stats。百分比属性按比例显示，暴击倍率按倍数显示；服务端未返回的可选属性显示“—”，不复制设计稿示例。效果来自实际stats.effects与已生效合剂。

从背包装备详情进入时，直接定位物品及部位；返回后保留背包分类和选中项。连接异常时保留页面并禁用写操作，显示恢复入口；成功但丢失响应的穿戴通过已有outbox和回执恢复，只执行一次。

实现入口为CharacterPanel、CharacterPaperdoll、character-equipment.css，以及main/presentation中的局部页面状态。默认概览不请求候选装备预览；收起浮层时使未完成预览失效，防止迟到数据写入已关闭详情。

真实临时数据库验收：`node --import tsx tools/accept-character-layout.mjs`。10项检查覆盖真实属性、六槽、空部位、长名称、候选滚动、换装及丢响应恢复、强化与锁定、旧核心、Esc焦点、背包上下文、五档视口、刷新存档保留。类型检查和17项相关单元检查通过。

## 2026-10-11 换装改为并排对比（方案 B）

用户反馈「人物界面，装备切换，也需要优化」。按 1280×720 实测，旧换装有四个问题：

- 候选和详情挤在左框的浮层里，立绘被盖住，右侧属性栏原样不动、也用不上；
- 详情能滚动的区域只有约 184px；
- 候选卡 88px 高，一屏只看得到约 4 张，也看不出比身上那件好还是差；
- 替换要点四下：部位 → 候选 → 替换 → 确认弹窗。

用户在线框图 A「右侧换装栏」和 B「并排对比」之间选了 **B**。

**换装时（点任一部位）**，整页分为四列：

| 列 | 内容 |
|---|---|
| 部位栏 | 六部位收成图标栏，点哪个就换哪个部位 |
| 候选 | 标题「更换××」，右上角关闭。候选行 64px 高，一屏约 6 行。每行显示名字、+强化等级、主属性和品质。右侧显示：穿戴中那件标「穿戴中」，同主属性的标 ▲/▼ 差值，持平写「持平」，主属性不同的不标。排序：穿戴中 → 同主属性按数值从高到低 → 其余 |
| 穿戴中卡 | 静态卡片（虚线边框）：主属性（含强化）、副属性、特殊效果 |
| 选中卡 | 原 `GearDetails`：服务端主属性、「装备后」逐项变化和总评，主按钮为 装备／替换／卸下 |

- 选中的就是穿戴中那件，或该部位为空时，只显示选中卡，居中，最宽 560px。
- 立绘和右侧属性栏在换装期间让位，关闭候选后恢复。
- 1280×720 实测：候选列表 400px 高，两张卡各 319px 宽，详情可滚动区 342px。

**替换一次完成**：去掉「装备对比」确认弹窗（删除 `GearComparison.ts`、对应 CSS 和 `main.ts` 的对比状态）。人物页的 装备／替换 直接写 `gear/equip`，服务端照常校验。总评和逐项变化已经在选中卡的「装备后」里，不再重复弹窗。

▲▼ 只比较主属性，在客户端用 `gearMainStat` 计算：`mainStat.value × (1 + primaryRatioPerRank × rank)`，与 `rules/main-stats.ts` 的 `mainStatContribution` 一致。这样不用为每件候选单独发 tip 请求。完整的属性变化仍以选中卡里服务端返回的「装备后」为准。

验收：`tests/inventory-ui-system.test.ts`「swap mode …」覆盖以下几点：

- 候选排序；
- ▲▼ 数值（含强化）；
- 换装时不渲染属性栏；
- 并排卡片；
- 一键替换按钮；
- 选中穿戴中那件时显示单卡和「卸下」。
