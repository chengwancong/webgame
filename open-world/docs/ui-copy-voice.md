# 游戏文案规范（玩家可见文字）

整理时间：2026-10-09。适用于所有玩家能看到的文字：界面、HUD、提示、结算、Tooltip、按钮、任务、对白以外的系统说明。对白人设另见任务配置表，但同样遵守 §3 禁用词。

**一句话原则：说玩家关心的结果，不说系统怎么算。**

## 1. 说话的人

- 系统文字是一位熟悉群岛的老船员在提醒你：简短、具体、带一点冒险感，不卖萌、不说教。
- 用“你”，不用“角色”“玩家”“本角色”。
- 说**发生了什么、接下来做什么**；不解释实现、规则来源、计算口径。
- 一个界面只回答玩家此刻的一个问题（我为什么输了？这件装备好吗？下一步去哪？）。

## 2. 写法规则

| 规则 | 不要 | 要 |
|---|---|---|
| 结论先行 | 有输出秒数 15/16（93.8%） | 被督猎者从背后偷袭了 |
| 动词开头的建议，最好可点击 | 先尝试控场或生存技能，分批接敌 | 按钮：[装上控场技能] [强化护甲] |
| 数字只留玩家能直接用的 | 怪物生命×1.6、攻击×1.25 | 危险 ★★☆☆☆ |
| 比较用箭头和颜色 | 3059 > 2813 -246 | 攻击 ▼246（红） |
| 名字具体 | 钥匙制作材料 2/64 | 沉星钥匙碎片 2/64 |
| 不写否认句、免责句 | 不保证净提升；仅由本阶段地城掉落或制作 | （删掉） |
| 不重复画面已表达的信息 | 角色已倒下 · 战利品已自动存入背包 | 战利品已收好 |
| 不写只有开发者懂的状态 | 处理中 / 冻结 / 已解析 | 正在出航… |

## 3. 禁用词（玩家可见文字中不得出现）

出现即视为缺陷。左列禁用，右列是常见替换方向（按语境选，不是机械替换）。

| 禁用 | 替换方向 |
|---|---|
| 阶段、第 N 阶段、stage | 岛名 / 地城名 / “这一带” |
| 造型、亲和、T1/T2/T3 | 外观 / 主手加成；不显示内部档位标签 |
| 构筑、BD、build | 你的技能和装备 / 搭配 |
| 冻结、快照、解析、执行器、回执、流水、事件记录 | 删掉 |
| 权重、保底、来源表、随机表、倍率、系数 | 更常见 / 必定掉落 / ★ |
| 输出秒数、有效输出、占比、DPS（结算页） | 删掉，或改成“你一直在攻击 / 你很难打到它” |
| 适配、取舍、同强化对比、产物 | 适合你的剑 / 按同样 +7 比较 |
| 相对、×N（作为主文案） | ★ 或“更强 / 更多” |
| 机制方向、阶段用途、部位：（标签式罗列） | 一句话说它干什么 |
| 实时作战、1至1人、1–1 | 单人 / 组队（单人默认不写） |
| 之后新刷出的营地生效 | 离开港口后生效 |
| 普通随机传说、原初主手（作为说明） | 传说装备 / 名字本身 |
| 处理中、请求中 | 具体动作：正在出航… / 正在学习… |
| 已解析、服务端、客户端、配置 | 删掉 |
| 难度修正、额外难度、准入等级 | 推荐 Lv 40 |

数字编号的层级（“5 · 深渊 5”）改为有名字或罗马数字（深渊 II）。

## 4. 字数上限

| 位置 | 上限 |
|---|---|
| 按钮 | 6 字（含图标外文字） |
| HUD 引导一行 | 14 字 |
| Toast 提示 | 18 字 |
| 状态标签（已击败、待挑战） | 4 字 |
| 结算页原因主句 | 20 字 |
| 结算页建议 | 最多 3 条，每条为按钮 |
| 装备/技能一句话说明 | 30 字 |
| 选项卡说明（世界层级、难度） | 主句 16 字 + 可展开详情 |

超出时删信息，不缩字号。

## 5. 数字换成图形

| 信息 | 用什么表达 |
|---|---|
| 难度 / 风险 | 危险 ★1–5（红色骷髅或火焰） |
| 奖励幅度 | 奖励 ★1–5（金色宝箱） |
| 属性变化 | ▲绿 / ▼红 + 差值；总评用一个标签：更强 / 更偏续航 / 更偏输出 / 较弱 |
| 进度 | 进度条 + x/y，旁边一句“哪里掉” |
| 死因 | 敌人头像 + 招式名 + 伤害数字 |
| 锁定 | 锁图标 + 一句解锁条件（“击败雾铃岛首领”） |

精确数值可以保留，但只能放在“详情”折叠区或 Tooltip 第二行，不能是主文案。

## 6. 自动检查

- 新增测试：扫描客户端源码中的中文字符串字面量与 `config/json` 中玩家可见字段，命中 §3 禁用词即失败（允许用白名单文件登记确需保留的专有名词，例如怪物名中恰好含“阶段”）。
- 按钮、HUD 引导、Toast 超出 §4 上限时给出警告列表。
- 文案改动仍走配置表（任务/NPC/对白）或代码常量的唯一来源，不在页面里另写一份。
