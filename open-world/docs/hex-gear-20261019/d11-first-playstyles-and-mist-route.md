# HEX-D11 首发四种打法 + 雾铃岛获取与挑战路线

> 版本：D11-1（2026-10-20，Claude 总策划，默认裁决）。回应评审：先证明玩家会为两件装备改变走位、技能选择或目标顺序，再扩大内容批次。
> 规则语义以 [d10](d10-rules-rulings.md) 为准；机制原文见 d03 / d06 / d07；文案模板见 d08。
> 本文只选**首发 8 种机制**，全部属于“无需新能力”批次（B03-0、B03-5a），Codex 现在就能落地；第二波招牌机制等共享能力验收后按 §6 追加。

## 1. 为什么这样选

- 评审指出：设计池 96 种是上限，**首轮应围绕不同的玩家行为组织**，而不是铺更多特效。
- 首发只做 **4 种打法 × 每种 2 件 = 8 种机制**，每种只开放 common / magic 两档（对应玩家 Lv10–15 的雾铃岛）。品质差异靠 rare / legendary 的“附加行为 / 质变”，后面的岛再放。
- 每种打法必须同时给出：**玩家因此做什么不同的事**、**必须承担的取舍**、**获得后和获得前的玩法差别**。三项写不出来的机制不进首发。

## 2. 四种打法

| 打法标签 | 首发两件（机制 id） | 玩家因此做的不同事 | 必须承担的取舍 | 前置 |
|---|---|---|---|---|
| **贴身绞杀** | A6 虚空裂隙、A2 余震裂地 | 把怪群拉进脚下的裂隙再打；围着同一个目标连续命中来凑余震 | 必须待在怪群里，受击多；裂隙放在原地不跟随，走开就没收益 | 无 |
| **先铺后炸** | S1 引爆印记、E-S3 印记接力 | 先用技能挂印 / 挂持续伤害，再换普攻去收；决定“先挂谁” | 对没有印记、没有持续伤害的目标收益很低；爆发要先准备，不能无脑按 | `dot-source`（S1 才需要；E-S3 无前置） |
| **穿行续战** | E-M3 行路回春、E-D3 控场成盾 | 持续移动、绕圈、先控住再贴近；不再站桩 | 站着不动几乎没有收益；没有控制技能时 E-D3 不会掉 | `control-source`（E-D3） |
| **节奏接力** | E-A5 技攻接力、E-A4 蜂群齐射 | 技能和普攻交替打，不连放同一类；把技能留给蜂群蓄满的时机 | 连续放技能 / 只普攻都会掉收益；节奏被打断就空转 | 无 |

两件同打法穿上时，另算 **对子共鸣**（d03 的 X2，强度 +10%，首发只给同打法对子，按打法标签判定，不按类别），用来让“成套”被感知到；不同打法混搭不加成也不惩罚。

### 2.1 获得后你会怎么玩（逐件）

| 机制 | 获得前 | 获得后 | 你会感觉到 |
|---|---|---|---|
| A6 虚空裂隙 | 站着放技能打 | 每 10 秒会在脚下留一道 3 秒的缝；你开始把怪往缝里带 | “怪在缝里掉血，我得别走太远” |
| A2 余震裂地 | 随便点目标 | 每第 5 次命中同目标引发震裂；你会咬住一只打 | “别乱换目标，凑够 5 下” |
| S1 引爆印记 | 持续伤害慢慢磨 | 命中带异常的目标会引爆它；你先挂燎原 / 流血再补一下 | “先点火，再引爆” |
| E-S3 印记接力 | 技能普攻混着用 | 技能命中挂印，普攻命中收印并缩短随机技能冷却 | “技能是上膛，普攻是扳机” |
| E-M3 行路回春 | 站桩 | 每走 10 格回 1% 生命；你开始绕着怪走 | “动起来就在回血” |
| E-D3 控场成盾 | 控制只是控制 | 控住敌人的瞬间得护盾；你更愿意先控再近身 | “控场不只是保命，还是开场” |
| E-A5 技攻接力 | 连放技能 | 施法后下一次普攻 +30%，命中后下一次施法 +20%；你开始交替 | “出手有节拍” |
| E-A4 蜂群齐射 | 技能随时放 | 每 8 秒蓄一次，下次技能命中放出蜂群；你会等蓄满再放大招 | “这一发技能要留着” |

## 3. 开放节奏：品质对应岛屿

按现有节奏目标（`pacing-targets`）：风栖首领 Lv7、雾铃首领 Lv14、赤炉首领 Lv21、霜镜首领 Lv26。装备门槛 10 / 15 / 20 / 25 因此**刚好一座岛一档**：

| 岛 | 玩家等级带 | HEX 开放内容 |
|---|---|---|
| 风栖 | 1–8 | 不开放（预告对白可有，不给装备） |
| **雾铃（首发岛）** | 8–15 | 槽 1（Lv10 任务）、common（Lv10 起可穿）、magic（Lv15 起可穿，首领掉三选一）、槽 2（击败首领后） |
| 赤炉 | 16–21 | rare（Lv20）、第二波招牌机制 |
| 霜镜 | 22–26 | legendary（Lv25）、召唤石后 K4 等前置机制 |

- 槽位解锁正式定为：**槽 1 = 雾铃 z2 任务（Lv10）；槽 2 = 雾铃首领击败后回港**。这替代 d02 的“样板阶段两槽默认开放”。
- 掉落品质不超前（d10 7.1）：Lv8–9 的玩家理论上能掉 common，但**掉落在“海克斯回响”任务接取后才开启**，避免有掉落没槽位。

## 4. 雾铃岛路线：选活动 → 战斗 → 有用奖励 → 调整构筑 → 首领 → 下一站

雾铃岛现有结构：6 个区（Lv8–9 渡口、10–12 林道、9–11 邮站谷、12–13 步道、13–14 溪谷、14–15 军需营）、3 个地城入口（field-mist-1/2/3）、2 个稀有精英（独铃织网者 z3、失邮苔壳 z5）、每区一个野外事件（守住 / 清退 / 怪潮）、首领军需平台（Lv14）。

| 步 | 时点（等级） | 玩家做什么 | 得到什么 | 玩法变化 |
|---|---|---|---|---|
| ① 试穿 | z2，Lv10 | 接 HEX 任务线第 1 条，完成“邮路林道清退侵军”（现有 waves 事件） | 槽 1 + **四选一 common**（四种打法各一件，卡片写打法标签和“适合谁”） | 第一次**选打法**，不是选数值 |
| ② 追第二件 | z3–z5，Lv9–14 | 去三个地城入口和两个稀有精英追同打法的另一件 | 倾向掉落（见 4.1） | 开始为同一打法找搭档；换一个目标顺序 / 走位习惯 |
| ③ 调整构筑 | 任意回港 / 营地 | 换装、看结算页的“触发次数 / 贡献占比” | 知道哪件在干活 | 保留还是换打法 |
| ④ 首领 | z6 军需平台，Lv14 | 击败首领 | **魔法品质三选一（三件来自不同打法）** + 槽 2 | 第二次选打法，这次能凑对子共鸣 |
| ⑤ 下一站 | 回港 | 铜铃说明嬗变台；青芒来信点名玩家的打法；航图出现赤炉 | rare 门槛预告（Lv20） | 为赤炉的 rare 准备 |

### 4.1 获取表（五问）

| 问题 | 首发答案 |
|---|---|
| 什么阶段遇到？ | Lv10 起，雾铃 z2 任务给第一件；之后随机掉落；首领三选一 |
| 当时有触发它的系统吗？ | 有。首发 8 件只依赖普攻、技能、持续伤害、控制；`dot-source` / `control-source` 不满足时不掉（d10 7.2）；K 系 / 绑定类不在首发 |
| 去哪里追第二件？ | 地城入口倾向：**入口 1（z1）→ 贴身绞杀**；**入口 2（z3）→ 先铺后炸**；**入口 3（z5）→ 穿行续战 + 节奏接力**。稀有精英：独铃织网者（织网）→ 先铺后炸，失邮苔壳（硬壳）→ 穿行续战。倾向＝对应机制权重 ×3（不排他） |
| 重复掉落有什么价值？ | 分解为回响碎片；嬗变台（赤炉前由铜铃开放）3 换 1 并可指定打法倾向；同打法第二件还能凑对子共鸣，所以“第二件相同机制”不是废品 |
| 怎么知道适合自己？ | 提示里的打法标签与“适合谁”；缺前置时红字说明缺什么；结算页显示该件本场触发次数与贡献占比 |

掉落来源与初值（只定量级，一次推导）：

| 来源 | common | magic | 备注 |
|---|---|---|---|
| 野外普通怪 | 0 | 0 | 不掉 |
| 野外精英（营地） | 2.5% | 0 | |
| 事件完成（守住 / 清退 / 怪潮） | 6% | 0 | 保底每事件首次 1 件概率翻倍 |
| 地城场地宝箱 | 10% | 0 | 按入口倾向 |
| 地城深处首领 | 保底 1 | 玩家 Lv≥13 起 25% 升 magic | 保底件按入口倾向 |
| 稀有精英 | 保底 1 | Lv≥13 起 40% 升 magic | 按精英倾向 |
| 军需平台首领 | — | **三选一 magic**（三种不同打法） | 首次击败必给 |

目标量级：整座雾铃岛（含重复）获得 **6–10 件**，玩家**至少凑成一对同打法**的概率 ≥ 60%（Codex 用掉落模拟跑一次验证，不通过则调倾向权重，不加掉率）。

## 5. 首领对打法的要求

军需平台沿用现有技能，不新增首领技能；要求现有技能映射到两个阶段，让**四种打法各有一段舒服、一段难受**：

| 阶段 | 压力 | 偏好 |
|---|---|---|
| 阶段 1（杂兵潮） | 持续涌出小怪 | 贴身绞杀、先铺后炸清群舒服；节奏接力难一点 |
| 阶段 2（首领冲刺 + 地面预警） | 需要移动躲避 | 穿行续战、节奏接力舒服；贴身绞杀难一点 |

做不到就登记缺口，不为此硬改首领。

## 7. 验证：先证明“玩家会改变玩法”

1. **客观指标**（每打法 2 件，在雾铃 z3–z5 基准战斗对比“无 HEX”）：
   - 触发条件达成率：70%–95% 的战斗里触发 ≥3 次（低于 70% 太难感知，高于 95% 等于无条件）。
   - 贡献占比：单件 8%–16%（对应 common / magic 的 d05 目标），两件同打法 ≤ 30%。
   - 击杀速度提升 ≤ 30%，不破坏雾铃节奏目标。
2. **主观清单**（用户试玩 10 分钟，每打法答“是 / 否”）：
   - 为了触发它，我是否改变了走位？
   - 我是否改变了技能释放顺序或留技能？
   - 我是否改变了先打谁？
   - 换成另一种打法后，上述行为是否不同？
   四种打法里**至少 3 种**对至少 2 个问题答“是”才算过；过了再放第二波，不过先调设计，不加内容。
3. 数据来源：战斗复盘（触发次数 / 贡献）、自动驾驶日志的触发统计；人工手感只做上述 10 分钟，不做长时间。

## 8. 命名与叙事要求

- **名称**用 d08（2–5 字）；每件新增一行 **`flavor` 来历**（灰字，≤28 字，物件感，绑定雾铃“邮路 / 信 / 迷雾”主题）。`hex-runes.json` 增加可选字段 `flavor`（缺省不显示）。
- **效果说明**句式固定：`触发 → 结果；限制`，冷却 / 上限 / 对精英无效等限制必须写在同一句里。

| 机制 | flavor |
|---|---|
| 虚空裂隙 | 邮路上有一道缝，寄进去的信再没回来过。 |
| 余震裂地 | 驿道石板被马蹄敲了一整年，终于松了。 |
| 引爆印记 | 火漆封口，一捏就烧。 |
| 印记接力 | 先盖章，后收件，一环扣一环。 |
| 行路回春 | 送信人的老话：脚不停，气就不断。 |
| 控场成盾 | 拦路的人站稳了，自己也就稳了。 |
| 技攻接力 | 一封一封接着送，别在驿站停。 |
| 蜂群齐射 | 蜂箱里的信号，等蓄满再放。 |

- **HEX 任务线**（雾铃，写进任务表，三条，须兑现承诺且体现玩家改变）：
  1. **「旧信上的六角印」**（青芒，z2）：承诺“把这批信的印记搞清楚再送”；给出线索，玩家完成清退侵军，得槽 1 与四选一 common。青芒口吻：轻快守信，对危险诚实。
  2. **「印记的主人」**（铜铃，港口）：铜铃用零件解释六角印是什么、槽怎么配、碎片和嬗变台怎么回收；不用堆砌术语。承诺“槽 2 等你带回首领的印”。
  3. **「寄往下一站」**（青芒，击败军需平台后）：来信点名玩家当前的打法（如“你选了先铺后炸，难怪那些侵军的信封全是糊的”），兑现第 1 条的承诺，附 rare 门槛预告。
- 以上三条文案落表前先交用户过目（沿用对白样板规则：第一章为样板，HEX 线新写，不改旧对白）。

## 9. 给 Codex 的落地清单（只含首发）

1. `hex-runes.json`：8 种机制 × common / magic = 16 条；名称与描述用 d08，门槛 10 / 15；增加可选 `playstyle`（打法标签）、`prereq`（前置标签）、`flavor` 字段（缺省兼容旧条目）。
2. 掉落：按 §4.1 的来源 / 倾向 / 前置过滤 / 品质不超前（d10 7）；“海克斯回响”任务接取后才开启掉落；掉落模拟跑一次验证“至少一对”的概率。
3. 槽位：槽 1 = 任务 HEX-Q01 完成（Lv10）；槽 2 = 雾铃首领击败后；军需平台首次击败给三选一 magic（三种不同打法）。
4. 生命周期与组合：d10 第 2、5 节（战斗 / 出战 / 冷却账本、互斥组、钳制）。
5. 对子共鸣：同打法两件 +10%（只首发 8 件）。
6. 结算页数据：每件 HEX 触发次数与贡献占比（复用战斗复盘）。
