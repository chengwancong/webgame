# HEX-D08 游戏内文案（名称 / 概念句 / 品质描述模板）

> 版本：D08-1（2026-10-20，Claude 总策划）。范围：首批铺量 B03-5a / B03-7a 的 29 种；D08-2 追加 D03 剩余的控制/位移/资源/联动补全（G–J，共 29 种，B03-1～4）。其余机制随各批次追加到本文件。
> 用法（Codex 落地）：`name`、`description` 直接写入 `hex-runes.json` 顶层；每个品质的规则 `description` 用下表模板，`{…}` 由参数生成（数值取自规则字段，百分比取整，时间写秒）。**不得出现原作英雄、技能、符文名**。
> 文风：沿用《深渊行者》中文短句，一句话说清“什么时候 → 发生什么”，不写“造成伤害提高”之类空话；数值一律用阿拉伯数字。
> 模板记号：C/M = 普通/魔法（只换数值）；R = 稀有起新增的一句；L = 传说起新增的一句（累加在 R 之后）。

## 校对规则（Claude 验收用）

1. 名称 2–5 字，同一类别内不重名，不与现有装备、技能、威能名重名（名称唯一校验由内容构建负责）。
2. 概念句 ≤ 24 字，不含数值；规则描述每句 ≤ 40 字，数值来自参数，改数值不改文案。
3. “R：”“L：”各自成句，品质提示在悬浮提示里自动加“稀有起：”“传说起：”前缀，模板文本里不重复写前缀。
4. 同一术语全篇一致：灵力（不写魔法值）、冷却、护盾、控制、印记、层。
