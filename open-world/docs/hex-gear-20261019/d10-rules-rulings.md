# HEX-D10 统一规则裁定（语义 / 生命周期 / 组合预算 / 传说原则 / 获取资格）

> 版本：D10-1（2026-10-20，Claude 总策划，默认裁决，Codex 直接按此落地，不退回设计问题）。
> 来源：外部评审指出 d06–d08 存在语义歧义、传说取消取舍、组合无预算、获取顺序缺失。逐条核对后成立，本文是**唯一规则源**：d03–d08 与本文冲突时以本文为准，文案（d08）再从规则生成。
> 单件强度仍按 d05 定档（common≈10% / magic≈14% / rare≈20% / legendary≈25%）；本文只补“怎样算”和“怎样组合不坏”。

## 1. 作用域术语（全库统一，“本场”一词停用）

| 术语 | 定义 | 清零时机 |
|---|---|---|
| **战斗** | 野外：从第一次敌我互相造成伤害起，到 8 秒无敌对伤害（脱战）止；副本 / 巢穴 / 首领图：整个场地（stage）或整个巢穴位面算一场，场内不因脱战重置，进入下一场地算新一场 | 脱战、换场地、死亡、回营 / 回港 |
| **出战** | 一次副本实例或巢穴位面；野外则指离开营地 / 港口到下次回营或死亡 | 实例结算、死亡、回营 / 回港 |
| **冷却账本** | 角色级、按机制 slug 记录“最近一次触发时刻”和“保命类最近触发时刻”，**不随换装、换图、脱战清零** | 只在**死亡复活**时清零（死亡本身已是代价） |

文案里的“本场”一律对应“战斗”；需要按出战计的，条目必须写“本次出战”。

## 2. 生命周期矩阵（状态在各事件下的去留）

| 状态类型 | 死亡复活 | 卸下 / 换装 | 断线重连 | 进入下一场地 | 回营 / 回港 |
|---|---|---|---|---|---|
| 战斗内叠层 / 增益（暴风收割层、灵魂、吞噬、怒气…） | 清零 | 该机制的叠层立即移除，**重新穿上不恢复** | 保留（战斗快照） | 清零 | 清零 |
| 临时机制（星卡额外机制、混沌嬗变抽中的套案） | 清零 | 来源机制卸下则同时移除 | 保留，且抽取序号不重置（见 4） | 清零，新场地重新触发开局规则 | 清零 |
| 保命 / 无敌 / 强效触发的冷却 | 清零 | **保留（账本）**，换装不能洗冷却 | 保留 | 保留 | 保留 |
| 拾取物（星卡、铁砧、魂火、灵果） | 清除 | 已拾取的收益随机制移除，地上的拾取物清除 | 保留（服务端实体） | 清除 | 清除 |
| 环绕体 / 召唤体 / 投掷物 / 场地 | 清除 | 立即清除 | 保留 | 清除 | 清除 |
| 印记 / 标记 / 暴露（挂在敌人身上） | 清除 | 立即清除 | 保留 | 清除 | 清除 |
| 内部冷却（ICD） | 清零 | 保留（账本） | 保留 | 保留 | 保留 |
| 倒下计数（K3，仅副本救援 / 复活 / 保命触发累计） | 副本内保留，野外不累计 | 保留 | 保留 | 保留 | 本次出战结束清零 |

- 战斗中允许换装，但按上表执行；服务端不另设“战斗中禁止换装”。
- 所有随机抽取用“战斗种子 + 抽取序号”，抽取序号写入战斗快照，**断线重连、重放回放都得到同样结果**，不能靠重连重抽。

## 3. 取值时点与口径

1. **击杀类低血判定**（黑暗收割 H7、先手之利 H10 的反面等）：取致命一击**结算前一刻**的目标生命比例。“击杀生命低于 50% 的敌人”＝致命一击前该敌人生命比例 < 50%；一击秒杀满血怪**不算**。
2. **受击类阈值**（hurt / low_hp：生命涌泉、死之舞、绝境意志等）：取**受击结算后**的自身生命比例，且结算后生命 > 0（致命伤害走 lethal 触发，不走 hurt）。
3. **“X% maxHp”的归属**：写“maxHp”默认指**施放者自身**；指向目标的必须写“目标最大生命”。逐条裁定：
   - H3 不死之握：额外伤害 = **目标最大生命** × 4/5/6/8%；回复 = **自身** 2% maxHp；本场 maxHp +1% 为**自身**。
   - P2 三击破甲、P3 无畏之魂、E-A2 天罚信标：伤害按**目标最大生命**；回复（P3 的 30%）按**该次伤害**计。
   - 目标最大生命比例伤害：精英、首领统一上限 **attack×3**（E-A2 对首领 attack×4、P2 精英 ×0.5 上限 attack×2 保持原写法）；普通怪不封顶（其生命低，自然很小）。
4. **hit / cast 的来源分类**沿用 d05 第 3 节：普攻 `basic`、技能 `cast`、其余间接伤害 `proc`，`proc` 不触发“普攻命中 / 技能命中”类规则。
5. **“每场一次”字样停用**：保命类统一用**冷却**表达（见 5.1），其它一次性效果写“每次战斗一次”并以战斗为单位清零。

## 4. 抽取与保留规则（星卡 K1、混沌嬗变 E-S4）

- **保留“上一条 50%”仅指紧邻的上一代，不累计**：抽到第 N 条时，第 N−1 条保留 50% 强度，第 N−2 条及更早的丢弃。任意时刻最多存在“当前一条 + 上一代一条”。
- “50% 强度”＝数值参数 ×0.5（概率、层数上限向下取整且不低于 1；持续时间、触发间隔不变）。
- **抽取池排除**：K 系全部、E-S4、E-S2 夺词缀（抽取 / 夺取类不套娃）、已装备的机制、当前正持有的临时机制、依赖未满足前置的机制（见 7.2）。同品质优先；池为空时本次抽取作废并返还收集进度。
- 抽中带 `combat_start` 的机制：抽中瞬间立即触发一次开局效果。
- 临时机制是否记入“已持有”：记入，避免与装备的正式机制重复。

## 5. 组合预算（防止“近乎不死 / 资源无限 / 技能不停”）

单件预算见 d05；本节约束**多件叠加**。

### 5.1 互斥组与共享冷却

| 组 | 成员 | 规则 |
|---|---|---|
| `lethal-save` 保命 | D3 不屈、E-D1 向死而生、E-D2 逃生舱、P5 怒气不死（保命分支）、K3 逆境之歌（传说保命分支） | 同组不可双装；保命类触发的最小冷却统一为 **120 秒**（账本记录），已有更长冷却的保持原值 |
| `invuln` 无敌 | E-M2 死之舞、E-D2 逃生舱、M6 幻影换位传说、E-C2 斥力环传说 | 同组**可双装但共享 20 秒冷却**；单次无敌（含延长）≤ **8 秒** |
| `cooldown-reset` 重置 | R3 灵力回路传说、E-R2 周期重置、R5 免费咏唱、R6 终结返还、K2 终章 | 同一时刻两件同时生效时，第二件的“重置 / 返还”效果 ×0.5（向下取整） |

### 5.2 全局钳制（模拟层硬上限，一次定档）

| 项 | 上限 |
|---|---|
| 来自 HEX 的冷却缩减合计 | 不超过 **40%**（与装备、天赋来源合计另有总上限，沿用现规则） |
| 来自 HEX 的减伤合计 | 不超过 **35%**（与装备护甲分乘区，不叠加进护甲公式） |
| 来自 HEX 的回复（回血 + 吸血 + 护盾折算）稳态 | 不超过**每秒 8% 最大生命** |
| 来自 HEX 的伤害乘区 | 单乘区合计不超过 **+60%**，两槽满配沿用 d05 的约 +50% 目标 |
| 来自 HEX 的灵力返还稳态 | 不超过当前灵力消耗速度的 **60%** |

### 5.3 高危对子清单（验证只跑这些，不做全组合扫描）

按“一次推导 + 一次验证”：只验证下列对子，在基准战斗里两槽满配，判据＝**存活时间提升 ≤ +60%、击杀速度提升 ≤ +50%、5 分钟压力战无零死亡**。

4. 死之舞 E-M2 + 逃生舱 E-D2（无敌覆盖）
5. 行路回春 E-M3 + 灵果 E-M4 + 拾魂 P9（走位叠回复）
6. 暴风收割 A5 + 觉醒试炼 E-R4 + 无尽吞噬 P10（伤害乘区）

## 6. 传说品质原则与修订

**原则**：传说强化“原玩法的回报”，**不取消原来的代价或判断**；任何无敌 / 保命 / 重置类传说必须有**总量上限**。传说不是“风险装备变成穿上就好”。

逐项修订（落到 d06 / d07 / d08 对应行）：

| 机制 | 原传说 | 修订 |
|---|---|---|
| E-M2 死之舞 | 无惩罚，每击杀延长无敌 1s | **保留惩罚**（基础失败损失 50% 当前生命；rare 减半为 25%；legendary 仍为 25%，不取消）；每击杀延长无敌 **0.5s**，单次触发总无敌上限 **8s**（基础 5s + 最多 3s）；5s 内击杀 ≥3 个视为成功：立即回复 15% maxHp，并把本机制冷却从 90s 缩为 45s |
| K3 逆境之歌 | 第 3 层倒下不清除，回复 40% maxHp | 回复 40% 需受 `lethal-save` 共享 120s 冷却约束；倒下后伤害层数保留至本次出战结束（原“每场 1 次”改冷却） |
| P5 怒气不死 | 保命期间攻击全暴击 | 保命走 `lethal-save` 120s；全暴击持续 3s 不延长 |
| E-D1 向死而生 | 100% 生命回复 | 回血后 8s 流血保留，传说仅“8s 内击杀 ≥2 个”的奖励回复 20%→30%，不取消流血 |
| D3 不屈 | 冷却条件 3s 内击杀 3 个减半 | 减半后最小 60s，不低于 `lethal-save` 下限的一半 |
| R3 / R5 / E-R2 | 清冷却 / 免费施法 / 重置 | 受 5.1 `cooldown-reset` 与 5.2 钳制约束 |

## 7. 获取资格与掉落规则

### 7.1 品质不超前

HEX 掉落品质上限 ＝ 玩家**当前等级 +2** 所能穿戴的最高品质（门槛 10/15/20/25）。来源决定品质分布，资格决定上限，**不掉穿不了的东西**。掉落时服务端按玩家等级判定；首次引导获得的那一件不受随机影响（见 d11）。

### 7.2 前置过滤

机制带前置标签，玩家不满足时**该机制在掉落抽取中权重为 0**（不是“掉了也穿不了”）：

| 前置标签 | 满足条件 | 影响的机制 |
|---|---|---|
| `dot-source` 持续伤害来源 | 当前技能库含 burn / poison / bleed 来源，或已装备能施加它们的 HEX | S1 引爆印记、E-R3、P1（P1 自带流血则免前置） |
| `control-source` 控制来源 | 技能库含 stun / freeze / fear / knockdown / root 来源 | E-D3 控场成盾、E-C2 |
| `summon-source` 召唤 / 宠物来源 | 拥有宠物或召唤石（霜镜岛后）或已装备召唤类 HEX | K4 助攻分红、H8 微光雀灵联动项 |
| `bound-skill` 绑定技能 | 必有（装备时玩家选一个技能槽绑定，N25） | K6、AB1–AB4 |
| `crit-source` | 暴击率 ≥ 5% | P5、A3 碎星弹幕 |

### 7.3 助攻分红 K4 的具体弱版本

- 有宠物 / 召唤物 / 队友时：按 d07 原文。
- **无上述来源时 K4 不进入掉落池**（前置 `summon-source`）。已持有但失去来源（宠物移除）的玩家：K4 退化为“你的**间接伤害**（持续伤害、场地、环绕体、标记引爆）在目标被击杀前 5 秒内造成过伤害，且最终击杀者是你的另一条伤害来源时，视为助攻，触发击杀类资源的 50%”；仍无此类来源则不触发，装备栏显示“当前没有可助攻的来源”灰字，**不隐藏、不报错**。

### 7.4 玩家看得懂、找得到

- 每件 HEX 的提示增加两行：**打法标签**（见 d11）与**适合谁 / 当前是否满足前置**（不满足时红字说明缺什么）。
- 重复掉落：分解得“回响碎片”，并可在拾星港**嬗变台**（d06 第 5 节，3 件同品质换 1 件同品质、可指定打法倾向）回收，不浪费。
- 战斗结算页显示每件 HEX 本场触发次数与贡献占比（复用战斗复盘 / 伤害拆解），让玩家知道“它到底干了什么”。
