# HEX-D05 定档与裁决（Claude 总策划，2026-10-20，默认裁决，Codex 直接按此落地，不退回设计问题）

## 1. D3 不屈：魔法品质治疗顺序
保命触发（HP 置 1）后，**同一规则内立即**结算 heal（先置 1 再治疗），不等下一 tick；免死窗口 2s 从置 1 时刻起算。

## 2. A2/S1 TTK 定档（推导一次）
推导口径：HEX 单条的期望输出贡献，以“单体基础普攻伤害=1.0”衡量，目标 common≈10% / magic≈14% / rare≈20% / legendary≈25%（上限 25%，两槽叠满≤约 +50%，低于一次技能构筑差距，不改变 TTK 基线）。
- **A2 余震裂地**（nth 5/5/4/4，nova ratio 0.6/0.7/0.8/0.9，半径 2.5）：单体每次命中均摊 0.12/0.14/0.20/0.225；群怪 2–3 目标时 0.24–0.67，属范围收益，定档**采用原值不改**。legendary 半径 3.25、ratio 1.05（D04）→ 均摊 0.26，略超 25% 上限但仅群怪成立，接受。
- **S1 引爆印记**（hit ICD 180，detonate 目标自身剩余 DOT 预算×0.5/0.6/0.8/1.0；rare 起 remove=true 且×1.5；legendary 半径 3 邻居各用自己预算）：本质是把 DOT 提前兑现，净增益最多为“预算×(ratio−1)”不会凭空放大（remove=true 时消耗预算）。定档：common/magic ratio ≤1 不消耗（纯增量 +50%/+60%），rare 0.8×1.5=1.2 已按 D04 定为 0.8×1.5=1.2、legendary 1.0×1.5=1.5，**采用 D04，不再改**。ICD 保持 180t 防止无限兑现。
- 验收口径：每品质单独断言 effect_triggered 次数与伤害量（容差 ±1%）。

## 3. B05 未明项裁决
- **普攻/技能权威分类**：以技能表为准：`skillSlot 0`（基础攻击/武器普攻）= 普攻 `basic`；其余槽位及 HEX 赠技的主动释放 = 技能 `cast`；HEX/field/DOT 的间接伤害不算二者（来源 `proc`），不得触发“普攻/技能命中”类规则，避免递归。
- **E-D3 控场成盾**：护盾持续 8s（超时消失），可被新一次覆盖取较大值；“控制类状态”集合 = freeze、stun、fear、petrify、knockdown（击倒）、root；slow/silence/vulnerable 不算。
- **E-M3 行路回春**：legendary 溢出转护盾上限 = 12% maxHp，护盾持续 6s，不叠加（取较大）。
- **夺词缀 E-S2 映射补全**：teleport（瞬移）→ 自身获得 8s 内移速 +20% 且受击后 8% 概率闪现 3 格；summon_minions（召唤）→ 获得 1 个存活 20s 的小跟随体，造成 0.15 attack/秒（无跟随体能力时降级为攻击 +8%，在回执注明）。其余沿用 D06 3.2 的映射（swift→攻击速度 +15%、shielded→8% 护盾、frost_nova→攻击附 slow、fire_trail→移动留灼烧轨迹 0.1 attack/秒）。

## 4. N3–N6 精确规格（P2/P3，不阻塞）
- **N3 嘲讽诱饵（decoy）**：在原地生成不可被选为目标的诱饵实体，持续 T 秒（D02=3s），范围 8 内非 boss 敌人将其视为优先目标；诱饵不受伤、不阻挡移动。
- **N4 清除控制（cleanse）**：移除自身全部 control 类状态（集合同 E-D3）并给予 0.5s 控制免疫。
- **N5 移速加成 buff**：statMod moveSpeed ×(1+x)，持续秒数由规则给出，不叠加取较大。
- **N6 复制命中触发（replay-on-hit）**：复制一次 on-hit 类规则，复制出的触发 `chain depth+1`，depth>=1 时不再复制（禁止递归）。
