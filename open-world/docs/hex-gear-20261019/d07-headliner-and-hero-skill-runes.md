# HEX-D07 战绩乐团系 + 英雄技能/被动符文化（4.0 补充）

> 版本：D07-1（2026-10-20，Claude 总策划，Claude 默认裁决，不需用户确认）
> 起因：用户指出还应包含海克斯大乱斗 4.0 的 K/DA 相关（乐团机制），以及把原有英雄的技能、被动做成符文。本稿接 D03（36 基础款）、D06（26 奇趣款），再增 **34 种**，合计 **96 种 × 4 品质 = 384 条**。
> 取舍原则：**借机制形状，不借名字**。游戏内名称、描述、图标一律原创，不得出现原作英雄名、技能名、符文名；本文“灵感”列只用于设计追溯，不进游戏文案。

## 0. 调研来源与结论（2026-10-20 查阅）

- ARAM Mayhem 4.0「Journey to Stardom」（补丁 26.21，2026-10-21 上线）：[4.0 预览](https://arammayhem.com/articles/aram-mayhem-4-0/)、[PBE 预览](https://aramgg.com/en/blog/aram-mayhem-4-0-pbe-preview)、[Season 3 新增强化](https://hexgate.app/blog/aram-mayhem-season-3/)。
- 4.0 新增 8 个“乐团（Headliner）”，每局一个，作为全局规则修正：**K/DA**（定期收到粉丝星卡，集齐一套获得额外强化）、**True Damage**（多杀/终结/拆塔让小兵掉落铁砧，全队受益）、**HEARTSTEEL**（强化被贴纸标记后额外加成）、**Pentakill**（开局强化一个基础技能，18 级再强化第二个）、**Cafe Cuties**（生命遗物回复更多并短暂加速）、**Command Line**（首次重抽同时提升稀有度）、**Space Groove**（全队跳舞攒迪斯科球，触发全员奖励）、**The Bee Band**（蜂蜜回复 / 蜜蜂伤害的地图事件）。
- 能力强化（Ability Augments，26.12 起）：把强化绑定到**某一个技能**——多重施放、三连弹、连锁反应、法术分裂、回响施放、汲取、针垫等 [能力强化说明](https://arammayhem.com/ability-augments/)、[设计师博客](https://www.leagueoflegends.com/en-us/news/dev/dev-augmentmaxxing-aram-mayhem/)。
- 竞技场里有大量“**赠送一个英雄技能 / 符文本体**”的强化（自动投斧、自动魔弹、分身戏法、象限斩、弹球、电击 + 相位、攻速三连击等）[竞技场强化列表](https://wiki.leagueoflegends.com/en-us/Arena_(League_of_Legends)/Augments)。

**结论与本作转译**：
1. 乐团机制本质是“**整场战斗的目标/收集/连击规则**”。本作没有队伍竞技，转译成**战绩类 HEX（K 系）**：星卡集齐开临时第三槽、连杀乐章、倒下后越战越勇、助攻分红、多杀铁砧、绑定共鸣。
2. 英雄技能/被动符文化 = 三种形状：**符文本体型（H）**（经典基石符文的触发形状）、**被动型（P）**（英雄被动的叠层/阈值形状）、**赠技型（G）**（HEX 自带一个自动施放的小技能，玩家半自动战斗天然适配）；再加 **技能强化型（AB）**（绑定到技能栏某一格）。
3. 36 + 26 + 34 = 96 种是**设计池**；上线按批次逐步放出，每批通过功能验收即发，不设一次性全量目标。

## 1. 通用规则（沿用 D03 第 0 节与 D06 第 1 节）

等级门槛 10/15/20/25；品质规则 common/magic 同行为强度梯度，rare 加附加行为，legendary 质变；不升品、不可强化、2 槽、同机制不可双装（U-01～U-07 不变）；数值上线前 TTK 推导一次。

新增约定：
- **本场状态**：标“本场”的层数/进度只在一次出战（野外一轮 / 一场副本）内有效，退出或结算即清空，不写档。
- **绑定技能**（AB 系与 K6）：默认绑定**技能栏第 1 格**的技能；legendary 额外绑定第 2 格。玩家改技能栏时绑定跟随格位，不跟随技能 id。
- **IP 约束**：名称原创；描述只写机制；图标走六角符记规范，不得使用原作图形。

能力标记同 D06：✅ 现有规则可表达（N0c 核验）；🔧 需新能力（第 3 节）；？需 Codex 核验是否已有。
