# 技能页统一 UI 与窄屏验收

2026-10-02。本页迁移保留已确认的 C 分组技能册、分类切页、桌面左侧技能与装配／右侧详情结构。没有角色形象，也没有修改激活、成长或资源规则。

## 当前实现

- `skills-panel.ts` 使用公共 `tabsHtml`、`statusBadgeHtml`、`resourceCostHtml`、`statRowHtml`、`buttonHtml` 与 `currencyIconHtml`。激活／升级是蓝色次操作，保存是杏金主操作；两者复用同一尺寸和忙碌状态。
- 本页 CSS 的颜色、字号、字重、间距、控件尺寸、描边与动效引用语义 Token；移除了整套 `book-*` 色板及专用按钮皮肤。
- 1280×720 等桌面保持双列分组技能册。900px 以下采用技能列表、装配、详情的纵向顺序，列表保留独立高度与内部滚动；375px 为单列技能卡，四个页签使用名称与计数上下排布。
- 图标始终有固定槽位，选中／悬浮／键盘焦点不改 padding、边框厚度或图形尺寸。长文在自己的详情区域滚动；大数值费用不拆断数字。
- 未激活仅显示激活；等级和技能书条件分开；已激活仅升级；满级没有下一档费用。缺失报价按待同步处理，不显示免费升级。恢复中禁用恢复按钮，待确认但未恢复时保留可用恢复入口。
- 保留 `skill-page-${category}` 和原动作 ID，与应用已有分类焦点和列表滚动恢复兼容。`presentation.ts` 由主代理额外保存 `.skill-book`、`.skill-detail-body`、`.skill-training` 的滚动位置。

## 2026-10-03 用户选定 A 完整上下对照

实机升级区采用“当前效果／升级后效果”，保留两份已解析技能的完整描述，并呈现伤害／回复／护盾、冷却、能量、距离、范围、前摇、持续时间以及可用的投射物、牵引参数。原来的单数值对比和“数值不变”推断已移除；文本中的机制变化仍完整展示，不因几个参数相同而隐藏。

描述文本按文字与数字对齐，所有变化的百分比、固定值、次数及新增／移除的数字均分别标记，保持未变化内容可读。当前效果中的变化用金色，升级后用绿色；已解析参数直接按字段比较。算法只处理文字对齐与呈现，不解析公式，也不重算成长或效果。颜色、字号与间距使用现有 Token。

升级消耗使用公共 `resourceCostHtml` 的 requirements 模式，仅显示资源名称和所需数量。每项资源分别判断：足够为亮色字，不足为红字；去掉持有量及重复“资源充足／金币还差”的可见文字，保留可访问状态。按钮是否可用仍遵守服务端报价和既有控制逻辑。

已有角色实机核对斩击 28 → 31、护身印 70 → 78，分类切换时详情框和装配位尺寸、坐标稳定。1280×720 短内容无额外滚动条，1024×576 保留内部滚动且费用与操作可见，375×812 可滚动查看完整对照、费用、升级和保存。复杂公式、条件变化、新增效果和“金币足够／灵石不足”的颜色通过同一数字渲染与公共成本组件的独立展示页核对。

技能、完整效果对比和公共组件共 15 项测试通过；隔离前端构建通过。全项目类型检查仍存在本轮未改动的 `tests/dungeon-instance.database.test.ts:26`、`:29` 两处可能为空错误。证据见 `../.design/skills-approved-a-20261003/`。没有修改成长、费用、玩家数据或服务启动方式。
