# 战斗接触与技能表现

2026-10-01。当前运行版本为客户端 0.6.1、资源 world-art-20261001-v5、规则 ow-7、协议7、数据库9。下述碰撞与首批表现验收保留历史记录；当前技能表现改为复用现成素材，见 [现成技能特效接入](skill-source-effects.md)。本批仅修改前端表现和资源，伤害、费用、前摇、冷却与成长公式保留服务端解析结果，渲染不写入战斗或持久状态。

## 当前行为

- 人物与存活怪物具有脚底身体范围，普通走动沿接触面滑动，自动移动在受阻时尝试侧绕。快速突进、冲撞、背刺逐段检查身体和墙体；倒地怪物不阻挡行走。
- 相同位置的出生单位按确定的方向分离。人物半径 0.55 格，普通怪物 0.55、精英 0.65、首领 0.9 格，由内容源 `bodyCollision` 统一配置。等距屏幕上的上半身遮挡仍由深度排序处理。
- 投射物对整个移动段求最早接触，按先后处理怪物、人物与墙体；非穿透攻击停在首个目标，穿透攻击对同一目标只命中一次。单体、范围和区域攻击核对墙体视线。
- 手动施法事件保留到下一逻辑帧；前摇完成才发出释放事件，真实命中事件携带技能 ID。怪物技能前摇使用 30 Hz 战斗时钟，随机选择使用战斗种子。野外本地暂停时不靠系统定时器继续攻击；服务端副本没有暂停，面板、后台和掉线仍持续推进同一战斗时钟，见 [副本生命周期](dungeon-lifecycle.md)。
- 技能表现独立消费释放、命中、投射物和区域状态：斩击弧、旋转刀光、箭矢拖尾、火焰、冰棱、护盾、治疗粒子、突进残迹和雷链。技能释放动作按战斗持续时间播放；新世界或场景切换时清理旧效果。
- 自动施法在安全前摇窗口内保持释放位置；必须躲避时继续移动。躲避方向筛选包含身体阻挡，不再依赖穿过首领才能接近目标。
- 修正第 4–6 章各两个墙内出生点，生成器同步避开障碍并保留身体余量，出生源 ID 不变。

## 验收入口

`tests/combat-collision.test.ts` 检查走动、冲撞、重叠出生、倒地单位、突进落点、窄墙、前摇、掠过命中、墙后目标和暂停。原自动战斗与首章首领路径继续回归。

`node tools/accept-combat-contact.mjs` 使用临时数据库与正式玩家入口，完成账号登录、服务端授权和荒原自动战斗，并采样身体接触距离；独立美术场景以相同 World 与 WorldScene 释放十个代表技能。验收场景只进入 QA 构建，不给玩家入口添加状态修改接口。

实机证据位于 `../../docs/reviews/open-world/combat-contact-20261001/`：`result.json`、`operations.webm`、技能截图与 `live-meadow.png`。截图证明外观，逻辑测试与实机距离采样证明碰撞；生成图不能代替这些证据。

## 范围与限制

2026-10-01 后续修订（客户端 0.4.2）：原始 Spine 的逐帧 `ProjectileInitNode`、`AttackedNode`、手部与武器数据已导出为 `hero-sockets.json`、`native-actor-sockets.json`。挂点按实际贴图帧、缩放与朝向映射，替代统一向上偏移；原始重击特效按前后图层恢复。地面释放效果保持落点，受击火花按目标图层排序，飞行效果从发射点向目标身体高度过渡。箭矢、火球、闪电与远程单体技能使用不同表现，不再全部画作同一种光弧。

原始攻击帧 9、重击帧 13 对齐战斗释放时刻，恢复阶段单独映射；不修改伤害、前摇、冷却或成长值。生成的章节角色缺少原始 Spine 数据时，按当前模型高度提供受击点回退，不假装已有骨骼数据。工具为 `export-hero-effect-attachments.mjs` 与 `pack-hero-native-effects.py`；测试见 `effect-attachments.test.ts`，实机证据位于 `../../docs/reviews/open-world/effect-attachments-20261001/`。

此次表现对应已实现的八类执行机制。扩展内容中“反弹、复活、沉默、吸引、持续旋转”等专属描述，仍需各自的规则与执行器，不能因加上动效就宣称机制已经实现。未调整激活方式、升级费用、伤害或奖励数值。

压力场景包含约 200 个怪物与 300 个投射物；软件渲染的无头浏览器数据不能作为原生 GPU 性能认证。身体查询复用空间网格，移动后同步网格，出生或发生重叠时才进行全群分离检查。
