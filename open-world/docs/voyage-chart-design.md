结论：「小副本」需要的执行能力（实例、目标、发奖、模式切换）**已经齐了**，54 个地城小场地可以直接用。真正缺的是**远航的节点玩法**，以及把小副本串成节奏的**岛屿页**。

## 1. 一句话

**出海是主线，登岛是一串小副本。**在航图上自己选航线出海，路上打节点、拿三选一增益；靠岸后，从岛屿页里挑几个 3–8 分钟的小副本打（剧情、地城、怪潮、狩猎、寻宝、采集），打完回港整理，**每次回港都开一项新东西**，再出海。

不再有「在大地图上走路找点」这件事。

## 2. 主循环

```
拾星港（整理、强化、开新功能）
   │
   ▼
出海：航图选航线，插残页 → 5–7 个节点（每打完一站选下一站）→ 靠岸
   │
   ▼
岛屿页：本岛的小副本入口（剧情线索、地城、本次轮换的活动小副本）
   │   挑 1–3 个打，每个 3–8 分钟
   ▼
回港（或从岛屿页直接再次出海）
```

一个数值心流「阶段」（每岛 3 个）大致是：

| 段 | 时长目标（第 1 岛 → 第 6 岛） | 内容 |
|---|---|---|
| 推进 | 4 → 12 分钟 | 出海一次 + 1 条剧情线索小副本 |
| 开荒 | 3–4 → 20–25 分钟（沿用数值心流） | 本阶段地城：入口 1、入口 2 掉钥匙，深处是墙 |
| 爽刷 | 12–14 → 47–57 分钟（沿用数值心流） | 近海航线、怪潮/狩猎小副本、重打地城入口 |
| 回港 | 1–2 分钟 | 开一项新功能（§7） |

## 3. 远航（主干）

### 3.1 一次远航

1. **出发**：在拾星港或岛屿页打开航图，选航线，可以插 0–2 张航图残页（§3.3）。
2. **航图**：节点按层排列，每层 2–3 个，节点之间有连线。当前层和下一层能看清类型与奖励图标，再往后只显示「?」。
3. **节点**：每个节点是一个小场地（礁石、甲板、浮岛），一场 30–90 秒的遭遇，复用战斗核心和副本模式切换。
4. **增益**：部分节点结束后给三选一（复用 90 个增益和重抽规则），只在本次航行生效，结算时收回，并标注为「受控授予」。
5. **船体耐久**：只在本次航行内有效，风暴和失败的节点会扣。归零就结束航行，**已结算节点的收益保留**，残页用掉（J2）。
6. **撤离**：只能在补给港撤离；正常结束就是靠岸登岛，或打完终点海兽首领。

### 3.2 节点（首批 7 种；新增同机制的节点只改内容源）

| 节点 | 玩法 | 主要奖励 | 复用 |
|---|---|---|---|
| 漂流礁 | 一波杂兵，割草 | 金币、材料 | 本岛怪物模板 |
| 暮界巡逻舰 | 甲板上 1–2 只精英 + 护卫 | 装备（偏稀有） | 精英词缀、精英铭牌 |
| 沉船 | 守卫，或限时开箱，开箱期间有怪潮 | 宝箱掉落 | 宝箱、守护目标 |
| 难民船 | 不战斗，2–3 个有代价的选项：分补给（扣耐久）换好节点；护送一站（难度↑、奖励↑）；接走情报（揭示后两层）；**听到传闻（解锁本岛一条剧情线索）** | 情报、残页、剧情线索 | 对话表 |
| 星潮风暴 | 限时生存，地面预警，撑过就前进两层 | 跳层、潮晶 | 地面危险、扩张填充预警 |
| 补给港 | 修船或拿一次增益；唯一能撤离的节点 | — | 三选一 |
| 终点 | 首航/阶段航线：靠岸登岛；近海/远洋：海兽首领 | 首领掉落 | 首领模板 |

生成规则：节点图由服务端私有种子生成，客户端只拿到已揭示的部分；首层不出风暴；每条航线至少 1 个补给港；相邻两层不连续出现同一种战斗节点。

### 3.3 航图残页

从首领、巡逻舰、难民船、远洋终点掉落。出发前插进航图，改变这次航线怎么生成，插进去就用掉。

| 残页（首批示例） | 效果 | 代价 |
|---|---|---|
| 暮界补给线 | 巡逻舰更多，必掉指定部位装备 | 精英多一条词缀 |
| 难民航道 | 难民船更多，多一个好选项 | 战斗节点怪更密 |
| 风暴海图 | 风暴更多，终点奖励高一档 | 船体耐久上限降低 |

定向刷靠残页，不用盲刷。

### 3.4 航线种类

| 航线 | 开启 | 层数 | 用途 |
|---|---|---|---|
| 首航 | 新岛满足远航条件 | 3 | 每座新岛第一次**必走一次**，以后可以直接传送（J1） |
| 近海 | 该岛首航完成 | 5 | 本岛等级段的爽刷主途径，可重复、可插残页 |
| 远洋 | 第 3 岛之后 | 7 | 跨岛混合怪物与掉落 |
| 深海 | 裂星潮之后 | 7 + 深度 | 终局推层，**噩梦挑战并入**，旧噩梦记录只读保留（J3） |

## 4. 野外小副本（衔接）

每个小副本都是一个独立实例：3–8 分钟，单一场地或 2–3 段，有明确目标；开始、结算、断线恢复都走副本生命周期，可以切手动/半自动/全自动。

| 类型 | 玩法 | 出现方式 | 奖励职责 | 复用 / 新增 |
|---|---|---|---|---|
| 剧情线索 | 本岛故事的一条线：调查、救援、守护、路线选择，最后一段带战斗 | 登岛或难民船传闻解锁，常驻 | 剧情、一次性奖励、指定部位稀有（每岛最多 3 件） | 复用剧情副本的目标执行；对白和剧情含义不动 |
| 汇合 + 首领 | 关键线索完成后出现；最后阶段刻片复苏，可放一次回响爆发 | 常驻 | 首领掉落、点亮刻片槽 | 复用首领模板、开场爆发规则 |
| 地城（墙） | 入口 1、入口 2 刷怪掉钥匙，深处是墙 | 常驻，按阶段开启 | **本阶段钥匙只从这里来** | 直接用现有 54 个地城小场地，数值心流不变 |
| 巢穴（洞穴/地宫/废弃迷宫） | 从洞口一路走到底：2–3 个大厅割草，每厅同屏 20–30 只；最深处击杀洞穴首领后出现传送门，走进去结算回岛屿页（见 §4.1） | 常驻，每岛 1–2 个，可重复进 | 爽刷主体：经验、金币、材料，底层首领宝箱 | 复用地城场地与星潮夜冲锋刷怪、首领模板；新增巢穴涌出、出口传送门 |
| 怪潮 | 守住一个点，3–5 波越来越密的怪，最后一波带精英 | 轮换 | 爽刷高潮：经验、金币、材料 | 复用星潮夜刷怪、守护目标；新增波次模板 |
| 狩猎 | 一只稀有精英 + 一个场地机制（例：涨潮淹没、落石） | 轮换 | 定向装备、残页 | 复用稀有精英；新增场地机制 2–3 种 |
| 寻宝 | 限时跑图开箱，路线自己选，宝箱有守卫 | 轮换 | 宝箱、潮晶 | 复用宝箱；新增计时目标 |
| 采集 | 采集点沿路线分布，混少量护卫怪；全自动只采路线上的点 | 轮换（制作开放后） | 制作材料、本岛特产 | 复用 `crafting-gather.ts`；**取代原来的野外路线采集**（J8） |

### 4.1 巢穴：走到底、打首领、传送门出来（2026-10-18 用户提出；入口放在野外，正式设计以 `nest-dungeon-design.md` 为准，本节只作索引）

用户原话：野外要有洞穴、地宫、废弃迷宫的入口，进去爽刷，同屏 20–30 只，1–2 分钟割完一片；要玩家自己走到底，打掉洞穴首领后出现传送门出来，「更有诚意和心意」。

```
洞口（岛屿页卡片 → 进入洞口场景）
  → 甬道（零星小队，带路）
  → 大厅 1：踏入后巢穴涌出，同屏 20–30 只，约 1–2 分钟清完
  → 甬道 / 岔路（可选宝箱小间）
  → 大厅 2（第 3 阶段起可有大厅 3）：更密，混 1–2 只精英
  → 首领厅：洞穴首领
  → 首领倒下 → 首领宝箱 + 出口传送门亮起 → 走进传送门结算，回岛屿页
```

- **一路走到底**：一个实例按顺序串起甬道、大厅和首领厅，全程 4–6 分钟。不中途结算，也没有回头路；中途退出只保留已经结算的部分。
- **割草密度**：大厅「涌出」是踏入时一次性生成的，总量固定（每厅 50–80 只），存活上限 20–30 只，打掉一只就从巢口补一只，直到总量用完。用完后大厅清空，不在原地重刷（守 AGENTS「清场后不得原地自动重刷」）。怪物冲向玩家，复用星潮夜的冲锋逻辑。
- **巢穴杂兵档**：大厅的普通怪单独设档。单厅总血量 = 该阶段标准玩家群攻输出 × 90 秒，按 TTK 推导规则推导一次、验证一次；首领 TTK 沿用首领档。
- **出口传送门**：首领击杀由服务端确认之后才出现；画面播放门的开启，但门本身不决定发奖。走进传送门（或 10 秒后自动进入）就结算并回岛屿页。传送门要有开启演出（光柱 + 门框展开），这是「通关」的仪式感来源。
- **开放阶段**：第 1 阶段只有旋风斩一个群攻，一次打 3 只，割不动 20–30 只。按「补机制不砍量」，巢穴内发一个临时群攻增益，例如「巢穴回响：群攻范围 +60%」，只在巢穴内有效（J12）。
- **收益**：每分钟不高于同阶段爽刷基准，不掉阶段钥匙；首领宝箱算进同一预算。优势只在体感和首领宝箱的定向部位。
- **场地**：优先改造现有 54 个地城小场地的地形和摆件，补上洞穴、地宫、迷宫三套风格（先盘点缺口）。
- **性能**：存活上限 30 只在 `tools/horde-bench` 的 60 只目标以内；用可见浏览器实测一次。

**轮换**：每次登岛（或每次回港），岛屿页从「怪潮 / 狩猎 / 寻宝 / 采集」里按服务端种子挂出 2–3 个，所以每次靠岸看到的都不一样（J7）。

**岛屿故事**沿用方案 A 的结构，只把「地图上的点」换成「小副本」：

```
登岛（首航靠岸后的对白，点出三条传闻）
   ├─ 线索 A（剧情小副本）─┐
   ├─ 线索 B（剧情小副本）─┼─ 汇合（剧情小副本）→ 首领 → 回港
   └─ 线索 C（剧情小副本）─┘
```
- 三条线索没有顺序；也可以在远航的难民船上先听到传闻、提前解锁。
- 任务不卡进度：地城和首领按等级与世界事实开放，跳过故事照样能推进（方案 A 原则不变）。
- 目标认世界事实：「完成某个小副本、某个节点、某次抉择」，由服务端运行结果判定。

## 5. 拾星港与岛屿页

- **拾星港**仍然是可以走动的主城：工坊、NPC、仓库、海域难度、航图都在这里。港口模式不变（半自动）。
- **岛屿页**是航图上的一页，不另外做可以走动的登陆场景（J6）：上半部分是本岛插画和剧情进度，下半部分是小副本入口卡片（类型、推荐等级、奖励图标、剩余轮换时间）。从岛屿页可以直接再出海，不用每次都回港。
- 世界感交给小副本的场地美术和剧情演出，入口卡片本身只负责信息清楚。

## 7. 功能节奏：每次回港开一项

原则：
- **每次回港至少开一项**，前 2 小时大约每 10–15 分钟一项。
- **强度类系统的开启时点不动**（武器盘、召唤石、威能法典、世界层级等，都跟标准人日程绑着；挪动它们就要重新推导）。节奏变快靠的是：把内容类型、航线、残页、小功能插进中间的每次回港。

| 风栖 · 2 | 近海航线 + 航图残页 |

| 雾铃 · 1 | 怪潮小副本 |
| 雾铃 · 2 | 采集与制造 + 采集小副本（原：第二章回港） |

## 8. 奖励与数值口径

- 远航和轮换小副本**每分钟收益不高于**同阶段的爽刷基准，优势只在定向（残页、狩猎）和高潮（巡逻舰、怪潮最后一波、终点首领）。
- **阶段钥匙只从本阶段地城来**；远航和其他小副本不掉钥匙，也不掉钥匙的制作材料。数值心流的墙、钥匙、保底、纯刷级不变。
- 怪物 = 模板 + 指定等级 + 档位 + 世界层级修正，不按玩家等级缩放；TTK、TTD 沿用割草方案对应阶段的目标。
- 原来分给「野外走路探索」的 4.2 小时，改为远航推进 + 剧情小副本，总时长目标不变。
- 具体数值用主干工具推导一次、验证一次（`pnpm spine:check`），如实报告残差。

## 10. 边界（来自 AGENTS 和已有裁定）

- 节点图、轮换种子、掉落随机状态、未揭示节点不进客户端包；抉择、轮换、发奖只由服务端决定。
- 每个节点、每个小副本单独结算；断线从当前节点开头重试，复用同一种子，不增加奖励。
- 不在原地自动重刷敌人；新航线、新小副本都必须由玩家明确开始。
- 回响爆发仍然只在开场和首领战出现，不加常驻主动键。
- 满包规则不变：满包时阻止开启全自动，不自动分解、不自动回城。
- 反作弊只抽检，阈值用真实构筑测定，宁可漏判。
- 不跑无头浏览器；流程用自动驾驶验收，性能用可见浏览器测，用户只做几分钟的手感检查。

## 14. J6/J10 部分冻结落地规格（VOY-01，Claude 默认裁决，2026-10-20）

- 登岛：只走岛屿页，不做登陆场景（J6 不变）。
- 野外保留：玩家可进入的“入口走廊”——从岛屿落点到巢穴入口/位面门（含牧羊人地宫类野外位面门）所需的可走动区域，及入口本身；入口按所在岛阶段可见性开放（J12）。
- 野外冻结（入口停用，不删代码）：营地轮次、传送点网络、迷雾探索、疾跑耗体、悬赏板、野外随机事件、巡逻怪、远离入口走廊的区域。
- 冻结方式：服务端以单一开关 `fieldFreeze`（按系统分项）控制，停用时：不再生成该系统的新实例/任务目标；已有数据与存档保持可读，不清档；进行中的旧实例允许正常结算后退出。
- 任务目标：引用被冻结系统事实（如 clear_camp、传送点解锁）的步骤，按模板改认“小副本/节点事实”，无法改的步骤**仅对旧档**标记为 skipped-by-freeze 并直接发奖，不卡进度；**新角色的正式流程不允许出现 skipped 步骤**，每一步都必须有对应的小副本 / 节点行动。
- 验收：①新角色从开场到风栖首领全程可通关，无被冻结系统的必经目标，且路线中 skipped-by-freeze 步骤数 = 0（自动驾驶断言）；②走廊内可到达巢穴入口并进入；③被冻结系统在 UI 中无入口/红点；④旧档读取无报错、奖励不重复。
