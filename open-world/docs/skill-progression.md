# 技能激活、升级与装配

当前实现沿用V2现代卡通奇幻界面，采用分类分页、技能分组、右侧培养信息和四个装配位，不显示角色立绘。升级／激活与保存按钮同尺寸，技能操作为蓝色，保存为杏金色。

## 生命周期

新角色默认激活并装配斩击、穿云箭、护身印。其他技能的激活资格与已激活状态独立：等级达到要求后需要点击激活；技能书方式只检查配置指定的书，不叠加等级条件。激活成功后才允许装配或升级，激活不会自动加入装配草稿。

持久激活由skillRanks记录：没有条目表示未激活，条目1—5表示已激活及当前技能等级。服务端统一返回skillAccess，包含条件、持有数量、操作类型、费用、是否足够、当前效果与下一等级预览；客户端不计算费用或写入库存。

| 状态 | 可见内容与操作 |
| --- | --- |
| 未激活，条件不足 | 等级或技能书要求、差额；激活禁用 |
| 未激活，条件达成 | 激活条件与消耗；激活可执行 |
| 已激活，未满级 | 升级预览、需求与持有资源；资源足够才可升级 |
| 已满级 | 当前等级与满级说明；无下一级、无费用，升级禁用 |
| 请求中 | 禁止重复提交，不提前预测结果 |
| 响应丢失或结果未知 | 待确认，保留原命令编号与草稿，先读取回执 |
| 付款已确认但战斗同步失败 | 明示操作已成功；恢复战斗授权，不重复扣费 |
| 明确拒绝 | 保留状态与草稿，刷新报价与库存，显示对应技能的错误 |

## 激活与费用

等级方式的门槛来自packages/content/skills-expanded.ts，激活无资源费用。技能书方式当前配置：

| 技能 | 激活消耗 | 技能书来源 |
| --- | --- | --- |
| 燎原 | 燎原技能书1本 | 首次击败荒原守门人 |
| 雷链 | 雷链技能书1本 | 首次击败雾林祭司 |

书奖励在官方首领结算事务中直接进入技能书库存，并记录在回执／流水；同一击杀重试、后续周期再次击败同一首领均不重复发书。激活书技能不消耗金币、强化石或其他技能的书。

升级最多5级，费用为金币35＋当前技能等级×25，不消耗强化石。因此1→2级为60金币；满级没有升级报价。已有技能即使当前不满足原始激活条件，也不重新要求激活或技能书。

## 装配与恢复

装配草稿至少1项、最多4项、不得重复且只能包含已激活技能。换页保留草稿与查看位置；保存独立于激活和升级，不重复执行培养，不扣培养资源。升级资源不足或满级仍可装配。无修改或草稿无效时保存禁用。

激活、升级、保存通过角色版本、控制权和事务重新核对，命令指纹包含操作意图；同一编号不能跨激活与升级使用。确定失败可以重新操作；不确定结果先核对原回执，恢复后保留内存中的装配草稿。原回执存在时不重新提交扣费命令。

## 存档与版本

版本为client0.3.2、protocol4、rulesow-4、db6。第6版迁移保留旧存档已经装配的技能、已付费升级的等级、钱包和装备，为基础技能补齐激活记录。已通关相应首领且尚未学会书技能的旧档补发对应书，迁移仅执行一次。旧战斗授权失效后重新获取；历史回执保留。

目录现有55项，分类计数动态读取，已激活与可激活项优先展示，其余按门槛排序。没有专属图片的扩展技能采用对应机制的通用图示；扩展技能的特殊战斗机制不属于本轮状态接口修改，需要由其执行器单独验证。

## 验证

TypeScript、内容校验及79项测试通过。真实PostgreSQL覆盖资格拒绝、升级不足与满级、正确技能书消耗、首领首次奖励、重复回执、跨操作编号冲突、旧档迁移。Chrome实机覆盖25项以上状态与布局检查，四种分辨率、同尺寸按钮、跨页装配保存、请求失败刷新、响应丢失后的书消耗和草稿恢复，以及已确认付款后的战斗同步失败。
