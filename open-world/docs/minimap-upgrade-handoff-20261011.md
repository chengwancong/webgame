## 背景

用户 2026-10-04 选定小地图 B「圆形近域雷达」，2026-10-11 反馈“不太行”：**信息太少、和画面对不上、样子不好看**。已选改法：**保留圆形雷达，放大并补信息**。不换成方形或长方形。

现状（`apps/web/src/ui/minimap.ts`、`minimap-data.ts`、`minimap.css`，投影已改为与场景一致的等距）：
- 144px 圆形，视野半径只有 12 格，比主画面能看到的范围小很多，所以“看不到画面里有的东西”。
- 底色深绿，地面是一块纯色菱形，建筑、悬崖、水面、岛的边缘都没有，和奶白浅金界面不协调，也和画面里的沙地、海面对不上。
- 只有主角、敌人、少量 NPC、入口、地标圆点；没有任务目标方向、没有建筑轮廓。

## 不得改动

- 战斗、存档、任务、其他 HUD（任务条、A1 菜单、头像、金币）样式。
- 点击展开的全图面板及其导航功能保持可用（可同步美化配色，但不改行为）。
- 小地图的投影、数据来源（场景地图 JSON）、探索迷雾逻辑；只在其上增加绘制内容。
- 遵守 `docs/ui-copy-voice.md`、Token 规范（颜色、尺寸来自 `packages/ui-tokens/tokens.json`，不写死色值）、`docs/quest-guidance`：只用方向箭头，不画地面路径线，任务提示一行短文字。

## 批次

### M1 对齐画面（先于一切美化）

目标：玩家看主画面和看雷达，指的是同一个世界。
1. 实测主画面一屏能看到多少格（以 1280×720、当前相机缩放为准），把雷达视野半径设为**至少覆盖主画面可见范围的一半**，并作为 Token/常量写明来源，不再用魔法数 12。
2. 地面、海、边缘：用与场景一致的地面色表达（沙地/草地/石板按区域主色，取自场景资源的代表色或 Token），岛外显示海面色，岛边缘用一道浅色描边表示悬崖线，而不是深绿底加菱形。
3. 建筑与大型障碍用**占地轮廓小色块**绘制（星海地图沿用已有的 `foreground` 装饰数据，普通区域用 `region.obstacles`），不画屋顶细节。
4. 抽样核对：在营地、一个野外区域、一个星海地图各截图主画面+雷达，标出 3 个以上地标，位置方向一致。

### M2 补信息

1. **任务目标**：当前任务目标在视野内时画一个醒目的目标标记；在视野外时在圆周边缘画一个**朝向它的箭头**（不画路径线）。数据来自现有任务追踪的目标坐标，不新增后端字段，缺失则不画。
2. **图标分层**：入口/传送、首领、精英、普通敌人、NPC（任务 NPC 带 ?/!）、据点、采集点各一套形状和颜色，彼此可一眼区分；敌人按距离远近透明度略降，避免一团乱。
3. **主角朝向**：不要用固定朝上的箭头，也不要用 `facing`（只有左右）。用最近位移方向画一个小三角，静止时保留上次方向。
4. 圆周下方保留地区名，去掉“北向标记”的方位含义（等距下屏幕上方不是北），并同步 `docs/minimap.md`。

### M3 好看

1. 尺寸：雷达直径从 144 提到 **192px**（Token 化），保持右上角位置，不遮挡区域名、增益条和 A1 菜单；窄窗口时回落到 160px。
2. 样式：奶白浅金风格。外圈用奶白细边 + 浅金描边 + 轻阴影，内圈地面色见 M1；去掉深绿底和黑色硬边。图标用统一描边（奶白细描边），尺寸随雷达放大。
3. 缩放：滚轮或 +/- 按钮在 0.75×/1×/1.5× 三档切换视野半径，记在本机 localStorage，不进存档。
4. 点击仍展开全图面板；悬停显示一行“点击打开地图”。

### M4 验收

- 单元测试：视野半径来源、目标箭头方向（目标在视野外时箭头与 `project(目标)-project(主角)` 夹角 <1°）、朝向缓存、三档缩放；原有等距投影断言继续通过。
- 完整回归、`pnpm build`、`/api/health` 版本一致；可见 GUI 登录/会话恢复。
- 可见 GUI 逐张截图（1280×720，改前/改后并排）：营地、野外、星海地图、副本内、任务目标在视野内/外各一张、三档缩放；检查与任务条、区域名、金币、A1 菜单无重叠。存到 `docs/reviews/minimap-upgrade-20261011/`。
- 禁用词检查（`tools/copy-voice-scan.ts`）保持 0 命中。

## 默认裁决

- 信息过密时，保任务目标 > 首领/入口 > 精英 > NPC > 普通敌人，普通敌人先淡化或合并。
- 需要新美术资源才能表达的，用形状（圆、三角、菱形）加 Token 色代替，不新增图片。
- 与现有任务引导规则冲突时，以“只画方向箭头，不画路径”为准。
- 新数据需要后端字段才能得到的（例如目标坐标缺失），先不做，写入进度文件“待后端”，不要阻塞。
