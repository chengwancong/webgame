# 强化石

2026-10-03 按用户要求废弃未确认的灵石设定。装备强化消耗金币与强化石，+0→+1 为 35 金币、2 强化石；后续费用由服务端 `upgradeCost` 返回。装备分解获得 3 强化石，野外与挑战产出同步展示为强化石。

强化石只用于装备培养、装备威能萃取／刻印与词缀重铸。技能升级只消耗金币，1→2 为 60 金币；技能激活仍按等级或技能书配置。角色、召唤石、巅峰、雕文与专业去掉原先的灵石费用，保留已有金币和专用材料费用，不新增替代资源。

原先的灵石声望上交入口停用，服务端拒绝旧命令；区域声望继续从战斗获取，避免删去费用后产生免费重复刷声望。强化石沿用 `material` 数值字段，当前字段语义为强化石；不再存在独立的灵石资源或消耗。

验证覆盖真实 PostgreSQL 扣费、不足回滚、重复命令、技能零强化石升级、内容校验、类型检查、生产构建，以及本机服务浏览器登录、背包强化和技能升级。浏览器证据位于 `../docs/reviews/open-world/enhancement-stones-20261003/`。
