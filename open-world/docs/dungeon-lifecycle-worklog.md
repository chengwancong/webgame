# 副本生命周期实施记录

用户批准的流程已接入统一内容、服务端实例执行器、独立多人战斗、实时通道和客户端控制器。当前版本 0.8.1／协议 10／规则 ow-13／数据库 11；保留共享工程最新资源版本 v15-story-campaign。

正式规则与接口见 [副本生命周期](dungeon-lifecycle.md)。统一配置在 packages/content/dungeons.json，初值不在界面或生命周期逻辑重复定义。打开覆盖面板、后台、掉线不暂停；清场、续接与重连不重生敌人。成功、失败和退出返回营地，掉落逐事件自动入包。

已验证真实 PostgreSQL、HTTP、WebSocket 和 20 个独立账号；两名真实浏览器玩家与 18 个网络客户端同时加入，双方实机渲染 20 个独立角色。队友选择与焦点／尺寸保持稳定，队长退出后由最早在线成员接管。单人浏览器已验证正式击杀、自动入包、结果返回、丢失返回响应后幂等重试、背包与浏览器冻结不停战、原场刷新恢复和四个视口。

时间边界补齐：输入按服务端接收时刻排入战斗帧，截止后不进入历史补算；生命周期操作与重连先处理此前的实时进度。补位奖励从正式加入帧开始，恢复时使用原保留截止，不额外延长席位。事务失败恢复世界、已消费输入、待发送事件与回执；无法恢复时关闭并退还入场消耗。

完整回归、战斗明细清理和最终构建仍以 docs/reviews/open-world/dungeon-lifecycle/ 与 dungeon-lifecycle-release/ 的最新 JSON 结果为准。数值报告只比较固定种子的旧聚合／独立角色结构，不等于自然养成或玩家难度验收。本轮保留现有数值，不擅自补强首领。

一次性修改脚手架已删除；保留复验工具。发布采用停止常驻服务、完整构建、Limited 权限计划任务恢复、核对双入口和原存档的顺序；最终发布证据由 release-dungeons.mjs 与 verify-battle-result-release.mjs 记录。未提交 Git。

## 最终发布结果

完整回归 49 个文件、332 项通过；副本数据库验收 16 项通过，包含过期后迟到输入与 7 天明细清理。单人和 20 人浏览器报告均通过。停止服务、完整构建、恢复计划任务后，源指纹一致；8611／8612 实际健康、内容版本和账号登录／会话恢复均通过。原有 68 个账号与角色、520 份回执与流水保持不变；发布验收额外创建一个独立账号。常驻服务已恢复 running，Limited 权限计划任务正在运行。
