## 工具用法

- `pnpm pacing:derive --out=<推导目录> --from=<已完成验证目录>`：一次解析推导，只写报告。默认输出`.qa/pacing/latest`，默认输入`.qa/pacing/baseline`。
- `pnpm pacing:derive --out=<同目录> --apply --plan`：应用已审阅的同一计划，不重复推导。
- `pnpm pacing:derive --out=<调整目录> --from=<三种子验证目录> --adjust --recenter`：唯一偏差调整，沿用B3声明边际；仅日程偏离时一次修正已有经验需求曲线。
- `pnpm pacing:validate --out=<验证目录>`：默认三种子自然World/临时PG和240场完整/消融；报告中位数/min/max、逐规则触发及原始失败。`--seeds=41`只用于基线。
- `node tools/pacing/run-tests.mjs <回归目录> --all`：串行临时PG全量vitest，清理后写cleanup.json。
- `node tools/pacing/build-isolated.mjs --out=<构建证据目录> --keep`：隔离完整pnpm build并扫描实验入口，暂留自有构建目录；B6同命令加`--stamp-only`刷新最终规则版本并清理。
- `pnpm config:export` / `pnpm config:check`：工作簿机制旋钮独立导出，用户目标表保持只读。
