## 决策日志

1. 不扫描内容/契约模块里的 `throw` 和 schema 校验，也不扫描 `CONTENT` 类拒绝。这些是加载期校验，玩家看不到。
2. 不扫描 `asset-manifest` 的 note 字段。它是美术接入记录，不进入界面。
3. “1–1”只拦整段写成 a–b 的人数或区间标签。“3–20 格”“Lv1–150”这类正常取值范围不拦。
4. 战斗状态“冻结”（冰冻控制）改为在显示层叫“冰冻”，内部 ID 不变，不进白名单。
5. “世界层级”加入禁用词，因为 B3 要求玩家可见处统一叫“海域难度”。
6. 死因判定顺序：附带持续伤害 → 近身/召唤/位移突袭（被近身）→ 元素伤害（抗性）→ 其余算远程范围。形态优先于元素，因为“贴身爆发”该控场而不是换抗性装。
7. 招式 `hint` 由内容源逐条给，没填的按“技能类型 + 伤害类型”合成，不按技能 ID 硬编码；岛屿生成的技能按同一张表合成。
8. 建议按钮跳转复用现有动作：`panel/skills`、`bag-progression/talents-defense`、`bag-progression/talents-damage`、`panel/character`（锻造）、`panel/bag`。
9. 成功结算页不写“你倒在了这里”，改标题为“这一场你赢了”，并省略致命一击行（没有致命一击可讲）。
10. 港口 NPC 入口给港务长·澄而不是领航员·米洛：澄的人设是“承认风险”，且他原本没有服务按钮；米洛的「查看航图」不动，航图里另加「海域难度」按钮，两处入口都在。
11. 危险★/奖励★ 阈值放在 rules（服务端）：危险按怪物生命档位（1.3/2/4/9），奖励按四种收益平均倍率（1.15/1.45/1.85/2.4）。客户端只画星，不反推倍率。
12. 推荐等级不新增数值：取该档解锁条件里已有的等级门槛（普通首领等级 / 裂星潮起始等级 / 深渊的 50 级）。
13. 「详细数值」里的倍率写成“生命 2.6 倍”而不是“×2.6”，避免主文案出现 ×N，也不需要白名单豁免。
