## 实现

- effects契约扩为22种触发与17种动作（原有6/7 + 新16/10），动作与触发组合、字段和数值缩放路径有校验。50原子由effect-atoms.json加载，均有有效表现资源引用。
- World按事件接入击杀精英、位移、状态施加、受击/闪避/格挡、护盾增破、低血/致死、间隔/开战、移动距离、资源不足/消耗与区域结束。旧25连携及7500帧兼容样例保留。
- 独立/刷新叠层、阈值冻结、首领转迟缓、非冰伤解除冻结、易伤池、DOT暴击权限；自身增益与三种消耗、击杀窗口/移动/灵力计数、检查点保存。
- 回旋原子所需returns字段前置实现，出程和回程可分别命中，沿用整段碰撞；冻结/易伤复用现有冰晶与标记绘制，叠层显示数量。
- 震波使用cast_hits实际不同命中目标计数，不把附近未命中的目标算进去；荆棘反弹给真实攻击者。不衰同时作用于通用arc和旧连锁开关。
