**D1：开场巨兽从出现到倒下的秒数（目标 20–25 秒）**

跑的是客户端开场实际驱动的那一场战斗（`PrologueBattle`），地图是真实风栖岛，血量和回响爆发用 `prologue.json` 冻结值。玩家策略：身边 6 格内有敌人就站着打，没有就朝最近的敌人走。

| 武器 | 巨兽血量倍率（旧 → 新） | 潮能一满就按爆发（验收口径） | 爆发留到巨兽战（只记录） | 推导初值实跑 |
|---|---|---|---|---|
| 剑 | 40524 → 46784 | **22.7** | 15.7 | 20.7 |
| 法杖 | 10592 → 11739 | **22.7** | 18.5 | 21.4 |
| 暗器 | 43774 → 40596 | **23.1** | 23.3 | 26.4 |

- 推导：初值 = 授予构筑单体秒伤 × 22.5 秒。用初值实跑一遍，按"实跑秒数 / 22.5"等比修正一次。修正后按定稿血量重推爆发伤害，再实跑验证。没有扫参。
- `prologue-build.ts --check` 和测试都会复跑这一场，结果必须与冻结值完全一致。
- 剑把爆发留到巨兽战时是 15.7 秒，低于 20 秒。字幕提示的是潮能满了就按，所以按 eager 验收，hold 只记录。
- **更正上一版本节的表格**：上一版（剑 17.8、暗器 28.2）以及"第 3 波巡猎兽卡在地图西缘"，都是测试单独运行时落到 64 格静态占位图上测出来的。客户端 `main.ts` 会加载真实野外岛，所以玩家打的一直是 512 格的风栖岛。在真实岛上，去掉可达性检查站桩也不会卡。可达性检查作为防护保留。
- 冒烟（应用内浏览器，8612，新号 `qa_d1s1017`，暗器，不走位）：三波和巨兽都在真实岛上打完。巨兽战按了一次爆发，之后巨兽倒下，收尾字幕出现，然后交接到「落点求生」到达对话。

## 三、第三轮可视验收（只验 D5、D6）

**硬约束：**
- 每段从第一张截图开始计时，**≤ 5 分钟**。
- 每次截图前先看计时；到 4 分 30 秒立即停止，没看完的记「未覆盖」，不延长、不补段。
- 只用本地 8612 可视浏览器，不跑无头浏览器和探针，不访问 8790，不改源码，不执行 Git 状态变更命令。
- 截图和原始记录放 `.runtime/acceptance-g3/`。

**段 1：D5 击杀掉落演出（≤ 5 分钟）**

1. 段外准备（不计时）：`node tools/qa-checkpoint.mjs qa_g3d5_<序号> port-road sword`，然后在浏览器里用同一账号登录，关掉到达对话。
2. 开始计时。在风栖岛野外找一群普通怪，站在怪群里打。
3. 观察并截图：
   - 每次击杀，尸体位置蹦出金币和强化石小图标，随后飞向角色，不飘数字；
   - 掉部件时蹦出对应图标，并飘一行名字，例如「疾风羽 ×1」；
   - 图标和名字的上下层级：不被角色、血条挡住，也不挡住血条。
4. 结论写：通过 / 不通过（附复现步骤）/ 未覆盖。

**段 2：D6 能量用语与缺能量提示（≤ 5 分钟）**

1. 段外准备（不计时）：`node tools/qa-checkpoint.mjs qa_g3d6_<序号> salvage hidden`，然后登录。暗器的飞刀和扇刃都耗能量，挂着打会出现能量不够的情况。
2. 开始计时。冲进一群怪里，让技能自动放，直到技能格出现缺能量染色（进出都要持续 600ms 才显示）。截图，并悬停查看说明文字。
3. 打开技能→辅助→回气：说明应为「大量恢复生命和能量」。打开人物→详细属性：资源名为「能量」。
4. 「灵力」「法力」全部界面的覆盖以 A8 守卫测试为准，可视段只看上面三处，不遍历全部界面。
