# Open-world 玩家体验验收 · 2026-10-08

**总评：短战斗和构筑翻墙有爽点，连续游玩的心流仍被交互卡住、方向与奖励解释不足、重复内容打断，当前不建议通过玩家体验验收。**

最有说服力的正面经历是：自然30级角色在沉星密仓入口倒下，正常花费金币重配天赋、免费装配寒霜阵后，清过前段并击败首领。最伤体验的经历是：按屏幕提示交互却操作了另一个对象；想传送或研究构筑时界面卡忙；到了终局，界面仍指向新手目标，裂星潮首领进度又与普通首领标记混在一起。

## 3. 最伤体验的前十个问题

按本轮实际伤害与修复收益排序。P1为明显伤心流，P2为打磨；“想退出”是本轮明确标注的主观退出点，不等价于真人群体流失率。这里没有把有恢复路径的现象直接写成整个游戏不可继续的P0阻断。

### P-01 野外成长/传送会停在忙状态，玩家被迫恢复界面

- **现象｜可复现**：野外点击技能激活或航标传送后，相关操作及关闭按钮禁用，长时间不结束。龙眠首次传送超过100秒仍在地图；沉星新解锁航标再次发生。港口技能/天赋操作和地城路径可以正常继续。
- **复现路径**：恢复自然50级隔离检查点→龙眠岛→区域地图→“传送·誓约庭航标”；另一路是自然30角色击败沉星首领→回岛→地图→新解锁的“界桥前庭航标”。保留正常登录及角色状态，不用GM。
- **证据**：[龙眠卡住日志](evidence/s3-04-teleport-stuck.txt)、[沉星卡住截图](evidence/s3-30-new-waypoint-pending.jpg)、[新手技能卡住](evidence/s1-19-activation-stuck.txt)、[API日志摘要](evidence/network-summary.json)。传送等待期间有续租/permit成功，却没有相应`travel/waypoint`请求；所读控制台未见对应错误。
- **影响｜维度1/4/6/8**：战斗刚给出奖励或开放新路径，玩家想成长/移动，却进入分钟级等待。**主观退出点：正常按钮都不能用，像在替游戏排障。**
- **严重度｜P1，劝退风险高**。ESC/刷新有绕过路径，不能据此视为可接受；具体卡在哪个客户端结算环节尚未定位。
- **类型｜缺陷/接线**。
- **建议改法**：先查野外命令前结算、未完成Promise与忙状态复位；让禁用状态对应真实进行中的操作，并提供可恢复的明确状态。用新角色/已自然进阶角色各走一次“野外升级→关闭”“新航标→传送”完整路径；同时以真人鼠标复验工具输入边界。

### P-02 E提示的对象与实际执行对象不一致

- **现象｜可复现**：任务要求“听米洛介绍前哨”，画面提示“E 和领航员·米洛对话”，按E返回“悬赏板尚未开放”。回港箭头到达后出现“E 回拾星港”，按E也曾只提示走近目标。
- **复现路径**：新角色首战完成→跟随箭头→激活船台湾航标→不额外移位，按E与米洛交谈。回港范围例：落风坡→回港箭头→在显示E回港提示的位置按E。
- **证据**：[提示与错误返回](evidence/s1-10-e-wrong-target.txt)、[重叠站位](evidence/s1-09-waypoint-interact.jpg)、[回港范围](evidence/s1-51-port-e-mismatch.txt)、[鼠标绕过](evidence/s1-47-milo-direct-click.jpg)。
- **影响｜维度1/2/8**：玩家按游戏刚教的操作做，却得到另一个系统的拒绝，容易怀疑自己漏了前置或卡关。
- **严重度｜P1**。
- **类型｜缺陷/接线**。
- **建议改法**：提示和执行消费同一交互候选/对象ID及距离条件；校验任务NPC、航标、悬赏板、门户重叠时的优先级。保留多个对象的真实功能，避免让提示和快捷键分别选目标。当前可绕过方法是先拉开站位，再直接点击米洛角色；它不是新手应当自行发现的必需知识。

### P-03 全航标解锁后，1280×720地图的传送入口溢出

- **现象｜可复现**：龙眠8个已激活航标挤在一行，按钮名称竖排溢出，压住图例及下方入口。新手只有1–2个按钮时没有暴露问题。
- **复现路径**：自然50完整检查点→龙眠岛→打开区域地图，保持1280×720。
- **证据**：[8航标截图](evidence/s3-02-dragon-map.jpg)、[溢出记录](evidence/s3-03-map-overflow.txt)、[两航标正常对照](evidence/s3-29-rift-after-map.jpg)。
- **影响｜维度2/7/8**：本应奖励便利的解锁，反而让后期最常用的交通页更难读和点。
- **严重度｜P1**。
- **类型｜缺陷/接线**。
- **建议改法**：为全部真实航标建立可换行或可滚动的受限区域，保留按钮可辨的最小宽度与足够名称空间。验收0/1/2/8/9个入口及连续切换；不能靠删除航标、少列入口或缩成不可读文字掩盖。

### P-04 地城目标卡遮住首领血条与阶段信息

- **现象｜可复现**：地城进入第三段后，上中目标卡盖住首领姓名/血量条的中部；普通岛首领场没有这张卡，血条能完整读到。
- **复现路径**：风车地窖或沉星密仓→完成前两段→进入首领阶段，保持默认HUD和1280×720。
- **证据**：[风车地窖遮挡](evidence/s1-37-boss-observe.jpg)、[沉星地城遮挡](evidence/s2-25-boss-telegraph.jpg)、[独立岛首领对照](evidence/s3-21-island-boss.jpg)。
- **影响｜维度3/4/8**：玩家很难判断首领还剩多少、这次是否比上次打得好，直接损伤“看见自己在推进”的反馈。
- **严重度｜P1**。
- **类型｜缺陷/接线**。
- **建议改法**：明确首领条、地城目标、敌方施法提示的布局优先级与不重叠区域。沿用既有Token/公共控件及奶白浅金方向，不移动无关头像/系统菜单；用真实三段流程验证组合状态。

- **建议改法**：航图消费服务端对应相位的完成状态，分别呈现普通已平定、裂星潮待挑战/已完成；层4旁展示裂星潮x/6与剩余岛。结算明确这次推进了哪种进度。沿用一行方向引导，不引入强制主线。

### P-06 最后首领场开启全自动却不接敌，现场指路仍是新手目标

- **现象｜可复现的本轮观察**：龙眠裂星潮首领场默认落点开启全自动，不额外移动，超过2分钟仍无接战。自身4039/4039、首领70367833/70367833，伤害技能显示超射程；附近没有明确的“去首领身边”引导，HUD仍要求回风栖打2个敌人。
- **复现路径**：最终自然50存档→航图龙眠→重战维洛→全自动→不额外移动，观察入口附近的行动与血量。前五岛同一路径已经实际接敌并完成，不能让玩家推断最后一场突然需要另一个未说明的操作。
- **证据**：[进入场地](evidence/s4-27-dragon-tide-start.jpg)、[2分多后状态](evidence/s4-28-dragon-outcome.jpg)、[停场保存](evidence/s4-29-end.jpg)。
- **影响｜维度2/3/4/9/10**：玩家以为正在挑战，实际上没有输出；持续绕动和满血条没有说明问题出在接敌而非战力。**主观退出点：等待了几分钟，才发现一直没开始打。**
- **严重度｜P1**。
- **类型｜内容缺口/接线，根因待定位**。未手动沿路接近复验，不能称首领不可达，也不能称数值无法打过。
- **建议改法**：给首领场提供明确目标导航/接近提示，校核起点、自动活动范围与首领接敌条件的衔接。若保留“必须先手动走近”的设计，应清楚表达；保留现有活动半径，不把自动战斗改成全图无限探索。

### P-07 首领之前倒下、野外首领倒下，结果页缺可行动的解释

- **现象｜可复现**：沉星密仓入口倒下时，差距栏只说“先清理地城前段，抵达首领后再比较”；此时恰好是清不过前段。普通岛首领失败页只有0收益和返回，没有死亡技能或承伤来源回顾。地城到达首领后则确实有剩余生命、本次/目标DPS、生命估计与材料建议。
- **复现路径**：自然30基线进入沉星密仓→全自动入口群战失败；或普通沉星岛首领中移动离开近战射程、站在持续危险区后倒下。

- **影响｜维度3/4/6**：第一次撞墙需要被解释为可以行动的问题，现有信息会让玩家在升级、换装、换技能、少拉怪之间盲猜。
- **严重度｜P1**。
- **类型｜内容缺口**。
- **建议改法**：把短战斗回顾覆盖到前段与岛首领：最近承伤来源/危险区、持续输出情况、可刷来源与材料进度。用执行器/已有实际事件解析，不在UI复制数值公式。输入不足时说明本次DPS的上下文，避免让玩家只看到巨大的装备差距。
- **限制**：第三段手动尝试受工具输入间隔影响，57DPS不代表这套构筑的正常能力；同构筑此前自动通关已经留证。这次失败不计数值墙失败或真人手动收益。

- **类型｜内容缺口/设计取舍**。

### 4.2 旧数据的阶段上下文不能丢

同名地城在开启裂星潮后会由`characterDungeonDefinition`替换numericStage、准入/怪物等级与难度。W10自然路线“末两地城失败”不能只凭`field-rift-3`/`field-dragon-3`这个ID就自动归为普通阶段15/18；应看当场冻结定义。当前自然30分支的三次沉星密仓冻结阶段明确为13，最终PG记录分别是入口失败、通关、手动输入不足后的首领失败。

本轮保留这层区分，既不拿自然通关一个阶段抵销受控探针失败，也不把合法发行负载的可达结果当自然玩家体验。
