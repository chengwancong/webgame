# W2 通用野外玩法与世界相位

本批实现交接单 W2 的通用执行能力。六岛生产配置及自然养成指标分别在 W4–W11 验收，不以本批样本替代。

## 权威执行和配置

- `field-activities.ts` 使用服务端实际 `World` 与100ms推进器，事件、宝箱、稀有实例保存于 `ow_field_activities`。客户端仅提交输入，不能提交完成、时间、击杀或奖励。实例冻结地图、怪物、词缀、物品规则和私有掉落定义；离场、死亡、守护目标毁坏会失败。
- 歼灭、守护和三波怪潮均使用真实敌人、伤害和时间；怪潮在30秒内生成30–60杂兵及1精英。渲染消费实际事件缓冲，刷新继续原checkpoint。活动返回原野外时保留生命、能量、冷却、状态及击杀计数。
- 私有包量保证：精英1–2、稀有3–5、宝箱/事件2–4；物品共用已有实例工厂。实例、物品子来源、奖励回执、流水与世界事实在事务内防重。私有权重不返回客户端。
- 巡逻沿配置路径运动，使用营地轮次与刷新条件。角色配比和生命预算进入实际生成器。六词缀使用真实执行器；火焰足迹和传送登记正式表现资源。
- 新世界事实 `open_chest / complete_event / kill_rare / clear_dungeon` 支持先完成后接取并自动归档。野外地城准入服务端检查 `field-dungeon`；48×48地城段从 `field-dungeon-stages.json` 经共同资源池生成，生产构建写入 `production.json`，固定遭遇注册保留真实敌人。18个内容定义在逐岛批次填入。
- `世界.xlsx` 相位行与 `NPC.xlsx` 站位的 `when/until` 引用任务条件页target；服务端按角色解析，不可见营地不创建新轮次。NPC同一时刻唯一位置，任务中交谈和accept_stay保持原引导行为。前哨、物件和商人从公共视图显示。
- 世界表营地 `budget`、事件状态/特效资源列均有表头批注；章表追加功能描述与兜底提示。条件namespace不污染旧章节事件序列。首次触碰传送点自身就是开放兜底，不反向要求已经开放。
- 同分区80击杀触发星潮夜，36格外生成真实追击怪。超过怪物2级之后按每超出1级衰减15%、最低25%计算经验，悬赏沿用同一规则。
- 保留90旧天赋，新增三个独立获取节点补齐尸爆、击杀连锁、击杀叠伤；回能和减冷却保留原副属性来源。没有修改旧节点以冒充新增获取。

## 实际证据

- `regression.json / regression.log`：完整串行真实PostgreSQL回归170文件、1419通过、2既有跳过。首次4个失败保存在 `regression-first.*`，修复真实内容与旧兼容问题后通过。
- `visible/result.json`：可见IAB中五实例实际claimed，宝箱4件、waves2件、defend3件、horde2件、rare4件；守护360tick、怪潮1115tick，刷新后30/31目标续接至完成。受控Lv50和10HP零攻击敌人只证明通用链路。
- `visible/cleanup.json`：临时服务停止且临时库清理至0。正式库不参与受控测试。
- 地城事实、巡逻、相位与词缀均使用独立临时PG或真实World定向测试；最后补充地城生成和道路连通定向2项通过。完整日志失败版本保留。
- `kill-effect-acquisition.json`：真实学习及施法击杀取得效果，尸爆使用死者生命；93天赋包含原90节点。

## 公开界面

活动进度使用公共statusBar和现有地城HUD，地图只标已探索目标；资源消费已登记的两套正式清单。三种示意在 `.design/open-world-m2-m4-events`，未选定前继续公共控件功能版。稀有标牌使用正式角色显示高度，稀疏道路沿完整线段绘制。
