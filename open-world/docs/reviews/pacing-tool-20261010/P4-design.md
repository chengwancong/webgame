# P4 试玩面板实施边界

- 前端仅在 Vite DEV 且 VITE_PACING_TOOL=1 时动态导入；正式构建的入口/chunk不包含该模块。后端还须显式pacingLab+isolated标记、非production，接口再核对配置白名单账号。客户端隐藏不作为鉴权。
- 面板附着HUD，奶白浅金公共控件与Token，固定1280×720可见GUI。入口≤6字“节奏试玩”；显示真实试验World的击杀/时长/投影经验、下一等级估计、目标TTK与对应BD场景比。
- 实验开战读取当前角色的服务端解析构筑与显式技能等级，复制合法敌人、冻结版本与当前滑条（生命/攻击倍率）。已有实验与其他会话不受后续滑条影响。
- 实验World独立于奖励战斗：不用permit、不创建ow_kills/奖励/回执，不调用applyXp、award或角色写入。展示经验是纯规则投影，标签写“预计经验/时”，不是已领取奖励。
- 会话覆盖与运行状态只存当前session内存；同一登录会话的刷新保留；服务重启/新session重置。每会话只保留一场实验，结束/退出释放。服务器定时推进真实World，GET只读取状态、不推进、不暂停。
- 导出按钮为“导出建议”，文件声明requiresConfirmation=true、notApplied=true，带当前倍率、角色构筑说明、版本、种子与目标表来源；不直接写Excel/JSON配置。
- GUI用控制授予样本，明确区别自然日程：白名单/非白名单、两档生命倍率、在战中改滑条不影响当前场、下一场TTK变化、刷新会话恢复、导出下载文件。正式包登录只验正常角色，不出现入口。
- 数据未覆盖走位/躲避/手感，实验TTK不能代替自然BD获取与真人时间。
