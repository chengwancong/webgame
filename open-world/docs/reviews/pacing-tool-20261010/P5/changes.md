## 保持与局限

- 燃烧预算不足：保持1秒引爆间隔，用实测末击延迟反推火球轮转，按已记录火球伤害份额补偿单体/精英，非候选试探。
- 疾行预算略高：只校对群敌刃阵脉冲间隔，保留单体与机动，不降低其他搭配。
- 坚壁规避用两轮留存样本作单次插值初值；两轮还改变持盾效果，不能把插值宣称为单参数因果实测。
- 先手首领按两轮留存响应使用平方根增幅校正：直接命中与衍生引用都消费压制效果，不假设一次线性缩放。
- 仅一次解析推导，不执行候选对局；实测达成仍由下一次独立validate判断。
- 消融不去掉剩余基础技能、固有连招或合法装备属性；原始残差与失败保留，不能宣称整体平衡通过。
