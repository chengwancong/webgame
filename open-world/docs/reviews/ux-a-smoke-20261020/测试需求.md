## 2. 逐项场景

### A01 面板/弹窗/tab 动效（已提交 2adca2b8，快速回归）
1. 打开背包、技能、设置面板：淡入 + 轻微上移 + 0.98→1 缩放，约 120–200ms；关闭更短（约 90ms），无残影卡住。
2. 面板内切 tab：下划线滑到新 tab，不是瞬间跳。
3. 卡片列表（背包格/任务行）首次打开依次错峰出现（约 30ms 间隔，最多 10 个）。
4. tooltip 悬停有淡入。
5. 开「减少动态效果」：以上全部瞬时，无动画。

### A02 底部对白条（已提交 32bafe02）
1. 与营地 NPC 对话（米洛「落点求生」等多句任务）：对话条贴底，左侧说话人头像，姓名牌在文字上方不重叠。
2. 逐字出现（约 42 字/秒）；逐字过程中点击对话条空白处或按空格 → 先补全当前句，不翻页；再按一次才翻页/关闭。
3. 「回看」按钮在第二句起出现，点开显示已读句子，再点收起；翻页后历史保留，关闭对话后清空。
4. 「跳过」立即生效。旁白句（无说话人）无头像、斜体次要色。
5. 星潮海弹窗对话、进行中对白、任务完成多句对白都走同一条（星潮海 `starsea-chart` 不受影响）。
6. 对白原文与改前逐字一致（抽 3 段对比）。
7. 开「减少动态效果」：整句直接显示。
8. Enter 在对白里同空格；在输入框里按空格不触发翻页。

### A03 标题页（已提交，待验证）
1. 退出账号回到登录页：背景是营地（草地、石路、风车、帐篷、篝火、树、石头），不是纯色；整体缓慢飘移（周期约 1 分钟），暗角在。
2. 标题「深渊行者」有光泽扫过（周期约数秒，扫完静止一会）。
3. 右上有静音/音量控件，点静音后图标变灰，再点恢复；刷新后音量设置保持；设置面板里的主音量与之一致。
4. 右下有版本角标，数值与 `/api/health` 的 client 版本一致。
5. 「进入游戏」按钮按下有下沉/缩放反馈；输入账号 Enter 进入。
6. 命名页、「角色正在别处游玩」页同样有营地背景，输入框和按钮可用、焦点环可见。
7. 登录页 → 命名页 切换时背景不闪、不跳回起点。
8. 开「减少动态效果」：背景/雾/光泽全部静止。
9. 登录后背景消失，不残留（进入营地时 `#modal` 没有 `.title-bg`）。

### A07 技能栏反馈（已提交，待验证）
1. 一个冷却 ≥ 短冷却阈值的技能冷却到 0：该槽边缘有一次扫光（约 0.6s），不是反复闪。
2. 按下技能槽：按住时缩到 0.92，松开回弹。
3. 冷却中点击或按对应键位：槽位轻抖（约 0.28s）+ 红边闪；缺灵力时同样。
4. 「待找回」的封印槽不抖。
5. 不得出现整格变暗或持续闪烁（用户 2026-10-11 明确否定过）。
6. 减弱动效：无扫光/抖动，其余照常。

### A06 HUD 过程感（已提交，待验证）
1. 受击：血条先立刻下降，后面一条浅色「残影」延迟收缩；受击瞬间血条短暂变亮。
2. 血量 ≤ 30%：血条持续轻微脉冲；回到 30% 以上停止。灵力条无残影。
3. 拾取金币/领奖励：金币数字滚动到新值并短暂高亮，最终数值必须等于服务端值（对照背包/快照）。
4. 经验数字同理。
5. 升级：头像处一次柔光环 + 等级数字弹出；战斗中升级只排队成长卡，不暂停世界，脱战后才弹。
6. 减弱动效：数字直接落值，无残影动画、无脉冲。

### A04 开场坠落（已提交 c6569746）
1. 新建账号 → 命名 → 开场：看到镜头向下坠落（云层视差、速度线、地面逼近），落地有冲击 + 轻微震屏 + 柔光，不是刺眼纯白闪。
2. 对白与改前一致；「跳过开场」随时可用，点击后直接到选武器。
3. 三选一武器卡片：鼠标悬停播放约 1.5 秒该武器技能预演；移开停止；不悬停不播。
4. 开场总时长约 8 秒量级，不出现长时间空屏。
5. 开「减少动态效果」：无震屏、无速度线动画，剧情照常推进。
6. 选完武器进入营地，起手武器正确，账号可正常存档。

### A05 镜头（已提交 fc09540c，只能在有 WebGL 的真实窗口测）
1. 角色起步/转向：镜头有轻微前瞻和平滑跟随，不抖、不晃，停下后回正。
2. 角色在地图边缘、传送、切图后镜头不错位，不穿帮。
3. 首领出场与击杀：镜头短暂推近再回正。
4. 战斗中点击/技能瞄准的世界坐标不偏移（镜头只动渲染，不应影响命中与拾取点击）。
5. 开「减少动态效果」：恢复硬锁主角（无前瞻、无推近）。

### A08 小窗口提示 + 字号（提示已提交 96191941；字号已随 9718b4e3 提交）
1. 窗口缩到 <960×540：出现「请放大窗口」类提示，几秒后淡出；放大后不再出现；提示不挡输入。
2. 1280×720 下抽查 HUD、背包、任务页：次要文字 ≥13px，正文 ≥14px，无新增溢出、截断、换行错位。
3. `tokens.json` 中 `Font.Size.Micro` 为 13px，`tokens.css`/`tokens.ts` 已同步。
4. 16:9 等比缩放留边行为不变。
