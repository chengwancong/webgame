# 天赋图标精度调整 · 2026-10-05

用户补充要求：图标至少达到主界面图标的精度。按此要求，将主要属性和三系专精从单色轮廓改成与 `hudMenuIcon` 同一套材质调色板的 SVG 插画。该补充覆盖图形化文档 3.2 中“所有图标均为 currentColor 双色调”的外观限制；仍保留 SVG、32×32 viewBox、圆角描边及公共图标入口。

生产修改集中在 `apps/web/src/ui/icons.ts`。18 个图标键采用明确闭合轮廓、分离的阴影色面与少量高光；攻击、近战、物理伤害、技能伤害、冷却等别名继续共用对应图标。剑与盾、法杖、弓分别表达战士、法师、游侠。吸血使用血滴，避免和生命心形混淆。所有颜色直接复用现有 Icon、Danger 与 ChromeInk Token。删除被替换的旧路径，保留原来的调用接口、尺寸、可访问名称与未知属性回退。
