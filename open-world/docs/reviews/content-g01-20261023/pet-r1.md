# 宠物R1后端验证

源码目标：0.11.54 / protocol55 / ow-95 / db19；未部署。三种主动规则已从隔离原型接入正式 `petBuildParts`，其余15家族不变。常见攻击3%/生命4%、稀有攻击4%、传说攻击4%/暴击3%仍按旧档位；风芽鹿生命被动替换未完成。

## 行为、视图与回执

- 风绒每60tick只攻击一个目标，单次系数为原120tick技能一半。
- 风芽鹿每120tick产生主人最大生命4%（1级）的盾，持续90tick；无攻击，当前与保存方案都不会把其流派算作弱点伤害来源。最高盾量随既有等级系数成长。
- 岚羽每120tick首击加两次连锁，比例1/0.7/0.49，三个不同目标；单目标不回弹补足伤害。
- 宠物 `activeEffect` 直接从可执行规则产生。盾事件 `shieldGained` 是本次实际增量，保留 `amount` 旧语义；已有更大盾时不能按名义盾量播放增长提示。盾的持续期仍沿现有执行器刷新规则。
- `effect_triggered.followupActions` 从本场冻结规则派生；新岚羽为nova+arc，旧范围规则没有该后续动作。前端用本场事件而非局外新面板判定旧实例表现。
- 新增33项单测，连同设计、Z规则和首发HEX共83项通过；真实临时PG新5项+旧Z9项共14项通过。覆盖规则执行、盾时序、助阵、未拥有宠物过滤、当前/保存方案、前后检查点逐帧一致、旧范围规则恢复、API严格契约、幂等和战斗锁。

## 一次受控测量

入口 `tools/spine/pet-r1-verify.ts`（主干命令 `pet-r1-verify`）。3家族×4等级（1/10/20/30）×5种子（11/23/47/71/101）×2目标数（1/3），共120组新旧配对、240个真实World。固定100攻击、1000生命，24秒窗口；无角色技能、被动、暴击、HEX、弱点或护甲。靶不移动、不攻击，事件伤害必须与实际生命损失一致。

1级五种子结果一致：

|主动|旧单目标伤害|新单目标伤害|旧三目标总伤害|新三目标总伤害|新最高护盾|
|---|---:|---:|---:|---:|---:|
|风绒|1296|1296|3888|1296|0|
|风芽鹿|2154|0|6462|0|40|
|岚羽|2802|1278|8406|2802|0|

风绒保持名义单体频率预算，但明确失去旧范围覆盖；岚羽三跳共享原一次基数，实际目标不足就损失后续跳数。风芽鹿用伤害换盾，不能把40最高盾量当作40有效吸收。

这些是主动机制验证，不是实战TTK、有效护盾、通关成功率或被动等价证明。未据此进行二次调参，未宣称M14全绿。原始明细与输入哈希保留 `.runtime/content-g01/pet-r1-measurement*.json`，不进Git；执行后只补脚本类型标注，未改测量逻辑或再次测量。
