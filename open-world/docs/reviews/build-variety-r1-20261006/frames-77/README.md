RS 提交有意只暂存本任务差异，当时已存在的武器、任务表等未提交依赖不在纯 Git 检出中。独立基线因此由 RS 验收指纹、实施前备份和提交内容复原。164 个依赖文件与已提交的 RS 验收指纹相符。四个兼容依赖另行列明：两个后续美术清单、后续任务运行时，以及含 M1 协议扩展的实施前 contracts。构筑不含星潮海进度、不执行任务命令；伤害解析器、养成解析器、套装计算器、技能定义、技能机制和战斗执行器均单独与 RS 指纹核对。这里没有宣称纯净检出 RS 提交即可运行。
