## 0. 结论

1. **先把“效果”做成零件。** 每个零件 = **触发 × 条件 × 作用技能类型 × 效果 × 限制**。御魂的 4 件套、圣遗物的套装效果、海克斯的强化，本质上都是这样的零件，只是数值大小和获取方式不同。
2. **零件引擎已经有雏形**：武器流派连携（`packages/contracts/weapon-combos.ts`）已经实现了“命中/暴击/击杀/施放/第 N 次/被动 × 伤害类型/技能形态/目标状态 × 爆发/挂状态/扩散/裂片/回响/返还冷却/增伤”，并且有概率、冷却、每帧预算。只是现在只给主手流派用。本方案把它扩成通用的**特效原子库**，所有来源都引用它。
3. **六个来源分工**：

| 来源 | 参考 | 携带什么 | 力度 | 在哪拿 |
|---|---|---|---|---|
| 副属性（二级属性） | 御魂副属性、圣遗物副词条 | 纯属性；种类从 25 扩到 49 | 小 | 所有装备 |
| 部位主属性 | 御魂 2/4/6 号位、圣遗物沙/杯/头 | 头盔/项链/戒指/鞋随机主属性 | 中 | 所有装备 |
| 铭纹（新） | 暗黑 4 的“当……时”词缀 | 1 个小型触发原子 | 小 | 稀有 30%、传说必带 |
| 套装 2 + 4 | 御魂、圣遗物 | 2 件属性，4 件触发原子 | 中 | 18 套，按武器谱系 × 系列 |
| 威能 | 暗黑 4 威能 | 技能变形或大型原子 | 大 | 传说装备，萃取进法典 |
| 潮印（新） | 海克斯大乱斗 | 改规则的局内强化 | 大，局内有效 | 地城每次运行三选一 ×3 |

4. **目标**：17 个可成型的流派（§9），每个流派至少有 1 套 4 件套、1 个核心威能、2–3 种关键二级属性和偏好的潮印。同一个武器可以走 2–3 个流派，同一个流派也能换不同武器。

## 1. 现状诊断：为什么单一

| # | 事实 | 位置 | 后果 |
|---|---|---|---|
| 1 | 词缀 25 种：12 种通用属性 + 13 种“某类伤害 +x%”。13 种全部汇进**同一个加算区** | `gear-affixes.json`；`simulation/set-calculator.ts` `applyAffixBonuses` | 多一条“火焰 +15%”边际很低；不同词缀之间只是数字差 |
| 2 | 装备上没有任何触发特效。战斗里装备能打开的效果开关只有 4 个：燃烧、连锁、穿透、护盾 | `simulation/index.ts` `stats.effects` | 换装备不改变打法 |
| 3 | 套装：6 个谱系 × 2/4/6 件，属性都是“攻击 +1、暴击率 +3%”这类小数字，4/6 件再加一个标签乘区；没有条件，没有触发 | `equipment-runtime.json` `families` | 套装只是更大的数字 |
| 4 | 威能 154 个：80 个是 8 种通用属性的数值梯度，30 个技能专属大多是“伤害 +40% 范围 +30%”，16 个标签乘区，10 个神话（攻击 + 技能伤害）；**只有 18 个流派威能有机制** | `content/deep-progression.ts` `aspectDefinitions` | 掉落的传说大多只是数字 |
| 5 | 部位没有分工：所有部位抽同一个词缀池；没有随机主属性；强化只涨主属性 | `affix-generator.ts`、`combat-numerics.json` | 没有“这件鞋主属性对了”的追求 |

## 2. 特效原子

### 2.1 结构

把 `comboRuleSchema` 扩成 `effectRuleSchema`。新文件 `packages/contracts/effects.ts`，内容在 `packages/content/effect-atoms.json`。

```
原子 = {
  id, name, description,
  trigger,       // 何时检查
  conditions[],  // 全部满足才生效
  filter,        // 作用于哪些技能：标签 / 武器 / 伤害类型
  action,        // 做什么
  limits,        // 概率、内置冷却、叠层上限
  scale          // 哪些参数随来源等级缩放
}
```

来源只引用原子 ID 和档位，**不复制规则**：同一个“暴击时召落雷”，铭纹给 30% 伤害，套装给 60%，潮印给 120% 并去掉冷却。

### 2.2 触发

| 触发 | 现有 | 说明 |
|---|---|---|
| `hit` / `crit` / `kill` / `cast` / `nth` / `passive` | 有 | 沿用 |
| `hurt` | 新 | 受到伤害 |
| `dodge` | 新 | 闪避成功 |
| `dash` | 新 | 使用位移技能后 |
| `status_apply` | 新 | 对敌人施加指定状态时 |
| `low_hp` | 新 | 生命首次低于阈值（离开阈值后可再次触发） |
| `interval` | 新 | 战斗中每 N 秒 |
| `kill_elite` | 新 | 击杀精英或首领 |

### 2.3 条件

| 条件 | 例 |
|---|---|
| `target_status` | 目标燃烧 / 中毒 / 流血 / 感电 / 迟缓 / 冻结 / 破甲 / 易伤 / 受控 |
| `target_rank` | 普通 / 精英 / 首领 |
| `target_hp` | 目标生命 < 35% 或 > 80% |
| `self_hp` | 自身生命 < 50% 或满血 |

### 2.4 效果

| 效果 | 现有 | 说明 |
|---|---|---|
| `nova` / `status` / `spread` / `shards` / `echo` / `refund` / `amplify` | 有 | 沿用 |
| `buff` | 新 | 自身获得属性或乘区，持续 N 秒，可叠层 |
| `mark` | 新 | 目标获得“易伤”（受到伤害 +x%）或其他减益 |

| `heal` / `mana` | 新 | 回复生命 / 能量 |
| `cooldown` | 新 | 减少其他技能冷却，或重置一个 |
| `field` | 新 | 在地面留下持续区域（火海、毒云、雷区），沿用地面法术挂载 |

新增状态：`freeze`（冻结：不能行动，受到冰霜以外的伤害解除；首领只迟缓）与 `vulnerable`（易伤：受到伤害 +x%，单独乘区）。两个都要有执行器、特效（先从现成特效库检索复用）和测试。

### 2.5 限制（防失控）

- 沿用：衍生伤害不触发 `hit` 类原子；击杀连锁最多 2 层；每帧最多 24 个动作；回响不再回响。
- 每个原子必须写 `icd`（内置冷却）或 `chance`，二者至少一个；`passive` 除外。
- 同一个原子 ID 从多个来源获得时**取最高档，不叠加**（与现有威能“同类不叠加”一致）。
- 叠层类 `buff` 必须写上限。

### 3.2 伤害分区调整：三个加算池

现在所有 “+x%” 都进同一个加算池，越多越不值钱。改为三个互相相乘的加算池：

```
技能伤害 = 攻击 × 技能系数 × 等级成长
         × (1 + Σ类型增伤)    元素、形态、方式（火焰、近战、投射物……）
         × (1 + Σ条件增伤)    对精英、对受控、对近距离、对残血……
         × (1 + 易伤)          目标身上的易伤
         × 暴击
         × Π独立乘区           套装 4 件、威能、潮印、星潮之力……
```

效果：同样的 +15%，堆在“没人堆的池”里更值钱；条件类属性第一次有了独立价值，流派之间的取舍就出来了。实现位置：`rules/damage-zones.ts` 的 `DamageZone` 增加 `pool: 'type' | 'cond'` 字段，`foldZones` 分池相加。

### 3.3 部位主属性（御魂 2/4/6 号位、圣遗物沙/杯/头）

| 部位 | 主属性 | 说明 |
|---|---|---|
| 武器 | 攻击（固定） | 不变 |
| 衣服 | 护甲（固定） | 不变 |
| 头盔 | 随机：暴击率 / 暴击伤害 / 生命% / 受治疗加成 | 圣遗物“头” |
| 项链 | 随机：攻击% / 某元素伤害% / 某形态伤害% / 生命% | 圣遗物“杯” |
| 戒指 | 随机：攻击% / 某状态几率 / 冷却缩减 / 能量回复 | |
| 鞋 | 随机：移速 / 施法速度 / 护甲% / 生命% | 圣遗物“沙” |

各主属性的权重放在 `gear-affixes.json` 的 `mainStats` 新节。“暴伤头”“火伤项链”就是长期追求。

### 3.4 副属性按部位限制

- 词缀池加 `slots` 字段：例如状态几率不出在衣服上，荆棘只出在衣服 / 头盔上，施法速度不出在武器上。
- 同件不重复（现规则）；主属性和副属性不能是同一种。
- **强化开词条**（御魂）：强化到 +3 / +6 / +9 / +12 / +15 时各触发一次：副属性未满 → 新开一条；已满 → 随机一条提升一个档位。原来每级主属性 +8% 保留。旧装备从下次跨过节点开始生效，已强化的等级不补发。
- **重铸**：每件装备只能锁定一条副属性反复重铸（暗黑 4 规则），费用读配置。

## 4. 铭纹（装备上的小特效）

- 稀有装备 30% 带 1 条，传说装备必带 1 条（在威能之外）。
- 铭纹 = 一个原子 × 0.5 档。可出现的原子按部位分组（例：武器偏攻击触发，衣服偏 `hurt` 触发，鞋偏 `dash` / 移动）。
- 掉落时随机；重铸不能改铭纹；分解时有 20% 几率提取为“铭纹拓片”，可以拓到同部位另一件装备上（覆盖原铭纹）。
- 同一个铭纹多件同时穿戴，只有最高档生效（§2.5）。

## 5. 套装：18 套，2 件 + 4 件

### 5.1 规则

- 套装从 2/4/6 件改为 **2 件 + 4 件**。六个部位可以 4 + 2（两套），也可以 2 + 2 + 2（三套 2 件）。
- 套装身份 = **谱系 × 系列**（6 × 3 = 18 套）。造型阶段 T1/T2/T3 只缩放数值（×1.0 / ×1.25 / ×1.5）。已有 54 个套装名和 324 件装备的造型、名字都不变：同一谱系同一系列的三个造型阶段属于同一套效果（例：T1 和 T3 的剑·常规件可以凑成 4 件，按最低阶段计数值）。
- 套装不限武器：穿 4 件法杖·常规的效果，主手拿暗器也生效。
- 2 件给属性（进类型或条件加算池），4 件给一个原子（×1.0）+ 一个独立乘区（只对符合条件的技能）。

## 6. 威能：从数字改成变形

### 6.1 规则

- 新威能分两种：
  - **技能变形**：改变一个技能怎么放（引导、分裂、回旋、留地面、改伤害类型）；
  - **大型原子**：一个原子 × 1.5 档 + 一个独立乘区。
- 法典槽位、萃取、法典等级规则不变。
- 旧的 80 个通用数值威能、30 个技能专属数值威能、10 个神话**从掉落池移除**；已在法典里的继续生效，界面标“旧版”。18 个流派威能和 16 个标签威能保留。

### 6.2 首批 60 个

## 7. 潮印（海克斯式局内强化）

### 7.1 在哪拿

| 场景 | 次数 | 时点 | 有效期 |
|---|---|---|---|
| 地城每次运行 | 3 次三选一 | 进入时 / 清完中段精英 / 首领门前 | 本次运行 |
| 星潮夜（野外事件） | 1 次三选一 | 击退入侵后 | 离开该岛或 20 分钟 |
| 世界层级 IV 及以上的地城 | 额外 1 次 | 首领战中生命 50% 时 | 本次运行 |

每次运行有 1 次“换一组”。

### 7.2 档位

| 次序 | 银 | 金 | 棱彩 |
|---|---|---|---|
| 第 1 次 | 70% | 30% | — |
| 第 2 次 | — | 100% | — |
| 第 3 次 | — | 70% | 30% |

同一次的三个选项档位相同（海克斯规则）。

### 7.3 内容（90 个：银 40 / 金 35 / 棱彩 15）

| 类 | 例 |
|---|---|
| 属性砧（银） | 暴击率 +10%；状态几率 +20%；技能范围 +20%；移速 +15% |
| 原子强化（银 / 金） | 获得任一原子 × 银 1.0 / 金 1.6，从当前构筑相关的主题里抽 |
| 套装共鸣（金） | “若穿戴 4 件炽炉：引爆范围 +50%，引爆后保留 1 层燃烧” |
| 规则改变（金 / 棱彩） | 所有投射物额外 +2 且不分摊伤害；所有范围技能命中后 1 秒再炸一次；每次位移重置一个随机技能冷却；生命上限的 50% 转为护盾，护盾每秒回复 |
| 豪赌（棱彩） | 只能用一个技能，该技能伤害 ×3、冷却 −50%；生命上限减半，暴击伤害 +150% |

- 选项生成会偏向当前构筑：至少 1 个选项与玩家已有的套装、威能或主属性标签相关（海克斯“协同”提示）。
- 潮印只在局内生效，不进存档成长，不进交易。
- 完整 90 条见 [内容清单 §5](open-world-build-variety-catalog.md#5-潮印-90-个)。

### 7.4 服务端要求

- 选项由服务端用副本实例种子生成，写在实例状态里；选择是一条带 `command_id` 的副本命令；断线重连保留已选和待选（[副本生命周期](dungeon-lifecycle.md)）。
- 已选潮印并入实例的构筑快照（`rules/dungeon-build.ts`），战斗核心只消费解析后的参数。
- 是否开放潮印、次数、档位表由 `dungeons.json` 的公共默认 / 模板 / 逐副本覆盖声明（剧情副本、团队副本可以关闭）。

### 7.5 与数值心流的关系

数值心流的墙就是阶段地城首领，所以地城里的标准人**默认带潮印**：按“每次随机选、不刻意配合”的平均收益，把地城内标准人单体秒伤记为 ×1.25、等效生命 ×1.10。地城怪物的难度修正同步乘上这两个系数，墙的“到达比”和钥匙大小不变。`tools/numeric-flow-sim.py` 增加参数 `AUGMENT_DPS=1.25`、`AUGMENT_EHP=1.10` 后重跑 §3。会配合构筑选潮印的玩家能拿到 ×1.4–1.6，就是“玩得好过墙快”的空间。

## 8. 防作弊与服务端

- 所有属性、主属性、铭纹、套装、威能、潮印的生效结果由服务端解析成参数，客户端战斗只执行（现规则）。
- **抽查的“最快清场时间”必须把触发特效按上界算进去**（全部触发、全部暴击），宁可估得更快，也不误判正常玩家（用户既定原则：只做抽查，宁漏不错）。新原子上线时必须同步更新上界估算，否则不启用对应抽查。
- 每个原子的触发次数、衍生伤害进入战斗统计，便于测量和面板显示。

## 13. 验收

1. **流派可组**：§9 的 17 个流派都能用当前内容组出来；每个流派的核心零件（4 件套、威能、关键属性）在对应阶段地城或野外有获取来源。
2. **平衡带**：`pnpm balance` 按 17 个流派各跑一遍，在各自擅长的内容（清怪 / 单体 / 生存）上，表现在中位数的 0.8–1.25 倍以内；没有任何流派在全部三项上都排前 3。
3. **深度有效**：同等级“成型”比“随便穿”高的倍数，不低于 [Build 深度设计](build-depth-design.md) §1 的目标（23 级 1.5 倍 → 50 级 7.6 倍）。
4. **不失控**：任意构筑下每帧动作数 ≤ 24；衍生伤害不触发命中类原子；10 分钟压力测试帧时间不超过 M0 的预算。
5. **防作弊不误判**：带满触发特效的构筑跑 100 次合法清场，抽查误判 0 次。
6. **存档**：旧装备的全部属性、强化、锁定保留；旧威能在法典里继续生效并标“旧版”。324 件收藏装备的套装加成随规则版本切换为 2 + 4（规则升级，已开战的实例继续用冻结规则）；旧 6 套（狂战士等）保留旧规则。随机主属性、铭纹只出现在新掉落装备上；强化开词条从此后的强化开始生效。
7. **局内强化**：潮印选择在断线重连后保留；同一实例重复提交选择只生效一次；剧情副本按配置关闭。
