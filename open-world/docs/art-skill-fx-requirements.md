# 深渊行者 - 技能特效美术需求

> 怪物技能、BOSS技能、环境特效的视觉效果需求

---

## 特效设计原则

### 视觉清晰度
- **可识别性**：玩家必须能快速识别危险技能
- **前摇提示**：重要技能有明显的预警
- **颜色编码**：
  - 红色 = 危险/伤害
  - 蓝色 = 冰冻/减速
  - 紫色 = 暗影/诅咒
  - 金色 = 增益/神圣
  - 绿色 = 毒素/治疗

### 技术规格
- **文件格式**: PNG序列帧 或 Spine动画
- **帧率**: 30fps
- **分辨率**: 根据技能范围（32×32 到 512×512）
- **透明度**: 使用Alpha通道
- **混合模式**: 多数使用Additive（加法混合）
