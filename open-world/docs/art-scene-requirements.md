# 深渊行者 - 场景美术需求

> 3个新章节的场景、地图、环境美术资源需求

## 第4章：冰封雪域 - 场景需求

### 场景主题
**"刺骨寒风的冰雪荒原"**
- 色调：冰蓝色 + 白色 + 银灰色
- 氛围：寒冷、荒凉、空旷
- 天气：暴风雪、雾气
- 时间：永夜（极地）

### 地图元素需求

#### 1. 地面Tileset
**地面类型（32×32像素）：**
- 厚雪地面（主要）- 白色、有积雪纹理
- 冰面 - 蓝色透明感，有裂纹
- 冰雪混合地面 - 过渡区域
- 岩石露出地面 - 灰黑色岩石+积雪

**数量需求：** 至少16种变体（边角、转角、中心）

#### 2. 环境装饰物
- **冰柱**（Prop）
  - 大型冰柱：高度3格，可作为障碍物
  - 小型冰锥：点缀地面
  - 数量：20-30个/地图
  
- **雪堆**
  - 大雪堆：2×2格，阻挡视线
  - 小雪堆：1×1格，装饰
  - 数量：30-40个/地图

- **冰冻树木**
  - 枯树+冰霜：高度4-5格
  - 倾倒的冰树：地面装饰
  - 数量：15-20棵/地图

- **冰晶簇**
  - 发光的蓝色水晶
  - 尺寸：1×1到2×2格
  - 特效：微弱发光
  - 数量：10-15簇/地图

#### 3. 障碍物
- **冰墙**
  - 厚度：1格
  - 高度：3-4格
  - 纹理：半透明冰块，有气泡
  
- **冰岩**
  - 不规则形状的巨大冰石
  - 尺寸：2×2到4×4格
  - 数量：5-8个/地图

#### 4. 地标建筑
- **安全点 - 冰霜营地**
  - 简易帐篷（兽皮+冰柱支撑）
  - 篝火（蓝色火焰）
  - 尺寸：3×3格
  
- **传送门 - 冰之门**
  - 两根高大冰柱形成拱门
  - 中间旋涡状传送光效
  - 尺寸：2×3格

- **BOSS入口 - 冰霜王座**
  - 巨大的冰制拱门
  - 台阶向上3层
  - 尺寸：5×5格
  - 特效：蓝色迷雾萦绕

### BOSS房间 - 冰霜王座

**尺寸：** 48×48格（小型竞技场）

**布局：**
- 中央圆形平台（直径30格）
- 周围环绕冰柱（8根，等距分布）
- 地面：光滑冰面纹理

**装饰：**
- 王座：背景中央，巨大冰雕座椅
- 冰雕像：4座，守护四方
- 吊灯：顶部冰晶吊灯（装饰）

**特效：**
- 地面反光效果
- 雪花持续飘落
- 蓝色雾气弥漫

## 第5章：暗影深渊 - 场景需求

### 场景主题
**"黑暗侵蚀的亡灵领地"**
- 色调：深紫色 + 黑色 + 暗红色
- 氛围：诡异、压抑、恐怖
- 特效：黑雾、幽灵火
- 时间：永夜

### 地图元素需求

#### 1. 地面Tileset
**地面类型：**
- 腐蚀土地（主要）- 紫黑色，龟裂纹理
- 深渊裂缝 - 黑色深渊，边缘发光
- 紫色草地 - 枯萎的诡异植被
- 骸骨地面 - 散落白骨

**数量需求：** 至少20种变体

#### 2. 环境装饰物
- **死树**
  - 扭曲的枯树，树干发紫光
  - 高度：4-6格
  - 数量：25-30棵/地图

- **墓碑**
  - 倾斜的石碑，刻有符文
  - 尺寸：1×1格
  - 数量：40-50块/地图

- **骸骨堆**
  - 散落的骷髅和骨架
  - 尺寸：1×2格
  - 数量：30-40堆/地图

- **诅咒石碑**
  - 高大的黑色石碑，发紫光
  - 尺寸：1×3格
  - 特效：紫色光晕
  - 数量：8-10块/地图

- **幽灵火盆**
  - 紫色火焰的火盆
  - 尺寸：1×1格
  - 特效：火焰动画
  - 数量：15-20个/地图

#### 3. 特殊机制装饰
- **光明祭坛**（游戏机制）
  - 发金色光的圣洁祭坛
  - 尺寸：2×2格
  - 特效：金色光柱向上
  - 数量：4个（BOSS房）

- **黑暗裂缝**
  - 地面裂开，冒出黑雾
  - 尺寸：2×2格
  - 特效：持续黑烟
  - 数量：10-15个/地图

#### 4. 地标建筑
- **安全点 - 圣光结界**
  - 金色光罩保护的小区域
  - 地面有光明符文
  - 尺寸：3×3格
  
- **传送门 - 暗影之门**
  - 黑色岩石拱门
  - 中间紫色漩涡
  - 尺寸：2×3格

- **BOSS入口 - 深渊之口**
  - 巨大的深渊裂口
  - 向下台阶5层
  - 尺寸：6×6格
  - 特效：黑紫色雾气翻滚

### BOSS房间 - 暗影祭坛

**尺寸：** 48×48格

**布局：**
- 中央祭坛（5×5格）
- 四周4个光明祭坛（对称分布）
- 地面：黑色大理石+紫色符文

**装饰：**
- 巨大的暗影雕像（背景）
- 骷髅柱子×8（环绕）
- 悬空的灵魂碎片（装饰）

**特效：**
- 紫色雾气从地面升起
- 光明祭坛发金光
- 黑色能量在祭坛中旋转

## 第6章：龙骨荒漠 - 场景需求

### 场景主题
**"龙族陨落的远古废墟"**
- 色调：黄褐色 + 橙红色 + 金色
- 氛围：荒凉、史诗、远古
- 特效：沙尘暴、龙魂幻影
- 时间：黄昏

### 地图元素需求

#### 1. 地面Tileset
**地面类型：**
- 沙漠地面（主要）- 黄色沙地，有风纹
- 龙骨化石地面 - 白色巨大骨架嵌入地面
- 废墟石板 - 破碎的古代地砖
- 岩石地面 - 红褐色岩石

**数量需求：** 至少24种变体

#### 2. 环境装饰物
- **龙骨化石**（核心元素！）
  - **巨龙头骨**：6×4格，地标性
  - **龙脊骨**：8×2格，横跨场景
  - **龙肋骨**：2×3格，拱形
  - **龙爪骨**：3×2格
  - **龙尾骨**：5×1格
  - 数量：15-20块大型骨架/地图

- **废墟遗迹**
  - 倒塌的石柱：高3-5格
  - 破碎的石墙：2×1格
  - 石像残骸：2×2格
  - 数量：30-40个/地图

- **沙丘**
  - 大型沙丘：4×3格，可遮挡视线
  - 小沙堆：1×1格
  - 数量：20-25个/地图

- **龙之图腾**
  - 雕刻龙纹的石碑
  - 尺寸：1×3格
  - 特效：顶部有微弱火焰
  - 数量：8-10个/地图

- **水晶龙蛋**
  - 巨大的结晶化龙蛋
  - 尺寸：2×2格
  - 特效：红色光晕
  - 数量：5-8个/地图

#### 3. 障碍物
- **巨型龙骨**
  - 作为墙体的龙骨化石
  - 不规则形状
  - 尺寸：各异

- **岩石堆**
  - 红褐色巨石
  - 尺寸：2×2到3×3格

#### 4. 地标建筑
- **安全点 - 龙之遗迹**
  - 古代龙族神殿废墟
  - 有残破的龙雕像
  - 尺寸：4×4格
  
- **传送门 - 龙门**
  - 两根巨大龙牙形成的门
  - 中间金色传送门
  - 尺寸：3×4格

- **BOSS入口 - 龙王陵墓**
  - 巨大的地下墓穴入口
  - 龙形浮雕装饰
  - 台阶向下
  - 尺寸：8×8格
  - 特效：橙红色光芒

### BOSS房间 - 龙王陵墓

**尺寸：** 64×64格（超大竞技场）

**布局：**
- 椭圆形竞技场（长轴50格）
- 中央高台（10×10格）
- 四周有4根龙柱（3×3格）

**装饰：**
- 巨型龙骨王座（背景）
- 龙之壁画（墙面）
- 悬挂的龙魂幻影（空中）
- 地面龙纹图案

**特效：**
- 地面金色纹路发光
- 空中龙魂缓慢飘荡
- 沙尘暴效果（阶段2）
- 火焰从地缝冒出（阶段3）

**特殊元素：**
- **掩体岩石**×4
  - 用于躲避"毁灭吐息"
  - 尺寸：3×3格
  - 可被破坏

## 技术规格

### 文件格式
- **Tileset**: PNG, 32×32像素/格，透明背景
- **装饰物**: PNG, 透明背景，原点在底部中央
- **特效**: PNG序列帧或Spine动画

### 色彩规范
- **冰封雪域**: 
  - 主色：#A5D8FF (冰蓝)
  - 辅色：#FFFFFF (白)
  - 高光：#74C0FC (亮蓝)

- **暗影深渊**:
  - 主色：#5F3DC4 (深紫)
  - 辅色：#1A1B26 (黑)
  - 高光：#FF6B6B (暗红)

- **龙骨荒漠**:
  - 主色：#F59E0B (金黄)
  - 辅色：#92400E (深褐)
  - 高光：#FCD34D (亮金)

### 分辨率
- 游戏分辨率：1920×1080
- Tile大小：32×32像素
- 装饰物：根据实际大小缩放
