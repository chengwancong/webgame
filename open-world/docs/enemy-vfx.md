# 怪物弹道与危险预警

2026-10-02，本轮整改正式 `CombatVfx` 的敌方飞行主体、尾迹、真实命中反馈与地面预警。数值、判定、速度、前摇与延迟未修改；基础箭弹仅补充实际发射事件，普通范围攻击补充来源和施法实例，使表现能对应真实攻击。

## 当前表现

- 普通箭弹使用原有箭图，按箭尖绑定逻辑飞行点，主体长度76px；首领基础箭弹94px，短尾迹沿实际经过位置渐细。
- 寒冰箭／冰枪使用有实体色面、深色边缘与两面明暗的冰晶主体；白骨之矛使用独立骨节轮廓与米白骨色；虚空弹使用紫色实体核心、短旋流和尾迹。尺寸与相位配置在 `enemy-vfx-style.ts`，绘制在 `enemy-vfx-drawing.ts`。这些是本游戏的演出适配，不是APK原始粒子还原。
- 命中仍消费 `hit_resolved` 的真实接触点；冰晶／骨质碎片与虚空冲击同tick出现。没有预测伤害或伪造额外爆炸。
- 地面圆形边界一直保持真实等距投影尺寸，填色、倒计时弧线、向内流动与八个内向标记位于边界内。最后8tick加强边缘提示；减少动态保留范围与时间信息，取消呼吸与循环流动。
- 光束保留真实方向、半宽与长度，地面箭头沿攻击方向流动，横向时间线表示准备进度；不会用一个旋转矩形代替实际世界投影。
- 同一次怪物施法的前摇与落地延迟共用时间基准，预警在交接时不从零重新开始。延迟和触发时刻以当前战斗剩余tick为准。玩家自己的延迟区域不再使用敌方红色危险提示。

## 实现约束

危险边界与攻击主体使用受保护的对象池条目，屏外裁剪生效。预算不足时优先减去尾迹与附加颗粒；暂停冻结战斗时间和尾迹采样，死亡和换场景清理实例与施法时间表。

Phaser的GPU透明度打包会让大于1的alpha回绕；公共路径绘制已限制到0～1，避免临近触发的呼吸峰值反而让边缘消失。颜色来自共用Combat Warning Tokens。

APK战斗粒子仍按原可用性清单登记；本轮不将这些适配标记为APK原作还原或390组粒子已接入。

## 验收入口

`/monster-vfx-qa.html` 使用正式WorldScene、正式角色资源与真实战斗核心，在独立内存世界运行。支持前后渲染器对照、正常／慢放、逐帧、弹体／命中前暂停、三个地面背景、录像与20/30、60/100压力场景。压力场景补入的零伤害弹体只用于性能，不用于证明技能机制或真实发奖。

基线为 `combat-vfx-before-enemy.ts` 与 `vfx-profiles-before-enemy.ts`，仅验收页引用，正式游戏只加载整改后的渲染器。

用户要求预览保持播放：默认正常速度，标杆集持续循环；录像保存和性能采样完成后不自动暂停画面。逐帧或关键时刻暂停只在用户手动选择对应控制时启用。

暴风雪后续修正：首领单技能预览隔离默认普攻，按完整前摇和持续时间播放；正式演出使用从上方落下的雪片、阵风和落地消散，取消ice-air弹体贴图与通用地面冰锥。修正见 `docs/reviews/open-world/blizzard-vfx-20261002`，此前标杆录屏未播到暴风雪释放，不能作为其最终视觉验收证据。

针对性检查覆盖实际普通箭弹发射/命中关联、范围攻击来源、怪物前摇与延迟交接、暂停、真实触发时刻，以及危急脉冲alpha边界。既有55技能、怪物与首领的战斗轨迹保持一致。视觉、录屏、性能与发布结果另见 `docs/reviews/open-world/enemy-vfx-20261002`。
