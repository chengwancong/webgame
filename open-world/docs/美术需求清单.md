## 📦 交付格式

### 文件结构
```
art-assets/
├── chapter4-tundra/
│   ├── scenes/          # 场景PNG
│   ├── monsters/        # Spine动画（JSON+Atlas+PNG）
│   └── fx/              # 特效序列帧PNG
├── chapter5-abyss/
│   ├── scenes/
│   ├── monsters/
│   └── fx/
├── chapter6-dragonbone/
│   ├── scenes/
│   ├── monsters/
│   └── fx/
└── common/
    ├── ui/              # 通用UI元素
    └── particles/       # 通用粒子贴图
```

### 技术规格
- **场景**：PNG，32×32px/格，透明背景
- **怪物**：Spine 3.8+（JSON + Atlas + PNG）
- **特效**：PNG序列帧，30fps，透明背景，Additive混合
- **分辨率**：1920×1080基准

### 命名规范
```
场景：{地图ID}_{元素类型}_{编号}.png
  例：tundra_ice_pillar_01.png

怪物：{怪物ID}.json + {怪物ID}.atlas + {怪物ID}.png
  例：frost_wolf.json

特效：{技能ID}_{效果类型}_{序号}.png
  例：blizzard_snowflake_01.png
```
