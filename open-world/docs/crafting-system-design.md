# 素材与制作系统设计（2026-10-14 草案）

定位：贯穿六岛 → 裂星潮 → 世界层级的**长期目标**。刷图的每一分钟都在攒"下一件想要的东西"。
这个系统和掉落是互补关系，不能替代掉落：掉落负责惊喜，制作负责确定性和定向追求。

**缺口**
1. 世界里没有可采集的东西，采集和"探索、割草"没有关联。
2. 材料不分岛，到了第 6 岛，第 1 岛的材料就没有意义了。
3. 配方太少，产出又只有"给一件固定装备"，**不能定向**（部位、武器倾向、元素），所以不构成追求目标。
4. 没有长期的熟练度/大师化，满级之后没有可以继续追的东西。
5. 配方的获取方式和开放世界的"发现"无关。

## 1. 设计原则

1. **刷图即采集**：材料主要来自本来就在做的事（割草、开宝箱、打精英/首领、探索），采集点只是补充。不额外增加"去挖矿"的独立劳动。
2. **制作是定向，不是更强**：同一阶段内，制作品的期望强度 ≤ 掉落上限。制作品的好处是"指定部位/倾向/元素 + 锁一条词缀"，天花板留给掉落和精工。
3. **旧岛材料永不作废**：所有岛的材料都能提纯成通用的"星尘"，回老岛刷也有收益（但不产出当前阶段钥匙，遵守 numeric-flow §4.2）。
4. **全部专业开放**：单机没有交易，"六选二"只会制造后悔。改成全部开放、各自升熟练（和天赋改为全部开放的方向一致）。
5. **配方靠发现**：配方从宝箱、稀有怪、拆解、声望、世界事件中获得，图鉴记录收集进度。
6. **服务端为准**：采集、制作、提纯都走服务端命令，提供不写入的预览，回执幂等；客户端只显示服务端已经解析好的结果。

## 2. 素材体系

### 2.1 四层结构

| 层 | 用途 | 来源 | 示例 |
|---|---|---|---|
| **T0 通用** | 所有制作的基础消耗 | 分解、所有怪物 | 强化石（保留）、**星尘**（新增：提纯产物） |
| **T1 岛屿特产** | 本岛配方的主料，每岛 3 种 | 采集点 2 种 + 怪物部件 1 种 | 见 2.2 |
| **T2 首领 / 精英** | 本岛高阶配方、钥匙保底 | 本岛地城精英、稀有、首领 | 每岛 1 种领主材料 |
| **T3 星潮 / 终局** | 精工、大师配方、世界层级 | 裂星潮、世界层级、团本 | 方阵碎片、传说精华、金月、雕文粉尘（沿用旧 ID，改来源） |

### 2.2 六岛特产（主题和元素对应，为抗性药剂、元素锻造服务）

| 岛 | 采集①（矿/晶） | 采集②（植物） | 怪物部件 | 领主材料 | 主元素倾向 |
|---|---|---|---|---|---|
| 风栖岛 | 风纹铁 | 鸣羽草 | 疾风羽 | 风暴核心 | 闪电 / 物理 |
| 雾铃岛 | 雾银 | 铃兰露 | 幽影鳞 | 雾铃之心 | 暗影 / 毒素 |
| 赤炉岛 | 赤炉铜 | 烬椒 | 熔甲片 | 炉心余烬 | 火焰 |
| 霜镜岛 | 镜冰晶 | 雪绒苔 | 霜牙 | 冰镜碎片 | 冰霜 |
| 沉星岛 | 沉星石 | 星藻 | 裂隙甲壳 | 坠星残核 | 奥术 |
| 龙眠岛 | 龙骨矿 | 龙息花 | 龙鳞 | 龙眠之瞳 | 物理 / 火焰 |

> 旧材料迁移：矿石/草药/皮革 → 拆分成各岛特产；角色碎片、召唤碎片、觉醒结晶保留原用途，只修改来源描述。开发期允许清档（见 dev-period-wipe-ok）。

### 2.3 提纯（让旧材料一直有用）

- 任意 T1 材料按 **10 → 1** 提纯为星尘；T2 按 **1 → 5**。
- 星尘可以**兑换任意已解锁岛的 T1 材料**，比例 1 → 3，有损耗，用来防止循环刷取。
- 结果：在第 6 岛缺第 2 岛的料，可以用溢出的材料兑换，不必回去补采；想回老岛割草爽刷，产出也能折成星尘。

### 2.4 堆叠与背包

材料不占 24 格装备容量（沿用现规则），单种上限 9999。材料页按"岛 / 层级"分组，每种显示**来源**和**用于哪些配方**（已有"来源与用途"框架，补数据即可）。

## 3. 获取方式

| 来源 | 产出 | 说明 |
|---|---|---|
| 割草击杀 | T1 怪物部件、少量强化石 | 按怪物族群掉落，在服务端结算 |
| **采集点**（新，`objects.kind=gather`） | T1 采集①② | 每个区域 4–8 个，走近后**手动或半自动采集**（全自动挂机时只采路线上的）；本轮清场后不刷新，**重新进入区域时刷新**，规则和清场一致 |
| 宝箱 | T1 混合、**配方** | 150 个现有宝箱加入配方掉落池 |
| 精英 / 稀有 | T2、配方 | 稀有怪首杀必掉一张本岛配方 |
| 地城首领 | T2 领主材料、钥匙材料 | 钥匙材料只出在本阶段地城（numeric-flow 规则不变） |
| 分解 | 强化石、**拆解学习** | 传奇/套装首次分解时学会它的"图样"，见 5.2 |
| 声望商人 | 配方、稀有 T2 | 用岛声望解锁，金币购买 |
| 世界事件 / 裂星潮 | T3 | 终局材料 |

**采集点的服务端校验**：命令带区域和坐标，校验节点在本轮还没采过、距离 ≤ 2 格、角色不在副本中。只做抽样判定，阈值宽松（遵守"宁漏判不误判"）。

## 4. 专业（全部开放）

| 专业 | 产出 | 对应已有系统 |
|---|---|---|
| **锻造**（武器/护甲） | 定向底材装备、钥匙保底件 | 工坊强化 / 重铸 |
| **饰品工艺**（戒指/项链/护符） | 饰品，偏元素抗性和特效 | 补齐头盔/鞋/戒指空槽的来源 |
| **炼金** | 合剂（攻击/生命）、**元素抗性药剂**、**割草食物**（原烹饪）、提纯 | 合剂模板 |
| **附魔** | 词缀精华、刻印、觉醒结晶 | 威能萃取 / 刻印 |

**熟练度**：每个专业 1–100 级，只靠制作获得经验（采集不单独分专业，统一为"采集熟练"，提升采集额外产出概率）。
熟练度门槛和岛对应：风栖 1–15 / 雾铃 15–30 / 赤炉 30–45 / 霜镜 45–60 / 沉星 60–75 / 龙眠 75–90 / 星潮 90–100。
**溢出的熟练度不卡进度**：配方按岛解锁，熟练度只影响"精良率"（5.3），所以不会出现必须先刷熟练才能做钥匙的情况。

## 5. 制作产出：长期目标在哪里

### 5.1 定向锻造（主线追求）

1. 选**部位** → 选**武器倾向**（物理杖 / 法术杖等，遵守 10-07 的决定）→ 选**元素倾向**（可选，消耗对应岛的领主材料）。
2. 产出：本阶段等级的装备，主属性固定，词缀随机，但**必定带 1 条和所选元素/倾向相关的词缀**。
3. 品质：蓝 / 稀有为主；传奇需要"图样"（5.2）。
4. 预览：服务端返回可能的词缀池和概率（复用 `stageKeyRecipeRandom` 的可预览随机流），不提前暴露具体结果。

### 5.2 图样收藏（最长线）

- 首次分解某件传奇或套装件 → 学会它的**图样**（类似暗黑 4 的威能法典，但范围扩大到套装）。
- 图样 + 材料 → 锻造出指定传奇/套装件，词缀随机，传奇效果确定。
- 套装件兑换（numeric-flow 阶段 18 的制作形态）就在这里实现。
- **图鉴**：六岛 × 部位 × 图样，完成度提供小额永久加成（沿用现有 `collectionDefinitions`，把 `craft-8` 改成按岛分档）。

### 5.3 精良制作与精工（满级后的深坑）

- **精良**：每次制作有概率出精良（主属性 +5%~10%），概率 = 基础 5% + 熟练度加成，**上限 30%**。
- **精工**（世界层级解锁）：对已有装备（掉落或制作都可以）消耗 T3 材料，提升 1 级精工，共 5 级，每级主属性 +4%；第 3、5 级可以**锁定 1 条词缀后重铸其余**。
  这是终局材料的主要去向，和世界层级的奖励倍率一起，构成"越刷越强"的无限出口。

### 5.4 元素抗性药剂与饰品（填补抗性系统的出口）

- 抗性药剂：+X% 指定元素抗性，持续 30 次击杀或 1 次首领战；岛首领战前准备的定向答案（符合产品目标"失败可理解 → 有可执行改善"）。
- 饰品工艺：戒指/护符的主要来源，词缀偏抗性、生命、特效。

### 5.5 工坊建设（看得见的长期目标）

拾星港工坊有 4 座设施：锻炉、饰品台、炼金台、附魔台。每座 1–6 级，用金币 + 各岛 T2 材料升级（每岛的领主材料对应 1 级）。
- 升级效果：解锁本岛配方等级上限、精良率 +2%、提纯损耗降低。
- 场景表现：工坊外观随等级变化（换贴图或摆件），在港口能直接看到成长。
- 这是金币预算中"制造 30%"的主要消耗。

## 6. 与阶段钥匙的衔接

- 钥匙"制作形态"统一归入制作系统：在工坊的"本阶段钥匙"页签显示进度条（7/12），材料只来自本阶段地城（规则不变）。
- 定价公式不变：**开荒目标时长 × 1.4 的期望产出**，约 23% 的玩家靠它拿到钥匙。
- 制作系统的其他产出**不能绕开钥匙**：定向锻造的等级上限 = 当前已通过的阶段，不能提前做下一阶段的装备。

## 7. 数值框架（只定结构，具体值按"一次推导 + 一次验证"）

| 项 | 推导依据 |
|---|---|
| 定向锻造件强度 | = 本阶段掉落同品质中位数，精良件约等于 P70 |
| 定向锻造成本 | 本阶段爽刷时长的 25%–35% 的材料产出 ≈ 1 件 |
| T1 掉率 | 每分钟割草的期望产出 → 满足"一个爽刷期做 2–3 件定向件 + 1 次工坊升级" |
| 金币消耗 | 合计 ≈ 每章金币收入的 30%（工坊建设 12%，制作手续费 10%，图样锻造 8%） |
| 精工 | 每层世界层级的爽刷期可升 1 级精工，与层级奖励倍率 ×1.08 同量级 |
| 提纯比例 | 保证"回老岛刷"的每分钟星尘收益 < 在当前岛直接刷 T1 的 60% |

验证：在 `tools/numeric-flow-sim.py` 增加制作路径，确认①钥匙保底占比仍约 23%，②制作不让开荒中位时长下降 > 5%，③金币结余保持在 20% 左右。

## 11. 已拍板（2026-10-14）

1. **专业全部开放**，不做二选一；删除 `profession.choose` 和采集次数。
2. **全自动挂机只采路线上的采集点**（自动寻路经过、距离 ≤ 2 格时顺手采）；不为采集专门绕路，手动/半自动可以采任意点。
3. **烹饪并入炼金**：割草增益食物作为炼金配方（拾取范围、金币、材料掉率），和合剂共用"N 次击杀"的消耗品模板，同类增益只能生效一个。
4. 工坊外观（默认，未单独确认）：4 座设施合并为 **3 档外观**（1–2 / 3–4 / 5–6 级），减少美术量。
5. 精工（默认，未单独确认）：**上限 5 级**；以后如果终局材料溢出，再加"星级精工"作为无限出口。
