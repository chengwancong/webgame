- 地图中的多次摆放不重复计成新素材；同一资源跨章引用不重复制作。

## 不可混淆的完成度

文档定案不是剧情已可玩；动作资源生成不是动态验收；技能预览不是机制已接入；代理自检不是主代理已通过。现有服务端资产、旧任务档案、奖励回执、角色成长与已开放功能保留。资源先进入独立验收页和正式资源包，再安排新主线工程接入。

详细任务和资源引用以 requirements.json 与 chapters/ 为准。文案变化不得改变稳定ID；新增ID或变更规格由主代理修改设计文档并广播给制作所有者。
