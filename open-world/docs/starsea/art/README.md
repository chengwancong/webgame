# 裂星远航美术需求总表

版本：starsea-20261003-d1。主代理定义与验收；六个子agent制作。全部ID和引用以 [requirements.json](../requirements.json) 为准。

## 规模与拆分

| 组 | 需求条目 | 生产所有者 |

这些是内容与需求数。独立骨架、源图片、皮肤、动作段、导出图集和多次场景摆放各自计数，不能相加当作独立美术数量。

## 全组视觉标准

- 角色：圆润头身、简化五官、柔和深色描边、手绘色面。对照实机主角与已确认的营地方案2：工程 .design/npc-scene-unification-20261003/camp-unified-v2.png。
- NPC默认实机100px高；普通80px、厚甲90px、精英110px、首领150px为本包验收基线，脚底固定，攻击最大动作边界独立测量。不得按原图整块透明画布高度错误缩放。
- 场景维持等距投影(32,18)与32px导航单元；背景远景、地表、装饰、碰撞和遮挡分层。
- 色面：主港奶白/暖木/青蓝/黄铜；暮界灰紫/奶白/青蓝晶核；龙裔米金/青蓝。敌方危险提示使用现有战斗Warning Tokens，元素色不能掩盖危险识别。
- UI维持奶白浅金与当前Token，不新增一套面板皮肤；小图标透明底、大轮廓、少色面、柔和描边，字由程序绘制。
- 模型主体、武器/手部、弹体、受击、地面和环境各自挂载；左右镜像与遮挡必须动态检查。

## 来源与制作顺序

优先读现有正式登记、原生角色完整骨架及已授权特效库，再检索可适配素材，再新制。用于图像生成/编辑的代理先读 imagegen 技能；不得用程序随手画替代该技能要求的位图制作。代码原生的导航、精确预警几何和UI标记保持代码实现。

原始库包含外层SP33、819怪物源库、Q版日式手游SPINE特效300套及已验证APK动效。登记绝对原始路径、哈希、版本、采用部件与调整。未验证资源保持待验证；原始动作缺失不能以两张静态姿态或平移单张图片冒充完成。

## 交付与公共接口

每组只写 assets/starsea/<group>/ 与 apps/web/public/art/starsea/<group>/，局部 manifest 放 assets/starsea/<group>/manifest.json。组内导出脚本与证据也保存在组内目录。六组固定为npc、monsters、bosses、vfx、scenes、props。

manifest字段契约见 requirements.json.manifestContract。源文件、运行文件、全部状态/动作、源哈希、调整、资源依赖、预览方法、自检限制必须可查。路径引用 project-relative 或绝对，runtime URL 使用 /art/starsea/... 或已存在的正式共用URL。

公共目录索引、构建入口、聚合包、生产验收页、资源版本由 props_integration 唯一改写。主代理只改文档、台账和验收报告。
