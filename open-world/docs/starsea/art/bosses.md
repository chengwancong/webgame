# 六章首领美术需求

默认150px显示高，最大动作包围盒与足点另测。首领需idle、move、attack、hurt、death、三种技能的合法动作映射，以及phase-enter/phase-active/phase-end表现说明。不同技能可以共用原生动作，但分别登记真实动作与时序，不伪造不存在的招式帧。

- 第1章；模板候选：meadow-boss，仅后续规则参考，不准因画面改变其数值。
- 主体：灰紫与黄铜重甲、宽圆肩、短巨刃；头盔开口让面部仍可读。
- 技能：ss-fx-b01-lance、ss-fx-b01-stomp、ss-fx-b01-charge。
- 阶段部件：护肩核心由低亮变高亮，保持实体主体与轮廓。
- 来源：优先已验证的完整原生rig与姿态。旧chapters.json中raster-animation-preview不自动成为正式动态；若沿用此来源必须真实补齐并验证动作。
- 交付：主体、衣装/武器、阶段部件、真实动作配置、源版本/哈希、动态预览、所有技能挂点。
- 验收：首领大体型不覆盖危险范围，阶段部件不裁切、不跳足点，死亡后工具/粒子清理。
