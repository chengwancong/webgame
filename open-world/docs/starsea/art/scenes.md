# 场景与环境需求

13地图规格见[maps.md](../maps.md)。地表、摆件与效果独立，保留等距透视与深度。主港暖木/奶白/青蓝，森林清楚绿与溪谷，赤炉铜灰/橙火，霜镜蓝白，沉星灰紫/灰白，龙眠米金/青蓝。每岛至少有一件独特主题建筑/摆件；不能全部只给通用岩石染色。

## ss-scene-ground-port · 主港石地

- 章节：1；类型：ground。
- 要求：独立可平铺纹理、接缝核对；32px导航单位不等于只能32px原图。
- 独立交付：原始、导入与运行文件；尺寸、透明、枢轴、可用状态/变体、源哈希、材质与调色记录。共用项只制作一次。
- 连续平铺检查四边和道路交叉；原图允许大于32px，保持采样清晰。
