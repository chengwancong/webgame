## 一、现状诊断：为什么"单调"？

### 当前养成维度（仅有4个）
```
1. 角色等级 → 基础属性
2. 装备品质 → 属性倍率
3. 装备强化 → +10强化
4. 技能等级 → Lv1-10
```

### 问题本质
| 问题 | 表现 | 后果 |
|------|------|------|
| **维度太少** | 只有"变强"，没有"变多" | 玩家无事可做 |
| **无搭配深度** | 装备只堆数值，没有Build | 抄作业，无思考 |
| **无长线目标** | 满级即毕业 | 弃坑 |
| **无内容消费** | 打完副本没追求 | 上线没事干 |
| **Farming无感** | 刷装备只为数值 | 过程枯燥 |

### 核心解决思路
> **从"一维强度堆叠" → "多维组合构建"**
> 让玩家追求的不再是"攻击力+50"，而是"这个武器盘/威能组合能不能打出10倍伤害"

## 二、三款游戏的拆解与借鉴

### 《碧蓝幻想》(GBF) — 武器盘是灵魂
```
核心: 武器盘 (Weapon Grid)
- 9格武器盘: 主手 + 8副武器
- 每把武器带"武器技能" (攻刃/必杀刃/守护/技巧)
- 方阵乘区 (Omega) vs 普通乘区 → 乘算/加算
- 武器上限突破 (Uncap ★0-★5)
- 召唤石加护 (Summon Aura)

为什么适合我们:
✅ 纯数值配置 → 完美适配挂机/自动战斗
✅ 搭配深度极高 → "方阵2+方阵2" vs "方阵4" 伤害差数倍
✅ Farming目标明确 → 刷武器、刷方阵、突破
```

### 《暗黑破坏神4》(D4) — 威能与巅峰
```
核心: 传奇威能 (Legendary Aspects) + 巅峰盘 (Paragon)
- 威能: 从传奇装备萃取，刻印到其他装备
- 威能法典: 永久收集，一次解锁无限使用
- 巅峰盘: 50级后解锁，节点盘 + 雕文插槽
- 太古/神话品质: 更高品质层级

为什么适合我们:
✅ 威能 = Build核心 → "旋风斩威能"改变技能机制
✅ 威能法典 = 长线收集目标
✅ 巅峰盘 = 满级后继续成长
```

### 《魔兽世界》(WoW) — 天赋与长线
```
核心: 天赋树 + 声望 + 专业 + 团本
- 天赋树: 3系专精，每系关键天赋 (Capstone)
- 声望: 势力等级，奖励图纸/坐骑/装备
- 专业: 采集/制造，自给自足
- 团本: 20人协作高难内容

为什么适合我们:
✅ 天赋树 = 角色定位差异化
✅ 声望 = 区域长线目标
✅ 专业 = 生产循环
✅ 团本 = 终局社交内容
```

## 四、系统A：武器盘系统 (Weapon Grid) ★核心

> 这是最重要的差异化系统，GBF的灵魂，完美适配挂机数值游戏

### 4.1 武器盘结构
```
武器盘布局 (9格):
┌────┬────┬────┐
│ 主手│ 副1 │ 副2 │   ← 主手: 角色实际使用的武器
├────┼────┼────┤   ← 副武器: 只提供"武器技能"加成
│ 副3 │ 副4 │ 副5 │
├────┼────┼────┤
│ 副6 │ 副7 │ 副8 │
└────┴────┴────┘
```

### 4.2 武器技能类型（武器盘的核心）
每把武器带1-2个"武器技能"，决定它在盘中的角色：

| 技能类型 | 效果 | 乘区 | 数值(满级) | 定位 |
|---------|------|------|-----------|------|
| **攻刃 (ATK)** | 攻击力+X% | 普通乘区 | +15% ~ +30% | 输出基础 |
| **必杀刃 (Skill)** | 技能伤害+X% | 普通乘区 | +20% ~ +50% | 技能流核心 |
| **守护 (HP)** | 生命值+X% | 普通乘区 | +15% ~ +35% | 生存 |
| **铁壁 (DEF)** | 防御力+X% | 普通乘区 | +12% ~ +25% | 坦克 |
| **技巧 (Crit)** | 暴击率+X% | 普通乘区 | +8% ~ +18% | 暴击流 |
| **方阵攻刃 (Omega)** | 攻击力×N倍 | **方阵乘区(乘算)** | ×1.5 ~ ×2.5 | **核心爆发** |
| **方阵必杀 (Omega)** | 技能伤害×N倍 | **方阵乘区(乘算)** | ×1.8 ~ ×3.0 | **技能流核心** |

### 4.3 乘区机制（深度所在）
```
最终攻击 = 基础攻击 × (1 + 攻刃总和%) × 方阵倍率
最终技能伤害 = 基础技能 × (1 + 必杀刃总和%) × 方阵必杀倍率

关键规则:
- 普通攻刃: 加算 (多把武器相加)
- 方阵倍率: 乘算 (多把武器相乘)
- 方阵 × 普通 = 爆炸伤害

示例对比:
【配置A】8把普通攻刃(各+25%)
  = 100 × (1 + 200%) = 300攻击

【配置B】4把方阵攻刃(各×2.0) + 4把攻刃(各+25%)
  = 100 × (1 + 100%) × (2.0^4)
  = 100 × 2 × 16 = 3200攻击

结论: 方阵配置是普通配置的 10倍伤害！
     但方阵武器极难获取 → 这就是Farming动力
```

### 4.4 武器等级与上限突破 (Uncap)
```
武器等级: Lv1-150
每级提升: 武器技能效果 + 武器自身属性

上限突破 (Uncap) ★0 → ★5:
★突破    等级上限   技能效果   消耗材料
★0       Lv50      100%      -
★1       Lv75      130%      同种武器×1
★2       Lv100     160%      同种武器×2 + 方阵碎片×20
★3       Lv125     200%      同种武器×3 + 方阵碎片×50
★4       Lv150     250%      同种武器×5 + 方阵碎片×100 + BOSS素材
★5       Lv150     300%      金月×10 (极稀有货币) + 传说素材
```

### 4.5 武器品质与获取
| 品质 | 武器技能数 | 获取方式 | 定位 |
|------|-----------|---------|------|
| 普通 (R) | 1个 (低级) | 普通怪掉落 | 过渡 |
| 精良 (SR) | 1个 (中级) | 精英/副本 | 中期 |
| 稀有 (SSR) | 2个 (高级) | BOSS/高难 | 核心 |
| 方阵 (Omega) | 1个方阵技能 | **高难副本 farming** | **终局核心** |
| 神话 (Primal) | 2个方阵技能 | 隐藏BOSS | 天花板 |

### 4.6 武器盘数值示例（终局目标）
```
终局"方阵技能流"武器盘 (目标):
主手: 神话武器 (必杀刃×2.5)
副1:  方阵必杀 (×3.0) ★4
副2:  方阵必杀 (×3.0) ★4
副3:  方阵必杀 (×3.0) ★3
副4:  方阵攻刃 (×2.5) ★4
副5:  方阵攻刃 (×2.5) ★3
副6:  必杀刃 (+50%) ★4
副7:  必杀刃 (+45%) ★4
副8:  技巧 (+18%暴击) ★4

计算:
方阵必杀倍率 = 3.0 × 3.0 × 3.0 = 27倍
方阵攻刃倍率 = 2.5 × 2.5 = 6.25倍
必杀刃加算   = 50% + 45% = 95%
技能伤害 = 基础 × (1+95%) × 27 = 基础 × 52.65倍

对比"普通堆攻击"配置:
技能伤害 = 基础 × (1+95%) × 1 = 基础 × 1.95倍

差距: 27倍！这就是Build的深度和追求
```

## 五、系统B：传奇威能系统 (D4) ★Build核心

### 5.1 威能机制
```
流程: 获取传奇装备 → 萃取威能 → 存入威能法典 → 刻印到其他装备

威能法典: 永久收集，一次解锁 → 无限次刻印 (可重复使用)
```

### 5.2 威能分类与数值
| 威能类型 | 槽位 | 效果示例 | 数值 |
|---------|------|---------|------|
| **攻击威能** | 武器/手套 | 技能伤害+40% | 高价值 |
| **防御威能** | 胸甲/护腿 | 受伤时获得护盾 | 生存 |
| **资源威能** | 头盔/戒指 | 击杀回能+30% | 续航 |
| **机动威能** | 鞋子 | 位移技能CD-50% | 手感 |
| **效用威能** | 护身符 | 掉落率+25% | Farming |
| **专属威能** | 特定槽 | **改变技能机制** | **Build核心** |

### 5.3 专属威能示例（改变玩法）
```
【旋风斩威能】刻印于武器
基础旋风斩: 半径3.5格，25伤害
刻印后:    半径6格，伤害+80%，且拖拽敌人
→ 从"小范围技能"变成"清场核心技能"

【多重箭威能】刻印于手套
基础箭: 1支
刻印后: 5支，每支60%伤害
→ 从"单体"变成"扇形AOE"

【吸血威能】刻印于戒指
基础: 无吸血
刻印后: 造成伤害的15%转化为生命
→ 开启"吸血流"Build
```

### 5.4 威能法典收集（长线目标）
```
威能总数: 120个
- 普通威能: 80个 (副本掉落)
- 专属威能: 30个 (BOSS掉落)
- 神话威能: 10个 (隐藏内容)

收集进度奖励:
收集30个 → 全威能效果+5%
收集60个 → 全威能效果+10%
收集90个 → 全威能效果+15%
收集120个 → 全威能效果+20% + 专属称号
```

## 六、系统C：天赋树系统 (WoW + D4巅峰)

### 6.1 三系专精（角色定位）
```
每个角色可选1系主专精 + 1系副专精

【战士系】近战/生存
  关键天赋: 狂暴(攻速+30%)、铁壁(减伤25%)、
           斩杀(对低血敌人+100%伤害)
  
【法师系】技能/爆发
  关键天赋: 奥术强化(技能伤害+50%)、
           节能(技能消耗-40%)、元素共鸣(连锁伤害)
  
【游侠系】暴击/机动
  关键天赋: 致命(暴击伤害+80%)、迅捷(移速+25%)、
           多重射击(攻击分裂)
```

### 6.2 天赋树结构
```
每系天赋树: 6层 × 5节点 = 30个天赋节点
天赋点数: 等级50 + 声望奖励 = 最多60点
投入规则: 需先投入下层才能解锁上层

节点类型:
- 小节点 (每点+2%属性): 24个
- 大节点 (每点+8%属性): 4个
- 关键天赋 (Capstone, 需20点投入): 每系1个
```

### 6.3 巅峰盘 (Paragon) — 满级后
```
50级后解锁，每级+1巅峰点 (无上限，缓慢)
巅峰盘: 4块盘，每块含:
  - 普通节点 (+1%属性)
  - 魔法节点 (+5%属性)
  - 稀有节点 (+15%属性 或 特殊效果)
  - 雕文插槽 (插入雕文，范围增益)

雕文系统 (D4核心):
雕文等级 Lv1-21，提供"范围内节点效果+X%"
例: "战士雕文" Lv15 → 半径4内所有力量节点效果+75%
```

### 10.2 噩梦地下城 (D4式)
```
机制: 普通副本 + 随机词缀 → 难度递增
词缀示例:
- 怪物生命+100%，伤害+50%
- 玩家技能冷却+30%
```

### 12.2 需要扩展的 Stats 类型
```typescript
// 现有 Stats
export type Stats={
  hp:number; attack:number; armor:number; speed:number; 
  mana:number; regen:number; effects:Effect[];
  critChance?:number; critMultiplier?:number; 
  lifesteal?:number; cdr?:number; dodge?:number; penetration?:number;
};

// 需新增字段 (支持新系统)
export type Stats={
  ...现有字段,
  // 武器盘乘区
  omegaAttackMult?:number;   // 方阵攻击乘区
  omegaSkillMult?:number;    // 方阵技能乘区
  // 威能
  aspectSkillDamage?:number; // 威能技能伤害
  // 召唤石
  summonAttackAura?:number;  // 召唤石攻击光环
  summonSkillAura?:number;   // 召唤石技能光环
  // 天赋/巅峰
  talentAttackBonus?:number;
  paragonAttackBonus?:number;
  // 觉醒
  awakeningBonus?:number;    // 全属性加成
};
```

### 12.3 伤害公式升级
```typescript
// 现有公式 (简化)
damage = ATK × skillRatio × (1 + crit) × (1 - defReduction)

// 新公式 (多层乘区)
damage = 
  ATK 
  × (1 + 攻刃总和)        // 普通加算
  × omegaAttackMult       // 方阵攻击乘算
  × (1 + summonAttackAura)
  × (1 + talentAttackBonus)
  × skillRatio
  × (1 + 必杀刃总和)      // 技能伤害加算
  × omegaSkillMult        // 方阵技能乘算
  × (1 + aspectSkillDamage)
  × (1 + crit)
  × (1 - defReduction)

// 这就是"乘区嵌套"带来的爆炸伤害和Build深度
```

| 方阵技能乘算 | ×27倍 | 极难 | 3把方阵×3.0 |

| 天赋加成 | +60% | 中 | 满天赋 |
| 觉醒加成 | +30% | 难 | 觉醒Lv10 |

### 13.2 终局战力目标
```
满配"方阵技能流"总乘区:
攻击面: (1+300%) × 32 × (1+80%) × (1+60%) × (1+30%)
       = 4 × 32 × 1.8 × 1.6 × 1.3 = 478倍基础攻击

技能面: (1+200%) × 27 = 3 × 27 = 81倍技能倍率

理论总伤害倍率: 478 × 81 ≈ 38,718倍

对比"裸装": 1倍
对比"普通满配": 4 × 3 = 12倍

结论: 
- 普通玩家和深度玩家差 3000倍+
- 这提供了极深的追求空间
- 但每一层都需要明确Farming → 有目标感
```

## 十四、为什么这个设计能解决"单调"

| 原问题 | 解决方案 | 效果 |
|--------|---------|------|
| 只有变强没变多 | 10+养成维度 | 每天有事做 |
| 无搭配深度 | 武器盘乘区 + 威能 | Build千变万化 |
| 无长线目标 | 威能法典/武器突破/声望 | 数月追求 |
| 无内容消费 | 高难/噩梦/团本/赛季 | 终局有事干 |
| Farming无感 | 方阵武器明确掉落 | 刷有目标 |

### 核心改变
```
之前: 玩家追求"攻击力 +50"
之后: 玩家追求"方阵4+方阵2 配置，打出100倍伤害"

之前: 满级即毕业
之后: 满级只是开始 (巅峰盘/神话武器/冲Tier)

之前: 抄一套装备
之后: 每个玩家武器盘/威能/天赋都不同
```
