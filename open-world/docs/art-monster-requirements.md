# 深渊行者 - 怪物美术需求

> 3个新章节的怪物角色、BOSS、动画需求

---

## 怪物美术总览

### 设计原则
- **风格统一**：与现有怪物（柴狼人、骷髅等）风格一致
- **差异化**：每个章节有独特的视觉主题
- **可读性**：2D俯视角下，轮廓清晰
- **动画流畅**：Spine骨骼动画，30fps

### 技术规格
- **文件格式**: Spine (JSON + Atlas + PNG)
- **分辨率**: 角色高度约128-256像素
- **动画帧率**: 30fps
- **命名规范**: `{怪物ID}_{动作名}.json`

## 第4章：冰封雪域 - 怪物需求

### 1. 冰霜狼 (frost_wolf)

**概念**：被冰雪魔法侵蚀的巨狼

**外观特征**：
- 体型：比普通狼大1.5倍
- 皮毛：白色+冰蓝色，毛发有冰晶
- 眼睛：发蓝光
- 四肢：爪子覆盖冰霜
- 特殊：呼吸时有白色冷雾

**尺寸**：
- 身长：96像素
- 身高：64像素

**必需动画**：
```
1. idle (待机) - 循环，轻微呼吸
2. walk (移动) - 循环，四足奔跑
3. attack (攻击) - 单次，扑咬动作
4. hit (受击) - 单次，身体后仰
5. death (死亡) - 单次，倒地消散
```

**特效需求**：
- 脚步带起雪花粒子
- 攻击时口中冒寒气
- 死亡时化为冰晶消散

**参考现有资源**: `xiaolang` (小狼)，重新着色+冰霜效果

## 通用动画规范

### 标准动画列表
所有怪物必需：
1. `idle` - 待机（循环）
2. `walk` - 移动（循环）
3. `attack` - 基础攻击（单次）
4. `hit` - 受击（单次）
5. `death` - 死亡（单次）

精英/BOSS额外：
6. `skill1/2/3` - 技能动画
7. `phase_start` - 阶段转换
8. `enrage` - 狂暴

### 动画时长建议
- idle: 无限循环
- walk: 0.5-0.8秒/循环
- attack: 0.3-0.6秒
- skill: 0.5-2秒
- hit: 0.2-0.3秒
- death: 1-2秒

### Spine骨骼命名规范
```
root
├── body
│   ├── head
│   ├── torso
│   ├── arm_L
│   ├── arm_R
│   ├── leg_L
│   └── leg_R
├── weapon
└── fx (特效挂点)
```
