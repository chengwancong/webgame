# 任务系统 §13 第 1–3 步：框架与兼容接入

日期：2026-10-06。依据：`open-world-quest-system.md` 方案 A；本批不扩展至第 4–6 步的 51 条完整任务内容与全旅程平衡验收。

## 已落地

- 配置：引导/支线/悬赏分类；任务系列、线索、关键线索、发现、放弃、追踪、悬赏参数；步骤世界事实引用；条件/传闻/世界门页；条件对白解析。章节开放项迁入独立条件，保留任务路线与非任务兜底路线。
- 运行时：v2 多任务状态，按任务 ID 推进；最多 20 个进行中任务、单一追踪；同区域波次冲突拒绝，跨区域废弃旧波次；重接保留尝试次数，避免旧怪物 ID 重用；首领/门/调查/航标/分区/已结算营地事实；等级或上一岛首领开放海域，六首领开放裂星潮。
- 接口：发现、到达、接取、开门、追踪、放弃、航标以及原战斗/对话操作，沿用 command_id、revision、控制租约与事务；完成奖励、任务档案、回执、流水共同提交。过期任务怪不能再提交击杀。
- 界面：任务类型、岛屿分组/线索计数、追踪与放弃；单行 HUD；无追踪时附近推荐；地图问号；航图等级提示；NPC 对话按具体任务提交，防守按波次所属任务处理。
- 迁移：v1 游标折算到 done/quests；保留进行中波次和选择；不补发奖励、不修改历史档案。数据库保留迁移前后任务状态对。早期 v2 记录加载时补全尝试次数。
