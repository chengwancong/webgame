## 2. 氪度阶梯（新规则）
三档在**体型、取阶、画法、配色、装饰、特效**六个方面同时拉开差距，一眼就能分出档位。

| 方面 | 零氪 | 轻氪 | 重氪 |
|---|---|---|---|
| 显示高度（幼 / 成 / 觉醒） | 44 / 56 / 68 | 48 / 62 / 74 | **54 / 70 / 84** |
| 取阶 | a 起步（现状） | a/c/e 或 b/c/e | **c/d/e 或 b/d/e**：幼年就要帅，觉醒是库里最华丽的那阶 |
| 画法 | 样稿 1：底色加一块硬边暗部 | 再加一层硬边高光和身上花纹（条纹、斑点、鳍纹） | **精绘**，见 §3 |
| 配色 | 本岛底色，流派色只用在点缀上 | 本岛底色加流派色花纹 | 本岛底色加流派色饰件，再加金属和宝石材质 |
| 流派标识 | 项圈小吊牌徽记 | 肩甲或护片上的中号徽记 | 徽记融进饰件，比如冠饰、胸甲中心、翼饰 |
| 职业挂件 | 无 | 小号 | 大号，并与饰件同色系 |
| 特效 | 无 | 无 | 地面光环加跟随粒子；不透明度 0.85，尺寸跟随体型；不能挡住脸，也不能盖过主角 |

**统一规则**
- **体型上限**：重氪觉醒放宽到主角高度的 85%，原规则是 75%。
- **配色**：不再把流派色混进整个身体。身体底色在同岛同档内统一；9 只之间靠花纹、饰件、宝石和特效的颜色区分。
- **不变的**：描边和点眼色 `#3c2b23`、五官规则（不要牙、獠牙、怒眉、竖瞳）、只换贴图不动骨骼。

## 3. 重氪精绘：两种画法，给用户挑
两种画法共用以下约束：
- 仍然是本作的圆润、细描边、手绘色面风格。不要写实纹理，不要粗黑描边，不要整体渐变。
- **色阶**：4–5 个硬边色阶，包括底色、暗部、深暗部、高光和边缘光。
- **眼睛**：比零氪大一号，加两个高光点。
- **翼膜、鳍、冠刺**：画出骨线或分片。
- **库原图里的华丽结构全部保留**：多层翼、长尾鳍、角冠、鬃毛。这些结构不再简化成剪影。

| 画法 | 重氪 A「精绘」 | 重氪 B「精绘 + 饰甲」 |
|---|---|---|
| 精致感来自 | 色阶、边缘光、花纹 | 在 A 的基础上，把金边饰甲画进贴图：额冠、胸甲、翼尖、尾环，嵌流派宝石 |
| 气质 | 灵兽 | 坐骑、守护兽 |
| 风险 | 跟轻氪的差距主要靠细节，44px 下要实测能分出来 | 饰件多，容易显得重，挂件要让位 |

**材质分区**：可以新增材质号，但必须仍能无损分区。
- 金属：底、暗、亮三个色块；
- 宝石：底色加一个亮点；
- 发光：运行时叠加；
- 边缘光：一个硬边色块。

金属和宝石的颜色进色板，跟着流派变；发光材质的叠加方式写进报告。

1. **龙眠阶梯样稿**：
   - 流派取「余烬」和「霜卫」两个，看冷暖两种配色是否都成立；
   - 档位：零氪、轻氪、重氪 A、重氪 B 四档；
   - 每档 3 形态。
   - 用真实 Spine 渲染，风栖野外地表做底，和主角、`ss-mon-wind-hound` 按实际大小、脚底对齐同排摆放，并附 2 倍放大。
   - 放在同一张对比图 `evidence/ladder-dragon.png` 里。
2. **动作检查**：重氪 A 和 B 各取 idle、move、attack 三个动作，每个动作取 3 帧，放大 2 倍。
3. **六岛重氪家族候选表** `evidence/heavy-candidates.png`：
   - 每岛 2–3 个候选；
   - 每个候选列出原库 c/d/e 阶的拼装渲染，标明推荐取哪几阶，并写一行理由；
   - 选择标准：剪影帅、有翼、角、鬃毛或长尾这类华丽结构，非人形，不持武器，不恐怖。
   - 可以考虑现用家族的后几阶，比如 A7 d/e 的翼龙、B1 e 的龙海马、A3 e 的花角鹿，也可以从全库 50 个家族里重新挑。

4. **预览页**：在 v3 预览页加「阶梯样稿」开关，样稿能播放五个动作并支持镜像。
5. **体量估算**：按样稿实测，推算改完 162 只后的总量。
   - 预算上限放宽到 **65MB**；
   - 超出上限时，先给出降本方案，不得删减数量。
6. **报告**：`assets/starsea/pets/v4-sample/report.md`。
   - 写明重氪 A 和 B 各自的优缺点，不替用户选；

## 6. 默认裁定
| 情况 | 裁定 |
|---|---|
| 重氪 c 阶幼年超过 54px 时，按比例缩小后描边变糊 | 按 54px 重新出描边粗细，不改成 b 阶 |
| 库原图的华丽结构在 44–54px 下糊成一团 | 合并成更大的分片，保留轮廓特征，不整块删掉 |
| 精绘色阶在小尺寸下变脏 | 先去掉深暗部，保留高光和边缘光 |
| 饰甲遮住点眼或嘴 | 移开饰甲，五官优先 |
| 地面光环和怪物预警圈难以区分 | 光环改成不闭合的弧段加粒子，不用实线圆 |
