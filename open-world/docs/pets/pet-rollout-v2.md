## 2. 画法规范（全部沿用 PA2 已定的值）
- **描边和点眼**：统一 `#3c2b23`；描边粗细换算方法和 PA2 一致（原零件坐标宽 1.6px）。
- **样稿 1 打底**：一个底色加一块硬边暗部，外轮廓圆滑，不要细碎毛丝、写实纹理、渐变和外发光。
- **样稿 2 用在毛类部位**：圆齿绒边，加浅肚皮 `#fff7e6`。只用在表里写明的部位上：熊全身、猪的鬃毛。软泥、龙、海马不用。
- **五官统一**：
  - 实心深棕点眼加一个白高光，小嘴，可以有腮红 `#e8b7a4`；
  - **不要牙、獠牙、怒眉、竖瞳**。原图里的龇牙、张嘴怒吼都改画成闭嘴或微张的小嘴；
  - 猪的獠牙改成两颗圆钝的奶白小牙尖；
  - 原素材五官有多种做法：画在头部贴图里、做成独立零件、带眨眼槽。全部照 PA2 风绒的做法处理，闭眼和睁眼要对得上。
- **颜色直接画进贴图**，不用槽位乘色或双色 tint。每岛色板如下，具体色值写进 `decisions.md`：

| 岛 | 主色 | 点缀 | 暗部 |
|---|---|---|---|
| 雾铃 | 苔绿 | 雾白、花苞粉 | 深苔绿 |
| 赤炉 | 铜灰 | 橙红火焰（鬃毛），火焰用平涂的两到三色块，不做发光 | 深铜 |
| 霜镜 | 白蓝 | 银蓝冰纹 | 灰蓝 |
| 龙眠 | 米金 | 青蓝（冠刺、翼膜、角尖） | 深米褐 |
| 沉星 | 灰紫 | 奶白星点（3–5 颗小四角星或圆点），浅紫鳍 | 深灰紫 |

- **贴图**：按原零件尺寸的 2 倍交付，对位与原图一致；只换 atlas 贴图，region 名、骨骼、动作、槽位、附件参数一律不动（与 PA2 相同）。PA2 的手工 SVG 原坐标重描、闭眼 UV 反算和 PMA 渲染修正，都可以直接复用。

## 3. 交付
**目录**：
- 源码与记录：`assets/starsea/pets/v2/`；
- 运行资源：`apps/web/public/art/starsea/pets/v2/`；

**每只 3 个形态**，共 6 × 3 = 18 套：

**证据图**：

## 5. 3.5 骨骼兼容核对（第 1 步）
Claude 只验证过 3.5 能解析、能套用首帧。正式导出前，要对 C6、B5、D2、B1 选用的三阶逐个检查：
- 每个动作的全部帧都在可视 Chrome 里用 3.6 运行时播放一遍；
- 和 Spine 3.5 原版播放对照（库目录有 `.spine` 工程；没有对照手段时，用原零件按动作关键帧核对）；
- 检查有没有缺件、错位、网格撕裂、IK 翻转、绘制顺序错误、颜色和透明度动画异常。

结论按家族写进 `decisions.md`。

## 6. 默认裁定
| 情况 | 裁定 |
|---|---|
| 某个 3.5 家族在 3.6 运行时下动作异常，且只改贴图修不好 | 换成同岛的 3.6 后备家族（赤炉 C4、霜镜 C8、龙眠 A7、沉星 S9），阶段改选零件最少、外形最接近同一只的三阶，按本规范重画；记原因 |
| 原阶段的成长差异太小或不像同一只 | 在该家族五阶里改选，规则：三阶逐级变大、零件只增不换物种；记原因 |
| 五官做在贴图里，改小嘴后与动作里的张嘴帧冲突（攻击时张嘴） | 闭嘴脸画在头部贴图，嘴的开合交给原有的嘴部零件或槽位；原素材没有独立嘴部零件的，攻击帧也保持小嘴，不新增零件 |
| 獠牙、角、刺做成独立零件 | 保留零件，重画成圆钝、短小的造型，尺寸不超过原零件 |
| 原素材自带特效零件（火焰、冰晶、光） | 按平涂规范重画，不做发光和渐变；在清单里标「含内置特效」 |
| 星点在动作中滑动（画在会形变的网格上） | 改画到形变最小的身体区域，或减少颗数，最少保留 3 颗 |
| 熊的绒边在 44px 下变成锯齿 | 减少圆齿的数量、加大单个圆齿，不改回硬边 |
| 火焰鬃毛和绒边冲突 | 鬃毛根部用绒边，火焰部分用平涂色块 |

## 7. 硬阻塞（只有这些可以停）
- 某岛的 3.5 首选家族和 3.6 后备家族都无法正常播放；
- 需要改骨骼、动作、`packages/asset-manifest`、`apps/web/src`、版本号或数据库才能继续。

## 8. 文件权限与禁止
- 只写 `assets/starsea/pets/v2/` 和 `apps/web/public/art/starsea/pets/v2/`；库目录、PA1、PA2 和实机资源都是只读。
- 不改公共 manifest、游戏源码、规则、版本号；不重启服务，不碰 8612 / 8790；不 git commit。
- **不跑无头浏览器**：导出和预览用可视 Chrome，串行，一次一套。
- 原始渲染和大图只留在本地 `evidence/`，报告只写结论（≤200KB）。
- 禁止：只交文档；用静态图冒充动作；删减宠物数或形态数；为了凑效果动骨骼或动作；跳过自检。

## 9. 自检
- 逐帧检查：零件与身体之间没有缝和错位，眨眼时睁眼和闭眼对得上，镜像正确，全部帧都在格子内。
- 三形态逐级变大，不超过显示高度；六只的描边色、点眼画法、描边粗细一致。
- 五官检查：18 个形态都没有牙、獠牙、怒眉、竖瞳（猪的圆钝小牙尖除外）。
- 来源登记齐全：原零件和新贴图的 sha256、手工重描路径、imagegen 原图路径（如有）。
