# 宠物重画样稿需求（PA2，2026-10-17）

状态：用户已裁定方向——**保留库里的原生骨骼和动作，零件按本作画风重画**（平涂、细棕描边、点眼）。本批只做风栖一只，出 3 张样稿给用户挑。挑定后再按选中的画法铺开其余 5 只，那是另一批。

## 1. 为什么重做（PA1 的问题）
PA1 资源已全部完成（`docs/pets/pet-modeling-requirements.md`），但和实机怪物按显示大小并排一看，明显不协调：
- **画风不一致**：库里的素材是厚重渲染、粗黑描边、高饱和渐变，绒毛和泥都带写实纹理；本作主角和怪物是平涂色面、细描边、点状五官。
- **成长三阶是三种不同的生物**：a/c/e 取阶，风绒从毛球直接变成了猪兔，铜芯从炮车变成了机器人。
- **岛屿调色把颜色调脏了**：槽位乘色压在渲染贴图上，苔芽成了橄榄泥色，星泡成了洋红。

PA1 的产物不删、不改，留作对照。本批另开目录。

## 2. 范围
- **只做风栖一只**，家族 D1。成长改用 **a / c / d** 三阶：毛球 → 长触角 → 再长耳朵和须。三阶的零件逐级增加，是同一只在长大；e 阶（猪兔）不用。
- **只换贴图**：骨骼、动作、时序、槽位、绘制顺序、挂点逻辑一律不动。唯一允许改的是骨骼 JSON 里 region 附件的 `path`（指向新贴图），附件的宽高、偏移、旋转都不动。
- **不做外观变体**（b/d 皮），等画法定了再说。

## 3. 三张样稿的画法
三张都必须满足共同约束，彼此只在「体积感」一项上有差别，方便用户只比较这一点。

**共同约束**
- 配色：风栖色面——身体奶白，触角、耳朵用青蓝，描边和阴影偏米褐。三张样稿配色完全相同。
- 颜色直接画进贴图。**不用槽位乘色或双色 tint**，PA1 的调色参数一律去掉。
- 描边：单一深棕色。色值从实机主角 `/art/mini-hero/navy/` 和怪物 `ss-mon-dock-scavenger` 的描边取样，记下取到的色值。粗细在显示尺寸下约 1–1.5px，不能用粗黑描边。
- 眼睛：实心深棕点眼，加一个白色高光点；可以有一抹腮红。闭眼画成一道弧线。
- 不要写实纹理，不要细碎毛丝，不要外发光，透明底。
- 贴图按原尺寸的 **2 倍**交付，构图、对位与原图完全一致：内容在画布里的位置等比放大，这样附件偏移不用改。可以先画 4 倍，再缩到 2 倍。

**三种体积**

| 样稿 | 画法 |
|---|---|
| 1 极简平涂 | 一个底色加一个硬边暗部。外轮廓圆滑，只留 3–5 撮小毛尖。最接近实机怪物 |
| 2 平涂毛边 | 一个底色、一个硬边暗部，再加一块浅色肚皮。外轮廓做成一圈圆齿状的绒毛边 |
| 3 柔和色面 | 一个底色加一层柔边暗部，接近 NPC 和场景的手绘色面。外轮廓同样本 1 |

**绘制方式**：可以用 imagegen 出稿，但最后每个零件都要按原零件的形状和对位手工修整成单独的透明 PNG。生成原图存 `sources/`，记录路径和 sha256，方式同 `assets/starsea/monsters/` 的 dusk-clasp。

## 4. 交付
目录：`assets/starsea/pets/repaint/`，运行资源放 `apps/web/public/art/starsea/pets/repaint/`。三种样稿 × 三阶，共 9 套，每套用 PA1 同一导出管线：
- 30fps、单格 256 的帧图集；
- `actor.png`、`actor.json`、`sockets.json`、`profile.json`；
- 显示高度 44 / 56 / 68px，动作 idle、idle2、move、attack、knock。

**样稿图（每种画法一张，共 3 张，存 `evidence/`）**，每张都要有：
- 底图用风栖岛野外的正式地表贴图（见 `docs/scene-dressing.md` 的风栖草地和道路材质），不要纯色底；
- 实际显示大小：主角（`/art/mini-hero/navy/`）、`ss-mon-dock-scavenger`、`ss-mon-wind-hound` 和三阶宠物站在一起，脚底对齐；
- 同一排再放一份 4 倍放大，方便看清描边和点眼；
- 一律用真实 Spine 渲染帧，不能是拼贴画稿。

**对照图**：3 种画法加 PA1 原版，四列并排（三阶 × idle 首帧，实际大小），存 `evidence/compare.png`。

**预览页**：在 PA1 的并排预览页加一个「样稿 1 / 2 / 3 / PA1」切换，五个动作都能播放。

## 5. 自检
- 每个动作逐帧检查：零件与身体之间没有缝和错位（重点看 attack 和 knock 的挤压拉伸），眨眼时睁眼和闭眼不错位。
- 镜像正确，全部帧在格子内，三阶逐级变大，且不超过 §4 的显示高度。
- 三种画法的配色、描边色和描边粗细一致，差别只在体积表现上。
- 每个零件都登记来源：原零件路径和 sha256、新贴图 sha256、imagegen 原图路径。

## 6. 执行方式（强制）
- 一次做完：
  1. 描边取样；
  2. 样稿 1 三阶；
  3. 样稿 2；
  4. 样稿 3；
  5. 导出；
  6. 样稿图、对照图；
  7. 预览页；
  8. 自检；
  9. 报告。
- 每一步完成后更新 `assets/starsea/pets/repaint/progress.md`，中断后从这里续做。
- 能按 §7 裁定的不要停下来问，裁定写进 `repaint/decisions.md`。
- 结束状态只有两种：**全部完成**；或者其余全部完成后，被 §8 的硬阻塞卡住。

## 7. 默认裁定
| 情况 | 裁定 |
|---|---|
| 某零件 2 倍重画后，动作里和身体接缝露底 | 把该零件边缘向内多画 1–2px 重叠，不改附件 |
| 须（`mao1`–`mao4`）太细，平涂后看不清 | 加粗到显示尺寸约 1.5px，颜色用描边色 |
| 闭眼脸和睁眼零件位置对不上 | 以 `yan` 零件的位置为准，重画 `tou` 上的闭眼 |
| imagegen 出稿与零件形状差太多 | 手工按原零件剪影重描，记「手工重描」 |
| 样稿 3 柔边暗部缩小后变脏 | 收窄柔边宽度，不改成硬边（不然就和样稿 1 一样了） |

## 8. 硬阻塞（只有这些可以停）

- 需要改骨骼、动作、`packages/asset-manifest`、`apps/web/src`、版本号或数据库才能继续。
