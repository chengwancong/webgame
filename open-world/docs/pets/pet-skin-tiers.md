## 2. 分级结构
每岛用 3 个家族，一个氪度一个家族；同一氪度下的 9 只（3 职业 × 3 流派）是同一套骨骼换皮。

| 氪度 | 家族定位 | 区分手段 |
|---|---|---|
| 零氪 | 本岛基础家族（PA3 的那只） | 色板，加一个小号流派徽记 |
| 轻氪 | 本岛进阶家族 | 色板，加中号流派徽记，加职业挂件（小） |
| 重氪 | 本岛珍稀家族，选零件多、成长变化最大的 | 色板，加大号流派徽记，加职业挂件（大），加常驻特效 |

**三个维度各自怎么体现**：
- **岛**：色板的底色走本岛色面（见 PA3 §2）。
- **职业**：职业挂件的类型。剑系是围巾或肩甲；法杖系是浮空晶石；暗器系是面罩或尾饰。
- **流派**：色板的主色，加流派徽记的图形。
  - 3 职业 × 3 流派 = 9 种徽记，六岛通用；
  - 流派具体叫什么、用什么元素，由 GPT 按现有技能体系定（物理和六元素并列，见技能与天赋改版方向），写进 decisions。
- **氪度**：挂件和特效的丰富程度逐档递增，家族也逐档换成更精致的模型。零氪不能只靠换色区分，至少要有小徽记。

## 4. 画法（沿用 PA2 / PA3，不变）
- 样稿 1 极简平涂打底；毛类部位用样稿 2 的圆齿绒边和浅肚皮。
- 描边和点眼 `#3c2b23`。五官统一：点眼、小嘴，不要牙、獠牙、怒眉、竖瞳。

## 5. 资源格式（硬约束）
**禁止逐只烘焙完整帧图集。** 486 套（162 × 3 形态）每套约 0.6MB，合计约 300MB，不可接受。

**要求：每个家族 × 形态只烘一套，其余全部靠数据驱动换皮。**
- **底图**：按 PA2 管线导出，同时导出「材质分区」，标明每个像素属于哪个色块（底色、暗部、点缀、肚皮、描边、眼……）。
  - 平涂画法的色块是固定的，可以无损分区。
  - 分区图的具体编码方式由 GPT 定，写进 report。
  - 编码必须能让运行时只用「分区图 + 色板」就还原出画面。
- **色板**：162 套，每套是「材质号 → 颜色」的表。
- **挂件**：徽记、职业挂件的独立透明 PNG，每种有小、中、大三档尺寸。
- **皮肤表**：`assets/starsea/pets/v3/skins.json`，162 条，每条包含：
  - id、岛、职业、氪度、流派；
  - 家族和形态底图；
  - 色板；
  - 挂件列表（挂点、偏移、层级）；
  - 特效引用；
  - 暂名。
- **体量**：运行资源总量 ≤ **50MB**。在报告里列出实际体量。
- **预览页**：GPT 自建，在可视 Chrome 里用「底图 + 色板 + 挂件 + 特效」实时合成，证明 162 只都能正确显示。要能按岛、职业、氪度、流派筛选，能切换五个动作，支持镜像。
  - 预览页只在组目录里，不改游戏源码。
- **静态证据**：

## 8. 默认裁定
| 情况 | 裁定 |
|---|---|
| 推荐家族在 3.6 运行时下动作异常，或重画后仍然凶、不像宠物 | 从 §3 的后备家族里换一个，同岛不能重复用家族，记原因 |

| 某种材质（渐变火焰、半透明翼膜）无法无损分区 | 改画成平涂色块后再分区，不保留渐变 |
| 两套色板在 44px 下几乎分不出来 | 调色板主色，保证同岛同档的 9 只两两都能区分，并在自检里抽查 |
| 挂件挡住脸或在动作里穿插 | 按挂点调整偏移和层级，必要时换挂点；不改骨骼 |
| 特效库里没有合适的元素特效 | 用最接近的一种调色复用，记录调色参数；不新画 |
| 体量超过 50MB | 先降低重氪特效和挂件的贴图尺寸，再考虑降低底图帧率，不减少宠物数 |
