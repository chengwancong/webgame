# 技能表现整改 V2

> 2026-10-11 起，受击、范围释放与状态标记改用特效库手绘受击层，线条示意图已移除，见 [技能受击层与打击感](skill-vfx-hit-layers.md)。

2026-10-01。覆盖55个玩家技能、11个章节怪物技能及16个章节BOSS技能；常规攻击另行登记。目标为清楚、有力、适度华丽。本轮仅修改表现与内部事件的来源元数据。

## 实际改造

- `vfx-profiles.ts` 显式登记技能命名空间、阶段、元素、轮廓、尺寸、力度与已知机制缺口。未知配置会进入诊断，不通过通用回退冒充完成。
- `combat-vfx.ts` 消费真实施法、命中、投射物、持续区域与BOSS状态。施法实例、来源和目标贯穿命中；雷链按同一次实际施法的命中目标连线，火球与冰弹使用专用8帧透明素材。
- 地面预警只有一个所有者，使用世界坐标绘制等距椭圆与真实光束轮廓；屏幕层仅显示名称、倒计时、打断提示与进度条。旧圆形Canvas预警、墙上时钟和重复标签已移除。
- 武器、手部、发射口、受击点与地面分开绑定；已有原始逐帧挂点保留。新BOSS施法图集使用按阶段定义的相对帧挂点，标明为手工定义，未冒充Spine骨骼数据。
- 新BOSS施法母版每个24帧（缩放按整段最大轮廓统一计算），分蓄力、释放和收招；长蓄力达到蓄力姿态后保持等待真实释放事件。原两帧待机/行走资源仍为历史预览，未宣称本次完成全部角色动画。
- 所有表现与伤害数字使用战斗时钟；世界切换清除旧单位与效果，修复同一区域换World后残留怪物的问题。命中闪色采用Phaser4的TintMode接口。
- 装饰图像/图形预算96、附加碎屑预算384；危险范围、攻击主体和命中主帧不被装饰预算淘汰。复用对象池，并对屏外视觉裁剪。减少动态模式关闭震动并减少装饰。

## 资源与复现

现成素材原件与原元数据保留。新增素材保存于 `assets/skill-fx/v2/`，技术打包仅做帧格切分、缩放、透明边距与脚底对齐，不重绘图像。三个施法母版共72个不同帧，加两种弹体16帧和地面火焰8帧。`node tools/build-vfx-v2.mjs` 检查透明通道及重复帧，再生成图集与来源哈希，已接入正式构建。

`combat-art-qa.html` 仅进入QA构建，支持整改前/后、0.25倍慢放、单帧推进、释放暂停、五种角色模型、标杆集、录像下载、全量玩家技能及20敌人/30弹体、60敌人/100弹体负载场景。测试工具不接入玩家状态修改接口。旧表现代码只由QA对照入口引用。

验收证据集中于 `../../docs/reviews/open-world/vfx-v2-20261001/`。`coverage.json` 区分配置登记、实际播放与视觉验收；资源存在不能替代视觉通过。最终结果以该目录的实机报告和录像为准。

## 机制边界

按用户选择，保留原伤害、前摇、费用、冷却、命中与成长逻辑。箭雨、陨石术当前零持续时间未产生伤害，火球当前只有单体命中；本轮不补范围伤害或伪造命中。怪物死亡爆炸目前缺实际触发，也单独列为未验收。其他扩展技能的反弹、复活等描述不因表现注册而视为已有执行机制。

`tests/vfx-v2.test.ts` 对照整改前69组确定性战斗轨迹，并检查完整登记、真实接触点、施法关联与等距几何。碰撞、挂点、首章首领及成长战斗回归继续执行。发布时核对真实前后端版本、恢复营地与战斗，并保留存档。
