# 全界面统一 UI / UX / UE 规范检查表（2026-10-25）

本表把 `项目.md`、`docs/ui-design-system.md`、`planning-bd-v1/22-ui-direction-a-plan.md` 以及 10-22「任务引导降级」口径压成可逐条判定的检查项，用于审计全部生产界面。规则本身以上述原文为准；本表只做汇总和判定方法，不新增风格。

判定：**通过 / 不通过 / 不适用**。「测」= 在 1280×720 舞台用内置浏览器（非无头 GUI）注入 DOM 测量脚本 `tools/ui-uniform-probe.js` 实测；「读」= 读代码判定。

## UI（视觉一致）

| ID | 规则 | 判定方法 |
|---|---|---|
| UI-01 | 颜色、字号、间距、圆角、阴影只取 `tokens.json`；CSS / 渲染 TS 不写十六进制和裸字号 | 读：`node tools/audit-ui-system.mjs` 剩余项 |
| UI-02 | 字号层级：H1 28 / H2 20 / H3 16 / Body 14 / Caption 13 / Micro 12；正文 <13px、任何文字 <12px 为不通过（A1 菜单名 12px 例外） | 测：最小字号、<13px 文字占比 ≤35% |
| UI-03 | 按钮、页签、关闭钮、确认框、字段、状态胶囊、资源数值一律走公共件（`buttonHtml` / `tabsHtml` / `panelHeaderHtml` / `confirmationHtml` / `fieldHtml` / `statusBadgeHtml` / `resourceAmountHtml` / `resourcePillHtml`） | 测：可见 `<button>` 中不带 `data-ui="button"` 的数量（菜单、技能栏、物品格等专用件除外） |
| UI-04 | 面板头统一：每个窗口一个标题（页面级 panelHeader），**只一个关闭钮**；嵌套区块用 section 级标题，不再出关闭钮 | 测：可见关闭钮数量 = 1 |
| UI-05 | 物品格、奖励卡用品质描边；地面掉落无框；技能栏保持安静 | 读 + 测：物品格带 `data-rarity` / 品质类 |
| UI-06 | 图在字前：物品、技能、资源、系统入口有图标；纯文字列表只出现在设置、战报、规则说明 | 读 |
| UI-07 | 状态胶囊只表达异常（失败、不可执行原因、待确认）；正常状态用角标 | 读 |
| UI-08 | 大时刻（结算、开箱、解锁）用缎带 + 评价章 + 奖励翻入；日常面板不用缎带 | 读 |

## UX（信息与流程）

| ID | 规则 | 判定方法 |
|---|---|---|
| UX-01 | **一屏一个主按钮**（primary）；没有可执行主操作时可以为 0 | 测：可见 `.ui-button--primary` ≤1 |
| UX-02 | 面板不超出 1280×720 舞台；固定外高面板有 `min-height:0` 的内部滚动链，最后一行内容和操作可达 | 测：面板矩形在舞台内；可滚动区最后一个可交互元素可滚到 |
| UX-03 | 不可执行的操作**事先**禁用或降级，并常驻写明原因或缺口（缺资源、未解锁、条件不足）；不靠点了才报错 | 测：禁用按钮附近有原因文字 / `title` / `aria-describedby` |
| UX-04 | 关键决策信息在首屏：替换看到属性变化、强化看到消耗和缺口、出发看到推荐等级 | 测：关键区块与主按钮同时在可视区内 |
| UX-05 | 每个列表有空状态（`stateBlockHtml`），加载显示「读取中…」，错误给恢复入口 | 读 + 测：空列表样例 |
| UX-06 | 跨系统导航有按钮：看到「去 X」就有能点的入口，并直达对应页签 / 部位 / 条目 | 测：含「前往」「去」字样的纯文字无按钮 |
| UX-07 | 不强制对话：任务对白最多一行提示，回港自动确认；剧情对白可跳过 | 读 |
| UX-08 | 文案：同一信息只写一次；不出现开发占位（TODO、undefined、NaN、[object]、空括号） | 测：文本扫描 |
| UX-09 | 页签名和内容一致：页签写什么，点进去就是什么（不出现「强化·重铸」只有强化这类） | 读 + 测 |

## UE（手感与反馈）

| ID | 规则 | 判定方法 |
|---|---|---|
| UE-01 | 所有按钮有悬停、按下、禁用、忙碌、焦点五态；忙碌防重复提交 | 读：走 `buttonHtml` 即满足 |
| UE-02 | 状态切换不挪位：选中、悬停、刷新不改变图标尺寸、内容位置、滚动位置 | 测：连续切换两个条目，比较列表滚动偏移和首个图标矩形 |
| UE-03 | 成功、失败都有即时反馈：成功有数值变化或小仪式，失败有原因提示；只在服务端成功后庆祝 | 读 |
| UE-04 | 动效短（弹出 220ms、奖励翻入 ≤800ms），`prefers-reduced-motion` 与 `[data-motion-reduced=true]` 下取消 | 读：CSS 中动画均有减少动态分支 |
| UE-05 | 键盘：Esc 关闭当前窗口，页签可方向键切换，焦点可见 | 测：Esc 关闭 |
| UE-06 | 文字不被裁切、不重叠：长名称换行或省略号并有 `title`；溢出隐藏的文字必须有省略号 | 测：`scrollWidth > clientWidth` 且无 ellipsis 的文字节点 |
