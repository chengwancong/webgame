## 缺口（按对玩家的体感排序）

| 编号 | 优先级 | 问题 | 证据 | 做法 |
|---|---|---|---|---|
| UX-A01 | P0 | **面板/弹窗/提示切换全是瞬间出现**。全工程只有 9 个 `@keyframes`，没有一个用于面板进出、tab 切换、tooltip；Motion token 只有 3 档时长 + 1 条缓动，没有回弹和错峰 | `*.css` keyframes 盘点；`tokens.json` Motion | token 增加 `Ease.Out/Back`、`Stagger`；`OverlayStack` 统一进出场（120–200ms 淡入 + 8px 位移 + 0.98→1 缩放，退出更短）；tab 下划线滑动；卡片列表错峰 30ms；全部走 reduced-motion |
| UX-A02 | P0 | **对白体验像表单**：无逐字显示、无头像、对话框居中盖住场景，文字区大半留白；第一章对白是用户定稿，这里只改呈现不改字 | 开场营地“落点求生”实机；`automatic-quest-dialogue.ts` 无逐字逻辑 | 底部锚定对话条，说话人头像（先用已有小人模型/NPC 小图）；逐字显示，点击/空格先补全再翻页；保留跳过与历史回看 |
| UX-A03 | P0 | **标题页是纯色底**，没有画面、动态、音乐和设置入口，也没有版本号；命名页反而用了营地虚化背景 | 8612 首屏实机 | 复用营地背景 + 缓慢飘移 + 标题光泽扫过；加音量/静音与版本角标；进入按钮加按压反馈 |
| UX-A04 | P0 | **开场坠落与“镜头坠落”的决定不符**：实际是深色渐变 + 一道 CSS 光带 + 一行 12px 字，约 8 秒几乎全空；三选一卡片只有静态图标，选之前看不到这招长什么样 | `prologue-controller.ts`、`prologue.css`；记忆 opening-hook-decisions | 用 Phaser 场景做真镜头下落（云层视差、速度线、落地冲击 + 震屏 + 柔光闪），不改对白；选卡悬停播 1.5 秒该技能预演。柔和半透明，不做刺眼白闪 |
| UX-A05 | P1 | **镜头硬锁主角**：每帧 `centerOn(主角)`，没有移动前瞻、死区、平滑；大招、首领出场没有推拉 | `scene.ts:260` | 纯渲染层：速度前瞻 + 临界阻尼跟随；首领出场/击杀短推近；受 `motionReduced` 控制；不改世界状态 |
| UX-A06 | P1 | **HUD 数值缺过程感**：玩家血条只有 200ms 线性缩放，没有延迟残影条、受击闪、低血脉冲；金币/经验没有数字滚动；升级没有专属庆典，成长卡片是纯信息排队 | `ui/hud.css .meter`；`main.ts` 成长卡片 | 血条加残影层 + 受击微闪 + 低血脉冲；金币/经验数字滚动并在变化处短暂高亮；升级用一次柔光环 + 数字弹出（战斗中仍只排队） |
| UX-A07 | P1 | **技能栏缺“活”的反馈**：有冷却扫描，但没有就绪闪光、按下弹压、资源不足抖动 | `ui/hud.css .skill-slot` 仅 border/filter 过渡 | 冷却归零时一次边缘扫光；按下 0.92 弹压；缺资源/冷却中按键时槽位轻抖 + 红边闪 |
| UX-A08 | P1 | **窗口太窄时整体缩到 7–8px 且无提示**；1280×720 下 50 个文字节点有 19 个是 12px，次要信息偏小 | 窄窗实机；DOM 抽查 | 设最小舞台尺寸与“请放大窗口”提示；次要文字提到 13px，正文 ≥14px（走 token） |
| UX-A09 | P2 | 没有手柄、字号缩放、色盲配色；右键菜单为 0 | 关键词盘点 | 仅在要上 Steam/掌机时升级；先做字号缩放与色盲备用品质色 |
| UX-A10 | P2 | `src` 里并存 `*-before*.ts` 旧副本和大量评审页，`main.ts` 118KB；不影响玩家，拖慢迭代 | 目录 | 归 Codex 排期清理，Claude 不动共享源 |

## 做的顺序

UX-A01 → A02 → A03 → A07 → A06 → A04 → A05 → A08。A01 面最广、改动小，先做；A04 工作量最大且涉及用户定稿的开场，放在 A01–A03 之后，对白原文不动。每项做完在应用内浏览器过一遍（面板、对白、标题），不跑无头测试，不并行重任务。
