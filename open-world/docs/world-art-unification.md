# NPC 与场景统一画风

2026-10-03，用户选定方案2，依据为工程 `.design/npc-scene-unification-20261003/camp-unified-v2.png`。正式画面使用独立素材和原生动态角色。

## 当前实现

- 七位剧情 NPC 复用主角的完整原生 Spine 4.2.43 骨骼、图集与动作，分别选择服装、头部、发型和工具。铁匠的锤、龙裔的斧复用已确认的手绘装备图，跟随真实手骨骼；不将这些附加工具宣称为原包自带附件。
- 显示高度固定为 100px，脚底和深度固定，方向镜像覆盖人物与工具。地图切换销毁旧 NPC、纹理与交互节点；共用 GPU 在最后引用释放后保留 300ms，支持快速换图，随后完整释放。
- 九个独立透明摆件：树、旅舍、石堆、传送门、锻造台、归途灯、车队残骸、木桥、路标。五张地表：草地、石路、雪地、深渊岩地、荒漠地面。
- 十三张正式地图共用手绘轮廓、明暗和材质语言。森林保留冷色草地；裂谷、雪域、深渊、龙骨使用各自地表、道路调色、岩石调色与边界颜色。位置、路网、碰撞、导航和玩法准入仍由原地图与服务端配置控制。
- 道路以同一次路径描画完成铺装和主题调色，避免交叉路段重复叠加透明颜色而变成深色块。
- 森林草药、书卷和冰晶线索复用正式手绘物品资源；预览目录不是剧情通关或功能解锁证据。

## 资源与构建

原始 PNG 与生成提示词保存在 `assets/environment-handdrawn/`。环境通过内置 imagegen 生成；导入仅做透明边缘裁切、等比例缩放、留边及图集打包。`packages/asset-manifest/environment.v2.json` 记录原始与发布哈希、枢轴、尺寸、主题调色和物品复用关系。

NPC 选择表在 `assets/story-npcs/selection.json`；`packages/asset-manifest/story-npcs.json` 登记原始版本、皮肤、动作、工具和显示高度。主角原始骨骼和图集未改写，人物动作不是由几张静态图假装播放。

`pnpm build` 已包含 `build-world-art.mjs` 与 `build-story-npcs.mjs`，生成资源不依赖 Codex 缓存仍存在。新旧资源源文件保留，不覆盖历史原始素材。

## 验证与边界

类型检查、内容校验、正式构建与 20 项人物相关测试通过。七位 NPC 动态与镜像、原生暂停不推进、工具手骨骼挂载已检查；十三张地图逐项加载并留存截图。

初轮原生 GPU 测试在 RTX 4070 SUPER、1280×720 下，20 敌人与 30 弹体的帧耗时 P95 为 16.7ms、场景处理 P95 为 2.3ms。地图切换预览的滚动采样包含加载峰值，不能用它代替稳定混战指标；最终性能复核见验收目录。

真实临时验收账号完成了调查和第一波战斗，服务端提交奖励、摄像机移动与地图显示正常；该过程未通关整个主线。正式服务则验证已有角色恢复营地、原存档与回执保留。实际版本以 `versions.json` 为准；并行规则更新继续保留，不把它们算作本轮美术改动。
