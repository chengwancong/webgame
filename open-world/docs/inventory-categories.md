# 独立背包与普通道具分类

2026-10-01：正式背包采用用户认可的独立窗口结构，并沿用技能页的蓝色层次、细边、暖金选中态与蓝色动作按钮。人物、六部位和角色总属性移入独立人物窗口；所有背包分类都保持同一分类区、网格区和详情区。

## 数据与操作

| 分类 | 数据与行为 |
| --- | --- |
| 全部 | 汇总真实持有物品，不填入设计稿数量 |
| 装备 | 原装备实例；品质/六部位筛选，服务端强化与分解报价、锁定；换装跳转人物并聚焦当前物品 |
| 消耗品 | 攻击/生命合剂、技能书。合剂使用1瓶，持续20次真实击杀，同类生效中禁用；书跳转对应技能，激活由既有技能界面处理 |
| 材料 | 11种材料的数量、来源和用途；跳转已实现的养成入口，不伪造通用使用操作 |
| 任务 | 当前没有任务物品库存，显示空态 |

24格容量只计装备实例，材料和消耗品堆叠独立。普通道具数量来自 `Snapshot.progression` 与 `skillBooks`；服务端当前不保证 `progressionView` 随角色快照返回，分类不能依赖它。未知材料保留数量并显示用途未配置。

合剂复用 `progression/preview`、`progression/action`、现有命令outbox和回执恢复；使用后的库存以回执快照为准。即使成功响应丢失，切到其他分类后仍可通过固定页脚恢复，不能重复扣除。技能书与材料的导航本身不消费资源。

## 人物窗口边界

正式版已独立出六部位人物窗口，保持当前四个数值槽与旧核心兼容；头盔、鞋子、戒指仍是未配置运行装备的空槽。324张装备图与注册表不自动转为可穿戴或可掉落装备。

用户最新指定的魔兽世界／暗黑4人物布局已制作成[新交互设计稿](../../.design/inventory-categories/CHARACTER_WOW_D4.md)：中央人物、两侧六槽、常驻属性栏、当前部位换装浮层。用户已批准该稿落地，正式人物页已采用该布局，并接入原有穿戴、比较与管理流程，见[人物实现](character-equipment-ui.md)。

## 资源与复核

14张正式基础图覆盖两种合剂、11种材料及技能书底图；每本书叠加关联技能徽记。图标通过正式UI资源清单发布，游戏不引用 `.design` 路径。来源见[普通道具美术记录](../../docs/05-art/inventory-icons-handdrawn-20261001/README.md)。

真实数据库浏览器验收入口：`node --import tsx tools/accept-inventory-categories.mjs`。它使用隔离临时数据库，覆盖空库存、五类固定布局、实际合剂使用、成功后丢失响应的幂等恢复、书籍激活、材料导航、换装/强化/锁定、满容量、分解后领取与刷新保留。证据在[本轮记录](../../docs/reviews/open-world/inventory-categories-20261001/result.json)。

另由独立Agent复核1024×576、1600×900、1920×1080及375×812：分类区域、图标尺寸、滚动与焦点稳定；窄屏分类行采用内容高度，避免搜索栏覆盖分类。窄屏纵向内部滚动时，少量物品仍保留固定列表高度，可能出现局部空白，作为后续窄屏优化项。主交付画布为1280×720。

发布后使用 `node --import tsx tools/accept-inventory-published.mjs` 检查实际health/content版本、14张资源解码、开发账号免密码登录、进入营地和会话刷新恢复；结果保存为同目录 `published.json`。

本轮已完成停止服务→构建→恢复服务，客户端 `0.6.3`，资源 `world-art-20261001-v6`，协议7、规则ow-10、数据库9保持原版本。11项真实数据库路径检查及发布后浏览器检查通过。实际health/content一致，14张基础图成功解码，免密码登录、营地、会话恢复与装备保留正常。

装备提示卡同时适配新网格：点击选择时收起，移开再悬停可重新查看；提示不覆盖自身条目，也不覆盖桌面右侧详情操作。空间不足时使用单列内部滚动，发布后已在1280×720、1024×576及375×812实际核对。
