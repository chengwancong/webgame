# 玩法参考：杖剑传说（2026-10-23）

> 用户要求：「玩法方面，我希望可以参考杖剑传说」。Claude（总策划）写。原则：借形不借名；先盘点本作已有，再定借什么；不推翻已批准的「单岛主城 + 星门副本」结构。

## 1. 杖剑传说是什么（公开资料整理）

| 系统 | 做法 |
|---|---|
| 战斗 | 半即时、全自动。策略几乎全在**战前配置**：职业 + 技能搭配 + 装备词条 + 幻兽。换装备、换技能不花成本 |
| 职业 | 战士 / 法师起步，转职分支（骑士、斗士、贤者、术士），每次转职开 10–12 个新技能；同职业有多个流派（反伤、连击、治疗、召唤、暗牧） |
| 元素 | 风 / 水 / 火 相互克制，前期就是主要策略点 |
| 大地图 | 迷雾逐步揭开；宝箱、精英、隐藏剧情随机事件；**属性门 / 工具门**（钻头、毒素药水）要用后来拿到的道具回头开；女神像激活；**区域完全探索奖励**，探索度直接提升挂机产出 |
| 挂机 | 离线持续产出，后期大地图仍然产挂机资源 |
| 副本 | 每个国度一个特色副本，4 人组队或匹配，普通 / 困难 / 噩梦；每日 2 次免费奖励 + 2 次付费追加 |
| 装备 | 六阶品质（白蓝紫橙金红），红色有套装；**强化有共鸣**（全身每 +5 / +10 给额外属性），+100 后镶宝石；词条可锁可洗 |
| 幻兽 | 金色幻兽上阵，带独有被动和战斗技能，按场景换 |
| 赛季 | 2–3 个月一季，季末按装备评分给 D–SSS 评价，养成等级折成永久加成 |
| 风格 | 温馨手绘、纸娃娃换装 |

公认的缺点（测评原话概括）：装备 1–2 周就淘汰、洗练门槛高、大量战斗机制和词条用不上、新技能远强于旧技能、赛季逼着天天在线、组队玩法人气撑不起来。

## 2. 对照本作现状

| 杖剑传说 | 本作现状 | 判断 |
|---|---|---|
| 全自动战斗 + 战前配置 | 已有手动 / 半自动 / 全自动；全自动会自动选三选一增益 | **有**，缺「配置方案」：没有一键切换的技能 / 装备 / 宠物方案 |
| 元素克制 | 物理与元素并列、护甲 + 元素抗性已定 | **半有**：怪物抗性存在，但节点上看不到「这里怕什么」，玩家没理由换配置 |
| 迷雾大地图 + 工具门 + 探索度 | 512 格大岛已冻结；星门节点 + 巢穴「走到底」做大世界错觉 | **缺**：节点打完就完，没有回访理由、没有收集进度 |
| 探索度 → 挂机产出 | 码头派遣：已打通航区离线采集，12 小时上限 | **半有**：产出只看「打通没打通」 |
| 转职分支 | 武器倾向 + 天赋四树 + 83 技能 + 找回招牌技 | **有**，不另加转职，避免和天赋重叠 |
| 副本三难度 + 每日奖励次数 | 刻度（world-tiers）+ 每日首通加成 + 周常首领 | **有** |
| 强化共鸣 / 养格子 | 强化跟着装备走（`gearContribution` 里的 reinforcement） | **缺**：换装就白强化——正是杖剑「装备不保值」的病根之一 |
| 幻兽上阵 | 宠物**只有美术，没有玩法**（M13 §1） | **缺**，而且是现成的空位 |
| 赛季评价 D–SSS | 本场评价 S / A / B（FP3）、赛季 P28 已有称号 | 够用，暂不加 |
| 4 人组队副本 | 无组队 | **不借**：没有玩家基数撑匹配 |

## 3. 借什么（按价值排序）

| 批次 | 内容 | 借的是 | 规模 |
|---|---|---|---|
| **Z1 出战方案** | 3 套方案，每套存技能槽 + 装备 + 天赋 + 宠物；港口和星门选节点时一键切换，免费。节点卡片标出敌人主属性和弱点（如「多冰霜 · 怕火焰」），当前方案不对路时给一行提示 | 战前配置即策略、元素克制可见 | 中：前端为主，服务端存方案 |
| **Z2 部位强化 + 共鸣** | 强化等级从装备挪到部位（6 个部位），换装不丢；全身部位都到 +5 / +10 / +15…给共鸣属性。旧装备上的强化按「部位取最高」一次性迁移 | 养格子、强化共鸣 | 中：规则 + 迁移 + 数值一次推导 |
| **Z3 宠物上阵** | 1 只上阵（主动技能 + 被动）、2 只助阵（只给被动）。宠物来源已定为节点首通（M13）。被动走现有 build-sources 的属性 / 规则，不新造效果系统 | 幻兽上阵、按场景换 | 中大：玩法设计 + 战斗接入，美术 GPT 已有 |
| **Z4 航区探索度** | 每个航区的节点里藏：隐藏宝箱、属性门、工具门（如「需要雾铃的铃钥」才开的风栖密室）。航区页显示探索度 %；到 50% / 100% 给永久奖励，**并提高该航区码头派遣产出** | 迷雾探索、工具门回访、探索度喂挂机 | 大：需要场景摆件 + 美术，最后做 |

**不借**：组队匹配、技能抽卡、装备快速换代、高门槛洗练（本作已是「每件 ≤1 条词缀，只随掉落」）、赛季强制在线、竖屏。

## 4. 默认裁决

| # | 问题 | 默认 |
|---|---|---|
| Z-D1 | 先做哪批 | Z1 → Z2 → Z3 → Z4；Z1 改动最小、立刻让元素克制有意义 |
| Z-D2 | 部位强化后旧强化石怎么办 | 迁移时按部位取最高；多出来的不退（开发期可清档） |
| Z-D3 | 宠物会不会让全自动更强 | 上阵宠物伤害计入 TTK 推导（一次推导 + 一次验证），不额外加 |
| Z-D4 | 探索度要不要地图迷雾 | 不要大地图迷雾；迷雾只在航区页上表现为「未发现」的节点内容 |
