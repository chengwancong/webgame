# Grok 30 小时全内容测试要求（2026-10-22）

适用版本：测试服（client 0.11.50 / protocol 53 / rules ow-91 / db 19）。开跑前先请求 `https://43-165-179-11.sslip.io/api/health`，版本不同就停下报告。

当前开放范围：拾星港 + 风栖（Lv1–8）+ 雾铃（Lv8–15）两个航区，共 20 个节点。赤炉、霜镜、沉星、龙眠、深潮五个航区按计划锁定，只测锁定提示。30 小时 = 已开放内容全覆盖 + 三种武器 + 三种操作模式 + 跨日日常 + 重复刷取 + 挂机耐久 + 稳定性。

【开跑前】
1. 打开 https://43-165-179-11.sslip.io/api/health，确认 versions 为 client 0.11.50、protocol 53、rules ow-91、db 19。不一致就停止并报告。

【30 小时分段】按顺序做，每段结束写一段小结（用时、通关节点、等级、问题数）。

第 1 段（0–6h）主号 qa_grok_hub1 首通全部 20 个节点
- 新号建角色 → 开场（坠星、镜头坠落、武器三选一选剑）→ 应回到拾星港，不能进旧野外大地图。
- 星门打开航图：节点旁弹出节点卡（名字、推荐等级、预计时长），出发前有确认；锁定节点和锁定航区要显示锁定原因。
- 任务引导已降级：剧情节点进场直接开打，不需要找 NPC 按 E；台词每步最多一行，不挡操作；回港不弹逐句对白（最多一行轻提示）；港口没有任务箭头，任务追踪栏默认收起、可展开。若仍出现强制对话、按 E 才能继续、任务箭头，记为 BUG。
- 开放规则：每个航区的剧情 + 巢穴节点一开始全开；关口要「本航区再通关 N 个节点」（共 3 个），不再有关口任务清单；工坊在第一次打完节点回港时开放，码头在风栖关口首通后开放。
- 巢穴：连续击杀出现连斩计数（10/25/50 档字样升级，停手约 3 秒淡出）。
- 狩猎：机制每场随机（落石预警圈 / 涨潮半边地面减速 / 引雷桩）。遇到引雷桩时：精英有护盾条，场上两根石柱，站在旁边读条 2 秒「击碎引雷桩」，碎一根护盾变短，两根都碎出现「护盾破碎」横幅。每次记下本场是哪种机制。
- 怪潮：分 4 波，波次提示清楚，最后一波结束才算成功。
- 寻宝：五箱限时；偶尔有一箱读条后变成「宝箱怪」，目标行变为「击败宝箱怪，夺回宝箱」，打死后照常拿该箱奖励；全开五箱有额外一箱。
- 关口首领：打到半血屏幕上部出现一次「首领名 · 狂暴」横幅（不重复）；局内三选一增益；首通后应开放后续节点，并可能解锁外观或宠物图鉴。
- 局内：三选一增益卡、倒下与撤离、出口；结算页左右两栏，有本场评价 S/A/B 与「距 S 还差 N 秒」；回港结算显示本次总收获、首通、新开放功能。
- 雾铃开头应获得第一个海克斯（保底）；记录在哪个节点、什么界面拿到。
- 每升一级检查技能开放或找回、技能栏、天赋点；记录 Lv1→15 每级大约用时。

第 2 段（6–10h）副号对比武器
- qa_grok_hub2 选法杖、qa_grok_hub3 选暗器，各从开场打到风栖关口首通，并至少打通雾铃剧情1，各约 2 小时。
- 对比三种武器：动作、手感、清怪速度、首领用时、死亡次数。重点看技能出手动作、挂点特效是否贴手/贴武器，转身后特效位置是否正确。

第 3 段（10–16h）重复刷取与随机性（主号）
- 每个狩猎节点至少各打 6 次，统计三种机制出现的次数；引雷桩至少完整打 2 次。
- 每个寻宝节点至少各打 6 次，记录宝箱怪出现次数，以及同一场掉线重连后宝箱怪是不是同一个箱子。
- 残页（武器残页 / 绞杀残页 / 精英残页）：从风栖剧情2 之后开放。每种至少插一次，确认效果说明与实际一致（精英数量加倍要真的变多），确认残页是消耗还是保留。
- 若有挑战档或难度刻度可选，每档至少打一次，记录敌人强度和奖励变化。
- 装备：记录掉落品质分布、词缀（每件最多 1 条）、换代提示；背包满时的提示和处理；一键分解（已穿戴、锁定、强化过、传说等受保护装备不能被分解）；一键穿戴推荐是否合理。

第 4 段（16–20h）港口系统逐项点检（主号 + 副号）
- 港务厅：章节进度、档案、成就、港口建设（工坊 / 船台 / 邮局各 4 阶）。升级前后看港口是否多出灯、旗、摊位，以及有没有奖励。
- 工坊（机巧师·铜铃）：强化（只能在工坊锻造台 5 格内操作，离远了应拒绝且不扣资源）；重铸需要 23 级，当前等级达不到，应显示条件不足；制作 / 铭纹若有，记录配方来源。
- 码头：挂机路线派遣与收益；进港时由服务端结算，离线一段时间后回来看收益是否合理、能否重复领取。
- 邮局 / 委托板：4 格，每天 8 条，最多累积 3 天，不应再出现 600 秒冷却。领一次后不能重复领。
- 今日面板：每日首通 ×2（每天 10 个节点，只在成功时消耗，装备不翻倍），剩余次数显示与实际一致。
- 技能页（分组技能册）、天赋页、人物换装（并排对比）、任务页（常驻多任务列表 + 固定详情）、背包。
- 仓库、外观、宠物：入口存在就测完整流程；不存在记「未开放」，不算 BUG。
- 港口里永远不刷怪；死亡或失败一律回到星门前。
- 所有功能都能从右下菜单直接打开，不强迫走路；只有待办建筑头上有红点。

第 5 段（20–23h）跨日日常（分 3 个自然日，每天约 1 小时）
- 每天在服务器日切前后各登录一次（以今日面板显示的刷新时间为准），确认首通 ×2 次数、委托板刷新，以及累积到第 3 天不会超过上限。
- 记录日切当下正在副本里时会发生什么（副本不能中断，奖励不能丢）。

第 6 段（23–27h）操作模式与挂机耐久
- 副本内三种模式都要用：手动（键盘走位，看按下即动、停下不被拉回、被击退或冲刺后位置正确）、半自动、全自动。
- 全自动：自动寻路、开箱、碎引雷桩、选卡（约 8 秒后自动选，不是总选第一张）、走出口。
- 连续全自动挂机 2 小时：观察内存和帧率变化、掉线、卡死、背包满时的行为（满包应停下并提示，不能无限挂）。
- 同屏人多处（港口 NPC 聚集区、首领战）：同屏原生角色超过 8 个也应全部显示；首领出招、转阶段、倒地时人物不能闪一下消失。首次进港前几秒卡一下属于正常（正在缓存），之后应流畅。

第 7 段（27–30h）稳定性与边界
- 副本中：切后台 3 分钟回来、刷新页面、断网 30 秒再恢复。应恢复到原来的位置、血量、冷却和已击杀，不能重刷怪、不能补满血、不能重复发奖。
- 结算页弹出前后刷新：奖励只发一次。
- 同一号开第二个标签页：应有冲突提示，不会两边同时控制。
- 浏览器 devtools 网络限速（Fast 3G）跑一个巢穴：区分「网络慢」和「操作迟滞」。
- Lv15 封顶后：经验条、升级提示和雾铃之后的引导是否合理；锁定航区提示是否清楚。
- 用三个号分别回顾一遍完整的新手 30 分钟体验，写出最影响留存的 3 个问题。

【每个问题的记录格式】

严重度：阻断（无法继续玩、丢档、重复发奖、奖励丢失）/ 严重（功能错误但能绕过）/ 一般 / 体验
步骤：从哪个页面开始，依次点了什么，是否刚从后台回来

实际：实际提示、错误码、卡住位置和持续时间
复现：复现次数 / 尝试次数，刷新后是否仍复现
截图时间：带时区；截图避开口令和 cookie
账号 / 角色名 / 等级 / 节点名 / 本场狩猎机制（如适用）
环境：浏览器版本、窗口尺寸、网络情况（帧率低和网络慢分开记）

【体验记录】（不是 BUG，单独一节）
- 每个节点：实际用时 vs 卡片上的预计时长、难度感受（太易 / 合适 / 太难）、死亡次数、最有趣和最无聊的点。
- 升级节奏：Lv1→15 每级用时表；哪里卡等级、哪里需要回头刷。
- 掉落与成长：什么时候换装备、第一次拿到海克斯和词缀装备时是什么感受。
- 三种武器各打一个分（1–10）并说明理由。

【最终报告结构】
1. 版本与时长：health 版本、三个号各自总时长、各段实际用时。
2. 阻断问题（先列）。
3. 严重 / 一般 / 体验问题。
4. 覆盖表：20 个节点 × 三个号的通关情况；港口每个功能「通过 / 失败 / 未开放 / 未验证」。
5. 统计：狩猎机制分布、宝箱怪次数、掉落品质分布、每日刷新核对结果。
6. 体验记录与新手 30 分钟留存问题前 3。
没有亲自完成的项目标「未验证」；登录成功或 HTTP 200 不算可玩验收。
