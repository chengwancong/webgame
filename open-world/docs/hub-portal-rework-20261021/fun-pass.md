# 下本趣味补强（2026-10-22 起）

用户 2026-10-22：「你继续推……你一定要做成一个有趣的RPG下本游戏」。M03/M04 已经定了副本外壳、九种类型、三选一和结算页，这里只补**一场之内的爽感与惊喜**，不新增大纲外系统。缺美术一律先占位，需求登记在 [art-backlog.md](art-backlog.md)，之后交 GPT 批量出图。

## 盘点（只看已落地代码）
| 项 | 现状 | 判断 |
|---|---|---|
| 打击反馈 | 伤害数字、受击闪白/位移、震屏、物理技能动作、受击层特效 | 够用 |
| 掉落 | 地面图标弹出/弹跳/飞向角色，稀有/传说光柱 | 够用 |

| 割草节奏 | `entity_died` 事件已有 | **没有连斩计数**，巢穴 50–80 只一厅打完没有任何反馈 |
| 结算 | 收获、首通、海克斯统计、差距诊断 | **没有本场评价**，打第二遍没有「打得更好」的目标 |

| 自己的移动 | 副本里服务端权威，插值已改缓冲 | 仍有约 1 个快照间隔的输入延迟（本地预测未做） |
