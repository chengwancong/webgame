# 像素模式世界空白修复 · 2026-10-27

用户在 127.0.0.1:8612 开启像素模式后，只看到 HUD 和文字，地形、建筑、人物全部消失。截图不入 Git。

## 原因与修复

- 本项目使用 Phaser 4.2.1。RenderTexture 默认 renderMode 为 render；draw() 只写入 DynamicTexture.commandBuffer，不执行。PixelWorldTarget 未调用 render()，因此世界纹理一直为空，主相机却已隐藏原世界对象。
- 在世界对象解除遮罩、文字仍排除的同步窗口内调用 render()，立即执行队列。根对象先过 willRender 检查，避免隐藏的物件和原有相机排除项被直接画入。
- 低分辨率目标固定 640×360、倍率 2；校正内部相机的缩放枢轴和合成图位置，使不同背板尺寸下的世界、固定背景与文字相机对齐。
- 相机排除位也影响 InputManager.inputCandidate。遮罩只保留到场景 render 事件，随后还原；关闭、异常与销毁时恢复原位并解除监听，避免人物恢复显示后仍不能交互。
