## 0. 执行方式（强制）

1. **一次连续做完 R0 → A1 → A2 → A3 → A4 → A5 → R9**，项与项之间不停、不等确认、不回来问。允许的结束状态只有两种：
   - **全部完成**：§6 完成定义全部勾上；
   - **硬阻塞**：已经做完所有不受阻塞影响的项，只剩 §5 列出的硬阻塞项。
2. 进度文件：同目录 `art-fp-progress.md`（你创建并持续更新）。每完成一项勾一项，写输出路径、尺寸、sha256 前 12 位和一句自检结论。中断后从第一个未勾项接着做。
3. 决策日志：同目录 `art-fp-decisions.md`，每条一行：问题｜处理｜依据条目。
4. 协作中心：`游戏协作.md` 超过 40,000 字符先按规则归档；任务队列加一行 `ART-FP | P1 | 进行中 | Codex | A1–A5 副本趣味美术 | 素材不入库`，完成改「待接线」。只用 `更新游戏协作.ps1`。
5. **素材不进 Git**：`apps/web/public/art/` 和 `.runtime/` 被 Git 忽略，部署脚本会从本机复制运行时图片。能提交的只有资源清单 JSON / TS、本交接的进度和决策文件。提交前看 `git diff --cached --stat`，出现 png / webp / atlas 图片就撤掉。
6. **不下载新素材**：只用本机已有的库（`source-assets/SP33 魔兽风二头身SPINE`、`spine源文件_召唤与合成…819套`、`Q版日式手游SPINE特效300套`、现有游戏图）和图像生成（imagegen）。要从网上下载任何素材包，都必须先由用户逐次同意，所以本批一律不下载。
7. 本机重任务一次只跑一个；不跑无头浏览器和浏览器自动化（本机常驻 MU）。看效果用本地图片拼对比图，不开游戏。

**禁止**：只写文档不出图；交付纯色块、几何图形或文字截图冒充成品；拿库素材原样不处理就交（要按 §2 统一画风）；改玩法代码和数值；把原始生成图、对比图、PSD 提交进 Git；用纯 SVG 程序化自绘做场景物件（A4、A5），这类画风用户已经否决过两次。

## 3. 统一技术要求

- 一律透明 PNG（sRGB，预乘关闭）；图集用 TexturePacker JSON（hash）格式，内边距 2px，不旋转。
- 运行时文件按显示尺寸的 2 倍出图，单张图集不超过 2048×2048，A1–A5 运行时文件合计 ≤ 6MB。
- 源文件（生成原图、分层稿）放 `.runtime/art-fp/source/`（被忽略；注意 `open-world/assets/` 和 `.design/` 是入库目录，不要往里放），清单里的 `source.path` 指向它。
