# 柴犬主角 · 游戏内试用接入

用户在查看独立样片后要求“更新到游戏试试”。本次将像素模式中的主角替换为该柴犬，原画风关闭开关后仍使用原主角；不改账号、外观装备数据、技能数值、碰撞或动作时长。

## 已接入

- 20 个主角入口、58 个 manifest 条目：启动角色、七武器 native／wardrobe、旧职业兼容入口与双手剑。成品路径统一在 `/art-pixel/hero/shiba-v1/`，源图不覆盖。
- 待机、移动、普攻、技能、投射、受击、死亡及已有长柄动作分支，均从原主角 Spine 动作烘焙。每个条目的 duration、impactTime、frameTimes、帧数和行号保留既有值，只更新皮肤像素和跟随新骨骼的挂点。
- 沿用原主角骨架、IK 与手部约束；旧动作时间不同的入口，按释放点分段映射到原 Spine 动作，不改变游戏时钟。剑使用柴犬样片短剑，其他武器保留各自像素造型并跟随真实手部变换。
- 身体与武器保持分层；空手装备状态不显示武器。柴犬毛色、白嘴套、眼睛保持稳定，仅蓝色衣服接受装备换色。原人形帽子／披风覆盖层暂不叠到犬耳和脸上。
- 修正死亡终帧的贴图边界，倒地时保持完整头部轮廓；该调整只影响贴图内部位置，并同步帧挂点。
- 像素清单与主色板颜色不变，主色板版本标记更新到 `abyss-shiba-60-v4` 以刷新 manifest。独立样片继续保留；游戏只使用烘焙精灵表，不新增实时骨骼计算开销。

## 验证与发布

全 2958 项像素清单校验通过（0 issues）；`tsc --noEmit` 通过。新增测试覆盖全部主角入口、衣服换色不污染犬毛，以及死亡各帧完整轮廓；既有动作时长／命中边界测试通过。相关测试共 23 文件／105 项通过（`--maxWorkers=1 --no-file-parallelism`）。本机 8612 实际返回 20 个 Shiba 主角条目。发布回执完成后补入。

没有运行浏览器自动化，也未修改其他会话的 main.ts、API、存档或配置表。HUD／对话头像沿用原流程，本次重点是世界角色与换装预览的像素形象。

## 真机检查

1. 开启设置中的“像素画风”，进入港口，场景主角应是黄白脸、三角耳、卷尾的柴犬，不再是白发人形。
2. 走动、左右朝向、七种武器与技能释放；核对握点、投射起点、命中时刻，不能只看待机。
3. 查看受击与倒地，头部不被贴图边界截掉；复活后的造型与动作恢复。
4. 换装预览仍为柴犬，衣服可换色，耳朵和脸不被旧人形帽层遮盖。
5. 开关关闭后恢复原主角，反复切换和跨地图时不应出现空白世界或残留图层。

这是用户要求的游戏内试用版，未将像素校验通过当作用户视觉认可；犬型帽装、独立头部装备等新造型后续按试玩反馈处理。
