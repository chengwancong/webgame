# Grok 真机检查清单：细腻像素画风（2026-10-28）

**本清单全部待真机检查，不代表已通过。** 用正常游戏界面操作，在右下「设置」→「声音与显示」→「像素画风」切换；同时检查「减少镜头与动画效果」。使用测试角色，不清库、不编辑正式角色数据。发现问题时记录设备、浏览器、窗口尺寸、DPR、地图、对象、动作/阶段和开关状态，并附可定位的画面或短录屏。

本轮基准是 **1280×720 原生世界、128×128 主角画格、约96px原生人物身高、64色共享美术主色板**，采用最近邻显示；不是把旧64px小图整体放大。原素材保留，关闭开关须完整恢复。**NPC对话头像与现有字体按约束保留原画风，未下载新字体**，不要当成漏换；美术源色板约束不等于字体、阴影、运行时淡入淡出合成后的整屏只能有64色。

## PX0：整屏样板、尺度与开关

- [ ] 在主城港口同屏查看主角、港务长、建筑、树石、地面和HUD：应当是明快、清楚的像素簇，材质没有铺满碎噪，也没有写实厚涂和粗程序占位图混在一起。
- [ ] 在1280×720及普通大窗口、DPR 1/2等实际设备条件下检查：世界轮廓清楚，文字保持原生可读；不能出现整屏发糊、半幅空白或世界与HUD位置分离。
- [ ] 对照主角、NPC、建筑和门洞的比例：约96px人物保持细节，不能再次把64px角色或16px地物撑大冒充高精度素材。
- [ ] 同一地点静止、移动、转身并开关像素模式：角色脚点、地图位置、交互提示和固定HUD应对齐，不出现切换后整体平移或相机突然拉偏。
- [ ] 查看奶白浅金面板、选中态和主操作按钮，确认主色调统一；美术边缘没有软模糊残留，原生文字不被压成大像素块。

## PX1：主角、原Spine动作与换装

- [ ] 核对世界、HUD头像、角色页和外观预览的柴犬身份：立耳、短口鼻、奶白面罩等识别特征一致，不能回到人脸、盾牌头像或像麻雀的剪影。
- [ ] 逐一查看剑、锤、斧、弓、杖、暗器、魔杖的待机、移动、攻击、施法、受击、死亡；身体与武器不分离、不穿帮、不被画格截掉。
- [ ] 左右朝向反复切换，检查镜像、握点、武器尖端和特效释放挂点；长柄、远程和双手姿势尤其不能错手或从脚下发射。
- [ ] 对照开关前后的同一动作或慢动作录屏：沿用原Spine动作总时长、命中/释放边界与受击时机，不因换美术提前命中或拖长动作。
- [ ] 在外观页切换部位与套装后返回世界：衣服色阶和实际形象对应；头、手、裤装、背饰缩略图各自表达真实部位，空背饰不能显示一件虚构披风。

## PX2：港口建筑、设施与状态

- [ ] 用可访问的测试存档检查工坊、船台、邮局1–4级及其建设页预览：等级/状态能区分，列表与详情展示同一建筑，不再用铃、车或泛用房子冒充设施。
- [ ] 查看仓库、衣橱、宠物院、摊位、货物、灯柱、营火、码头和船；轮廓与功能相符，摆放、脚点、遮挡和交互距离保持原位置。
- [ ] 查看星门未启用、可交互和播放动效等实际状态：基座、门环、光效和交互提示一致，不丢帧、不缺层，人物不会站到错误的门内位置。
- [ ] 对照已有的起重设施、水车、熔炉、罐体、管道、工作台等语义设施：应当能看出实际用途，不能仍是通用石柱或同一幢房屋；破损/开闭/工作状态不要串图。
- [ ] 在港口前后穿行并打开建设、仓库、外观等界面：前景遮挡和菜单层级正常，建筑牌记不被当成巨大地物，也不盖住操作区。

## PX3：NPC与对话

- [ ] 在港口、剧情和野外逐类查看NPC：港务长、工匠、药师、学者、商人、邮差、龙裔、守卫等职业能辨认，不是所有人共用同一小人。
- [ ] 检查待机、移动、停下和转身，保持约96px人物尺度；头、手、脚、衣摆没有漂移、断开或截帧，移动后脚点不滑到地面之外。
- [ ] 查看名字、交互提示与真实站位，进入和退出对话时，世界人物和点击目标不消失、不偏移。
- [ ] 对话头像继续使用原头像，文字与排版清楚；这是约定保留项，不能为了追求像素覆盖而误换成错误的通用头像。
- [ ] NPC附近开→关→开，再离开并返回地图：恢复原形象与采样后，重新开启仍能显示正确职业、朝向和动作。

## PX4：普通怪、精英、首领phase与模块

- [ ] 检查本轮怪物各设计大类、普通/精英变体和可访问首领：保持各自头部、主色、甲片/鳞片和武器特征，不能混用随机怪物；近战、法师、铳手的武器要正确。
- [ ] 查看待机、奔跑、攻击、施法、受击和死亡，尤其观察换动作后是否串到别的帧；打包图集不能出现相邻动作、身体切片或空白格。
- [ ] 触发首领实际阶段变化，覆盖phase-enter、phase-active、phase-end对应表现，以及蓄力、破绽和大招：动作顺序与原时钟保持，读条和危险提示可辨认。
- [ ] 查看已有的独立武器、炮口、护盾或身体模块：跟随正确首领与朝向，释放位置、隐藏/破坏和死亡状态不悬空、不遗留在上一阶段。
- [ ] 比较开关前后的同一场战斗：受击、命中范围、碰撞和数值不变；首领卡片里的冰女王、深渊领主、龙王应与游戏中的最终新造型一致。

## PX5：183组地表、地形与跨图

- [ ] 在港口、各岛、野外和副本查看183组原生32px地表的实际使用：草、土、石路、水、雪、岩地能区分；垂直墙面不能再误铺成整片地板。
- [ ] 对照原画风沿道路、岸线、悬崖、墙边走一遍：地表拼接与原掩膜对齐，能走/不能走的位置和原来一致，不出现新通道或视觉上的假路。
- [ ] 横跨地表块和加载边界，检查接缝、角部、路径转折、遮挡与树石脚点：没有黑缝、透明洞、错色块或一块地表错移32px。
- [ ] 在不同地图间往返、靠近地图边缘并返回港口：新地面和物件持续显示，不能因旧缓存或合成目标销毁而留空白、残留上一图或整体错位。
- [ ] 查看地下/岩壁区域已有的工作台、管道、罐体、楼梯及自然物：真实设施/生态语义与地图一致，前后景和原导航位置不被美术替换改变。

## PX6：技能、命中、物理特效与掉落光柱

- [ ] 覆盖近战、投射物、持续区域、护盾、治疗和元素命中特效：像素边缘清楚，颜色能辨认元素，不出现泛用光球代替所有技能。
- [ ] 对照原模式检查总时长、命中/peak、释放挂点和消散：长条、圆环、落点与地面范围不因换图被压扁、撑大或移到错误原点。
- [ ] 查看已有物理杖术和土系表现：陨坑、裂纹、尘土、碎石各有实际形态；不能把球状法术或垂直落石轨迹当成地面裂纹/陨坑。
- [ ] 首次释放、连续释放、不同技能交替和转身释放时，检查复用的特效图像：不串上一招的帧或颜色，不在冷加载后永久留原画。
- [ ] 开启「减少镜头与动画效果」后核对：原有减少震屏、残影与碎屑的行为仍生效，命中反馈、范围和伤害逻辑保持。
- [ ] 查看四种品质的40×192原生硬像素掉落光柱：生长、淡出、位置和覆盖范围保持，不能残留旧柔化渐变、变成大白板或在关闭开关后仍用像素光柱。

## PX7：宠物18家族、54形态与头像

- [ ] 按现有宠物图鉴/可用测试存档逐家族核对18×3共54形态：各形态保留对应生物特征，不能用随机异种或同一通用轮廓冒充进阶。
- [ ] 查看待机、跟随移动和现有辅助/攻击条件触发时的表现：沿用SP33原时钟，动作和效果挂点不分离、不瞬移、不切成空白帧。
- [ ] 宠物与约96px主角同屏时比例协调；不同体型有区别，不能通过放大小图把幼体和大型形态都变成同样的像素团。
- [ ] 打开宠物详情、编队和相关列表，检查54个独立头像、选中/锁定/空槽状态：头像与世界形象一致，控件不被大图集尺寸撑开。
- [ ] 召回/更换宠物、跨图并反复开关画风：跟随者、头像与动作全部同步恢复，没有旧宠物残留或第一次加载后不换图。

## PX8：HUD、图标、静态SVG和战斗界面

- [ ] 遍历背包、技能、养成、外观、任务、设置、航图、宠物与建设页：32/16等原生档位清楚，图标不撑大控件，长文字、滚动、选中与焦点占位稳定。
- [ ] 核对实际图标语义：设置是齿轮、搜索是放大镜、指南针有方向、行囊是背包；HEX机制/六类别、属性、节点和地区徽记不再大批复用通用菱形。
- [ ] 查看100px旅行罗盘、120px胜/负/待确认旗、128px评价章印和64px地区钥匙：细节在目标尺寸清楚，不能是32px小图硬撑大；锁态与字母也要可读。
- [ ] 查看任务状态、空/加载/错误/成功状态图、分页和退出图标；关闭开关后原SVG恢复。进度环、pip、页码、开关和滑杆仍显示真实数值/状态，不能被静态图冻结。
- [ ] 检查钱包硬像素金币整条40帧循环，可用慢动作录屏观察：不能只播放首帧/少数采样帧、出现空白格、跳位或变成巨币；循环与原时长一致，余额不因动画改变。
- [ ] 连斩数字、乘号、中文档位和首领/破盾横幅完整显示，安全文字区不被底图遮挡，图集没有裁错帧或越界；原生中文字体保持清楚。

## PX9：全流程、缓存与真实回归

- [ ] 从新打开的游戏页进入港口，再跑野外/副本、战斗、拾取和常用窗口：记录仍在用占位、错语义或缺失资源的具体对象，不能以盘点覆盖率代替美术判断。
