# C5 宠物内容与表现规格

18 个家族沿用 SP33 原生生物 runtime ID，不换模型。技能名、性格短句与战斗定位已进入 pets.json；9 流派说明明确当前实际元素，未把流派名写成不存在的弹射、穿透、控制机制。

## 成长与跟随

- 幼年 1–9 级、成年 10–19 级、觉醒 20–30 级；等级不超过角色等级。上阵结算经验 100%，助阵 50%，按现有规则。
- 仅上阵宠物出现在副本。静止播 idle/idle2，追随播 move；attack 只由真实宠物伤害触发，knock 仅用于相应表现事件。
- 转向、进门、回港、断线恢复均保留同一阵容；不显示助阵实体，不重复生成上阵宠物。
- 跟随无独立碰撞阻挡，不挡玩家与交互目标；旧动作未加载时保持上一有效帧，不制造空白闪烁。
- 三个稀有度全部玩法获取；关口、探索满额、狩猎+关口的来源沿 M17，不做付费标签。

## 现有机制边界

当前规则的家族差异是稀有度系数与被动，流派差异是元素；同稀有度不同家族没有不同动作机制。新增技能名称和性格不能冒充新的战斗效果。若要求每个家族独有机制，须补规则实现及一次数值验证，本批未加入虚构效果。

## 给 Claude 的前端清单

- 宠物详情消费 skillName、flavor、combatRole、flowDescriptions；activeLine/passiveLine 继续来自服务端实际参数。
- 宠物视图契约已追加可选 skillName/flavor/combatRole/flowDescription 字段，服务端返回真实内容；前端接入由 Claude 完成。
- 两种物理流派和两种冰霜流派不得显示弹射/穿透承诺。
