# 追逐寻宝：会跑路的宝箱 · 2026-10-26

用户选择「追逐寻宝：追宝箱怪、拦截携宝小怪」。本轮改造已存在的寻宝宝箱怪，直接接入正式星门寻宝节点，没有新增玩法目录、货币或养成系统。

## 玩家路径

从星门进入任一已解锁寻宝节点，首个入口为风栖航区 Lv8「风车迷宫」。开到宝箱怪时，它先苏醒1秒，再沿两段短路线逃跑；转弯喘息1.5秒，玩家提前站到下一拦截点可使它停2.5秒。世界引导和雷达优先标记拦截点，停顿时指向怪物本身。

追逐最多18秒；走完路线或被堵住后，它停止逃跑、转为普通战斗。自动战斗可以继续追打，手动抄近路、冲刺或控制技能可以缩短追逐。没有无敌锁血或强制等待，伤害足够高时仍能直接击败。

击败后通过原 `hub-chest:<id>` 账本发放原箱奖励，追逐过程中原箱交互隐藏且服务端拒绝提前领取。五箱完成、总时限和原结算流程不变。

## 首遇与持久化

- 新寻宝实例查询该角色作为队长的历史运行记录：尚无 `hub.mimic.chase` 时冻结 `mimicIntro=true`。原随机已选中宝箱怪就沿用，否则指定第一个箱子，确保新旧角色都能首次体验。
- 实际唤醒后才记体验标记；之后新局保留原35%随机出现率。未开箱就退出不会消耗首次体验。
- 参数集中在 `packages/content/treasure-chase.json`，创建实例时冻结为 `mimicRules`。旧存档没有这份规则时维持旧宝箱怪行为。
- 路线、阶段、开始／截止tick、停顿和拦截次数随World checkpoint保存；恢复不重新抽路或补满生命。
- 真正移动只有World的怪物追逐分支一个所有者，复用已有碰撞和控制规则。路线只选一次，每段开始时求一次路径，普通追击AI不会再挪动同一只正在逃跑的怪物。
- 未来地图没有合法路线时明确降级为原地战斗并记录体验，不传送、不重复保证。
