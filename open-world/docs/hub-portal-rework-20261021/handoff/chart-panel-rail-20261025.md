# 航图面板改版：右侧信息栏（Claude → GPT，2026-10-25）

用户截图反馈：航图（`apps/web/src/hub/chart-panel.ts` / `.css`）浮动卡片挡路线、信息碎、字太小。本文是改版方案、默认裁决和验收标准。**只改表现和布局，不改接口数据、出发流程、残页/档位/海域难度的逻辑。**

## 一、现状问题（截图实测）

1. 浮动卡片 `.hub-card` 固定 288×376：未解锁节点只有两行字，也撑出一大块空白；卡片落在第 4 列，正好压住通往关口的虚线，玩家看不见后面的路线。
2. 当天可首通的节点每个都挂一个「首通 ×2」角标，这是全航区共有的状态，逐个挂只增加噪音。
3. 航区页签塞了徽记、名字、探索圆环、百分比、两颗星和 Lv 范围，7 个页签挤成一排，缩放后看不清。
4. 节点圆盘 64px，里面的类型图标只有 24px，认不出类型；关口节点（`kind: 'gate'`）和普通节点长得一样，看不出它是航区终点。
5. 底部关口任务行 `.hub-gate-quests` 没有任务时仍然占高度，形成一条空栏。
6. 未解锁节点只写 `lockReason`，不告诉玩家前置节点是哪一个，也没法跳过去。
7. 标签和卡片正文用 caption 字号，按 1280×720 舞台等比缩小后低于可读线。

## 二、目标布局（1280×720 舞台，面板不滚动）

```
┌ 航图 ─────────────────────────────────────── [海域难度 · X] [×] ┐
│ (风栖◔)(雾钟◔)(赤炉🔒)…  ← 页签：徽记+名字+小圆环                 │
├──────────────────────────────────────┬──────────────────────────┤
│                                      │ 信息栏 300px              │
│   节点图（宽约 880，高约 540）        │  未选节点 → 航区概况       │
│   5 列 × 3 行，关口固定最右列         │  选中节点 → 节点详情       │
│                                      │  底部固定主按钮「出发」    │
└──────────────────────────────────────┴──────────────────────────┘
```

### R1 右侧固定信息栏（替代浮动卡片）

- 面板主体改成两列：左侧 `.hub-graph`，右侧新增 `.hub-chart-rail`（宽 300px，与面板同高，内部内容区可滚，按钮区固定在底部）。
- 图区常量改为 `GRAPH_W≈880`、`GRAPH_H≈540`（以实际可用空间为准，常量仍集中定义并被 TS/CSS 共用）；`GRID_COLS/ROWS` 不变。
- **删除** `cardPlacement`、`CARD_W/CARD_H/CARD_GAP/CARD_EDGE` 以及卡片 `left/top/width/height` 内联样式和 `data-side`；节点卡内容搬进信息栏，函数可改名 `nodeRailHtml`（`nodeCardHtml` 保留为别名或同步改测试）。
- 信息栏两种状态：
  - **未选节点 → 航区概况**：航区名与 Lv 范围；探索度明细（复用 `exploreDetail` 的内容，分节点/秘藏/锁门三行，里程碑奖励一行）；「今日首通 ×2 剩 N 处」（N = 本航区 `firstClearBonusAvailable` 且非 hidden/locked 的节点数，N=0 时不显示）；关口任务（原底部 `gateQuestHtml` 内容搬到这里）。无主按钮。
  - **选中节点 → 节点详情**：原卡片全部行（介绍、推荐等级/时长、掉落、首通、最好成绩、元素、秘藏、锁门、残页、档位、错误提示）。底部固定「出发」主按钮。右上角关闭按钮改为「返回航区概况」（action 仍是 `hub-node-deselect`）。
- 底部 `.hub-gate-quests` 行删除，高度还给图区。
- 信息栏不再是弹层，去掉 `role="dialog"`，改为 `role="region"` + `aria-live="polite"`，`aria-label` 写节点名或航区名；焦点管理沿用 `hub-controller.ts` 现有 `pendingFocus`。

### R2 航区页签精简

- 每个页签只显示：徽记 + 名字 + 小探索圆环（22px）。
- 百分比、星星、Lv 范围从页签移除，改放进圆环/页签的 `title` 提示，详细信息在信息栏航区概况里看。
- 未解锁航区：整颗变灰（已有 `-locked` 徽记），名字后加锁图标；`title` 显示 `lockReason`。

### R3 节点

- 类型图标从 24px 放大到 40px（`cnSprite(..., 40)`），圆盘保持 64px。
- 「首通 ×2」文字角标改成圆盘右上角一颗金色小圆点（约 10px，`aria-label` 仍写「今日首通双倍」），说明文字放在信息栏。
- 关口节点：圆盘 80px，换一套底框样式（加粗双描边或专用色，先用 CSS 实现，需要正式底框图就登记 art-backlog）；名字下加一行小字「关口」。关口节点在模板里本来就在最右列，不动坐标。
- 推荐节点：静态外发光改为 2.4s 一次的缓慢呼吸光环；`prefers-reduced-motion` 和 `[data-motion-reduced=true]` 下保持静态。
- 选中节点：保留现有高亮环；连线不变。

### R4 未解锁节点的下一步

- 信息栏写明前置节点：从该节点 `links` 里找第一个 `open` 或 `cleared` 的相邻节点；找不到就只显示 `lockReason`。
- 给一个 secondary 按钮「定位前置节点」，`data-action="hub-node-select"` + 前置节点 id，复用现有选中流程（不新增 action）。
- 未解锁节点不显示「出发」按钮，信息栏底部按钮区为空。

### R5 字号

- 按 1280×720 舞台：节点名、信息栏正文最小 14px，信息栏标题用 h3。节点名超长仍省略号，`title` 给全名。
- 不靠缩字号塞内容，塞不下就让信息栏内容区滚动。

## 三、默认裁决（直接采用，不回来问）

- 新颜色/尺寸/时长先进 `packages/ui-tokens/tokens.json` 再生成，CSS 不写十六进制字面量；按钮、页签复用 `ui/controls.css` 和 `buttonHtml`/`tabsHtml`，**每屏只一个 primary**（出发）。
- 海域难度弹层位置、内容、逻辑不动；只保证它不被信息栏遮挡（z-index 高于信息栏）。
- 选中隐藏节点、busy 状态只读、背包满时出发按钮文案等现有行为全部保留。
- `hub-controller.ts` 只做必要改动（例如焦点目标从卡片改为信息栏）；不改接口、不改 contracts。
- 锁定航区（`region.status==='locked'`）：左侧仍显示空状态块，信息栏显示航区概况中能显示的部分（名称、解锁条件）。
- 规则没覆盖的边角：选更简单、对玩家更直观的处理，记进进度文件（问题｜处理｜依据）。需要改信息结构/接口的，记「待 Claude」并跳过该处。
