# M02 CONTENT-G01 功能细则

依据：../modules/M02-stargate-chart.md，10-22 引导降级与10-23 M17新决定优先于旧段落。

## 规则

六区统一十节点格位模板；连线只表达关系，区内不要求沿连线通关。深潮每日刷新。

## 边界

前一区关口解锁本区；本区任意三个非关口节点首通解锁关口。深潮不生成固定节点图。

## 数据与界面字段

ChartRegionView.nodes、links、pos、status、lockReason；日节点 id 带服务端日期。

## 验收标准

每区十节点连通；越级请求拒绝；05:00 前后日 ID 改变，旧实例继续用入场快照。

## 给 Claude 的前端清单

按上述真实字段展示状态；本文件为接线和验收要求，未声称界面已实现。未知或未定价的内容保持明确不可领取，不能用占位奖励冒充已发。

## 原待定项逐项覆盖

- 节点图是否每个航区画不同形状（更像地图），还是统一模板（更易生产）。默认：统一模板，节点图标随航区换色。
- 深潮的随机节点每天刷新还是每 48 小时刷新（参考剑与远征奇境探险 48 小时）。默认：每天。
