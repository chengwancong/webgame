# M07 CONTENT-G01 功能细则

依据：../modules/M07-gear-loot-hex.md，10-22 引导降级与10-23 M17新决定优先于旧段落。

## 规则

18巢穴偏向部位见下表；节点与残页各将对应部位权重乘3，同部位只乘一次。

## 边界

以部位集合去重后乘权重；不同部位都获得3倍，不能连乘成9倍。HEX仍每件最多一条、六部位生效、只随掉落。

## 数据与界面字段

节点publicDropNote、服务端掉落偏向表、残页slot值。

## 验收标准

18节点都覆盖两部位；无重复部位；同向/异向残页权重断言，品质与总件数保持原预算。

## 给 Claude 的前端清单

按上述真实字段展示状态；本文件为接线和验收要求，未声称界面已实现。未知或未定价的内容保持明确不可领取，不能用占位奖励冒充已发。

## 原待定项逐项覆盖

- 巢穴每个场地定哪 2 个偏向部位。默认：按场地主题（例：船坞遗址 → 武器、衣服），写功能细则时列全 18 个巢穴的表。
- 已用残页「定向部位」的同时进狩猎（自带部位偏向），两者指向不同部位时怎么算。默认：各自 ×3，不相乘；同一部位时只算一次。
