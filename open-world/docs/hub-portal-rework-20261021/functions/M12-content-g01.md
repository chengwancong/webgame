# M12 CONTENT-G01 功能细则

依据：../modules/M12-endgame-deep-tide.md，10-22 引导降级与10-23 M17新决定优先于旧段落。

## 规则

通过深渊N层开放海域难度N+1，最高100，已开低档可随时切回；每十层大奖一次。

## 边界

大奖构成沿传说精华/金月/残页；50和100层加外观。缺M14价值折算，暂不能写数量或开放领取。

## 数据与界面字段

highestFloor、已领milestones、daily nodes、weekly rotation、冻结风险词条。

## 验收标准

12首领相邻不重复；每日六节点四类型齐；重复大奖请求不重复领；未定价大奖不得发放。

## 给 Claude 的前端清单

按上述真实字段展示状态；本文件为接线和验收要求，未声称界面已实现。未知或未定价的内容保持明确不可领取，不能用占位奖励冒充已发。

## 原待定项逐项覆盖

- 深渊层与海域难度直接绑定（通过 N 层才能选 N+1），会不会卡住只想刷不想推层的玩家。默认：绑定（火炬、不朽都是这样），已解锁的低档随时能切回去刷。
- 每 10 层大奖的具体内容。默认：传说精华 + 金月 + 残页包，第 50、100 层加外观；数量在 M14 定。
