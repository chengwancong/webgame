# M08 CONTENT-G01 功能细则

依据：../modules/M08-crafting-idle.md，10-22 引导降级与10-23 M17新决定优先于旧段落。

## 规则

派遣只去六航区，不去深潮；三船总每小时采集不超在线25%，一天挂机加快速收益不超在线一小时。

## 边界

探索100%的1.5倍也纳入上限；12小时封顶；每日一次快速收益，2小时仅给一船。

## 数据与界面字段

dockRates、materialsPerHour、goldPerHour、accruedHours、quickAvailable。

## 验收标准

3船×12小时+2小时并含探索加成验证；只出T1矿物植物和金币，无装备/T2/T3/钥匙。

## 原待定项逐项覆盖

- 派遣产出上限取在线的 25% 是否合适（剑与远征的挂机收益约占日常资源的主体，但本作以在线刷为主）。默认 25%，M14 推导时校验「一天只领挂机 + 快速收益」不超过在线 1 小时的产出。
- 派遣船队能否派到深潮。默认：不能，深潮只产 T3，派遣不出 T3。
