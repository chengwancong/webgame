# M05 CONTENT-G01 功能细则

依据：../modules/M05-combat-controls.md，10-22 引导降级与10-23 M17新决定优先于旧段落。

## 规则

全自动选卡等待8秒；手动/半自动不代选；半自动不在目标完成后自动拾取。

## 边界

倒计时以服务器截止时刻为准；恢复不重置8秒；半自动由玩家移动，真实战斗不停。

## 数据与界面字段

controlMode、选择截止时刻、candidate IDs。

## 验收标准

三模式切换及断线恢复；自动只提交一次，手动不被自动选卡覆盖。

## 给 Claude 的前端清单

按上述真实字段展示状态；本文件为接线和验收要求，未声称界面已实现。未知或未定价的内容保持明确不可领取，不能用占位奖励冒充已发。

## 原待定项逐项覆盖

- 全自动自动选卡的等待时长。默认 8 秒；半自动和手动不自动选，等玩家选（实时模式下出卡不暂停战斗，沿用现状）。
- 半自动是否也做「目标完成后自动拾取」。默认：不做，保留半自动「我来走位」的意义。
