# M03 CONTENT-G01 功能细则

依据：../modules/M03-dungeon-types.md，10-22 引导降级与10-23 M17新决定优先于旧段落。

## 规则

每区三剧情、三巢穴及四特色节点；怪潮四波；狩猎本期单人。

## 边界

狩猎按种子冻结三机制：风栖落石、雾铃涨潮、其余引雷桩为招牌 50%，另两种各25%。

## 数据与界面字段

hub.kind、objective、stages、hunt.mechanic、波次、信标耐久。

## 验收标准

重连机制不重抽；四波后仅一次终局；信标归零失败；不得创建四人狩猎。
