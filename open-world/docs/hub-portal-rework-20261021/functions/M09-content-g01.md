# M09 CONTENT-G01 功能细则

依据：../modules/M09-port-building.md，10-22 引导降级与10-23 M17新决定优先于旧段落。

## 规则

船台第2阶保留重抽+1；生命星晶仍挂六区狩猎/寻宝首通，完全自选。

## 边界

重抽增益进入局内期望测量，不另调TTK目标。星晶卡片区分未获得/已获得。

## 数据与界面字段

collectible.kind/owned、船台tier、rerolls。

## 验收标准

12来源一一对应；重复首通不增加；不领星晶仍可通关关口。

## 给 Claude 的前端清单

按上述真实字段展示状态；本文件为接线和验收要求，未声称界面已实现。未知或未定价的内容保持明确不可领取，不能用占位奖励冒充已发。

## 原待定项逐项覆盖

- 船台第 2 阶的「重抽 +1」是否太早影响平衡。默认：放第 2 阶（约 3–4 小时），M14 推 TTK 时把它算进期望增益。
- 生命星晶挂在寻宝 / 狩猎首通，玩家可能跳过这两类节点。默认：照挂，节点卡片标「◇」提示即可，不强制（无严格主线，option A）。
