# 03 游戏内容大纲：单岛主城 + 星门副本

> 2026-10-21 方案稿。结构依据 01 参考对照的 R1–R10，内容依据 02 盘点。本文是全部模块的上位大纲：模块文档只展开本文已列出的内容；要新增内容，先改本文。

## 1. 一句话

**拾星港是唯一的岛。港口中央的星门打开就是航图：选航区、选节点、选难度，传送进 3–8 分钟的副本；打完带着战利品回港整理、变强，再进星门。**

不再有「在大地图上走路找点」。远航稿 v1 的方向保留，并收得更紧：航行本身不再是一层玩法，航图就是星门的界面。

## 2. 主循环

```
拾星港（整理装备 / 工坊 / 港口建设 / 接委托 / 领挂机收益）
   │  走几步到中央
   ▼
星门 → 航图：航区 → 节点 → 难度刻度 → （终局）插残页
   │  传送
   ▼
副本（3–8 分钟）：房间 / 段落之间三选一增益 → 首领或目标 → 结算
   │  传送门出
   ▼
回港：结算页 → 新解锁提示（每次回港最多开一项新功能）
```

**单场节奏**：进门 → 2–4 段战斗，段间三选一 → 目标 → 结算。局内增益只在本场有效（R6）；装备、海克斯、材料、经验、技能找回进度永久保留。

**单日节奏**（参考暗黑不朽、剑与远征的日常结构）：
1. 回港先领挂机收益和委托。
2. 每个节点当天首次通关有加成。
3. 周常首领每周有固定次数。
4. 剩下的时间自由刷：推进主线航区，或者在刻度里刷装备和海克斯。

**不做硬体力**（R7）：奖励加成有每日上限，但入场不限次数。这样不会出现“体力扣光就不能玩”。

## 3. 世界结构

### 3.1 主城：拾星港
- 一屏左右的紧凑港口。星门居中；工坊（铜铃）、船台 / 航图（米洛）、港务厅（澄）、邮局 / 委托（青芒）、仓库、宠物、外观围成一圈，每处走 3 秒内能到。
- 主城不放怪、不放战斗，进主城自动切安全 HUD（沿用现有安全地图规则）。
- 港口随进度「建设」：每开放一项功能，港口里多一处建筑或灯火（参考 Hades 冥王殿随进度变化）。

### 3.2 航图：6 个航区 + 终局
航区就是原来的六座岛，每个航区一个主题、一章剧情、一段等级，玩家时间沿用 progression-goal-plan 的实测估算：

| 航区 | 等级 | 章节 | 关口首领 | 关口时点 |
|---|---|---|---|---|
| 风栖 | 1–8 | ss-c01 航图之外的乘客 | 登港先锋 | 约 1:00 |
| 雾铃 | 8–15 | ss-c02 寄往敌境的信 | 军需官 | 约 3:20 |
| 赤炉 | 15–21 | ss-c03 炉心争夺战 | 采能机 | 约 6:10 |
| 霜镜 | 21–27 | ss-c04 冰封的应答者 | ss-c04 首领 | 约 9:45 |
| 沉星 | 27–32 | ss-c05 敌人的故乡 | ss-c05 首领 | 约 13:20 |
| 龙眠 | 32–37 | ss-c06 群岛再次启航 | ss-c06 首领 | 约 17:20 |
| 终局「深潮」 | 37–45 | 主线收尾后开放 | 周常首领 | 17h 起 |

### 3.3 航区内部：节点图（参考 Warframe 星图 + 关口，R3）
每个航区约 10 个节点，连线解锁，打通一个节点就点亮相邻节点：

| 节点类型 | 每航区数量 | 来源 / 复用 | 说明 |
|---|---|---|---|
| 剧情 | 3–4 | 章节任务 + 旧剧情副本 | 推进章节，首通给关键奖励（招牌技找回、功能开放） |
| 巢穴 | 3 | field-x-1..3（每个 3 段） | 走到底打首领，从传送门出来；主要装备来源 |
| 狩猎 | 1 | 稀有精英 | 单首领短战，掉指定部位 |
| 怪潮 | 1 | world-night 怪潮 | 守点打波次，材料和经验多 |
| 寻宝 | 1 | 宝箱 + 小机关 | 短，产图样、配方、残页 |
| 关口首领 | 1 | ss-map-boss-n | 前置：本航区剧情节点完成 + 一组教学目标（参考 Warframe 关口任务）；通关开下一航区 |

六航区共约 60 个节点。其中巢穴 18 个，直接复用现有 54 个小场地。

### 3.4 难度刻度（参考火炬刻度、不朽挑战秘境，R4）
难度有两层，都复用现有内容，不新增第三套：
- **海域难度**（全局刻度，复用 world-tiers）：航行 → 风暴（第三航区首领后）→ 潮涌（裂星潮后）→ 深渊 N 层（深渊之后无限往上）。以前在港口或前哨切换，改为在星门航图上切换。解锁时点不动，因为它是强度系统。
- **节点挑战档**：节点通关后，可以选「高难挑战」（复用 high-* 副本规则，赤炉 · 3 回港开放）；龙眠之后开放「噩梦」（复用 nightmare 首领）。
- 终局「深潮」就是深渊 N 层往上推。T8 装备只出在高层。

### 3.5 残页改图（参考火炬罗盘与信标，R5）
- 进门前可以在航图上插航图残页：起初 1 张，后来最多 3 张。每张改一项，比如怪物数量、精英比例、掉落率、海克斯概率、指定套装、首领词条。高收益的残页同时带风险词条。
- 首批残页在风栖 · 2 回港开放，用来定向刷；终局扩到 3 槽，并加入风险词条（沿用远航稿 §3.3 的残页清单）。
- 残页从副本掉落，形成「刷图→得残页→刷更好的图」的自给循环。

## 4. 30 小时内容时间线

| 时段 | 玩家在做什么 | 新开放（每次回港最多一项） |
|---|---|---|
| 0–0.5h | 坠星觉醒开场 → 武器三选一 → 落在拾星港 → 星门教学 → 风栖第 1 个剧情节点 | 星门、副本内三选一增益 |
| 0.5–1h | 风栖剧情 + 巢穴 → 关口首领 | 工坊强化、风栖巢穴、残页首批、首领重战 |
| 1–3.5h | 雾铃：首个海克斯（HEX-Q01 保底）、怪潮、狩猎 | 怪潮、采集与制作 / 挂机路线、狩猎 |
| 3.5–6.5h | 赤炉：套装开始掉、寻宝 | 寻宝、委托板、武器盘、高难挑战、海域难度「风暴」 |
| 6.5–10h | 霜镜：传说首件 | 残页第二批（指定套装）、副属性重铸、召唤石 |
| 10–17.5h | 沉星、龙眠：构筑分化 | 威能法典、团队副本、残页第三批、周常首领 |
| 17.5–30h | 深潮终局：裂星潮、潮涌 → 深渊 N 层、T8 装备 | 裂星潮、噩梦、深渊层数、残页 3 槽 |

开放顺序照搬远航稿 §7 回港开放表，只是把「航线」换成「星门里的节点」。强度类系统（武器盘、召唤石、威能法典、海域难度）的开放时点不动。

## 6. 默认裁决（待你复核）

| # | 裁决 | 理由 |
|---|---|---|
| A1 | 远航的“航行节点”玩法不做，航图直接就是星门界面 | 少一层，进战斗更快（R2、R8） |
| A2 | 不做硬体力，只做每日加成上限 | 本作没有付费体力设计；避免“扣光不能玩”（R7） |
| A3 | 野外大地图冻结，不删代码 | 先验证新结构成立再清理（沿用 J10） |
| A4 | 主线按航区顺序推进，航区内节点可以自选顺序 | 兼顾“有方向”和“无严格主线”的旧决定（option A） |
| A5 | 先做风栖 + 雾铃两个航区的完整样板，你试玩 20–30 分钟后再铺其余航区 | 返工量大，先证手感 |

## 7. 与旧决定的关系
- **推翻**：远航稿「航行节点为主循环」、J6/J10「野外保留到巢穴入口的可走区域」、大岛野外 M2–M4。
- **保留**：坠星开场、武器三选一、无严格主线（航区内自由）、巢穴「走到底→首领→传送门出」、海克斯 D13、TTK 推导口径、制作全开放与挂机路线、宠物美术方向、所有 UI 规范。
