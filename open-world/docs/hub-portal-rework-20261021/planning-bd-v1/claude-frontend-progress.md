## 已接与未接

已在界面落地（数据来自 fixture）：
- **状态**：遇敌转入 → 载入（含失败重试、版本不一致、无遭遇）→ 等待 → 移动/技能预览 → 确认 → 正在结算 → 敌方行动 → 托管 / 请求接管 / 「当前动作结束后接管」 → 断线横幅与自动恢复 → 正在确认战斗结果 → 胜利 / 失败 / 撤退 → 返回探索。
- **两项额度**：「移动：可用/已用」和「技能：可用/已用」分开显示。
  - 已用时虚线框、删除线、空心◇，不只靠颜色区分。
  - 写明「移动与技能各一次，先后自选」「普攻也占用」。
- **移动**：
  - 可达格来自投影 `legalMoves`（服务端给出的完整路径）。
  - 悬停时显示虚线路径；点击后请求预览，显示实线路径、箭头和逐格步数；再点同一格或按「确认行动」才执行。
  - 不可达的格子显示 ✕ 和服务端给的原因：无法通行 / 已被占用 / 斜向两侧须可通行，不能穿过夹角 / 目标超出范围。
- **技能**：
  - 射程用虚线框，影响范围用斜纹，目标用准星。
  - 预览分「已知 / 行动时确定」两类。
  - 未迁移的旧技能（火球术、屏障）用虚线槽，标「尚未迁移」，不能选。
- **宠物**：风绒·幼年，不占格，贴在主角格左下。卡片显示以下内容：
  - 辅助条件、状态、本回合剩余次数。
  - 由真实事件驱动的反馈：`pet-assist` 时绿环脉冲、显示「护盾 +10」；`pet-skipped` 时写明原因。
  - 「宠物不占棋格，满足条件时自动辅助。」
- **倒计时**：
  - 只在手动且等待主角行动、进入最后 10 秒时显示「将在{s}秒后托管」，带进度条。
  - 归零后显示「等待服务端确认托管…」，不在本地切换。
  - 截止时刻和服务端时钟偏移都来自投影；断线、刷新、预览都不重置。
- **托管**：
  - 开启后持续本场。横幅区分「等待超时，已转为托管」和「已开启托管」。
  - 托管与手动走同一条指令路径。
  - 接管在安全边界生效，不补行动，冷却照旧。
- **断线**：
  - 指令失败后保留同一 commandId，恢复连接后自动重发，服务端幂等。
  - 遇到控制冲突时提示「这个角色正在另一处操作。」。
  - 版本过期时提示「同步完成后再继续操作。」并重新同步。
- **键盘**：
  - 方向键移动格子光标，Enter 选择/确认，Esc 取消。
  - M 移动，1–4 技能，E 结束行动（还有额度时先弹确认），A 托管/接管。
  - 重新渲染后焦点按 `data-focus` 恢复。
- **减少动态**：系统设置或工具条都能开启。开启后移动直接落位，飘字不动画，受击改为描边。

## 契约缺口（需要后端 / 规则方给出）

1. **遭遇接口**：`engage / load / preview / submit / control / subscribe / returnToExplore` 都还没有服务端版本。字段草案在 `contract.ts`。
2. **棋盘模板**：尺寸、每格的 `walkable / blocksSight / hazard`、`dressing` 与美术的映射、出生点。
3. **正式移动步数**：`budget.moveSteps`，以及以后是否存在地形移动成本。
4. **技能的回合制定义**：每个技能的 basic/skill 分类、射程、范围形状、是否要视线、冷却（按回合算）、费用。旧的 0 槽普攻不能自动映射。
5. **伤害预览口径**：`known` 和 `uncertain` 怎么划分，暴击、闪避、抗性是否公开。
6. **敌方**：AI、意图公开格式（ART-TAC-14）、行动顺序或先攻规则。
7. **宠物辅助**：触发条件、效果、触发窗口和上限，以及 `pet-assist` / `pet-skipped` 事件的正式 schema。目前借用 `support.ts` 原型做次数上限。
8. **托管策略的服务端实现**：现在是 fixture 写死的策略。
9. **推送通道**：需要 WS 或 SSE，并支持按 `seq` 补发断线期间的事件。现在重连只拿到投影，错过的动画会跳过。
10. **每个投影都必须带 `control.serverNowMs`**：前端靠它换算倒计时。
11. **结算回执**：奖励列表（`rewards`）、节点是否完成、返回去哪里（星门副本节点还是拾星港），以及失败的去向。
12. **撤退**：是否允许撤退，以及撤退的后果。
13. **多端操作**：如何判定冲突，以及谁拥有控制权。
14. **版本协商**：规则版本或协议版本不一致时如何处理，返回哪里。
15. **大型单位**：`footprint > 1` 的格子投影。
16. **棋盘目标物与节点任务状态**（ART-TAC-15）。

## 实现裁决（自主判断，留档）

- **棋盘视角**：正俯视方格，DOM 按钮格加 SVG 覆盖层。没有用 Phaser，也没有用等距视角，键盘、读屏和焦点都能直接用。
- **舞台**：1280×720 等比缩放并留边。左栏 232px，右栏 248px，顶栏 52px，指令栏 88px。9×7 样例棋盘的格子约 70px。
- **确认方式**：点格子发起预览，再点同一格或点「确认行动」才执行。预览不消耗额度，也不续期等待。
- **托管期间**：托管时也显示敌我动作；横幅常驻「托管中」，带「请求接管」按钮。在结算期间请求接管时，显示「当前动作结束后接管」。
- **结束行动**：还有额度时先弹确认框「还有可用行动，可继续操作或结束。」
- **样式**：只用现有 Token（允许 color-mix），没有新增 Token。

   - 然后移动，再用「横扫」：预览显示虚线射程、十字斜纹、准星、已知伤害和「部分结果将在行动时确定。」
   - 确认后有飘字，记录写「受到 12 点伤害」。
5. 两项额度用完后自动进入敌方行动：横幅显示「敌方行动 · 暮界刀兵 甲正在行动」，敌人绕过岩石走近并攻击。
   - 第一次受击后，宠物卡显示「刚刚：风护，护盾 +10」，主角身上有绿环。
   - 同一回合第二次受击时，显示「未触发：本回合已辅助过…」。
   - 敌方阶段不显示倒计时。
6. 打开 `?scenario=timeout`（等待 15 秒），什么都不点：
   - 剩 10 秒时出现「将在10秒后托管」并开始倒数。
   - 中途点几次「移动」和格子预览：倒计时不重置（对照诊断行的截止时刻）。
   - 归零后显示「等待服务端确认托管…」，随即通知「等待超时，已转为托管」，托管开始自动出手。
7. 托管中点「请求接管」：
   - 如果正在结算，显示「当前动作结束后接管」，动作完成后通知「已接管，轮到你操作」。
   - 已用的额度不恢复，横扫冷却照旧。
   - 再点「开启托管」（或按 A），横幅显示「托管中 · 已开启托管」。
8. 在倒计时进行中点工具条「断开连接」：
   - 横幅显示「连接中断，正在恢复战场。」，指令按钮禁用，倒计时继续走。
   - 点「恢复连接」，约 1.5 秒内显示「连接已恢复，战场已同步。」，诊断行的截止时刻不变。
9. 点工具条「模拟刷新页面」：恢复同一场战斗（记录写「已恢复进行中的战场」），截止时刻不变。
10. 点「丢失下一条回执」，然后做一次移动：
    - 先显示断线，恢复后自动重发同一指令。
    - 主角只走一次，记录不重复。
11. 点「下一次指令冲突」，然后提交行动：提示「这个角色正在另一处操作。」，可以重新确认。
12. 用 `?scenario=load-error` 打开：显示「暂时没能载入战场」，点「重试」后进入。
    - `?scenario=version`：显示「战场版本不一致」，没有重试按钮。
    - `?scenario=empty`：显示「没有可进入的遭遇」。
13. 打到胜利（可以开托管加速）：
    - 先显示「正在确认战斗结果…」，再出现「战斗胜利」，奖励行写「隔离预览不发放奖励…」。
    - 点「返回探索」，按钮显示「正在返回…」，然后进入「已返回探索」。
    - 点「再来一场（fixture）」可以重开。
14. 用 `?scenario=defeat` 打开并结束行动若干次：显示「战斗结束」，按钮为「返回拾星港」。
15. 撤退：点「撤退」弹确认框，取消后焦点回到撤退按钮；确认后显示「已撤退」。
16. 键盘：
    - 方向键移动格子光标（有蓝框），Enter 预览，再按 Enter 确认，Esc 取消。
    - 数字 1、2 选技能，E 结束行动（还有额度时先弹确认）。
    - Tab 能到达所有按钮。
17. 工具条「减少动态」（或打开 `?motion=reduced`）：移动直接落位，飘字静止，受击改为红色描边。
18. 浏览器窗口缩小或放大：舞台保持 16:9 等比缩放并留边，文字不溢出。在 1280×720 下逐区截图，检查奶白浅金风格、是否有文字截断、按钮重叠、格子错位。
