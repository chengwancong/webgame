# 26 · 养成功能树：细分到本体、操作和阶段

2026-10-25。用户要求将 25 号功能清单细化，例如技能解锁/等级、武器本体/强化/突破，并明确这些只是举例，不代表功能已经存在或已被确认。

本文件是目标方案的细化建议，不是现版本功能盘点，也不授权修改生产配置。23/24 号已经确认的成长主线、三属性映射、攻速行动条、单次行动额度继续生效。

同日用户进一步收敛：人物固定成长贡献不足终局属性的1%，不自由加点；装备词条由物品等级和品质共同决定，强化上限取决于品质；不加入装备突破、精铸材料回收、全身共鸣；加入装备本体制作；天赋与巅峰合并，本轮按此前已确认的满级长线保留巅峰。下表已覆盖此前冲突建议，其余未明确决定项仍为建议或候选。

标记：**建议**＝拟纳入；**并入**＝作为已有系统内部功能；**候选**＝尚未确定是否设置；**支撑**＝必要管理操作，不算额外战力线；**不另设**＝当前不建议做成独立养成。

## 1. 人物本体

| 子功能 | 玩家行为 / 改变 | 状态 |
|---|---|---|
| 主等级提升 | 获取战斗和推进经验，提升主等级与基础成长 | 已确认方向 |
| 三主属性基础成长 | 随角色成长固定获得力量、敏捷、体质；人物自身固定成长的终局实际贡献不足1%，装备/巅峰来源另算 | 已确认固定成长，无自由分配 |
| 自由属性加点 | 不提供手动分配三主属性的功能 | 不加入 |
| 属性洗点 | 没有自由加点，因此不提供对应属性洗点 | 不加入 |
| 属性汇总与来源查看 | 看清等级、装备、巅峰等来源各提供什么 | 支撑 |

| 技能装配 / 卸下 | 在现有技能槽中选择携带动作，已学成长保留 | 支撑 |

## 3. 武器与其他装备

武器、防具、饰品共用加工体系；以下以武器为例，防具与饰品对应自己的部位和属性。

| 子功能 | 玩家行为 / 改变 | 状态 |
|---|---|---|
| 武器本体 | 通过掉落或制作获得类型、基底与固有特性，决定可使用技能及攻击特征 | 获取路径已确认包含制作 |
| 物品等级 | 决定基础属性与普通词条的数值区间/预算 | 与品质共同约束词条；不是额外武器经验等级 |
| 装备品质 | 参与决定普通词条数量、档次、可用范围，并决定强化上限 | 关联关系已确认；各品质具体配置后续定 |
| 普通词条生成 | 按本体物品等级与品质共同生成属性组合 | 已确认双约束，具体词条池/数值后续配置 |
| 装备本体制作 | 选择已学配方/图样与本体目标，消耗材料生成实际可穿戴装备；武器、防具、饰品共用这条生产路径 | 用户明确加入 |
| 武器强化 | 沿用槽位投入保值；穿戴武器的品质决定当前有效强化及继续强化上限 | 品质上限已确认；保值的衔接解释见下文 |
| 强化上限 | 由装备品质决定，各品质允许的最高强化等级后续定 | 不再以独立装备突破开放 |
| 全身共鸣 | 不提供跨部位强化达标奖励或独立共鸣等级 | 用户明确不加入 |
| 普通词条重铸 | 修改允许调整的普通副属性，修补好胚子短板 | 建议，不影响 HEX |
| 单件精铸等级 | 投入高难材料培养当前这件装备，深化其优势 | 建议，绑定具体装备 |
| 精铸阶段奖励 | 到达阶段节点获得重点强化；定向/随机方式另定 | 并入精铸 |
| 装备突破 | 不提供突破按钮、突破材料或独立突破步骤，也不改名塞回精铸阶段 | 用户明确不加入 |
| 精铸材料回收 | 不返还已投入精铸的材料；更换/分解也不变相返还 | 用户明确不加入 |
| 精铸重置 | 是否允许调整精铸结果仍未确认；即使后续允许，也不能返还已投入材料 | 候选，不是已定功能 |
| 装备锁定、比较、穿戴、仓储、普通分解 | 管理装备并获得常规分解产出；不按精铸投入追加返还 | 支撑 |
| 武器额外经验等级、升星、普通装备直升最高品阶 | 会与掉落阶层、部位强化、精铸重复，削弱高难掉落价值 | 不另设 |

**等级与品质的分工建议**：用户确定的是“两者共同约束词条、品质决定强化上限”。落实时建议物品等级主要约束基础数值和词条数值区间，品质主要约束词条数量/档次/可用范围以及强化上限。该具体分工是设计解释，参数后续统一配置，不凭品质名称手填数量或百分比。

**强化保值衔接**：沿用此前槽位投入保值的方案，记录的强化进度可以保留，当前装备只生效到自身品质允许的上限。换低品质装备不删除既有投入，换回高品质装备恢复其允许的有效等级；升级操作也受当前品质上限约束。此为本轮对新上限要求与原保值方向的执行解释，不增加第二条强化进度。

**制作边界**：装备制作生成本体，不只是对掉落装备做强化；制作的物品等级/品质由配方、材料和已开放难度约束，普通词条采用相同的等级×品质规则。制作不提供指定 HEX，也不改变 HEX 仅随装备掉落的既定来源。更高潜力本体继续需要对应阶段的获取条件，没有装备突破或低阶本体直升最高品阶。

| 子功能 | 玩家行为 / 改变 | 状态 |
|---|---|---|
| 威能发现 / 获得 | 从装备掉落发现新的核心机制 | 建议 |

| 收录品质改善 | 再获得更优同类威能时改善可用版本 | 建议，具体强度继承规则待定 |

## 6. 唯一的巅峰系统

| 子功能 | 玩家行为 / 改变 | 状态 |
|---|---|---|
| 独立天赋树、天赋点与天赋重置 | 不再与巅峰并列；有价值的关键选择并入巅峰节点 | 合并，取消独立入口 |
| 满级长线开启 | 主等级满级后进入唯一巅峰系统，原星图如复用仅作承载 | 已确认保留一个系统，沿用巅峰方向 |
| 巅峰经验与等级 | 满级后继续积累经验并推进长线 | 建议实现方式 |
| 巅峰点投入 / 路线推进 | 沿路径取得属性和专精收益 | 建议 |
| 巅峰关键节点 | 深化已选打法，节点价值单独设计 | 建议 |
| 巅峰路线调整 / 重置 | 调整长线投入方向 | 建议，费用规则另定 |
| 第二个成长盘、独立天赋树、独立巅峰突破条 | 不增加重复成长系统 | 不另设 |

人物三属性没有自由加点；巅峰保留自身的路线/节点选择，两者不是同一操作。装备、巅峰提供的敏捷/攻速均须计算真实行动频率影响，不受人物自身固定成长不足1%的占比限制。

## 10. 管理功能归属

升级报价、效果预览、装备比较、锁定/分解/仓储、重置确认、保存出战方案、托管编排都要规划，但它们属于对应系统的支撑操作，不再各算一个养成层。

本文未明确确认的细化项继续供用户审阅。自由属性加点/洗点、装备突破、精铸材料回收、全身共鸣已经剔除，独立天赋合并入巅峰，不再作为后续候选。物品等级/品质与词条、品质与强化上限、装备本体制作已确定关系；具体数值、材料数量与存档迁移尚未实施。
