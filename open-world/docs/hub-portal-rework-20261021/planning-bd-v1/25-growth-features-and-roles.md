# 25 · 养成功能完整清单与定位

2026-10-25。按用户要求罗列功能与定位。23 号成长主线、24 号三主属性与行动条为已确认前提；本表是据此整理的保留/整合建议，尚不表示用户已逐项确认，也不表示线上已完成迁移。本次不改数值、配置或存档。

按用户追加要求，具体本体、操作与阶段功能见 [26 · 养成功能树细分](26-growth-subfeatures.md)。2026-10-25 最新收敛：固定自然成长贡献不足终局属性的 1%；不加自由属性分配、装备突破、精铸材料回收和全身共鸣；词条绑定物品等级与品质，强化上限绑定品质，加入装备本体制作；天赋与巅峰只留一套，本轮沿用已确认的满级长线并保留巅峰。

## 一、直接参与战斗成长的 13 项功能

| 功能 | 主要投入与收益 | 独特定位与边界 |
|---|---|---|
| 主等级 | 战斗/推进经验 → 等级与基础成长、技能/功能开放 | 前期教学和成长，约 6–8 小时达到 50 级，不承担后 20 小时的拖延 |
| 三主属性成长 | 固定自然成长及装备/巅峰来源 → 力量、敏捷、体质 | 映射按24号；不手动加点。角色自身固定成长的终局实际贡献不足1%，装备/巅峰来源正常计算 |
| 技能学习与升级 | 技能找回/学习、成长资源 → 新动作与基础效果提升 | 决定角色能使用哪些动作；技能觉醒并入这里 |
| 巅峰 | 满级经验与长线收益 → 属性、路线与关键节点 | 唯一的满级成长树，合并原天赋中的关键选择；没出目标装备也能进步 |
| 装备获取与阶层 | 对应难度掉落 → 装备本体、物品等级与品质 | 普通词条由物品等级和品质共同确定；更高难度带来更高成长潜力，不以第 N 套装备作为必经进度 |
| 装备本体制作 | 配方/图样、材料 → 实际可穿戴装备 | 提供定向本体获取；词条沿用同等级、同品质规则，不绕过高阶材料/难度，不提供指定 HEX |
| 部位强化 | 金币、强化材料 → 装备槽位提升 | 沿用换装保值，但当前可生效与可继续强化的上限由穿戴装备品质决定；不加全身共鸣 |
| 普通词条重铸 | 金币、材料 → 修正装备的局部短板 | 让好胚子更适合当前打法，保留选词条的取舍；不改 HEX |
| 单件精铸 | 高难材料 → 高阶装备的深度培养 | 培养具体好装备，保留精铸本身；不设精铸材料回收或投入返还 |
| 威能与法典 | 传奇掉落、萃取/使用 → 稳定可复用的核心技能机制 | 打法骨架；发现、记录、萃取、刻印归同一系统，不拆多个养成层 |
| 套装 | 多个装备部位的组合 → 协同效果 | 用槽位换组合收益，与散件形成选择；收齐所有套装不是必要进度 |
| HEX | 稀有装备掉落 → 绑定单件的特殊触发与机制 | 刷宝惊喜和上层优化；只随装备掉落，不转移、洗练或指定兑换，不设成必备通关门票 |
| 宠物成长 | 首通/探索获得、培养 → 等级/进阶、技能流派、助战或光环 | 补保护、输出或循环短板，内部整合为一条宠物成长路径；保持条件辅助、无独立行动条 |

## 二、支持养成的 4 项外围功能

| 功能 | 投入与产出 | 定位 |
|---|---|---|
| 采集、材料加工与配方 | 采集/配方 → 制作材料、生产能力与消耗品 | 为装备本体制作提供支撑；不另计第二条装备制造成长线，不绕过高阶材料准入 |
| 港口建设与工坊设施 | 冒险收益、建设资源 → 服务、配方、便利、产出路径 | 世界与服务成长；声望/阵营/捐献并入这里，成长奖励归相应系统，不另叠永久战力层 |
| 码头派遣 | 已开放路线与现实时间 → 有限补给资源 | 支持回归和轻量积累，不取代在线刷取和难度突破 |
| 探索收藏与外观 | 探索、图鉴、成就 → 完成感、外观与资源奖励 | 可选长期目标；探索成长奖励进入既有系统，不再叠独立乘区或要求收齐全部图鉴 |

这些是 17 个细分功能，不对应 17 个新菜单或独立材料条。建议归入人物、技能、装备、工坊、宠物、港口等少量模块。

## 三、最重要的职责区分

- 部位强化保值到角色槽位，穿戴品质限制当前生效上限；精铸绑定具体好装备且不返还投入材料。两者职责分开。
- 技能负责可用动作与基础效果；巅峰同时承接满级积累与关键选择；威能负责核心机制；套装负责多槽位协同；HEX负责单件稀有机制。
- 只保留巅峰，不再建立独立天赋树、天赋点或天赋重置入口；原星图可以作为其表现载体。
- 三主属性已确定固定自然成长，不提供手动属性加点/洗点。不到1%的占比只限定角色自身固定成长，装备和巅峰的属性来源分别核算。
- 装备普通分解仍是材料来源，但其常规产出不能暗中附加返还精铸投入，以免变相恢复已删除的材料回收。
- 敏捷会影响攻速与行动频率；装备、巅峰等来源须统一计算真实行动频率影响。

## 四、旧功能的整合去向

| 原独立功能 | 建议处理 |
|---|---|
| 技能觉醒 | 并入技能学习与升级 |
| 独立天赋树、天赋点与天赋重置 | 关键选择并入唯一巅峰系统 |
| 铭纹、拓印 | 并入威能与法典 |
| 武器盘、武器等级与突破 | 并入巅峰／星图，避免另一条重复乘区 |
| 角色突破、重复数值觉醒层 | 并入主等级或巅峰／星图，不再重复卡主等级上限 |
| 召唤石光环 | 并入宠物 |
| 召唤石数值、旧巅峰／雕文 | 整合进同一个满级长线 |
| 生命星晶、星核的独立乘区 | 改为探索奖励，进入既有成长线 |
| 声望、阵营、捐献 | 并入港口建设 |
| 旧精工与新精铸重叠的部分 | 统一为单件高阶装备培养入口，规则迁移另定 |
| 自由属性加点/洗点、装备突破、精铸材料回收、全身共鸣 | 用户已明确不加入，不再列为候选 |
| 局内随机强化选择 | 已撤销，不恢复 |

整合方案不等于删除旧存档；迁移与投入处理在具体实施时单独设计。

## 五、相关但不另立养成条的内容

- 世界难度、深渊、首领重战：检验成长、解锁装备成长权限与提供掉落来源。
- 主线、日常委托、探索节点：内容目标与资源来源。
- 出战方案、托管编排、仓库、筛选、指南：操作便利和决策工具，不另设置战力等级。
- 多套配装与换流派：可选玩法；一种武器、一套核心打法可以完成完整内容周期。

本表的后续重点是逐项确定来源、上限、材料与养成深度，不再增加与上述定位重复的新系统。玩家资源用语统一为蓝量、蓝量上限、蓝量回复、蓝量消耗。
