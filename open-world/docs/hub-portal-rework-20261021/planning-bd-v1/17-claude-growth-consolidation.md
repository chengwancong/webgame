## 2. 回收原则

1. **每个保留层必须回答一个不同的玩家问题**。问题重复的合并。
2. **战力层要么在棋盘上看得见，要么是长期保值的投入**。两者都不是的冻结。
3. **不删存档值**。回收的方式是冻结入口，把已有投入折算进保留层。开发期可以清档（记忆："Dev period: wipe OK"，先备份），但本方案默认折算，以便以后有真实玩家时同样适用。
4. **一个材料对应一个用途**。回收后材料种类同步收缩。
5. **乘区只留三个**：基础（等级 + 装备 + 强化）、BD 乘区（威能/套装/HEX）、长线乘区（一条）。现有 `[+]/[×]` 标注沿用。

## 3. 回收结果：5 个玩家问题

| 玩家问题 | 保留层 | 合并进来的 | 说明 |
|---|---|---|---|
| **我怎么打？**（打法） | 技能 + **威能** | 技能觉醒 → 并入技能等级；**铭纹 → 并入威能** | 铭纹和威能都是"改变技能怎么打"，玩家分不清。铭纹的"当……时"连接效果改成威能的次级词条，或者转成同效果的威能 |
| **我穿什么？**（装备） | 装备底子 + 词缀 + 套装 + HEX | 部位随机主属性 → **改为部位固定主属性** | 去掉御魂/圣遗物那一层随机。HEX 按 15 号改为绑定部位、条件触发 |
| **我的投入保值吗？**（成长） | 部位强化 + 共鸣 | — | 杖剑式，已经修好了换装不保值的问题 |
| **谁帮我？**（伙伴） | 宠物 | 召唤石的光环 → 并入宠物 | 召唤石和宠物都是"伙伴"，各自一套碎片太重 |
| **我还能长多少？**（长线） | **一条"星图"长线** | 武器盘、角色突破、巅峰、雕文、生命星晶、星核、召唤石的数值部分 | 一个界面、一种材料、一个乘区，满级后才有明显存在感 |

**天赋**单独处理：保留，但从"四树 × 5 阶的数值树"收缩成**少量战棋关键节点**。例如：
- 移动 +1；
- 普攻回灵力；
- 击杀后可再移动 2 格（每回合一次）；
- 护盾覆盖到下次行动。

这类行动经济节点正是战棋里最有价值的东西（15 号 §4.3），交给天赋做"打法倾向"的选择最合适。纯数值节点并入星图。

**外围不算战力层**：专业制作、港口建设、码头派遣保留为经济与便利，界面上不与战力层并列。声望/阵营/捐献并入港口建设（"港口的人认可你"）。

**局内**：~~潮印保留~~ **已撤销**（2026-10-24 用户不要肉鸽元素，见 20 号）。局内不再有随机强化。

回收后，玩家面对的是：

```
打法：技能 + 威能（+ 天赋关键节点）
装备：底子/词缀 + 套装 + HEX
成长：部位强化
伙伴：宠物
长线：星图
（外围：港口 / 制作 / 派遣；局内潮印已撤销）
```

## 4. 逐层处理表

| 原层 | 处理 | 玩家已有投入怎么办 | 内容/界面影响 |
|---|---|---|---|
| 技能觉醒 | 合并 → 技能等级 | 觉醒等级折算为技能等级上限 +N | 技能页去掉觉醒按钮 |
| 铭纹 + 拓印 | 合并 → 威能 | 已有铭纹按机制原子映射到同类威能次级词条；无对应的给萃取材料 | 8 种铭纹槽位表映射到威能部位 |
| 部位随机主属性 | 改为固定 | 已有装备保留原主属性（冻结实例），新掉落按部位固定 | 掉落生成器改一处 |
| 召唤石 | 光环 → 宠物；数值 → 星图 | 召唤等级折算星图点；碎片按比例换星图材料 | 召唤页关闭，宠物页加光环槽 |
| 武器盘 | 合并 → 星图 | 武器等级/突破折算星图点 | 武器盘页关闭 |
| 角色突破 | 合并 → 星图 | 已突破上限保留；后续上限由星图节点提供 | — |
| 巅峰 + 雕文 | 合并 → 星图 | 巅峰点折算星图点 | 50 级后开放的内容并入星图后段 |
| 生命星晶 / 星核 | 改为探索奖励的星图点 | 已拾取的折算星图点 | 探索收集物不再单列乘区 |
| 声望 / 捐献 | 合并 → 港口建设 | 声望阶段折算港口建设进度 | 阵营页并入港口 |
| 天赋四树 | 收缩为关键节点 | 返还全部天赋点，免费重置一次 | 天赋页重做为 1 页约 12 个节点、选 4–6 个 |

**星图**是新的整合层，不是新增系统：
- 一个界面、一种材料（星尘），来源是溢出经验、探索、重复掉落分解；
- 节点只给数值和便利，**不给行动经济**（行动经济只来自天赋、鞋子/武器的行动词缀、少数威能），以免长线数值垄断战棋取舍；
- 满级前进度缓慢，满级后成为主要的"没掉东西也在进步"来源，与深渊层数并列。

## 6. 风险与代价

- **工作量**：合并需要迁移脚本和折算规则；界面关闭 5–6 个页面。开发期没有真实玩家，用清档更省事，但折算规则仍要写，以备后续发布。
- **已做内容的沉没成本**：铭纹、召唤石、武器盘已经有美术和数值。可以复用：铭纹图标转为威能次级词条图标，召唤石美术转为星图节点插图。
- **数值重推**：基础与长线乘区变化后，TTK/斩杀线必须用主干工具重推一次、验证一次（`pnpm spine:check`），不做探索式扫参。
- **与已定决策的关系**：
  - 记忆中 2026-10-07 定过"天赋四树"，本文把它收缩成关键节点，这属于对已定结构的修改。
  - HEX 部位绑定沿用 15 号 R-2。
  - 两项都按默认推进；用户不同意时，天赋的退路是保留四树外形，但每树只留 3 个战棋关键节点，其余并入星图。
