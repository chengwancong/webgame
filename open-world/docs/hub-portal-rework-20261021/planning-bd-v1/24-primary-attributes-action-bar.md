# 24 · 已确认：三项一级属性与攻速行动条

2026-10-25。用户在确认 23 号终局成长方案后追加的设计决定。本文件记录策划约束，不代表已修改线上属性、战斗执行器或数值系数。

## 用户明确确定的关系

| 一级属性 | 影响的战斗属性 | 玩家理解 |
|---|---|---|
| 力量 | 攻击、格挡 | 打得更有力，并提高格挡能力 |
| 敏捷 | 攻速、闪避 | 行动条推进更快，并提高闪避能力 |
| 体质 | 生命上限、蓝量上限 | 能承受更多伤害，并储备更多技能资源 |

- 一级属性只增加力量、敏捷、体质这三项；不擅自再加智力、精神等一级属性。
- 同日用户追加确定：三主属性采用固定自然成长，不需要玩家自行加点，也不设对应属性洗点。角色自身固定成长对终局参考人物的最终属性贡献不足 1%，主要成长由装备与唯一的巅峰系统承接。
- “不足 1%”约束的是角色自身固定成长的来源贡献，不是把装备/巅峰上的力量、敏捷、体质全部限制到 1%；后续须看其派生后的实际收益，不能只比较裸字段数字或把不同单位的属性相加。具体基准与转换系数后续设计，不在本轮做演算或配置修改。
- 攻速影响行动条行进速度。行动条到达终点，单位获得一次行动；攻速因此影响真实行动频率。
- 玩家文案统一使用「蓝量」「蓝量上限」「蓝量回复」「蓝量消耗」「蓝量不足」，不再使用此前的另一资源称谓。

## 与战棋现有规则的衔接

1. 独立行动的主角和敌方单位使用行动条；推进速度由各自攻速决定。
2. 每次获得行动权，仍是一次移动＋一次技能，先后自选；普通攻击占技能/主行动额度，未用额度不结转。
3. 保留宠物的不占格、条件自动辅助定位，没有独立行动条，也不因此消耗主角的主行动。
4. 攻速和移动力是不同属性：攻速决定多久轮到自己，移动力决定这次最多移动多少格。敏捷不自动提供额外移动次数或额外单次技能次数。
5. 护甲、暴击、暴击伤害、穿透、抗性、蓝量回复等继续是独立战斗属性；本次未指定它们由三项一级属性派生，不能顺手追加映射。

## 行动条的执行口径

以下是落实已确认方向时采用的默认解释，数值系数不在本次锁定：

- 行动条采用战斗内逻辑推进，不依赖玩家现实中的思考速度。
- 当前单位选择操作、预览或播放动作时，其他行动条暂停；这与手动等待后切托管的墙钟是两套时钟。
- 行动结束后，消耗该次行动条并继续推进下一位；同一时点就绪的单位按稳定顺序处理，服务端拥有唯一结算权。
- 速度提升可以令单位更频繁获得完整行动，但不改变一次行动中的移动＋技能额度。
- 原冷却、状态持续、蓝量回复的结算时点需随行动条执行器统一迁移，不直接把旧秒数当作回合数。

- 同时覆盖 09 号「每轮最多一个正常回合、速度只影响先后」的旧候选。新攻速影响真实行动频率，快单位可以比慢单位更频繁获得行动权。

- 人物自身成长方式已确定为固定成长，不再保留自由加点候选；每点属性转换量、攻速范围、格挡/闪避边界及装备/巅峰来源后续统一进行数值设计，本次不手填系数或改存档。
