# M02 星门与航图

> 上位：03 大纲 §3.2–3.5。参考：R2（入口集中）、R3（Warframe 星图节点与关口）、R4（火炬刻度）、R5（火炬罗盘 / 信标）。

## 1. 目标
- 想打什么，3 次点击内就能进去：航区 → 节点 → 出发。
- 航图本身就是进度表：哪里打过、哪里能打、哪里锁着、为什么锁着，一眼看清。
- 定向刷（要某个部位、某套装、海克斯）有明确去处，不靠盲刷。

## 2. 玩家体验
1. 在星门前按 E，航图全屏展开，镜头先落在「上次去的航区」。
2. 左侧是 6 个航区加深潮的竖排页签，右侧是本航区的节点图：节点之间连线，打过的实心，能打的发光，锁着的灰色并带锁的原因。
3. 点一个节点，右下弹出卡片：类型、推荐等级、预计时长、首通奖励、本日首通加成是否还在、掉落重点（部位 / 套装 / 海克斯打法）。
4. 卡片上选海域难度和挑战档；开放残页后，再插残页。
5. 点「出发」→ 星门转场动画（约 1 秒）→ 进入副本。

## 3. 包含内容

### 3.1 航区

| 航区 | 等级 | 节点数 | 关口首领 | 解锁条件 |
|---|---|---|---|---|
| 风栖 | 1–8 | 10 | 登港先锋（ss-map-boss-1） | 开场完成 |
| 雾铃 | 8–15 | 10 | 军需官（ss-map-boss-2） | 风栖关口 |
| 赤炉 | 15–21 | 10 | 采能机（ss-map-boss-3） | 雾铃关口 |
| 霜镜 | 21–27 | 10 | ss-map-boss-4 | 赤炉关口 |
| 沉星 | 27–32 | 10 | ss-map-boss-5 | 霜镜关口 |
| 龙眠 | 32–37 | 10 | ss-map-boss-6 | 沉星关口 |

### 3.2 每航区的节点图模板（10 个）

```
        [剧情1]──[巢穴1]──[狩猎]
           │         │
[入口]──[剧情2]──[巢穴2]──[怪潮]──[关口首领]
           │         │        ╱
        [剧情3]──[巢穴3]──[寻宝]
```
- 「入口」不是节点，表示从上一航区连过来。
- 剧情 1 打完点亮剧情 2、剧情 3 和巢穴 1；之后每打完一个节点，点亮与它相连的节点。航区内的顺序由玩家自选（A4）。
- 关口首领的前置是本航区全部剧情节点 + 关口任务（一组 2–3 个教学目标，例如“穿上一件带海克斯的装备”“在工坊强化一次”），参考 Warframe 关口任务。
- 怪潮、狩猎、寻宝这几类节点**按开放表逐步出现**（远航稿 §7），开放前是灰色问号。

### 3.3 节点卡片字段

| 字段 | 内容 |
|---|---|
| 类型与名称 | 例：巢穴 · 风车地窖 |
| 推荐等级 | 来自副本定义的怪物等级 |
| 预计时长 | 3–8 分钟（模板值） |
| 首通奖励 | 一次性，例：招牌技找回、功能开放、钥匙 |
| 本日首通加成 | 有 / 已用（M11） |
| 掉落重点 | 部位、套装、海克斯打法偏向（读服务端公开掉落说明，不展示概率） |
| 难度 | 海域难度选择 + 挑战档（高难 / 噩梦） |
| 残页槽 | 开放后显示 1–3 个槽 |
| 最好成绩 | 最快通关时间、最高层数（深潮） |

### 3.4 海域难度与挑战档
- 海域难度复用 world-tiers：航行、风暴、潮涌、深渊 N 层。切换入口从“港口或前哨”改成**航图右上角**，切换后对所有节点生效。
- 挑战档是针对单个节点的：高难挑战复用 high-* 规则（入场快照、时限），噩梦复用 nightmare 首领。
- 解锁条件全部沿用现有规则，不提前。

### 3.5 残页
- 槽位：风栖 · 2 开放 1 槽，霜镜开放 2 槽，深潮开放 3 槽。
- 残页从副本掉落（寻宝节点和首领掉得多），进门时消耗；副本失败也消耗（参考火炬信标），已经结算的收益保留。
- 首批 6 种：定向部位、定向套装、海克斯打法偏向、精英加倍、掉落率 +、首领加词条（奖励加倍）。数值和清单在 M12 定。

### 3.6 深潮（终局航区）
- 没有固定节点图，每天刷新 6 个随机节点（各类型混合），外加 1 个周常首领节点。
- 深渊层数往上推：每层通关解锁下一层，界面显示“当前最高层”。

## 4. 规则要点
- 节点解锁、首通、加成、残页消耗、难度全部由服务端判定；客户端只渲染服务端给的航图视图（沿用“客户端只消费服务端权威状态”）。
- 出发时服务端冻结本次副本的规则版本、难度、残页效果，副本中途切换难度不影响本场。
- 已打通的节点可以无限重打；关口首领打过之后，变成“首领重战”节点（远航稿 §7 风栖 · 3）。

## 5. 接口
- 依赖 M03：节点 → 副本定义的映射（类型、场地、时长）。
- 依赖 M07 / M12：掉落说明、残页效果。
- 依赖 M10：剧情节点 = 章节任务步骤，关口任务的目标。
- 依赖 M11：本日首通加成状态。
- 给 M15：航图界面、节点卡片、转场。

## 7. 待定
- 节点图是否每个航区画不同形状（更像地图），还是统一模板（更易生产）。默认：统一模板，节点图标随航区换色。
- 深潮的随机节点每天刷新还是每 48 小时刷新（参考剑与远征奇境探险 48 小时）。默认：每天。
