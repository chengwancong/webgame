# M03 副本类型与模板

> 上位：03 大纲 §2 单场节奏、§3.3 节点类型、§3.4 难度。参考：R6（局内成长不带出局）、R8（短时段完整收益）；魔渊之刃（一段一段往下打，首领后传送）、DNF（房间制副本、见底仍可打完）、不朽（远古秘境 / 挑战秘境 / 周常首领分开）、剑与远征（王座之塔每 10 层大奖）。
> 数据依据：`packages/content/dungeons.json`（53 个定义、8 个模式）、`field-dungeon-stages`（54 个场地）、`docs/nest-dungeon-design.md`、`docs/voyage-chart-design.md` §5–8。

## 1. 目标
- 所有副本用**同一个外壳**：进门 → 若干段 → 目标 → 结算 → 传送门回港。玩家只学一次。
- 每类副本有一个清楚的用途（推剧情、刷装备、刷材料、定向、推层），玩家看类型就知道该去哪。
- 尽量复用现有 53 个副本定义和 54 个场地，新做的只有波次、场地机制、计时目标这几个模板。

## 2. 玩家体验
1. 星门转场后落在副本入口，顶部一行写本场目标（例：「清空两座大厅，击败洞穴首领」）。
2. 每打完一段，出现一次三选一增益（M04），选完通道打开，走进下一段。
3. 打完目标，结算页弹出：本场收获、首通、本日首通加成、最快时间。
4. 原地出现传送门，捡完东西走进去，回到拾星港星门广场。全自动模式会自动拾取并走进传送门（沿用巢穴规则）。

### 3.2 类型说明

**剧情**
- 一段战斗 + 一个剧情事件（对话、护送、调查点），最后一段是小首领或章节首领。
- 剧情目标用任务系统 v2 的事实型目标（fact），节点通关 = 写入对应章节事实（M10）。
- 剧情节点首通后可以重打，重打只给普通副本收益，没有首通奖励。

**巢穴**
- 三段：第一、二段是涌出大厅，第三段是首领厅（地城深处首领，墙首领预算 240 秒）。
- 涌出规则全部沿用巢穴设计 §5：存活上限 20 / 24 / 28 / 30，每厅总量 50 / 60 / 70 / 80，精英在 70% 进度插入，不在原地重刷。
- 巢穴回响（群攻范围 +60%、伤害 +20%）只在第 1、2 阶段给。
- 首领死后出现出口传送门（半径 1.2），没有倒计时。
- **阶段钥匙材料只从巢穴节点掉**，其他类型都不掉（远航稿 §8）。
- 海域难度到潮涌后，巢穴改用定义里已有的 `hardmode`（例：`field-wind-3` 的 hardmode 是第 19 阶段、40 级）。

**狩猎**
- 一个小场地：先清少量护卫（可省略），再打稀有精英。精英有一个场地机制，首批 3 种：涨潮淹没（地面分区轮流进水，站水里减速）、落石（预警圈后砸下）、引雷桩（打碎桩子才能破精英护盾）。
- 掉落偏向卡片上写明的部位（读服务端公开掉落说明）。

**怪潮**
- 守住场地中央的信标。默认 4 波：波次之间 8 秒空档；每波数量递增，最后一波带精英。
- 刷怪复用星潮夜的选点和冲锋（spawnDistance、count、eliteCount），新增「波次序列 + 信标耐久」两项。
- 信标耐久归零 = 失败；玩家全灭也算失败。

**寻宝**
- 一张小图上散着 4–6 个宝箱，路线自己选；部分宝箱有守卫，开箱要站在旁边读条 2 秒。
- 计时结束时立刻结算，按已开宝箱数给奖励；全部打开有额外一箱。
- 战斗量最少，是「中场休息」的类型。

**关口首领**
- 首通开下一航区。通关后变成「首领重战」节点，可以无限重打（远航稿 §7 风栖 · 3）。

**深渊层（试炼塔）**
- 就是深潮的深渊 N 层往上推（M12），不另做第二条爬塔线。每层一只首领，从首领池抽：6 个关口首领 + 6 个 `trial-*` 首领，按层数加强度。
- 每 10 层一次大奖（参考剑与远征王座之塔）；层数只往上记最高，不掉层。

**周常首领与团本**
- 周常首领沉星起开放：六个关口首领（按当前海域难度）每周轮换一只；深潮开放后再叠加噩梦词缀池（`docs/nightmare-expansion-20261021.md`，8 种抽 2），每周换一组。
- 噩梦不是周常：它是关口首领的挑战档，沿用 P27——4 个入口（原 `nightmare` + 冰原 / 深渊 / 龙骨三王）、1–100 层、每日 5 次共享。
- 团本原样复用，每周次数沿用 `challenge.raidWeekly`。次数和奖励在 M11 定。

### 3.3 统一模板

```
入场（loading ≤ 120 秒）
  └─ 段 1 → [三选一] → 段 2 → [三选一] → … → 目标段
        └─ 目标完成 → 结算页 → 出口传送门 → 拾星港星门广场
```

| 模板字段 | 默认 | 说明 |
|---|---|---|
| `kind` | — | story / nest / hunt / tide / treasure / gate / abyss / weekly / raid |
| `node` | — | 航图节点 id（M02） |
| `segments` | 按类型 | 场地 id 列表，或波次序列 |
| `objective` | 按类型 | defeat-boss / reach-portal / defend-beacon / open-chests / story-fact |
| `augmentRounds` | 按类型 | 段间三选一次数，规则见 M04 |
| `timeLimitSeconds` | 按类型 | 见 3.1；团本沿用原值 |
| `returnRegion` | `ss-map-port` | 统一回星门广场；原 `town` 和野外地图全部改掉 |
| `firstClear` | 节点表 | 首通奖励（M02 / M10） |
| `rewardRef` | 掉落表 | 航区 × 海域难度 × 类型（M07） |

不变的现有默认：断线保留 1800 秒、`buildLocked`（局内不能换装）、救援（5 秒、2 格、30% 血）、单人为主、`refundSystemAbort`、发奖防重。

### 3.4 难度怎么叠加
- 海域难度（world-tiers）对所有类型生效：改怪物强度和掉落档。
- 节点挑战档只对巢穴、狩猎、关口首领开放：「高难」复用 `high` 模式（入场快照、每日次数），「噩梦」只在关口首领上出现，复用 `nightmare`（P27：1–100 层、每日 5 次）。
- 残页（M12）只能插在巢穴、狩猎、怪潮、寻宝上。剧情和关口首领不接受残页，避免主线卡在改图上。

## 4. 规则要点
- 实例创建、段推进、目标判定、结算、首通都在服务端；客户端只播放和展示。
- 每段单独存进度：断线回来从当前段开头继续，已击杀和已开的宝箱不重刷，也不补满血（巢穴设计 §8）。
- 失败（全灭且无救援、信标破、超时）：已经结算过的段收益保留，本场没有最终奖励，首通不算；寻宝超时不算失败，按已开宝箱结算。
- 不在原地重刷敌人；再打一次必须从星门重新出发。
- 收益口径（远航稿 §8）：任何副本的每分钟收益不高于同阶段割草基准；狩猎、寻宝的优势只在「定向」，怪潮的优势只在「最后一波」。数值在 M14 推导一次、验证一次。
- 满包规则不变：满包时不能开全自动，不自动分解，不自动回港。

## 5. 接口
- 给 M02：每个节点对应的副本定义、预计时长、推荐等级、掉落说明。
- 依赖 M04：段间三选一的次数与规则、失败与撤离、结算页内容。
- 依赖 M07：按类型和难度的掉落表、阶段钥匙材料。
- 依赖 M10：剧情节点的事实目标。
- 依赖 M11：本日首通加成、周常次数。
- 依赖 M12：深渊层首领池与强度曲线、残页效果。
- 依赖 M14：每类副本的 TTK 与每分钟收益目标。
- 给 M15：副本 HUD 的目标行、波次 / 计时 / 信标耐久显示。
