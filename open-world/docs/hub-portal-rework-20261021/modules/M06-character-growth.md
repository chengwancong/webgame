# M06 角色成长

> 上位：03 大纲 §4 时间线、§5。参考：R3（Warframe 关口用教学任务教核心系统）、R6（局外成长永久保留）、Hades（能力免费洗点、鼓励尝试）。
> 依据：`docs/progression-goal-plan.md` §0 岛屿与时间、§4（招牌技找回）、`docs/balance-30h-design.md`（每级用时公式、50 级满级、巅峰等级）、`docs/skill-talent-redesign-20261007.md`（天赋四树）、83 个技能、41 个天赋。

## 1. 目标
- 等级、技能、天赋的规则和数值不动；只把「在哪里拿到」从野外任务改挂到航区节点。
- 「把开场那套找回来」仍是前 3.5 小时的主动力：每一次找回都落在一个看得见的节点上。
- 关口任务顺带教会核心系统（强化、海克斯、天赋），不靠弹窗教学。

## 2. 玩家体验
1. 开场选完武器，技能栏里有灰色带锁的「待找回」招式。
2. 航图上，带找回的节点卡片上有一枚刻片图标，写「找回：漩涡之刃」。
3. 打完那个节点回港，结算页后播找回演出：刻片一闪、灰图标亮起，再弹一张卡说明这招解决什么问题。
4. 关口首领前，航图上列出 2–3 条关口任务，例如「在工坊强化一次」「点一个天赋」，每条完成都有一次性奖励。

## 3. 包含内容

### 3.1 等级（沿用）

| 航区 | 玩家等级 | 关口时点 | 装备阶段（换代等级） |
|---|---|---|---|
| 风栖 | 1–8 | 约 1:00 | T1 |
| 雾铃 | 8–15 | 约 3:20 | T2（L10） |
| 赤炉 | 15–21 | 约 6:10 | T3（L17），套装开始掉，首件传说约 L21 |
| 霜镜 | 21–27 | 约 9:45 | T4（L23） |
| 沉星 | 27–32 | 约 13:20 | T5（L28） |
| 龙眠 | 32–37 | 约 17:20 | T6（L33） |
| 深潮 | 37 → 50，之后巅峰等级 | 17h 起 | T7（L38）、T8（L45，只出在高层） |

- 等级段与关口时点以 progression-goal-plan（ow-74 实测）为准，与 03 大纲 §3.2 一致；balance-30h 的旧章节表（1→10、10→17…）不再作为口径。
- 每级用时 `2.886 × 等级^0.8` 分钟；50 级后巅峰等级（经验 600 + 100 / 级），无限。
- 经验来源从「野外刷怪 + 任务」改为「副本 + 首通 + 委托 + 挂机」，总量不变，分配在 M14 定。

### 3.2 招牌技找回改挂节点

找回事件原来挂在章节任务完成上（`tasks.json skillRecovery`）。章节任务改成剧情节点后（M10），找回跟着搬到对应节点：

| 找回 | 原触发 | 新节点 | 时点 |
|---|---|---|---|
| 剑 / 暗器 找回 1 | `ss-c01-t01` 落点求生 | 风栖 · 剧情 1 | 0:03 |
| 法杖 找回 1 | `ss-c01-t04` 两条进港路 | 风栖 · 剧情 3 | 约 0:45 |
| 三系 找回 2 | `ss-c01-t05` 风栖首领 | 风栖 · 关口首领 | 1:00 |
| 剑 找回 3 | `ss-c02-t03` 找回信使 | 雾铃 · 剧情 2 | 约 1:55 |
| 法杖 / 暗器 找回 3 | `ss-c02-t04` 追踪军需队 | 雾铃 · 剧情 3 | 约 2:40 |
| 三系 找回 4 | `ss-c02-t05` 雾铃首领 | 雾铃 · 关口首领 | 3:20 |

- 找回的招式、顺序、提速阈值全部沿用 progression-goal-plan §4.2 和 §6（含 10-17 的对调）。
- 找回只认节点首通（服务端判定）；重打不重复触发。
- 剧情节点与章节任务的对应见 M10 §3.1（每章 t01–t04 → 3 个剧情节点）。

### 3.3 关口任务（教学）
参考 Warframe 关口：每个航区关口首领前 2–3 条，完成一次性给奖励，教的是本航区新开放的系统。

| 航区 | 关口任务 | 教什么 |
|---|---|---|
| 风栖 | 打完 2 个巢穴；在工坊强化一次 | 刷装备、强化 |
| 雾铃 | 穿上一件带海克斯的装备；点一个天赋；派遣一次挂机路线 | 海克斯、天赋、挂机 |
| 赤炉 | 凑齐一件套装 2 件；打一次寻宝；接一个委托 | 套装、寻宝、委托 |
| 霜镜 | 重铸一次副属性；插一张残页进副本 | 重铸、残页 |
| 沉星 | 激活一个威能；打一次高难挑战 | 威能、挑战档 |
| 龙眠 | 打一次团本或周常首领；把一件装备强化到 +10 | 团本 / 周常、强化深度 |

- 每条关口任务的目标都是已有的事实型目标（fact），不新增任务机制。
- 关口任务所需的系统必须在本航区或更早开放（对齐大纲 §4）。具体文案与奖励在 M10。

### 3.4 天赋（沿用）
- 伤害 / 防御 / 辅助 / 特殊四棵树，全部开放；共用等级点和声望点，上限 60 点。
- 每棵树 5 层，本树投入 0 / 5 / 10 / 15 / 20 点依次开层；第 4 层二选一，第 5 层关键天赋，60 点内最多 2 个关键天赋。
- 改动只有两处：
  1. **洗点在港口免费**（参考 Hades），副本内不能改（`buildLocked`）。
  2. 「声望点」随声望改成港口建设（M09），来源换名，点数总量不变。

### 3.5 技能
- 83 个技能、4 栏技能栏、武器倾向、元素并列全部不变（2026-10-07 决定）。
- 招牌技以外的技能怎么学：保持现状（「本岛可学卡」改名为「本航区可学」，在节点首通或等级到达时出现，规则不变）。

## 4. 规则要点
- 等级、经验、找回、天赋点全部服务端结算；找回演出由客户端比对前后快照得出（沿用 progression-goal-plan §4）。
- 找回事件改挂节点后，测试要覆盖：三系武器各走一遍风栖 + 雾铃，四次找回都在表中时点 ±10% 内触发。
- 不改经验曲线；如果新结构的副本经验让时点偏移超过 10%，在 M14 调经验分配，不调曲线。

- 依赖 M09：声望点改为港口建设后的来源。
- 依赖 M14：副本经验分配，保证找回时点不漂。
