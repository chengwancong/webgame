# M15 UI 与 HUD

> 上位：03 大纲 M15 行（港口 HUD、星门航图界面、副本 HUD、结算页）、§7（所有 UI 规范保留）。参考：R1（主城里只走路和交互）、DNF / 魔渊之刃（城镇 HUD 与副本 HUD 分开）、Warframe 星图（节点卡片 + 出发确认）、Hades（局内选卡三张横排、回到大厅一次一项新东西）。
> 依据：根目录 `项目.md`（字体、字号、色彩、间距、控件统一标准）、`packages/ui-tokens/tokens.json` 与 `ui-components.ts` / `ui/`（不另建皮肤）、AGENTS 中已选方案（4「奶白浅金」、A1 右下菜单、安静技能栏、小地图 B「圆形近域雷达」+ A「实景缩略」、任务条浅金 / 奶白渐隐、护盾条 C、精英铭牌 A、人物换装 B）、`docs/hud-layout.md`、`docs/ux-audit-20261020.md`（UX-A01～A10）、记忆 aspect-lock-after-w3（16:9 等比舞台，留边 C「场景模糊延伸」）、现有界面文件（`battle-result-panel.ts`、`augments-panel.ts`、`sea-difficulty-view.ts`、`bounty-view.ts`、`progression-panel.ts`、`stage-key-view.ts`、`appearance-panel.ts`、`crafting-controller.ts`、`ui/dialogue-bar.ts`、`ui/quest-tracker.ts`）。

## 1. 目标
- 这次改版**不换视觉体系**：所有新页面用现有 Token 和公共控件，按项目.md 排版；不新建一套按钮、卡片、对话框。
- 只写每个界面放什么、从哪个模块拿数据、复用哪个现有组件；需要大改布局的页面，功能细则阶段先出多个方案示意图给用户选（AGENTS：大改布局前先展示示意图），再落地。
- 前端由 Claude 负责（设计 Opus、代码 Sonnet 子代理，记忆 model-split）。

## 2. 玩家体验
1. 港口里屏幕很干净：左上头像、右上金币、左侧任务条、右下 A1 菜单，没有技能栏和小地图。
2. 走到星门按 E，航图全屏打开；点节点出卡片，按「出发」进副本。
3. 副本里出现技能栏、模式按钮、段数小图、方向箭头；出卡时三张卡横排在屏幕中下方。
4. 打完结算页一屏看完：成败、本场构筑、掉落、首通和加成、新开放的一项。

### 3.2.1 关键页面的要点
**U2 / U3 航图与节点卡片**
- 节点卡片字段：类型图标、名称、推荐等级、预计时长、掉落一行（读服务端公开掉落说明）、状态（未解锁 / 可挑战 / 已首通）、角标（金色「首通 ×2」当日未用、「◇」收藏、残页槽）。
- 未解锁节点写一句解锁条件（如「先通关 雾铃 · 巢穴 2」），不显示灰色空卡。
- 海域难度、节点挑战档放在卡片里的下拉，默认收起。出发后进统一 loading 条（≤ 120 秒，M03），显示节点名和一条提示，不能重复点出发。

**U4 副本 HUD 的目标行**
- 顶部居中一句话加进度：`击败首领` / `守住信标 2/4 波` / `开启宝箱 3/5` / `走进传送门`；限时类型的倒计时放在目标行右侧，最后 30 秒变红，只提示一次。
- 怪潮：信标耐久条放在目标行下面；波与波之间显示「下一波 8…」。
- 寻宝：宝箱读条画在宝箱头顶（世界标签），不占 HUD。
- 巢穴：出口传送门出现后，目标行变成「走进传送门」，同时出现方向箭头。

**U5 三选一**
- 每张卡：档位色边、名称、一句效果；服务端判定「贴合你的构筑」的那张加一个小标。键盘 1–3 可选。
- 全自动下 8 秒倒计时，到时由服务端按「贴合构筑标签 → 档位高 → 编号小」选一张（M05 C5）；手动、半自动不倒计时。

**U6 结算页**（沿用现有 flex 列布局，战利品区可滚动让位）
- 成功：标题 → 用时 → 战利品（高档在前）→ 本场构筑 → 首通与加成一行（「今日首通 ×2 已用 x/10」）→ 收藏进度一行 → 新开放一项 → [回港] [再来一次]。
- 失败：标题 + 差距诊断一行（输出 / 生存 / 装备档，取服务端原因）+ 已保留收益 + 一个替代路线按钮，其余折叠（沿用 battle-result-ui 的 REPORT-FE ② 裁决）。
- 「再来一次」只在节点仍可挑战时出现。

**U7 / U13 回港顺序**
- 先结算页，关掉后才弹「今日」面板，再播港口对话和新开放演出；用弹窗栈排队，互不吞输入。离开 3 天以上时，回归汇总接在结算页后面。

### 3.2.2 客户端消费的字段（服务端权威）
- 航图节点：`node.status`、`firstClearBonusAvailable`、`shardSlots`、`collectible`、`recommendedLevel`、`estimatedMinutes`、`publicDropNote`。
- 「今日」面板：`daily.firstClearLeft`、`daily.commissionSlots`、`daily.commissionLeft`、`daily.weeklyBossLeft`、`daily.resetAt`、`idle.pendingCollect`。
- 副本 HUD：`objective.kind / text / progress`、`objective.timeLeft`、`beacon.hp`、`wave.index / total`、`chest.opened / total`、`segment.index / total`。
- 结算：`result.summary`、`result.diagnosis`、`result.firstClear`、`result.dailyBonus`、`result.build`、`result.collectibles`、`result.unlock`。
- 缺字段时**隐藏该元素**，不显示占位，也不用客户端自己算的值。字段名在功能细则阶段和 GPT 对齐后定稿。

### 3.4 舞台
- 16:9 等比缩放，留边用「场景模糊延伸」；任何窗口尺寸都照常显示，不加「请放大窗口」遮挡（用户 2026-10-07 已否决）。
- 新页面只按 1280×720 排版，不写宽度断点。

## 4. 规则要点
- 界面只显示服务端解析后的结果（首通、加成、次数、收益、掉落），不自己算；未知数值不补零（hud-layout）。
- 层级和提示全部走 HUD 仲裁（`docs/hud-arbitration-plan.md`）：弹窗走 `ui/overlay-stack.ts`，提示走 `ui/toast-queue.ts`（最多 3 条），世界标签走避让规则；新页面不自建 toast，不自定 z-index。
- 所有页面 Esc 可关；结算页除外（要点按钮），避免误关丢掉「回港」。
- 颜色、字号、间距、动效全部来自 `tokens.json`；新增 Token 走 `tools/build-ui-tokens.mjs`。
- 选中、悬停、切换不改变布局尺寸（项目.md「状态切换与布局稳定」）；验收要实际连续切换，不靠单张截图。
- 浏览器验收在内置浏览器做几分钟冒烟，不跑无头浏览器；MU 运行时不做自动化（记忆）。
