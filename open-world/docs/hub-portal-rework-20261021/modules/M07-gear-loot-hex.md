# M07 装备、掉落与海克斯

> 上位：03 大纲 §3.3（巢穴是主要装备来源）、§3.4（刻度越高掉落越好）、§3.5（残页定向）。参考：R4（火炬刻度、不朽挑战秘境：推得越高，所有来源品质越好）、R5（火炬罗盘定向）、DNF 手游（自动分解低品质）。
> 依据：`apps/api/src/economy.ts`（`economyArea` / `dropProfileFor` 按经济区取掉落档）、`drop-profiles.json`、`field-loot.json`、`equipment-drop-rules.json`、`hex-loot.json`、`packages/content/world-tiers.json`、`docs/hex-gear-20261019/d13`、`d14`、progression-goal-plan §5.4（换代预告）。

## 1. 目标
- 装备系统本身（324 件模板、54 套、T1–T8、强化、重铸、铭纹、威能、海克斯词缀）**一概不动**。
- 只改「从哪里掉」：野外刷怪和野外宝箱的掉落搬进副本节点，期望总量不变。
- 让玩家知道「这个节点主要出什么」，并能用海域难度和残页把掉落往想要的方向推。

## 2. 玩家体验
1. 航图节点卡片写着掉落重点：「巢穴 · 风车地窖：武器、鞋子；海克斯偏向 贴身绞杀」。
2. 副本里掉落照旧落在地上：品质色标签，带海克斯的标签前面有「◆」，并短暂亮一下光柱（D14）。
3. 结算页里，带海克斯的装备单独一行高亮。
4. 差 2 级就要换代时，追踪条出现「换代预告」，点开就是下一阶的掉落去处（推荐节点）。

## 3. 包含内容

### 3.1 掉落的三层坐标
**航区 × 节点类型 × 海域难度**，三层都复用现有数据：

| 层 | 现有 | 改法 |
|---|---|---|
| 航区 | 副本的 `area`（例：`ss-map-wind`）经 `economyArea` 映射到经济区掉落档（`drop-profiles.json`：词缀上限、各级怪物掉装率与品质权重、首次首领保底） | **不改**：航区就是原来的经济区。主城 `ss-map-port` 不掉落 |
| 节点类型 | 野外按怪物级别（普通 / 精英 / 稀有 / 首领）和事件、宝箱分表（`field-loot.json`） | 每类副本指定用哪几张表，见 3.2 |
| 海域难度 | world-tiers 的 `reward.gear` 倍率：航行 1 / 风暴 1.35 / 潮涌 1.8 / 深渊 2.2，深渊之后每层 ×1.08 | 不改；切换入口改到航图右上角，`switchAt` 从「港口 / 前哨」改为「星门」 |

### 3.2 每类副本的掉落

| 类型（M03） | 用的表 | 掉落重点 | 海克斯来源（D13） |
|---|---|---|---|
| 巢穴 | 普通 / 精英按经济区档；首领 = boss 档；段末宝箱 = field-chest | 主要装备来源；按场地定 2 个偏向部位；阶段钥匙材料 | elite、dungeonChest、dungeonBoss；打法偏向沿用 `hex-loot.json` 的 biases（如 `field-mist-1` → 贴身绞杀） |
| 剧情 | 普通 / 精英按档；小首领 = boss 档 | 少量装备，重点在首通奖励 | elite、dungeonBoss |
| 狩猎 | 稀有精英 = field-rare（3–5 件，稀有 90 / 传说 10） | 卡片上写明的 1 个部位，偏向权重 ×3（沿用 `familyBoost` 的倍数） | rare（原 `ow-*-rare*` 的偏向挂到狩猎节点） |
| 怪潮 | 波次怪按普通档，最后一波精英 = field-elite；结束奖励 = field-event | 材料、经验多，装备一般 | elite、event |
| 寻宝 | 每个宝箱 = field-chest；全开额外一箱 | 图样、配方、残页、潮晶；装备少 | dungeonChest |
| 关口首领 | boss 档 + 首次首领保底（`firstBoss`） | 首通保底稀有；重战按 boss 档 | dungeonBoss |
| 深渊层 / 周常 / 团本 | 沿用 high / nightmare / raid 现有奖励 | T7 / T8（T8 只出在高层，大纲 §3.4） | dungeonBoss |

- 野外原来的「星潮夜事件」「野外宝箱」「稀有精英」掉落，分别对应怪潮、寻宝、狩猎；**每个来源的期望件数和品质分布不变**，只是换了发生的地方。
- 不新增掉落表。如果某一类副本按上表算出的每分钟期望装备量超过同阶段割草基准（远航稿 §8），在 M14 调该类型的件数区间，不调品质权重。

### 3.3 海克斯词缀（沿用 D13 / D14，只改来源坐标）
- 规则不变：只随掉落；魔法及以上、`origin.kind = random` 的装备才会掷；每件最多 1 条；6 部位全部生效；同组只生效最高一条；同打法 ≥3 条共鸣 ×1.1；强度单条 common 5% / magic 7% / rare 10% / legendary 12%。
- 门槛不变：接取 HEX-Q01 之后，**雾铃航区**（原 `ss-map-mist` 经济区）的副本掉落才会掷海克斯。首发目录 8 种。
- 保底不变：Q01 进行中，下一件合格装备必带 common 海克斯；Q03（军需平台首杀）最高品质那件必带 magic 海克斯。Q03 改挂到雾铃 · 关口首领首通（M10）。
- 期望量不变：`hex-loot.json` 的来源概率按 D13 §2.2 的换算口径重算一次，输入从「野外各来源期望件数」换成「各类副本的期望件数」（3.2 表）。
- 地面辨识和自动拾取照 D14：标签加「◆」，自动拾取对带海克斯的装备忽略最低品质过滤。

### 3.4 品质与换代
- 品质：普通 / 魔法 / 稀有 / 传说，各经济区的权重不变。
- 换代：T1 → T8 的换代等级不变（L10 / 17 / 23 / 28 / 33 / 38 / 45）。换代预告（progression-goal-plan §5.4）的「下一阶去哪刷」从「去哪座岛」改为「推荐节点」：下一航区的第一个巢穴，或本航区高海域难度的巢穴。
- 套装从赤炉航区开始掉；首件传说约 6:10（L21），沿用标准曲线。

### 3.5 定向刷（残页的掉落部分）
残页清单和数值在 M12 定。本模块只约束「改掉落」的残页怎么作用：

| 残页 | 作用点 | 约束 |
|---|---|---|
| 定向部位 | 本场装备的部位权重：指定部位 ×3 | 和狩猎的偏向同倍数，不叠成更高 |
| 定向套装 | 赤炉起，本场套装件的套装权重偏向指定套装 | 只改「哪一套」，不改「出不出套装」 |
| 海克斯打法偏向 | 本场海克斯符文池的打法权重 ×3（沿用 `biasWeight`） | 不改海克斯概率本身 |
| 掉落率 + | 本场装备件数区间上限 +1 | 计入 M14 的每分钟收益上限 |

### 3.6 整理（主城）
- 背包满、批量分解、保护规则全部沿用。
- 每次回港，结算页提供「一键分解本次低于穿戴的普通 / 魔法件」（参考 DNF 手游自动分解）。带海克斯的、套装件、传说件默认不进一键分解。

## 4. 规则要点
- 掉落、海克斯、保底全部服务端在发奖时冻结，客户端不知道概率和种子（沿用 freezeFieldLoot / freezeHexLoot）。
- 节点卡片的「掉落重点」由服务端公开的掉落说明生成：只写部位、套装、打法名，不写概率。
- 副本内掉落照旧是地面掉落，离开副本时没捡的东西随实例结束（沿用现有地面掉落与实例保留规则）；全自动结束时自动拾取（M05 C3）。

## 5. 接口
- 依赖 M03：每类副本的段和怪物组成（决定用哪几张表）。
- 依赖 M10：HEX-Q01～Q03 改挂节点后的触发点。
- 依赖 M12：残页清单与数值。
- 依赖 M14：每类副本的期望件数与每分钟收益上限、海克斯概率重算。
- 给 M02：节点卡片的掉落重点。
- 给 M15：地面 ◆ 标签、结算页海克斯行、一键分解。
