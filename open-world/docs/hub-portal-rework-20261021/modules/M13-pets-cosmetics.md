## 1. 目标
- 外观、宠物的**来源**从「野外地区」改到「节点首通」，其他规则不变。
- 把盘点时发现的事实写清楚：**宠物目前只有美术资源，没有任何玩法、获取、接入代码**。本模块只定改版后的获取口子和展示位置，宠物玩法另开设计，不在本次改版里补（见 §7）。

## 2. 玩家体验
1. 关口首领首通，结算页多一行「解锁外观：冰原旅装」；回港后港口一圈的「外观」处有红点。
2. 外观页里已收集的可点、未收集的置灰并写获取途径（如「霜镜 · 关口首领首通」）。
3. 宠物处（港口一圈的一个摊位）在宠物玩法接入前只展示已开放的图鉴，不出现空的功能按钮。

### 3.3 宠物：本次只定获取口子

| 项 | 现状 | 本方案 |
|---|---|---|
| 资源 | 18 个家族、54 个形态、162 套皮肤已完成（PA6） | 不动 |
| 玩法（跟随、连携、共鸣、数值） | 未定，无代码 | **本次不做**；另开「宠物玩法」设计（§7） |
| 获取 | 未定 | 零氪档（每岛基础家族）挂**本航区关口首领首通**：解锁该航区的基础宠物图鉴条目 |
| 轻氪、重氪档 | 强度比已定（60 : 100 : 130），商业化方式未定 | 不进节点掉落；等商业化方向定了再定获取 |
| 港口位置 | 大纲 §3.1 港口一圈有「宠物」处 | 玩法接入前只开图鉴：已解锁的宠物可看三个形态和动作 |

- 这样做的理由：宠物强度占角色总强度上限 12%（重氪档），在玩法和数值没推导前接进战斗，会破坏 M14 的 TTK 推导。先把获取口子定在关口首领，玩法接入时直接发给已通关的角色，不用再改节点。

## 4. 规则要点
- 外观解锁、宠物图鉴解锁都由服务端在首通结算的同一事务里写入，回执里带新解锁项（沿用衣橱 V2 的 `ensureWardrobe` 做法）。
- 外观纯表现：保存外观不改属性、构筑、战斗授权（沿用现规则）。
- 解锁提示一行，不自动穿上（R11）。
