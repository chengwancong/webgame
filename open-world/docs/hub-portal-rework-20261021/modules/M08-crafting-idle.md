# M08 制作与挂机路线

> 上位：03 大纲 §2 单日节奏（回港先领挂机收益）、§4（雾铃开放采集与制作 / 挂机路线）。参考：R9（剑与远征挂机：最多累积 12 小时，每天 1 次免费快速收益 = 2 小时）、DNF 城镇制作。
> 依据：`docs/crafting-system-design.md`（四层材料、六岛特产、四专业、定向锻造、图样、精工、工坊建设、钥匙衔接）、记忆中的制作决定（2026-10-14：专业全开放、全自动只采路线上 ≤2 格的点、烹饪并入炼金、制作 = 定向不是更强）。

## 1. 目标
- 制作规则（376 配方、四专业、熟练度、定向锻造、图样、精良、精工、提纯、钥匙）**一概不动**。
- 材料和配方的来源从「野外」搬进「副本节点」，期望量不变。
- 新增一条离线收益（码头派遣），让玩家每次回来都有东西可领，但不超过在线刷的收益。

## 2. 玩家体验
1. 副本场地里有发光的采集点（矿 / 植物）。手动、半自动走过去按 E 采；全自动只顺路采离路线 2 格以内的。
2. 结算页里材料按航区分组列出。
3. 回港后，工坊头上有红点：有新配方，或者材料够做钉选的东西了。
4. 码头的米洛那里能派一支采集船队去已打通的航区，离线也在采；回港领一次。每天还有一次免费「快速收益」。

## 3. 包含内容

### 3.1 两种「挂机」，分开说清楚

| | 路线采集（已定，2026-10-14） | 码头派遣（新，大纲 R9） |
|---|---|---|
| 在哪 | 副本场地里的采集点 | 港口码头，米洛第二服务 |
| 怎么采 | 手动 / 半自动采任意点；**全自动只采路线上 ≤2 格的点，不绕路** | 选一个已打通的航区派船，离线累积 |
| 产出 | 本航区 T1 采集材料（矿 / 植物） | 本航区 T1 采集材料 + 少量金币；**不出装备、不出 T2 / T3、不出钥匙材料** |
| 上限 | 每段场地 1–2 个点，本场采完不刷新 | 最多累积 12 小时；每天 1 次免费快速收益 = 2 小时 |
| 开放 | 雾铃（大纲 §4 1–3.5h） | 同时开放 |

### 3.2 材料来源改挂

| 材料层 | 原来源（野外） | 新来源（副本） |
|---|---|---|
| T0 星尘、强化石 | 分解、所有怪 | 不变 |
| T1 采集①②（每航区 2 种） | 野外采集点，每区 4–8 个 | 副本场地采集点：巢穴每段 1–2 个，寻宝 3–4 个，剧情 / 怪潮每场 1–2 个；码头派遣 |
| T1 怪物部件（每航区 1 种） | 割草击杀 | 副本击杀（不变，按怪物族群） |
| T2 领主材料 | 本岛地城精英、稀有、首领 | 巢穴首领、狩猎精英、关口首领 |
| T3 星潮 / 终局 | 裂星潮、世界层级、团本 | 深潮、深渊层、周常、团本 |
| 阶段钥匙材料 | 只出在本阶段地城 | 只出在本阶段**巢穴**（M03、M07，规则不变） |

### 3.3 配方来源改挂

| 原来源 | 新来源 |
|---|---|
| 150 个野外宝箱的配方池 | 寻宝节点的宝箱、巢穴段末宝箱（同一个配方池） |
| 稀有怪首杀必掉本岛配方 | 狩猎节点**首通**必掉本航区配方 |
| 声望商人 | 港口建设（M09）里的对应设施，金币购买 |
| 分解传奇 / 套装学图样 | 不变 |

### 3.4 工坊（沿用，位置不变）
- 四座设施：锻炉、饰品台、炼金台、附魔台，每座 1–6 级，用金币 + 各航区 T2 领主材料升级。工坊建设归入 M09 港口建设统一展示，规则不变。
- 强化、重铸只在工坊做，5 格距离校验不变（M01）。
- 「本阶段钥匙」页签照旧显示进度（如 7/12），材料只来自本阶段巢穴。
- 熟练度门槛的「岛」改称「航区」：风栖 1–15 / 雾铃 15–30 / 赤炉 30–45 / 霜镜 45–60 / 沉星 60–75 / 龙眠 75–90 / 深潮 90–100。

### 3.5 码头派遣细则
- 派遣目标：任一已通关关口首领的航区，或当前航区（至少通关 1 个巢穴）。
- 产出速率按目标航区定，参考剑与远征「关卡越高、挂机越多」；但**每小时产出 ≤ 同航区在线刷巢穴每小时 T1 采集量的 25%**（数值在 M14 定）。
- 同时 1 支船队；港口建设可以加到 3 支（M09）。
- 进港时服务端结算（M01），领取前在码头显示「已累积 X 小时 / 12」。
- 快速收益：每天 1 次免费，立刻给目标航区 2 小时的产出，不消耗累积时长。

## 4. 规则要点
- 采集校验改到副本实例：命令带实例、段号和采集点 id；服务端校验该点在本场未采、距离 ≤ 2 格、角色在这个实例里。原来「角色不在副本中」的条件取消（野外冻结后不再有野外采集）。仍然只抽样判定，阈值宽松，宁漏判不误判。
- 全自动顺路采：由服务端寻路判断路线 ≤ 2 格，客户端不能指定绕路。
- 码头派遣的累积按服务端时钟，客户端改时间无效；离线时长上限 12 小时，超出部分不计。
- 制作强度 ≤ 掉落（定向不是更强）、定向锻造等级上限 = 已通过阶段、不能绕开钥匙：全部不变。
- 提纯与兑换（T1 10→1 星尘，星尘 1→3 换已解锁航区 T1）不变；码头派遣的产出也能提纯。

## 5. 接口
- 依赖 M03：各类副本场地里采集点的数量与位置。
- 依赖 M07：T2 / T3 / 钥匙材料与掉落表同口径。
- 依赖 M09：工坊设施、声望商人、船队数归入港口建设。
- 依赖 M11：码头派遣的红点、快速收益每日次数。
- 依赖 M14：派遣速率、采集点期望量、制作金币占比（每章收入 × 30%）。
- 给 M15：码头派遣面板、结算页材料分组。

## 6. 复用与新增

| 复用 | 新增 |
|---|---|
| 376 配方、四专业、熟练度、定向锻造、图样、精良、精工、提纯、工坊设施、钥匙页签 | 副本场地内采集点（摆进 54 个地城场地与新场地） |
| 采集点规则（≤2 格、本场不刷新、抽样校验） | 采集校验从「野外」改为「实例内」 |
| 宝箱配方池、稀有首杀配方、图样学习 | 码头派遣（累积 12 小时、快速收益、船队数） |
| 全自动只采路线上的点 | 狩猎首通必掉配方 |

## 7. 待定
- 派遣产出上限取在线的 25% 是否合适（剑与远征的挂机收益约占日常资源的主体，但本作以在线刷为主）。默认 25%，M14 推导时校验「一天只领挂机 + 快速收益」不超过在线 1 小时的产出。
- 派遣船队能否派到深潮。默认：不能，深潮只产 T3，派遣不出 T3。
