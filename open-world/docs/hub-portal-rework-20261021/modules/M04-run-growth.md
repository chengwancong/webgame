# M04 局内成长

> 上位：03 大纲 §2 单场节奏（段间三选一，局内增益只在本场有效）。参考：R6（局内成长不带出局）、魔渊之刃法盘（局内宝石不能带出局）、Hades（死亡回主城，局内祝福丢失、局外资源保留；镜子给重抽类能力）。
> 数据依据：`packages/content/augments.json`（90 个）、`dungeons.json` 的 `augments` / `augmentExtra`、`packages/rules/run-augments.ts`、`apps/api/src/dungeon-service.ts`（触发点、结算、失败诊断）。

## 1. 目标
- 每场 3–8 分钟里都有「这把怎么玩」的选择，同一个副本打第二遍也不一样。
- 局内的选择不影响局外平衡：出了副本全部清空，装备、海克斯、天赋才是长期强度。
- 失败不惩罚过重：捡到的东西留着，告诉玩家差在哪。

## 2. 玩家体验
1. 进门第一件事是三选一（开场选一张），卡面写清楚效果和档位（银 / 金 / 棱彩）。
2. 每打完一段，通道打开前再选一张。不满意可以重抽一次。
3. 首领战打到半血时，高海域难度下会多给一次选择（终局的惊喜点）。
4. 打完看结算页：本场选了哪些增益、拿了什么、用时多少。失败时多一块「差距诊断」：差在输出、生存还是装备档。

## 3. 包含内容

### 3.1 三选一增益（全部复用）

| 项 | 现状 | 本方案 |
|---|---|---|
| 增益池 | 90 个：银 40、金 35、棱彩 15；53 个通用（all），其余按元素、投射 / 范围、16 种打法标签 | 不变 |
| 每次选项 | 3 张，至少 1 张贴合当前构筑标签（服务端按冻结的入场构筑判断） | 不变 |
| 重抽 | 每场 1 次，同档重抽 | 不变；港口建设可以加到 2 次（M09，参考 Hades 镜子） |
| 套装前置 | 部分增益要求穿够某套件数 | 不变 |
| 档位概率 | 第 1 轮 银 70 / 金 30；第 2 轮 金；第 3 轮 金 70 / 棱彩 30 | 按段数映射，见 3.2 |
| 首领加选 | 海域难度 ≥4、最后一段首领血量 ≤50% 时，加一轮（金 70 / 棱彩 30） | 不变 |

### 3.2 每类副本的选择次数

现有触发点是「开场 / 第一段后 / 进最后一段 / 首领半血」。改成**按段触发**：开场一次，之后每进入新的一段前一次，最多 3 轮 + 首领加选。

| 类型（M03） | 轮次 | 时点 |
|---|---|---|
| 巢穴 | 3 + 加选 | 开场、大厅 1 后、大厅 2 后（进首领厅前） |
| 剧情 | 2–3 | 开场、每段后 |
| 怪潮 | 3 | 开场、第 2 波后、最后一波前 |
| 狩猎 | 1 + 加选 | 开场 |
| 寻宝 | 1 | 开场（只出银 / 金，偏移动与拾取类） |
| 关口首领 / 深渊层 / 周常首领 | 1 + 加选 | 开场 |
| 团本 | 沿用现状 | 沿用 |

- 现在 `story-*`、`field-*`、`plane-*` 都挂着 `augments-disabled`。改版后全部去掉，统一开放三选一（大纲 §2）。
- 巢穴回响和三选一同时生效，但回响只在第 1、2 阶段给（巢穴设计 §7），后期靠三选一和构筑本身。

### 3.3 局内资源
只保留三样，不新加货币：

| 资源 | 规则 | 来源 |
|---|---|---|
| 重抽次数 | 每场 1 次，不跨场累积 | 现有；港口建设 +1（M09） |
| 回响爆发 | 只在开场和首领战出现，不加常驻主动键 | 已定的开场方案 |
| 救援 | 组队时 5 秒、2 格、回 30% 血；单人无复活 | 现有 `rescue` |

不做局内金币、商店、局内宝石镶嵌：本作的长期构筑已经有装备、海克斯、天赋、威能四层，再加一层局内经济会挤占 3–8 分钟的节奏（R8）。

### 3.4 倒下、撤离与失败

| 情况 | 结果 | 依据 |
|---|---|---|
| 单人倒下 / 队伍全倒 | 本场失败，回星门广场 | 现有 `failed` |
| 主动撤离 | 随时可以从菜单撤离，按失败处理（不算首通、无最终奖励） | 现有 `abandoned` |
| 超时 | 失败；寻宝例外，按已开宝箱结算（M03） | M03 |
| 系统中断 | 退还入场消耗，已获道具保留 | 现有 `refundSystemAbort` |
| 断线 | 保留 1800 秒，回来从当前段开头继续，已选增益保留 | 现有 `retention` |

- 所有失败情况下，**局内已经捡到的装备、材料保留**，已经结算的段收益保留（沿用现有「已获道具保留」）。
- 残页在进门时消耗，失败不退（M02 / M12）。
- 每日首通加成只在成功时消耗（M11）。

### 3.5 结算页

| 区块 | 内容 | 来源 |
|---|---|---|
| 结果 | 成功 / 失败 / 撤离，用时，最快纪录 | 现有 outcome、剩余时间 |
| 收获 | 金币、经验、材料、装备（含海克斯标记）、宝箱 | 现有 Receipt、宝箱视图 |
| 首通与加成 | 首通奖励、本日首通加成是否用上 | M02 / M11 |
| 本场构筑 | 选了哪几张增益（局内，出门即清空） | 现有 augments.chosen |
| 海克斯统计 | 本场海克斯触发、伤害占比 | 现有 hexCombatStats |
| 阶段钥匙 | 钥匙材料进度（只有巢穴） | 现有 keyProgress |
| 差距诊断（失败时） | 输出不足 / 生存不足 / 装备档落后，指向工坊或换装 | 现有 diagnostic（withGapDiagnosis） |
| 下一步 | 「再来一次」「回港」「去下一个节点」三个按钮 | 新 |

「再来一次」直接以同样难度、同样残页槽（残页需要重新插，消耗新的）重新出发，不必回港；背包满时按钮置灰并提示回港整理。

## 4. 规则要点
- 增益的出卡、重抽、选择都由服务端随机和判定；客户端只看到当前三张卡和已选列表，不知道私有种子。
- 增益按入场时冻结的构筑判断适配（`buildLocked`），局内不能换装，所以不会出现「换装刷适配」。
- 出副本时增益清空，不存进角色存档。
- 数值：现有地城和剧情副本的怪物强度是在「无增益」下推出来的。开放三选一以后，M14 要按「每轮期望增益强度」重推一次 TTK，只推一次、验一次（balance-ttk-derivation）。

## 5. 接口
- 依赖 M03：每类副本的段数和触发时点。
- 依赖 M09：港口建设给的重抽次数。
- 依赖 M11：本日首通加成的消耗时机。
- 依赖 M14：开放增益后的 TTK 重推。
- 给 M15：三选一卡面、局内已选列表、结算页。

| 复用 | 新增 |

## 7. 待定
- 寻宝只出银 / 金、偏移动与拾取类，现有 90 个里这类增益够不够。默认：先用通用类（all），不够在 M14 校对时补 2–3 张，不砍掉寻宝的选择（fill-gaps-not-hide）。
- 「再来一次」是否保留上一场的残页组合（自动扣新残页）。默认：保留组合，自动扣，残页不够时提示。
