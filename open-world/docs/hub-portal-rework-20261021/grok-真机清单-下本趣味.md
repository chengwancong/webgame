# Grok 真机清单：星门副本 + 下本趣味补强（草稿，2026-10-22）

用户 2026-10-22 决定：真机测试一律部署云测试服交 Grok。本清单在以下前提满足后再发：
1. HUB 后端 B0–B3 与 FP 前端已独立提交，`deploy-staging.mjs` 发到测试服；
2. 测试服执行了切换点 S（先备份），新号登录后从拾星港出发；
3. `/api/health` 的 client / protocol / rules 与本次提交一致。

通用登录、会话、报告格式沿用 [grok-跑测指南](../cloud-20261018/grok-跑测指南.md)；测试号从 `qa_grok_hub1` 起。

## 必测流程
| 编号 | 步骤 | 期望 |
|---|---|---|
| G1 | 新号建角色 → 走完开场 | 回到拾星港，不进旧野外；港口中央星门可交互 |
| G2 | 星门 → 航图 → 风栖剧情 1 → 出发 | 节点旁弹卡、出发确认；进副本后 HUD 有目标行和段数 |
| G3 | 打完剧情 1 | 结算页左右两栏；有本场评价 S/A/B 与「距 S 还差 N 秒」（FP3）；回港 |
| G4 | 风栖巢穴：一厅连续击杀 | 屏幕出现连斩计数，10/25/50 档字样升级，停手约 3 秒后淡出（FP1） |
| G5 | 关口首领打到半血 | 屏幕上部横幅「首领名 · 狂暴」一次，不重复（FP2）；三选一加选 |
| G6 | 狩猎（多打几次，机制每场随机） | 落石：脚下预警圈后砸下；涨潮：半边地面进水减速；**引雷桩**：精英身上有护盾条，场上两根石柱，站旁 2 秒读条「击碎引雷桩」，碎一根护盾变短，两根都碎出现横幅「护盾破碎」（FP4） |
| G7 | 寻宝（多打几次） | 五箱限时；偶尔一箱读条后变「宝箱怪」，目标行变「击败宝箱怪，夺回宝箱」，打死后照常得该箱奖励（FP5） |
| G8 | 副本里手动走位（键盘/点击） | 按下即动，没有明显迟滞；停下不被拉回；被击退/冲刺后位置正确（FP6） |
| G9 | 副本内切全自动 | 自动寻路开箱、碎桩、选卡（8 秒）、走出口 |
| G10 | 港口：今日、港口建设、委托板 | 面板能开，数字不为空，领取一次后不能重复领 |
| G11 | 港口人多处（NPC 聚集区）站一会、首领战放技能/转阶段 | 同屏原生 NPC 超过 8 个也全部显示；首领出招、转阶段、倒地时人物不闪一下消失；左右转身挂点特效位置跟手（FP7） |

## 每项要记
- 狩猎写明本场机制；引雷桩记两次碎桩时的护盾变化和破盾横幅是否出现。
- G11 记同屏 NPC 数与帧率（浏览器性能面板或肉眼卡顿），首次进港前几秒卡一下属正常（在烘焙），之后应顺畅。
- G8 记网络延迟（浏览器 devtools 的 ping 或测试服 health 往返），区分「网络慢」和「操作迟滞」。
- 评价、连斩、横幅只是表现，不影响奖励；发现奖励随评价变化算 BUG。
