## 结论
1. **P30 开场衔接（无问题）**：prologue.json `fade` 句“刻片「咔」地裂开一道缝，光一格一格熄灭了”→ 进野外后 ss-c01-t01 接取对白（米洛“会用你手里的武器吧？站我旁边，先把它们打发走”）→ 完成句“有一招刚回到手上，别的还暗着”。技能自动施放，起手技由 `starterSkills` 提供（sword=cut / staff=staff_strike / hidden=throwing_knife），与三选一武器一致；无需额外操作教程。
2. **P17 巢穴入口 vs 任务目标（无冲突）**：tasks.json steps 中没有任何步骤要求进入巢穴/地城；入口（`field-dungeon:*`，标签“查看地城”，受 feature `field-dungeon` 控制，field-activities.ts:60）纯属可选内容，不会出现“任务指向入口却灰掉”的情形。唯一进副本的任务是 boss 类（t05 风栖船台，经首领门，不经巢穴入口）。
3. **c01 奖励**：6 个正式任务合计约 XP 4 949 / 金 535（c01 全章 29 条含支线 8 143 / 1 225），与 c02 章总 48 031 XP 相比有 ~6 倍台阶，符合“出岛后升级加速”，未见 c01 内断层。
4. **P31 团本单人缩编（默认裁决：不做）**：团本按多人协作设计，单人缩编会同时改变机制与掉落价值；已知限制记录于此，不立任务。
