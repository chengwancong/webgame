### ✅ Task #2: 修复小地图溢出（P1-03）
**问题**: 外框 154px = 画布 140px + padding 12px + 边框 40px(旧九宫格)，导致画布溢出容器 12px。

**修复**:
- 采用 V2 轻量边框（2px）代替旧版厚重九宫格边框
- 重新计算尺寸：外框 158px = 画布 140px + padding 8px + 边框 4px + legend 6px
- 确保画布完全包含在内容区

**文件**: `apps/web/src/style.css` 行96-100

**计算公式**: 
```
外框宽度 = 画布宽度 + 左右padding + 左右border
158 = 140 + 4*2 + 2*2 + 6(legend margin)
```

**验证**: ✓ 小地图 canvas 尺寸已修正为 140×140，CSS 尺寸精确匹配
