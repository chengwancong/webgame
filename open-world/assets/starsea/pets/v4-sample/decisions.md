# PA5 裁定

- 龙眠零氪 D2 a/c/e，轻氪 A10 a/c/e；重氪 A/B 均用 A7 c/d/e，先比较画法，不混入骨架差异。
- 样稿 24 个逻辑外观共用 12 套形态；流派只改变花纹、饰件、宝石、特效，身体米金底色固定。
- 延续 PA4 可编辑 SVG 零件源，重新绘制硬边色面、结构线及饰甲；原生 JSON 字节保持不变。最终展示一律来自完整 Spine 动画渲染。
- 按 §6 使用不闭合地面弧段，避免敌方实线预警圈。

- 实测修正：A7 头部原图含透明眼窗，yan 与原生眼睑位于头部后方。恢复原 alpha 眼窗、取消覆盖窗的闭眼画线；保留原生层序和眼睑动作。
- 导出改用 2× 硬件采样后缩至 256 单格，降低轻氪翼缘缩小锯齿；画布坐标、骨架和动作时序不变。
- 原库 B7 是兜帽人形，候选筛查淘汰；沉星候选改为 A7 / A3，避免人形及恐怖元素。

- 抗锯齿后重氪的精确 RGB 码字超过 65535。为保持无损，分区扩展为 24 位 RGB 索引；透明覆盖率从共享底图 alpha 读取。材质分区仍不进行有损压缩、不修改纹理颜色或动作，解码契约另写报告。

- 饰甲 B 的职业围巾保留大号，调整到主体后层，给胸甲和宝石让位。
- 44px 对照改为按当前帧真实 alpha 高度归一到 44px，避免翼展和呼吸导致虚标；该诊断倍率不改正式显示高度或原动作。
- 总表取 idle 0.15 秒，避开原生 0.4 秒附近的眨眼，用于比较点眼和双高光。

- 重氪点眼按原眼窗放大为圆钝椭圆并保留两个高光；A7 下颌长须改用饰件色，避免米白尖端被误读为獠牙。

## PA5-r2

- 甲A10与乙A7均先采用c/d/e；新样稿用独立r2资源和manifest，零氪/轻氪原文件冻结。
- r2五官、背腹分区规则覆盖PA5的米色身体与点眼规则。保留原吻部、下颌、尖角与爪，牙/獠牙只在贴图上消除。
- A与B共用本体画稿；B仅叠加小面积嵌甲。饰件单独输出mask并计算所有动作的可见投影面积，目标低于15%。

- r2 §6：A7 小尺寸虹膜改为与眼白对比更强的蓝紫色；不退回点眼。d阶下颌长须使用深背色，避免浅色尖端误读为獠牙。
- 12个54px首帧黑剪影制作自检通过：甲的角吻/背棘/爪/站姿可辨；乙的角冠、抬颈、长尾和鳍形可辨为鳍龙。A/B饰甲在体内，不靠改变外轮廓通过测试。

- r2预算复测：A10采用旧版去RGB残差会出现15–29/255的95分位通道误差，拒绝把该压缩步骤当成甲的交付方案，改以24fps＋无损图集＋gzip估算。乙的量化原型仍只作本地预算试验，未替换正式样稿。
- 动作抽查图加大列间距并保留右侧喷火范围，避免长鳍或原生攻击效果与相邻帧重叠、被总图边缘裁切。
