# PA5 裁定

- 龙眠零氪 D2 a/c/e，轻氪 A10 a/c/e；重氪 A/B 均用 A7 c/d/e，先比较画法，不混入骨架差异。
- 样稿 24 个逻辑外观共用 12 套形态；流派只改变花纹、饰件、宝石、特效，身体米金底色固定。
- 延续 PA4 可编辑 SVG 零件源，重新绘制硬边色面、结构线及饰甲；原生 JSON 字节保持不变。最终展示一律来自完整 Spine 动画渲染。
- 按 §6 使用不闭合地面弧段，避免敌方实线预警圈。

- 实测修正：A7 头部原图含透明眼窗，yan 与原生眼睑位于头部后方。恢复原 alpha 眼窗、取消覆盖窗的闭眼画线；保留原生层序和眼睑动作。
- 导出改用 2× 硬件采样后缩至 256 单格，降低轻氪翼缘缩小锯齿；画布坐标、骨架和动作时序不变。
- 原库 B7 是兜帽人形，候选筛查淘汰；沉星候选改为 A7 / A3，避免人形及恐怖元素。

- 抗锯齿后重氪的精确 RGB 码字超过 65535。为保持无损，分区扩展为 24 位 RGB 索引；透明覆盖率从共享底图 alpha 读取。材质分区仍不进行有损压缩、不修改纹理颜色或动作，解码契约另写报告。
