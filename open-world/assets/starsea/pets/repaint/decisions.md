# PA2 裁定

- 预览需求的“四档切换”在 repaint 独立页实现，读取 PA1 原资源作为第四档；遵守更明确的“PA1 不改”文件权限。
- 新 atlas 保持原 region 名；骨骼 JSON 尽量逐字节复用，只替换其引用的 atlas 贴图。附件 path 如不需要修改则不改，骨骼、动画、槽位、附件参数严格保持。
- a/c/d 共 16 个原始零件，三画法共 48 张独立透明 PNG，尺寸严格为各自原图的两倍。生成原稿放 sources，技术渲染/对位大图放 evidence。
- 按 §7，生成稿无法精确满足骨骼 UV 对位时，手工按原剪影重描；原稿、手工修整来源及哈希均登记。不以整张角色立绘替代分件。
- 样稿 1 生成稿含过多毛尖、成年身体上新增的耳状突起及轻微渐变，不符合精确分件约束。采用手工原坐标轮廓和色块重描（sources/*/parts/*.svg 为可复核画笔路径，输出仍为 2×透明 PNG）；保留原稿及哈希。此处理依据 §7 的“手工重描”，不是新骨骼或静态动作。
- 闭眼弧线位置由 yan 局部坐标经原骨骼变换、身体 mesh 三角形重心坐标反算 UV，结果在 sources/eye-alignment.json。睁眼覆盖层用相同奶白底覆盖闭眼，再绘深棕实心点眼和单白高光。
- 抽样发现旧 3.6 导出器的 blendFunc 会令叠层抗锯齿边缘降低身体 alpha，形成浅色眼圈。只在 repaint 渲染器改用同 RGB 混合、正确 coverage alpha 的 blendFuncSeparate；未改 vendor、骨骼、槽位或贴图乘色。用于消除技术白边，不是新画法差异。
- 为消除直通 alpha 纹理线性采样的细暗圈，新贴图上传时使用 UNPACK_PREMULTIPLY_ALPHA_WEBGL，Spine drawSkeleton 使用对应 PMA 混合；交付分件 PNG 仍为普通透明 PNG，颜色未乘色。
- §7 眨眼裁定进一步应用于整个闭眼时段：身体闭眼弧线使用所有 idle/idle2 闭眼帧的 yan 中心反算 UV 均值，不仅匹配第 0 帧。最终闭眼对位最大误差 a/c/d 为 0.201/0.065/0.060px；睁眼覆盖层遮住弧线，不改原生附件显隐时序。
- 本批按 §5 的每阶显示高度作为每动作垂直包络上限，沿 PA1 的整段固定相机缩放方式烘入帧和挂点；会导致攻击/击飞切换时体量变化。它属于导出相机展示比例，源骨骼、动作、附件参数均逐字节不变。三画法使用同一算法。
- 四列 PA1 对照直接读取原始 a/c/e 成长资源，明确标注；不把 PA1 的 d 外观改成成长形态，避免改写历史对照。
