# 开放世界正式美术资源

2026-10-06 用户要求美术先落地。此目录保存风栖岛首批正式源图、导入规则和资源台账；六岛完整需求继续以 `docs/open-world-expansion-plan.md` §4 为准。

## 本批资源与数量口径

当前首批 70 个稳定资源 ID：40 个摆件/地标/建筑/宝箱条目、5 个地表、9 个程序采样遮罩、10 个地图 SVG 标记、3 类原生前哨人物、3 项传送表现。其中独立新增原图 33 张；同一货箱的多用途引用、人物换装和程序表现不计为新增原图。

- 五个主要地标：风车、灯塔、搁浅船骸、木栈桥、船坞闸门。
- 完整自然造型池：树 4、灌木 3、岩石 5、花草 4、大山石 4，共 20 个可识别造型。
- 营地：帐篷、篝火、木栅、图腾、货箱、旗帜；另有修理台、补给箱、航标锚石、洞口与木哨塔。
- 前哨人物复用已验证 Spine 4.2.43 原生动作，选择独立身体/头/发型组合并复用职业工具。表现角色不自动增加 NPC 服务或任务；正式 NPC 位置和服务仍由工作簿配置。
- 地表保存 512px 发布文件，以 `mirrored-repeat` 明示镜像采样；原图不宣称天然无缝。8 类灰度地表过渡和1张迷雾遮罩是程序采样数据。
- 地图标记扩展现有原生 SVG 图形系统，颜色读取公共 UI Token；地图迷雾权威进度仍由 M1 系统负责。
- 航标激活、传送离开/到达复用已登记的 `telegraph-reuse/tip-glow.png` 静态部件，加独立程序时间线。不是整套原生 Spine 动效还原，也未绑定正式传送命令。

## 来源、导入与复建

`source/` 保存内置 `image_gen.imagegen` 的原始 PNG 与提示词记录，风格参考为项目 `.design/npc-scene-unification-20261003/camp-unified-v2.png`。帐篷初稿保留为 `tent-draft.png`，清理透明边界后的版本为 `tent.png`。

`spec.mjs` 是本批资源导入定义，不是任务/地图/服务配置源。`tools/build-open-world-art.mjs` 只做透明边缘裁切、等比例缩放、8px留边、现有图集区域提取和发布；不改写原始位图，也不替换现有星潮海包。输出：

- `assets/open-world/manifest.json`：来源、文件哈希、运行路径与各项状态。
- `packages/asset-manifest/open-world.v1.json`：工程资源登记。
- `apps/web/public/art/open-world/`：可独立加载的发布资源。

运行 `pnpm art:open-world` 和 `pnpm art:open-world:verify`。正式 `pnpm build` 已包含本批复建；源图不依赖 Codex 缓存。缺失源图会失败，`--allow-pending` 仅供制作阶段使用。

## 预览与验收边界

只读检查页：`http://127.0.0.1:8612/open-world-art-qa.html`；生产包由8611提供同名入口。支持分类、原比例资源、镜像、人物动作、暂停、航标状态、传送参考时间线及模块足点摆放。世界碰撞、任务进度、奖励和玩家存档均不由本页修改。

文件、哈希、透明留边、尺寸、原生皮肤与动作引用检查记录在 `.design/open-world-art-first/file-verification.json`。模块缩略检查在 `sprites-contact.jpg`；发布前后的真实数据库审计由只读脚本保存为 `save-before.json` / `save-after.json` / `save-comparison.json`。实际浏览器及生产发布结论另记，单独的文件检查通过不代表视觉或新地图玩法通过。

本批正式构建与独立生产页已验证。三类前哨人物的原生动作、修理工具镜像、播放/暂停，以及三项传送程序时间线有实际浏览器记录和截图，见 `browser-review.json`、`npc-*.jpg`、`ow-fx-*.jpg` 和 `production-module-preview.jpg`。修理员曾在后台更新期间出现一次网络加载失败，已在服务恢复后复验，失败截图保留。源与导入验证检查70项，无缺失/哈希错误；本批仍不把抽样资源预览等同于全地图实机验收。

发布期间已有其他游戏操作：账户/角色和回执数量持续增长，未使用“全表不变”声明。`concurrent-action-review.json` 核对了初次审计之前的回执与流水指纹全部保留，新增正常经验/金币/材料交易另列；当前簇未更换。本轮资源页不请求玩家写入接口。原游戏入口使用已有浏览器会话时停在创建角色页，未创建或清除角色；本轮没有完成该会话的旧角色恢复验收。
