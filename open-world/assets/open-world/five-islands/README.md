# 五岛美术一并交付

用户在2026-10-06明确要求雾铃、赤炉、霜镜、沉星、龙眠五座岛的美术一并完成。本包独立于已交付的风栖岛70项，不以一岛样板或部分图片作为五岛完成。

## 固定范围

每岛8项地表材料、20种自然造型主题版本、6项营地设施、15个地标（六分区各2–3个）、2种扩充建筑、3个地城入口、4类岛缘、4项前哨设施、一个航标和一座首领门。另有每岛2种普通怪外观、1种精英、3种地城首领、2种稀有精英，以及8名区域人物外观。

公共部分包含土路/石路/木栈道/冰路/熔岩石路、宝箱开合、六项事件物件、雾墙/封印门/断桥的两种状态、9张采样遮罩、10种地图标记、30个分区横幅图标、环境循环、传送/事件/稀有表现、水体/浅滩/瀑布着色器，以及指路/蹲下/坐地/挥手四类人物动作。

源图在 `source/`，内置 imagegen 的提示词逐项存为同名JSON。预览输入为已确认的等距手绘方案2；资产均为独立地表、模块和角色资源，不以整幅概念图替代地图。

## 数量口径与复用

- 新位图、既有位图引用、主题材质变体、换装人物和程序表现分别统计。
- 每岛自然物件复用20个经过检查的不同造型，加明示材质适配；不会把100个主题版本称为100张新原图。
- 地标每岛10项新造型加5项既有模块；同岛地标保持不同造型与用途，跨岛复用来源和调色可查。
- 区域人物沿用原始完整骨骼、服装、头部、发型和职业工具，不称40套原创骨骼。普通怪/精英/地城首领保留原动作与逐帧挂点，按已允许的材质/尺寸方案适配。
- 新动作是原加权骨架上的真实时间线；指路复用原生手势，蹲下、坐地和挥手有独立骨骼曲线与逐帧手部挂点。原7位人物的JSON与原包不改写。
- 水体使用公开GLSL着色器，环境保留原登记帧/静态部件和时间线；这些不冒充整套原作Spine还原。

## 工程入口

- 定义：`assets/open-world/five-islands-spec.mjs`。
- 构建：`node tools/build-five-island-art.mjs`；缺项会失败，`--allow-pending`仅用于制作阶段。
- 验证：`node tools/verify-five-island-art.mjs`；逐岛数量、文件/哈希、透明留边、图集帧/挂点、原生动作与新时间线必须通过。
- 发布：`apps/web/public/art/open-world/five-islands/`；公共登记：`packages/asset-manifest/open-world-five.v1.json`。
- 游戏调用：`apps/web/src/open-world-five-runtime.ts`，按当前地图的资源ID预加载，保留独立资源命名空间，不一次加载全五岛。
- 只读合并检查页：`http://127.0.0.1:8612/open-world-five-art-qa.html`，正式包对应8611入口。切岛、材质、动作、朝向、阶段、暂停和GPU水体均可检查。

## 完成门槛与当前状态

五岛美术已作为一批完成资源制作、导入和验收。共494个稳定资源ID、99张独立新增原图、321项明示材质适配；待制作项为零，五岛全部数量矩阵通过，833个不重复源/运行文件契约通过。合并页逐项完成80个角色的加载与移动、五岛地标/模块、25项首领阶段/死亡检查、四类原生骨架动作、五环境循环、三种WebGL2水体、物件状态切换与暂停检查。

完成状态为 `five-islands-resources-accepted`，证据在 `.design/five-islands-art/`，审核记录在 `review.json`。审核绑定完整资源定义与文件哈希的摘要；后续源/参数漂移会使复建退回待复核。正式构建通过 `tools/build-open-world-art.mjs` 的完整源门槛接入本包，不依赖 Codex 图片缓存。此前风栖岛70项保留。

本批修复了缩略图透明边缘、挥手手臂与挂点同步、实体状态固定画布/比例以及预览加载间隙误读空图片地址的问题，失败过程与最终复验记录分别保存。发布前后保留原账号、角色和全部历史回执/流水；期间有真实游戏操作，新增记录单独核对，不宣称全部角色状态恒定不变。

玩法规则、地图导航/碰撞、NPC服务、怪物模板与实际交互按配置表及后续工程集成验收，不由资源存在反推完成；此包不会写入玩家账号、成长或奖励。
