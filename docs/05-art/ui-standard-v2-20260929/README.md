## 这版的设计规则

1. 世界和角色承担丰富色彩，UI 底色安静；轮廓和留白建立层级，不依赖粗重装饰。
2. 午夜蓝与石板蓝作为面板底；暖米白用于文字；杏金色用于主操作、选中和焦点。
3. 面板采用细描边、轻微圆角或切角、有限阴影。保持游戏图标与少量星芒符号，不做普通管理后台。
4. 图标以明确轮廓、亮暗块和魔法色表达用途；不同状态在图标上叠加锁定、冷却或选中标记。
5. 保持四个装备部位、四个装配技能及同一套技能顺序。画面中的物品、数值和库数量是示意，不修改实际内容预算和规则。
6. 在 1280×720 至 1920×1080 下保留主要空间关系；低高度时调整分栏、间距或内容滚动，不能将文字整体缩小。

## 落地边界

本套是视觉方向稿，已经目视核对四张的样式一致性和主要信息结构，尚未制作可直接导入的控件图集、动画、地图或代码。角色和怪物为本版风格示例，尚不是已完成的游戏角色资产。

图片中的角色数值、物品计数、技能数量和描述均不能直接成为正式配置。背包示例包含的材料或物品不构成新系统需求；技能库示例只显示八项，当前实际内容仍按正式清单实现。动态文字、格子数量、价格和比较必须由真实状态生成，不从图片中裁出。
