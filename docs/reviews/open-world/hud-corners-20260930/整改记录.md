# 战斗 HUD 两个底角整改

对照：docs/05-art/ui-standard-v2-20260929/01-gameplay-hud.png。

左下：去掉矩形面板；三种模式合为胶囊切换，选中态金色；下方独立圆形暂停/继续按钮、实时状态与自动设置入口。停止原因仍显示在上方，未隐藏失败状态。

右下：四个入口改为圆形底座、奶油色实心图形、下方名称；金币独立置于上方，金额来自正式快照。快捷键通过标题和 aria-keyshortcuts 保留；待领取角标使用真实奖励数。

图标由共享 hud-icons.ts 输出 SVG；样式在 v2-layout.css，无新位图和外部依赖。HUD 定时刷新只更新状态，不再持续重建模式按钮，键盘焦点得以保留。

验收：1280×720、1600×900、1920×1080、1024×576 底角与技能栏无重叠；三模式切换、移动接管、暂停冻结模拟与继续、自动设置及四个入口通过；选中态悬停保持金色；金币等于正式余额；页面异常 0；TypeScript 通过。在线 8612 已确认提供新代码。

这些结论限于本轮两个底角，不代表整张地图和全部 UI 已达到概念图品质。
