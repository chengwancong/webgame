## 实际变化

- 六件装备已从几何占位图换为独立透明插画：剑、弓、护甲、饰品、核心、护盾。采用浓厚色彩、现代卡通幻想画风，保持蓝金与青绿、橙红的区分。框体、选中态、按钮和数字继续使用可维护组件。
- 背包采用角色／六列物品／装备详情三栏，1024×576 也保留此结构。比较与强化报价独立滚动，操作按钮不再盖住内容。
- 构筑采用上方四个槽位、左侧技能库、右侧详情和底部保存区。小窗口仍保留双栏，勾选后立即更新草稿与装配栏，正式保存经过服务端确认。
- HUD 缩为头像与状态、任务边栏、圆形地图、技能栏和模式／系统入口，减少大面积深色遮挡。
- 登录、角色创建、远行、任务、自动设置、设置和分解确认沿用同一套蓝色面板、奶油色文字和杏金色主按钮。
- 人物按追加要求从用户解压的 SP33 包中选择金发锤盾武士 `hero_wushi`。战斗模型、HUD 头像和背包立绘现在为同一角色。外观不改变装备属性或构筑计算。

## 人物与资源工程

原始骨骼版本 Spine 3.6.32。内部离线导出为 Phaser 图集，客户端不新增 Spine 运行时依赖。

共 143 帧，七类动作使用原始 Idle、Movement、Attack1、BeAttacked、Deaded、Skill、Celebrate，无静态动作替代。所有动作扫描统一边界、共同脚底锚点，打包时拒绝空帧和边缘裁切。修复渲染器每帧覆盖角色缩放的问题，并按原始朝向处理翻转。

来源、哈希、适配记录：`open-world/assets/actors/wushi/source.json`、`export.json`；装备来源：`assets/ui-source/v2/equipment/provenance.json`。原解压包未修改。生成源、必要动画帧及可复现导出工具作为正式构建输入保留。

组件页与游戏共用资源解析、槽位和样式；提供黑、白、灰、蓝及真实游戏截图背景。禁用、加载、选中、锁定、已装备、冷却、错误均有对应表现；键盘选择、提示框和滚动已操作验证。旧几何装备源与占位生成流程已退役。

## 与参考图的关系及边界

V2 的色彩、面板层次、装备插画、三栏背包、双栏构筑和紧凑 HUD 已落实。人物按后续要求改为资源包中动作齐全的卡通武士，因此不再沿用参考图里的蓝发人物；这不是逐像素复刻。

世界地形、建筑、敌人素材仍沿用当前游戏。本轮没有把地图背景重做成参考概念图的完整场景；这项差异在实际截图中如实保留。自动设置中原本缺少的拾取筛选／低生命停止仍明确标注，未借 UI 整改声称新增玩法。素材商业发布许可仍需正式发行前核对。
