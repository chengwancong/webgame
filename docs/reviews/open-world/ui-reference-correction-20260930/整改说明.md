# V2 参考图对照整改

## 结论
此前验收证明功能可操作，不足以证明与 V2 视觉一致。当前仍不能称为参考图完整落地。

## 本轮已改
- 行囊面板扩大到接近参考图的屏幕占比，三栏比例调整为约 27:46:27。
- 左侧角色增加脚底光环和正式属性摘要；沿用当前解压包角色，没有用参考图立绘冒充可动角色。
- 中部增加全部/武器/护甲/饰品/核心筛选，六列装备格，底部显示真实容量和钱包。
- 右侧扩大装备图、名称和比较行；装备操作固定在底部，详细预览可滚动。
- 蓝色背景减少灰度，选择状态使用金色边缘与光晕，已装备使用绿色勾选。
- 技能页改为四列大图标、每屏两排；顶部展示顺序编号、图标和名称，详情集中在右侧。
- 保留真实装配、升级、装备预览与服务端保存；未添加虚构道具填满格子。

## 本轮地图改动
- 运行代码中原有低饱和单色菱形地面已替换，草地与碎石路使用新生成的纹理。
- 主要场景物件使用透明图集，图集帧按实际轮廓检查后登记，不假定生成器准确遵守四等分。
- 道路由实际导航路径导出，连接安全点与交互目标；碰撞、敌群、地图尺寸和正式资产规则未改。
- 树木与岩石沿已有阻挡区和地图边界放置，建筑按脚底纵向排序；遮住玩家的前景物件淡化。
- 地块加载时烘焙外观纹理，卸载时释放纹理；额外地表边缘避免视野边界出现突兀空白。
- 新资源来源、哈希和图集帧记录在 open-world/packages/asset-manifest/environment.v2.json。

## 仍未达标的部分
1. 世界：本轮已用模块化草地、碎石路、树木、苔岩、房屋与传送门替换主要几何占位。仍缺少丰富的区域专属物件、细化锻造台、自然道路边缘与更有层次的场景编排，不能据此称为最终品质。
2. 人物：现有资源角色为大头 Q 版，参考图是较修长的冒险者。轮廓、头身比、服饰和动作需整套统一，当前不能宣称一致。
3. 技能详情：当前放大技能图标，尚无参考图中的独立场景化技能插画。
4. HUD、旅行、任务、设置没有在本轮完成逐像素对齐；本轮重点是背包和技能构筑的可见结构。
