# A「皮革铜边」实机记录

2026-10-03 用户确认整套 UI 的统一方向。永久参考保存在 `.design/leather-copper-20261003/user-approved-a.png`，当前标准写入 `项目.md` 和 `AGENTS.md`。本轮先统一主界面，再用行囊验证；技能、养成、外观、任务、设置窗口继承同一套公共色板和控件。

主界面右下采用细铜边、暗皮革方牌与六个彩色SVG道具插画；左下技能栏保留较明显的边框与正式技能图，战斗模式位于其下。金币条与交互提示使用简洁框体。大窗口仅在角部使用铜钉；内页平整，条目不增加厚框。悬停提亮边框，按下轻微下沉，选中保持金色亮边，键盘焦点继续显示。

颜色与尺寸唯一源为 `open-world/packages/ui-tokens/tokens.json`。旧蓝色公共面板已换为暖棕色；保留现有字体、布局、按键、页面内容与操作契约。菜单插画为程序内SVG，颜色全部消费Token。
