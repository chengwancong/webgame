## 落地细节

- 每套使用原生待机、移动、攻击、受击、死亡、技能、胜利七种动作，十一套合计 1,697 帧。缺少移动的候选未采用，没有以静态立绘充当移动动画。
- 一套角色的所有动作共用摄影范围；图集裁透明边并保留原画布与脚底锚点。左右翻转同时处理锚点，避免转向位置跳动。
- 普通敌人按可见轮廓校准 62–90 像素，首领 130–145 像素；精英相对自身尺寸放大 15%，加金色脚环和标识。取消旧版统一强制缩放和整身染色。
- 血条按各自轮廓高度定位。死亡按动画长度保留后移除。赤龙最后一帧为原素材透明淡出，显式记录，不当作缺帧。
- 攻击和受击动作对齐当前表现时段；连续同类攻击重新播放，结束后返回待机；暂停时动画同步暂停。表现不决定伤害和正式奖励。
- 当前资源入口为 `assets/actors/monsters.json`；源文件、哈希、动画记录在各角色目录；发布图集在 `apps/web/public/art/`。`tools/build_assets.py` 已改为重建当前 SP33 选择，不再重建并覆盖为旧 Pockie 怪物。

## 复现

在 `open-world` 运行：

```sh
python3 -X utf8 tools/build_assets.py
node --import tsx tools/validate-content.ts
node node_modules/typescript/bin/tsc --noEmit
node tools/accept-monsters.mjs
```

美术检查入口 `http://127.0.0.1:8612/monster-art-qa.html`，不连接正式资产；生产构建不包含这个 QA 入口。当前游戏入口仍为 `http://127.0.0.1:8612/`。
