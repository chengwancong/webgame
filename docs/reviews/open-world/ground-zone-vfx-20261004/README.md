# 持续区域飞弹误用修复

2026-10-04。用户指出持续地面圆中出现成群紫色“小蝌蚪”。实机截图复现为重力陷阱、虚空漩涡等区域循环播放 `arcane-projectile` 横向弹体的帧序列。

修复共用区域绘制分支：

- 奥术／暗影持续区域使用固定落点的贴地旋流和向心脉冲。
- 弹幕和箭雨使用向下的落点线段，移除不相符的横向奥术飞弹。
- 复用现有已登记地面材质、调色和线条绘制组件，没有新增或重画图片；已检索用户指定300套库中的光圈素材，此轮没有把原始Spine部件误称为完整动画接入。
- 真正飞行中的奥术飞弹继续使用原弹体素材与运动路径。
- 年龄消费战斗时钟，范围消费实际区域半径；没有修改伤害、费用、状态、冷却或战斗执行规则。

实现：`open-world/apps/web/src/combat-vfx.ts`、`ground-zone-vfx.ts`。

验收使用真实 `World` + `WorldScene` 控制场景，对重力陷阱、虚空漩涡、弹幕、箭雨和奥术飞弹采集前后截图与可见图像节点。四种地面区域的横向奥术弹体节点均为0，真正飞行中的奥术飞弹仍可见。前后场景资源错误为0。资料见 `before.json`、`after.json`、`verification.json` 和同目录PNG。
