# 副本回城修复验收（2026-10-03）

发布版本：客户端 0.8.6，协议 12，规则 ow-16，数据库 11。

## 问题与修复

入口显示「E 返回营地」，但服务端副本的交互分支优先执行救援／剧情交互，未处理入口返回。现在先检查入口距离，再执行副本退出命令。点击入口使用服务端移动，到达交互距离后执行退出；运行界面的退出按钮统一显示「退出副本并回城」。退出保留此前已提交的收益。

## 本轮验证

- 真实 PostgreSQL、HTTP、WebSocket 定向测试：3 项通过、15 项跳过。覆盖短时限失败、单人倒地失败并保留库存返回、全员倒地及同帧最终击杀优先级。单人倒地使用隔离测试账号的持久化夹具，未修改真实账号数据。
- TypeScript 检查、Vite 生产构建通过；服务重启后核对前后端版本一致。
- 在 `http://127.0.0.1:8612/`，真实账号 `cccc` 进入普通草原副本，再在入口按 E，成功返回归途营地。实际测试战斗收益正常入账，返回后角色为 4 级、414 金币、背包 8 件。
- 截图：`returned-town.png`。本轮实机验证了 E 返回；点击入口代码已修复，未单独作实机点击验收。

普通副本当前配置时限为 1800 秒（30 分钟）。本轮服务端定向测试能正常失败和超时，没有把「不会失败／超时」判定为已复现的服务端故障，也未缩短正式配置时限。

数据库测试结果位于相邻 `dungeon-lifecycle/database-tests.json` 与 `database-result.json`。本轮为定向验证，不代表重新执行整套历史测试。
