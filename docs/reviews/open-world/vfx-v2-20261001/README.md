## 已验证

- 55个玩家技能的真实World释放与可见表现均通过：[逐技能记录](players-55.json)。记录中的命中事件数包含零伤害事件，不代表技能描述中的所有附加机制已经实现。
- 89项显式表现登记，包含55玩家、11章节怪物、16章节BOSS技能及常规攻击；[coverage.json](coverage.json) 记录每项配置、素材和机制边界。
- 52项针对测试通过，包括69组整改前后战斗轨迹对比、碰撞、挂点、首章战斗、成长兼容、施法关联、延迟地面生效时机、图集帧尺寸与完整性。
- 在本机 RTX 4070 SUPER、1280×720 下，20敌人／30弹体与60敌人／100弹体的P95均低于20ms。具体帧耗时、渲染耗时、对象池及装饰丢弃记录见两份 `performance-*-final.json`；高负载优先减少装饰，攻击主体和危险范围保留。
- 黑暗仪式由真实攻击打断，[实机截图](screenshots/ritual-interrupted.png)与[状态记录](interrupt-state.json)留存。暂停状态两个时刻的游戏画面像素一致：[pause-check.json](pause-check.json)。
- 使用独立临时PostgreSQL、独立localhost会话完成正式登录、营地、野外战斗、护盾、回城与刷新恢复。角色从1级0金币成长至2级96金币，刷新后恢复，控制台无错误：[恢复截图](screenshots/live-restored.png)。临时数据库已正常关闭并清理，未接管正式角色的活动会话。
- 类型、内容检查和正式构建通过，本机8612服务已恢复，健康／内容接口与客户端版本已核对。

## 素材与边界

新增96个不同栅格帧：三个BOSS各24帧施法序列、火球8帧、冰弹8帧、地面火焰8帧。技术打包使用透明间隔分帧、统一源画布、统一脚底和整段最大轮廓缩放，并校验实际帧尺寸，避免裁切及站起后突然放大。BOSS待机、移动等其他动作仍使用既有资源；新施法挂点是逐帧图像上的手工定义，不是伪造的Spine数据。

按约定，本轮不修改伤害、冷却、前摇、费用与成长。箭雨、陨石术当前未产生伤害，火球没有范围爆炸，均单独标记。怪物死亡爆炸也缺少实际执行触发，不能把表现登记视作机制通过。反弹、复活等其他历史机制描述同样不由特效验收证明。

首次发布前后的正式库摘要一致；随后共享开发期间持续新增账号，因此最终全表摘要不再直接等同于初始摘要，未把这种差异宣称为“全部记录逐项不变”。已有奖励回执和流水摘要保持一致。存档相关只读记录保存在 `persistence-*.json`；本轮没有清空正式数据库或更改成长数据。

更早的中间截图归入 `screenshots/drafts/`，不作为最终视觉验收。标杆之外的技能完成了配置与真实播放检查，最终审美判断可在开发验收页逐项查看；配置存在不等同于用户已认可全部视觉细节。
