# A1「直接印字」菜单实施

用户选定 A1，将右下菜单改为紧凑方形奶白按钮。1280×720 下为64×64，名称以12px半粗体轻叠图标下缘，配2px奶白细描边，无模糊阴影和独立标签底条。图标与名称一同响应按下，选中采用浅金底和深金边。右上角红点露出按钮外沿，不被圆角裁切。

1024宽度下使用56×56，窄屏保持44×44点击区域与方形比例。名称仍在按钮内部。颜色、尺寸、描边来自现有公共Token与HUD样式，原菜单动作、图标、快捷键和界面流程沿用。

标准已写入 `项目.md` 与 `AGENTS.md`，示意依据为 `.design/compact-menu-labels-20261003/a1-printed.png`。实际操作由 `open-world/tools/verify-compact-menu-a1.mjs` 核对，结果见 `result.json`。

验证覆盖真实账号登录／营地恢复、六个菜单及人物窗口打开与关闭、文字在按钮内的位置和描边、红点边界、悬停与按下、连续物品选中尺寸稳定、三个视口下菜单和窗口几何、减少动画设置，以及API／content与网页版本同步。类型、内容、Token生成一致性检查、9项相关控件和配色测试及生产构建通过。本机预览在构建后恢复运行。
