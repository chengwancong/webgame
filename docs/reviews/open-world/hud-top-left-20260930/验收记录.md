# 左上 HUD 稳定布局与非战斗自动施法修复

## 问题与修改
原先护盾标签出现时增加一行，消失时 display:none，导致角色状态框和任务区移动；任务内容长度也影响高度。

现在角色区固定 340×106 px，头像固定 88×88 px，两条资源槽固定 236×18 px；名字过长省略并保留完整标题；等级独立；护盾位预留，只改变可见性。任务框固定 302×150 px，说明固定两行；详情在独立浮层展开，基础区域不增高。HUD 节点保留，只更新属性和文本。

此前自动循环对护盾没有威胁条件。现在营地禁止自动施法；野外自动护盾检查敌人的攻击范围与视线、覆盖角色的地面危险，以及尚存且会命中角色的敌方弹道。手动施法仍走原来的费用和冷却校验。野外缺血治疗仍可自动执行。弹道命中半径抽到现有 aiRules 作为唯一参数，被命中检测和威胁预测共同消费。

## 验收
- 21 项模拟测试通过：营地/空野外不自动开盾、手动开盾、近身威胁、残留来袭弹道、背离弹道、地面危险、野外治疗、原有战斗回归。
- TypeScript 通过。
- 真实浏览器及独立数据库：营地无自动护盾或冷却；手动释放后、护盾到期后和打开任务详情时，头像/状态区/资源条/任务框的 x、y、宽、高与基线完全相同。
- 1280×720、1600×900、1920×1080、1024×576 中上述区域尺寸保持相同；使用长角色名验证没有撑开面板。
- 模式切换、手动接管、暂停/继续、自动设置、背包/构筑/目标/设置入口回归通过，页面异常 0。
- 在线 8612 已确认返回新 UI 和模拟核心。
