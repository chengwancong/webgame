## 原因与修复

副本怪物构建 `dungeon-build.ts` 的映射返回值多了一处右括号，导致 API 导入失败。守护进程反复关闭前端、API 与数据库后重试，因此一次 HTTP 200 或 running 状态不能证明稳定可进入。日志中还记录了同批怪物配置更新期间的导入校验错误。

已修复括号并重新构建客户端。当前实际版本见 `versions.json`，本次为 0.8.5 / 协议 12 / ow-16 / 美术 v16 / 存档结构 11。

自动重载增加启动前检查：解析 API 入口语法、导入实际 API 依赖图；无数据库连接或服务启动副作用。验证过程中源码继续变化时等待稳定；发现错误时记录待更新原因并保留当前健康服务，同一错误版本不反复触发重启。
