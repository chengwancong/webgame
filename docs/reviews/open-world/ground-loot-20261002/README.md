# 地面掉落拾取验收

2026-10-02，客户端 0.7.5，资产 world-art-20261002-v9-ground-loot。

地面显示与背包一致的真实装备图标，叠加图标错开放置，名称不遮住相邻图标；长名称悬停展开。点击图标优先于附近敌人，自动走近后收取附近装备；拾取距离使用真实世界坐标，视觉错开不改变判定。用户后续确认去掉地面底框、底色、品质边框和装饰光圈，名称保留品质色。

默认所有战斗模式靠近自动拾取，设置可关闭。背包只装入剩余空位数量，余下道具保留；重复请求、重复 UUID 或跨角色请求均不会重复发奖。

## 实际验证

- [无底框与手绘图标](frameless-handdrawn.png)：后续修订，直接使用正式 GroundLootRenderer 的只读草地验收场景。剑、轻甲、方阵剑、原初剑已绑定昨天的手绘图；弓、护符和两类核心保留旧图，原矩阵没有对应类型。全部八张加载正常。此场景无账号或奖励写接口。
- [最初地上真实图标](icons-final.png)：修订前历史证据，生产 WorldScene、已发布正式图标和独立 PostgreSQL 服务。该图的底框已移除。可控布局掉落只布置在隔离数据库，未修改真实玩家物品。
- [点击拾取](click-pickup.json)：关闭自动拾取，在远处点一次衣甲图标后角色走近，三个不同装备一次进入库存，三个奖励均为已领取。
- [手动模式自动拾取](auto-pickup.json)：打开自动拾取并切换手动模式，点击空地走近后库存从 9 增加为 10，待领取数量减少；未点道具或按交互键。刷新后仍保留已领取装备。
- 临时真实 PostgreSQL 用例：批量命令幂等、重复 ID 去重、只剩一空位的部分领取和剩余保留、跨角色混合请求完整回滚均通过。
- 范围／视线及图标错开测试通过；现有 UI components／skills 检查通过。共 5 项针对性检查与 7 项现有 UI 检查，TypeScript 和生产构建通过。
- health／content／client 实际版本一致。截图页面无控制台错误；主服务保持运行，由系统任务计划托管。

说明见 [地面掉落与拾取](../../../../open-world/docs/ground-loot.md)。旧单件领取接口保留，服务端仍是物品与奖励唯一所有者。
