## 实机路径与数据限制

native-browser-result.json 直接读取临时 PostgreSQL 的实际角色状态：首章已报告，旋风斩已装配，燎原书1本，装备真实强化+1。首场在编写代码时长时间闲置达到30分钟上限；已获得进度与奖励保留。成功重试用正常赚取的等级、初始装备与实际激活技能，未注入测试属性。章末角色4级、强化后金币205；不能把此流程称为零失败的新手耗时或胜率样本。

六章批量数据检查用测试装备缩短战斗以隔离事务正确性，仍走原始服务器移动、施法、命中与交互；另独立测试原生实时守护、重启、检查点与手动首领推进。它证明事件与持久化，不能替代未逐张实机录像的后五章视觉表现。完整回归最终49文件、330检查通过，见 all-tests-result.json。

progression-budget.json 使用实际区域经验与本章一次性里程碑：不计重复刷怪、随机装备或额外任务，也能依次达到章节准入等级；六章预计1→15级。此为可达性算术。

角色、背景、怪物、战斗特效主要复用已有资源；小型调查物件和归途之灯为程序矢量道具。未声称所有APK／300套Spine动效已忠实还原，也未推进尚待确认的整体地图画风草案。

主数据库发布前后保留68账号、68角色、520回执、520流水，无删除、回退或接管正在游玩的角色。所有故事流程、属性测试与原生浏览器角色均在独立临时数据库；正常结束后明确关闭并清理临时数据库。永久开发数据库未清理。
