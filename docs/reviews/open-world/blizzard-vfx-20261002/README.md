# 暴风雪演出修正

用户指出暴风雪预览出现射箭。原预览把冰霜女王错误设为ranged，还让默认普攻混入命名技能；标杆集只播115tick，首轮暴风雪实际在120tick释放，导致根本没有播到降雪阶段。

预览现用正确的shaman类型，只展示选定首领技能，禁用预览中的默认普攻；这项隔离仅影响验收世界，不改变正式游戏首领攻击。标杆长度按真实前摇与持续时间计算，暴风雪完整播到294tick，仍保持连续播放。

正式暴风雪移除ice-air弹体贴图和通用地面冰锥铺设，改为54个错相雪粒从85～170px高度飘落，较大雪片具有六向结构，配合区域阵风、地表冷色与落地消散。落点始终在真实半径内，按落地点深度分层，不追随角色移动。战斗时钟、减少动态、预算和真实命中事件继续生效。

两项专项检查证明预览全程弹体数量为0、完整区域持续阶段与5次真实伤害均出现；雪粒向下移动、落点范围及减少动态冻结正确。另12项既有检查通过，TypeScript与生产构建通过。

客户端0.7.10，protocol8、rules ow-11、db10不变，assets world-art-20261002-v12-blizzard。此前enemy-vfx录屏未完整展示暴风雪，不能作为本技能最终验收依据；本目录after-normal.webm是本次修正的完整正常速度录像。

录像1280×720，10.07秒，浏览器readyState4且无媒体错误。实机持续降雪截图为snowfall.png，实时诊断显示1个暴风雪区域、0个弹体、未暂停。实际health/content/client版本一致，见versions.json。主游戏会话归属页面显示角色正在其他设备游玩，本轮未接管，避免中断正在进行的游戏；release-session-owner.png记录该状态。
