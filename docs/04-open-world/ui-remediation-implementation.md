## 模块 02/03/04/05/08/09：HUD（已实施）

- **布局**：左上生命/灵力/护盾紧凑条（姓名等级同行、头像用稳定预览、精确数值保留、护盾独立覆条+chip、低生命有 tooltip 警示）；其下目标追踪（标题+进度一行，路线操作 前往结界/回城/出发远行，键位教学收进「详情」展开）；右上小地图（敌=圆点、精英=三角、首领=空心菱形、安全点=方块、入口=圆环，形状+颜色双编码，带图例）；下中四技能槽；技能旁模式簇；右下固定四入口（图标+文字+快捷键，待领取并入行囊角标）。
- **区域标题**改为入区一次性横幅（2.8s 淡出，`data-motion-reduced` 时不淡出）；首领条固定上中。常驻钱包移除（金币在奖励反馈与面板中）。
- **技能槽**：真实图标 + 实际绑定快捷键角标 + 统一冷却遮罩（秒数）+ 不可用状态区分（缺灵力蓝框/超射程土框/无目标·生命充足·护盾中文字/倒下·暂停灰化）。悬浮或键盘焦点显示 tooltip：名称、作用、耗蓝、冷却、射程、当前不可用原因。可施放性判断仅复述同一套战斗数值做展示提示，不构成第二套规则。
- **模式簇**：三模式选中态同时有文字+金色描边+底部条；全自动显示 `world.autoState`（接近敌群/战斗/避开危险…）；停止原因就地显示并带对应动作按钮（背包满→整理背包；连接/控制权→恢复连接）；自动设置入口在模式簇内。
- **稳定性**：HUD 骨架 `mountHud()` 一次挂载；180ms 循环只改条宽/文本/类名/冷却数字，不再 `innerHTML` 重建，焦点与 tooltip 不再丢失；小地图画布节点稳定；feed 仅在内容变化时更新。

实测常驻 HUD 面板边界面积（1280×720，元素 boundingRect 求和）≈ 18–19%，未靠缩小文字达成（正文 13–14px，辅助 11–12px）。

## 模块 10/11/12：背包、比较、构筑（已实施）

- 背包：左角色预览+四装备槽（点击筛选部位、已装备金点标记）、中 24 格图标网格（锁定/强化等级/已装备标记、空槽用槽位素材）、右详情。页签「行囊 / 待领取（n）」。
- 比较：攻击/护甲逐项「当前 → 更换后（±差值）」+ 特殊效果「失去/获得」单独成行；服务端预览异步填充，读取中显示占位，失败显示错误并提示以实际操作为准，不用默认值顶替。
- 分解禁用解释原因；换装/强化等待期 `processing` 屏蔽重复提交（沿用原 write() 屏障）。
- 构筑：上排 1–4 装配槽（带顺序号）+ 下 12 技能库卡片（真实图标、机制、耗蓝冷却等级、升级与顺序按钮）；未保存草稿显示金色提示；复选框与 `data-action` 保持 QA 兼容。
