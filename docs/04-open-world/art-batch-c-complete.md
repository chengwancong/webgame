### 1.1 scene.ts纹理系统 ✅

#### 纹理加载（preload）
```typescript
preload(){
  for(const id of Object.keys(catalog.actors))
    this.load.atlas(id,'/art/'+id+'.png','/art/'+id+'.json');
  // Load Warcraft-style environment textures
  this.load.image('grass-tile','/art/environment/grass-tile.png');
  this.load.image('stone-path-tile','/art/environment/stone-path-tile.png');
  this.load.image('tree-sprite','/art/environment/tree-sprite.png');
}
```

#### 地面纹理替换
**之前（几何绘制）**：
```typescript
// 程序绘制菱形，填充纯色
g.fillStyle((isRoad?baseRoad:baseTerrain)-shade*0x020201,1);
g.beginPath();g.moveTo(p.x,p.y);g.lineTo(p.x+32,p.y+18);
g.lineTo(p.x,p.y+36);g.lineTo(p.x-32,p.y+18);g.closePath();g.fillPath();
```

**现在（纹理贴图）**：
```typescript
// 使用魔兽风格纹理
const tile=this.add.image(p.x,p.y,isRoad?'stone-path-tile':'grass-tile')
  .setOrigin(0.5,0.5).setScale(1).setDepth(-10000);
items.push(tile);
```

**改进**：
- ✅ 无菱形棋盘格
- ✅ 丰富纹理细节（草簇、石块）
- ✅ 魔兽风格色彩（浓郁绿#3D7C48、暖赭石#B77C43）
- ✅ 64×64贴图可扩展
