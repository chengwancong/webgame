# 大世界实施状态与验收边界

日期：2026-09-28。对应独立工程 `open-world/`。这是可玩开发版本，完整商业第一版尚未签收。原 Godot/Python 路径没有替换，旧数据没有迁移或删除。

## 现在可以玩什么

从营地注册、建角、出城，在斜视地图中自由移动、点击寻路、清剿敌群。手动、半自动、全自动可切换；移动立即接管。地图地块随位置加载，碰撞、桥、树、入口、据点有实际空间位置。角色与四类敌人外观来自用户资源，播放原动作，保持左右朝向和脚底排序。

四装备部位、十二技能、穿透/传导/燃烧/护盾效果有实际执行。背包比较和强化预览读取服务端。首领须走到结界并主动确认；三场胜利依次开放区域。金币、经验、材料、装备与进度保存到新版 PostgreSQL，退出后重登可恢复。

自动系统能够接敌、避开明确危险、移动到已确认装备附近拾取。普通装备也可在地面附近按 E 拾取；断线遗留装备在战利品面板恢复领取。背包满不销毁正式奖励。没有后台或离线收益。

## 关键工程实现

- `simulation.World` 不依赖图片、DOM、HTTP或数据库，测试与数值模型直接运行它。
- Tiled JSON 是碰撞、出生点、地标与连接的唯一源；不运行旧转换工具写入旧业务表。
- `contracts` 同时校验请求和关键响应；客户端不信任只有TypeScript类型的JSON。
- 服务端按正式装备推导属性与技能参数；正式费用与预览调用同一规则；私有奖励规则只在API，授权保存其快照。
- 数据库锁定角色，奖励来源唯一，资产、流水与回执同一事务；相同操作返回原回执，同ID换内容拒绝。
- 同一登录Cookie的第二标签也必须接管。历史回执可在旧控制失效后读取，新写入仍检查当前控制权。
- 换装/强化/装配先暂停并结尾批；等级在确认边界更新，不混用批次属性。死亡不会因等级确认而复活。
- 网络请求有超时，IndexedDB在提交前保存原命令。回包丢失查询原回执；恢复身份通过请求头，原命令指纹保持不变。
- 至多保留在途报告与后一段报告；超出时暂停，无无限收益积压。
- 30Hz逻辑与显示插值分离；空间索引、统一血条绘制、对象销毁与分块所有权降低压力成本。降低音量/表现不改变规则。
- Electron加载本地Web产物，沙箱/上下文隔离开启、Node集成关闭；本地代理只开放API转发，不提供任意文件/IPC权限。

本地模拟不证明每次移动/命中真实发生。来源、时间和控制权限制只能约束收益。本版没有竞技、交易、共享世界。

## 如何运行和继续维护

双击 `open-world/启动深渊行者.command`；或在该目录 `pnpm dev`，打开 `http://127.0.0.1:8612/`。关闭开发终端会停止服务，保留新版开发成长数据。

`pnpm content` 校验内容；`pnpm test:core`检查纯核心；`pnpm check`完成真实端到端管线。QA使用临时数据库，绝不复用玩家开发数据库。正式构建不带压力测试入口。细节见 `open-world/README.md`。

最终数值、硬件、样本、源码哈希与清理字节以 `docs/reviews/open-world/qa-result.json` 和 `acceptance.md` 为准。本页没有把待验项目标记为通过。
